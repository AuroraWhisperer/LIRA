# Animated Gradient 字体

Montserrat 已加入软件字体库，供所有组件选择，也是内置 `animated-gradient`（渐变气泡）的默认西文与数字字体；中文使用既有系统字体，公共字体参数可覆盖。400／700 与天穹横栏的 Latin 300 分支归入同一个 CDN 字体包，由现有资源任务下载、校验并缓存，不进入安装包；OFL 许可仍随客户端保留。共享字体入口保留 `Gradient Montserrat` 与 `Celestial Montserrat` 族名及原本地 URL。

两个原始 TTF 来自 [Google Fonts Montserrat](https://fonts.google.com/specimen/Montserrat)，使用 SIL Open Font License 1.1，原文见 [OFL.txt](OFL.txt)。取得日期：2026-11-07。公开商店视频用于比对字形、比例和动画，不作为运行资源；该选择不声明已知原作者字体文件。
