# Stargazer Poppins

Poppins 已加入软件字体库，供所有组件选择，也用于客户端 `stargazer` 弹幕的默认西文排版。两个字重归入同一个 CDN 字体包，由现有资源任务下载、校验并缓存，不进入安装包；OFL 许可仍随客户端保留。共享字体入口继续声明 `Stargazer Poppins`，本地 HTTP 保留原 `/fonts/stargazer/` 路径；中文使用既有系统回退，用户仍可通过公共字体参数覆盖。

`poppins-400.ttf`、`poppins-700.ttf` 分别取自 Google Fonts 的 [Poppins Regular](https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Regular.ttf) 与 [Poppins Bold](https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Bold.ttf)，使用 SIL Open Font License 1.1，许可原文见 [OFL.txt](OFL.txt)。参考商店视频及其画面只用于 `tmp/` 内的视觉分析，不作为产品资源交付。
