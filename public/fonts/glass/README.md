# Glass 字体

`quicksand.ttf` 为 Google Fonts 发布的原始 Quicksand 可变字体（300–700），已加入软件字体库供所有组件选择，也用于内置 Glass 弹幕的拉丁字母与数字；中文回退到本机中文字体。字体由现有 CDN 资源任务下载、校验并缓存，不进入安装包；OFL 许可仍随客户端保留。共享字体入口继续声明 `Lira Quicksand` 的 300–700 字重，本地 HTTP 保留原 `/fonts/glass/quicksand.ttf` 路径。

- [上游许可](https://github.com/google/fonts/blob/main/ofl/quicksand/OFL.txt)，原文保存在同目录 `OFL.txt`。
