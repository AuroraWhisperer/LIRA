# 郁香海风与线框星事共用宋体

`sea-breeze-serif.woff2` 已加入软件字体库，供所有组件选择；内置 `sea-breeze`、`sea-breeze-random` 与 `wireframe` 默认使用它显示中文消息、昵称与身份牌。西文优先使用系统 Times New Roman；更换字体后沿用用户选择。

- 来源：[Adobe Source Han Serif 2.003](https://github.com/adobe-fonts/source-han-serif)，[原始 Regular OTF](https://github.com/adobe-fonts/source-han-serif/blob/release/OTF/SimplifiedChinese/SourceHanSerifSC-Regular.otf)。获取日期：2026-11-06。
- 保留完整原字库覆盖，转换为 WOFF2，不按示例文字裁剪。为符合保留字体名称要求，内部名称改为 `Lira Sea Breeze Serif`，保留原版权信息；许可见 [OFL.txt](OFL.txt)。
- 原 OTF SHA-256：`78aa7a328fd974df2d688c8a9fd74a33d8334dfa84ab24d9d11efb2ffc464117`。
- WOFF2：16,710,792 字节；SHA-256：`530a1382941de5c67855e1d0a454040e62c4d83e05e3a47b1fbca634d6195992`。
- 共享字体入口以 `Lira Sea Breeze Serif` 声明，并保留 `Lira Wireframe Serif` 别名；两者复用同一文件，按实际文字需要解码。字体不进入安装包，由现有 CDN 资源任务下载、校验并缓存；本地 HTTP 为桌面预览和直播软件浏览器源提供相同的 `/fonts/sea-breeze/sea-breeze-serif.woff2` 路径。OFL 许可仍随客户端保留。

字形依据原作视频比对选择，不将其宣称为原作者已确认的字体。
