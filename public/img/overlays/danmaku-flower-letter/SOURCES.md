# 花与信笺素材来源

视觉原作：[《花与信笺》— 清兔 Cyan2](https://www.bilibili.com/video/BV1tG411u7JR/)。本目录为用户认可的本地矢量复刻稿，保留原作署名，不表示获得原作者授权或字形、细节完全一致。

纸框、条纹、邮戳、花叶、丝带及心形装饰来自 `tmp/flower-letter-replica/art.js` 和 `assets/ornaments.json` 的独立 SVG 重绘；当前运行时不使用原视频截图或旧版生成图片。上/中/下纸面切片与独立装饰保持原稿坐标，只有中段随正文高度延展。文字、时间、昵称、灯牌、金额、头像及表情由实时消息单独渲染，不在贴图中。

导出脚本为 `tmp/flower-letter-client-integration/export-art.mjs`，源坐标、逐帧研究及旧稿保存在该研究目录，均不随客户端运行时交付。船锚轮廓按本机 Segoe UI Emoji U+2693 描摹，字体文件未复制。大航海身份图标复用项目既有 B 站资源。默认字体为共享字体库的悠哉字体 `Lira Yozai`，许可及原始来源见 `public/fonts/library/README.md`。
