# 沉笺贝母底片

本目录的 `nacre.webp`、`nacre-mint.webp`、`nacre-blue.webp` 为本项目原创生成素材。2026-11-05 使用 LiraHub 绘图工具、`gpt-image-2.5-flare` 模型、high 质量生成透明贝母薄片，原始尺寸 2043 × 770；展示版本缩为 1400 × 528，绿、蓝版本在保留 alpha 和高光的基础上调色。

用户交付原图、完整提示词和元数据保存在仓库 `output/sinking-nacre/` 的 v2 文件中。素材不含研究阶段的艺术家作品，不包含文字；正文、昵称和事件内容由客户端原生 DOM 渲染。

消费者为 `public/css/overlays/danmaku/sinking.css`，随客户端 public 静态资源交付，仅选择该样式时由 CSS 读取，不加入启动资源下载。
