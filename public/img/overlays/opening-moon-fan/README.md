# 月渡花汀原画

此目录供 `opening-moon-fan-art.js` 与配套「月渡花汀」时钟复用。2026-10-05 为本主题生成的原创分层美术，
没有从用户提供的 Bilibili 视频提取或复用画面。参考仅用于蓝白古风配色与美术密度方向。

山水、银蓝折扇、四组花枝、书法标题及白鹤由连接的 LiraHub GPT Image 2.5 工具生成，
经透明边缘清理、裁切和 WebP 压缩；绢带材质由确定性程序生成。
动画在 Canvas 中实时绘制，图片本身不包含动作或音频。

- `landscape.webp`：1920×1080 山水庭院底景，亭台/月亮/倒影保留结构，远山和水纹减弱对比。
- `fan.webp`：1536×1024 透明折扇；扇轴为原图约 `(768,905)`。
- `flowers-*.webp`：四组独立透明花枝。
- `crane-body.webp`、`crane-wing-*.webp`：鸟身及两翼，运行时分别变换。
- `title.webp`：主题书法；自定义标题使用可编辑文本。
- `silk.webp`：512×96 绢带纹理，运行时网格形变。
- `jewel-left.webp`：独立金属/珠贝流苏挂饰。第二版仅保留一组，避免画面拥挤。

原始生成结果、提示词、素材处理脚本与验收输出位于本地
`tmp/opening-moon-fan/`，不进入运行时打包。第二版背景与挂饰的处理在
`prepare-revision-assets.py` 中；本轮生成但未采用的繁密枝蔓/右侧挂饰只留在原画目录。
