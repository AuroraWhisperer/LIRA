# 月渡花汀时钟

`moon-landscape.webp`（632×632）派生自相邻 `opening-moon-fan/landscape.webp`
的原创山水图，经裁切与中心提亮，保证数字和日期的可读性。其他装饰直接复用开播主题的
折扇、白山茶与流苏，不重复保存原画。加工脚本位于 `tmp/clock-moonlit-fan/prepare-assets.py`。

时钟由 HTML/CSS 分层构成，外围透明；文字由现有时钟运行时按设备本地时间更新。
组件缩略图 `../../component-previews/clock-moonlit-fan.webp` 为本样式实际渲染的透明截图。
