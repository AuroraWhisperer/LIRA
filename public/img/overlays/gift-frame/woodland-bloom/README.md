# 林间花信 · 2K 分层动效

`woodland-bloom-v4.webm` 为原生 **2560×1440、30fps、8 秒**透明 VP9 视频。
页面沿用既有资源路径并通过版本查询参数刷新缓存；运行时仍只播放一个视频，头像与感谢文字由独立 DOM 绘制。
DOM 保留 1920×1080 逻辑坐标，视频按视口等比呈现。

四边与铭牌使用 LiraHub 内置图像生成工具、`gpt-image-2.5-flare`、xhigh 质量重新绘制，
完整提示词保存在 `2k-prompts.json`。美术方向为清晰的植物插画：鼠尾草绿与橄榄绿叶片、奶油白玫瑰、
白色波斯菊与茉莉、低饱和古金色卷须。保留真实 Alpha，清理低透明度杂色与异常彩边。

- 上、下素材各为 1536×1024 的两段图集，分别缩小为两段 1312 像素宽的花叶，搭接为 2560 像素宽。
  输出为 `edge-top.webp`（2560×440）与 `edge-bottom.webp`（2560×400）。
- 左、右素材来自 1024×1536 的双列图集，等比缩小到 1440 像素高并裁去透明内侧余量，
  输出为 `edge-left.webp`、`edge-right.webp`（均为 414×1440）。
- 铭牌源图为 2172×724，裁去透明留白后缩小为 `plaque-2k.webp`（1030×153）。

素材只缩小，不放大旧 1080p 成片。静态花叶底层不做网格拉伸或逐帧变形，保留花瓣与叶脉细节。

`botanical-motion-atlas.webp` 是独立生成的八件透明装饰：窄叶枝、茉莉花苞枝、波斯菊花枝、
玫瑰花枝、阔叶枝、茉莉花枝、花瓣与落叶。使用相同工具、模型和 high 质量；提示词保存在
`botanical-motion-prompt.txt`。保留生成 Alpha，清除低透明度杂色，不使用矩形背景或几何轮廓抠图。

四边按相同深度顺序合成：活动枝叶与花茎在后，厚花叶与主花簇居中，独立活动花头在前，最后叠加飘落装饰。
花茎与花头使用相同的锚点及旋转参数，根部藏入主花簇，避免左侧花茎横穿玫瑰、花头被叶片切开。
密度直接体现在重绘素材中：四角、左侧上半部主玫瑰与右侧下半部花簇浓密，上边中段、两侧中段及
铭牌上方疏朗，不再靠局部挤压变形删减花叶。14 组活动枝叶、6 组活动花朵、4 枚飘落装饰错落分布。
枝叶与花朵围绕各自茎根错相摆动，花瓣和落叶沿边缘漂移旋转。
各层在 0–1.2 秒内依次展开，1.2–7.2 秒完整展示，7.2–8 秒退场。
中央原生像素区域 `(414,347)–(2146,1133)` 保持透明，漂移装饰也限定在四边区域。

先生成 2K 无损母版，再以 VP9 CRF 10 导出播放文件，保留透明通道；图集与铭牌只用于离线合成。
铭牌在 0.65–1.1 秒显现，头像和感谢文字同步入场，7.2 秒开始退场。
