# 航海旗帜 · 上舰感谢

三档透明动画取自用户指定的 BLC 大航海贺报公开素材，保留原始字节；不属于 LIRA 原创。

- 参考：https://www.bilibili.com/video/BV1dt42137TX/ （0–10 秒）
- 原插件：直播弹幕姬 BLC，开发者冷焰Flame；素材作者兔宝的神奇口袋。
- 原样式：https://i1.xuehusang.cn/openlivechat-css/fullScreenCele/default_skin.css
- captain.webp ← captain_test_loop_2.webp；admiral.webp ← default_captain_2_loop.webp；governor.webp ← default_captain_1_loop.webp。
- 原始来源、尺寸、时长及 SHA-256 见 provenance.json。
- avatar.png：B 站默认头像 https://static.hdslb.com/images/member/noface.gif 的静态转换；仅在事件缺少头像或头像不可用时显示。
- preview.webp：舰长动画中间帧与示例身份合成的小图，仅用于客户端样式卡片。

本目录素材通过 `node scripts/package-guard-nautical.js` 导出标准 ZIP，不随客户端内置分发。实际头像和昵称来自 LIRA 的上舰事件。ZIP 不包含第三方脚本、登录数据或网页。
