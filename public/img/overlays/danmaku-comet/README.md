卡片宽度按内容在 540–700 逻辑像素之间伸缩，最小高度为 207px。CSS 九宫格只伸展金框与昵称牌底板，四角插画保持原比例：上方花叶与白鹤跟随上沿，下方花簇、灯笼与轻纱跟随下沿。长正文或表情包撑高时，四角自然拉开，不集中在中部，也不纵向拉伸插画。独立昵称牌随姓名长度收缩或扩展，7～8 字昵称可单行完整显示，超长昵称在正文可用宽度内换行、不溢出，横框随昵称牌向下让位；四角装饰绘制在昵称牌上层，长昵称牌不遮盖花叶和白鹤；昵称文字左右各留 76px，避开前景枝叶。小区域由现有飘窗布局整体缩小。普通观众与大航海统一使用金色款，实时昵称和正文/表情使用暖金色与柔和白边，可继续自定义文字、背景透明度及速率。

正文可用宽度为 290–450px，左右内边距分别为 100px 与 150px，各比原先减少 30px，避开两端装饰。默认 30px 字号下，长消息每行约 15 个汉字；30 字排 2 行、40 字排 3 行，普通单行昵称下卡片高度分别为 233.5px 与 275.5px。正文上下留白为 23px，短消息仍保留 207px 最小高度。表情包保持比例、居中展示并撑高金框；昵称牌与正文之间保持独立间距，二者中线与金色底板中线对齐。
