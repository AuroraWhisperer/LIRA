## 应用盲盒配置

项目的 `giftBlindBoxConfig` 使用人民币金额（不是电池数），可直接使用下面的 JSON：

```json
[
  {
    "name": "七夕鹊匣",
    "price": 25,
    "outputs": [
      { "name": "宸星定情", "price": 1200 },
      { "name": "星河相拥", "price": 500 },
      { "name": "云桥缘续", "price": 66 },
      { "name": "鹊语相思", "price": 26 },
      { "name": "锦书传意", "price": 19 },
      { "name": "月下牵丝", "price": 5 }
    ]
  }
]
```

盲盒本体图片位于 `blind-box/`；六种开出礼物按换算后的人民币价值放入对应区间目录，文件名就是礼物 ID。
