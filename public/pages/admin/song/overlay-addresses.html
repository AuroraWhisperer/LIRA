直播场景 在画布中摆放多个组件，保存并应用后导入直播软件。更换组件或样式后沿用同一地址；浏览器源宽高与画布分辨率保持一致。 单独使用组件时，可复制下方对应地址；同一组件已包含在场景中时，无需再添加一份单独浏览器源。文本框通过直播场景输出，没有独立固定地址。

点歌与音乐

点歌板 样式、字号和滚动方式在「点歌板」中配置。
展示板 分类、排序和主题在「展示板」中配置。
直播歌词 用于 OBS / 直播姬浏览器源；字体、颜色和逐字效果在「直播歌词」中配置。

直播互动

弹幕姬 · 本机组件 使用已保存的样式，保持 LIRA 运行。
弹幕姬 · 在线源 在「弹幕姬」中选择样式并应用到直播画面，直播源地址保持不变。关闭 LIRA 后仍可显示。
直播小游戏 数字炸弹、五子棋和你画我猜共用此地址。
抽奖转盘 转盘内容和抽取操作在「小游戏」的转盘区域中配置。
弹幕投票与观众评分 在「组件 → 弹幕投票」或「组件 → 观众评分」中配置并开始活动。

礼物与心愿

滚动礼物 显示内容和样式在「组件 → 礼物姬」的滚动礼物区域中配置。
盲盒盈亏榜 排行数量、赢家筛选和标题在「组件 → 礼物姬 → 盲盒盈亏榜」中调整，修改后自动保存。
礼物许愿 在「礼物姬」→「礼物许愿」中按周期添加目标；统一展示长效、本日和本场直播许愿。
礼物特效与全屏礼物感谢 动画特效在「礼物特效」中配置，全屏礼物感谢在「礼物姬」中配置；两者共用此地址。
月底冲刺 目标与外观在「组件 → 礼物姬 → 月底冲刺」中配置。

场景与氛围

加班机 初始时长、礼物规则和背景在「加班机」中配置。
开播动画 文案、动画和音乐在「开播动画」中配置。
时钟 风格、日期、秒数和小时制在「组件 → 时钟」中配置。
