直播场景 可在画布里自由组合多个组件，保存并应用后把地址加到直播软件即可（浏览器源宽高请与画布分辨率保持一致，后续换样式也不用换地址）。如果组件已经放进场景，就不用再单独添加下方的组件地址；想单独拆分画布里的某个图层，可在画布中选中它并点击「复制组件地址」。

点歌与音乐

点歌板 在「点歌板」标签页中调整样式、字号和滚动方式。
展示板 在「展示板」标签页中调整排序和外观主题。
直播歌词 在「组件 → 音乐展示 → 直播歌词」中设置。
歌曲信息 在「组件 → 音乐展示 → 歌曲信息」中设置，与直播歌词共用音乐来源。

直播互动

弹幕姬 · 本机组件 在「组件 → 弹幕姬」设置本机样式和弹幕过滤，上屏时需保持 LIRA 运行。
直播小游戏 在「百宝箱 → 互动娱乐 → 小游戏」开始数字炸弹、五子棋或你画我猜，三款游戏共用此地址。
抽奖转盘 在「百宝箱 → 互动娱乐 → 小游戏」的「转盘」区域设置选项，再点「开始转动」。
弹幕投票与观众评分 投票和评分共用此地址，在「组件 → 弹幕投票 / 观众评分」中发起。

礼物与心愿

滚动礼物 在「组件 → 礼物姬 → 滚动礼物」中设置。
盲盒盈亏榜 在「组件 → 礼物姬 → 盲盒盈亏榜」中设置。
礼物许愿 在「组件 → 礼物姬 → 礼物许愿」中设置，会汇总展示长效、今日和本场心愿。
礼物特效与全屏礼物感谢 礼物掉落、礼物摇摇乐和全屏感谢在「组件 → 礼物姬 → 全屏礼物感谢」设置。开通或续费大航海的感谢画面在同组的「大航海感谢」设置。这些画面与「百宝箱 → 互动娱乐 → 礼物特效」共用此地址。
月底冲刺 在「组件 → 礼物姬 → 月底冲刺」中设置。

场景与氛围

加班机 在「组件 → 加班机」中设置时长、礼物规则和画面。
开播动画 在「组件 → 开播动画」中设置文案、画面和背景音乐。
时钟 在「组件 → 时钟」中设置样式和时间格式。

网页页面 网页歌单可分享给观众，主播中心需要登录 LIRA 账号。

我的网页歌单 在「歌单导入导出」中开启并同步歌库。
