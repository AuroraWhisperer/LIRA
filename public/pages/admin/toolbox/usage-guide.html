01快速上手

先确认连接状态

页面右上角有连接状态指示灯。前端未连接或弹幕监听未启用时，先点「刷新直播」等状态稳定再操作，否则弹幕和礼物数据不会更新。

四个主页面各司其职

点歌、播放、礼物、百宝箱——日常最常用的是点歌和播放，礼物页盯礼物流水，百宝箱里放辅助工具。不用一次全学会，用到哪个看哪个。

卡住了回到这一页

不确定哪里出问题时，回到使用文档看对应章节的说明，或者翻到最下面的「常见问题」。通常比到处乱点试错更高效。

02账号登录：先连直播间，再登音乐平台

LIRA 里要登录的账号分两层：Bilibili 账号和直播间号是一切互动功能的基础，必须最先配置；音乐平台账号只影响听歌体验，可以之后再补。

第一步：登录 Bilibili，填写本直播间号必做

在「点歌 → 设置」标签页点「扫码登录 Bilibili」，再把自己直播间的房间号填进「Bilibili 直播间号或链接」（直接粘贴直播间网址也可以）。这两步是之后点歌、礼物、弹幕姬等所有互动功能的基础——账号没登录或房间号填错，弹幕和礼物数据进不来，其他功能都无从谈起。

  • 配置完成后点右上角「刷新直播」，让连接用上新账号和新房间号。
  • 以后换账号或换直播间，同样要再点一次「刷新直播」。
第二步：登录音乐平台，解锁完整听歌按需

想要完整的听歌功能，还要登录音乐平台账号，三个平台的登录位置不一样：

  • QQ 音乐、网易云音乐：在 LIRA 里登录——播放页顶部切换到对应平台，点右上角的「登录」按钮按提示操作。
  • 全民 K 歌：在全民 K 歌自己的电脑客户端里登录，不在 LIRA 里操作；LIRA 只读取本机客户端正在播放的歌曲和逐字歌词。

03电脑上已经安装过 LIRA

1. 直接点击“下一步”无需卸载

如果安装程序提示当前用户已经安装过 LIRA，保持“仅为我安装”选中，直接点击“下一步”。

2. 保持原位置并点击“安装”保持默认

安装位置不用修改，直接点击“安装”即可重新安装或升级。

小提示：“下一步”和“安装”按钮在窗口底部的同一位置，保持默认选项连续点击即可。

04主流程：一次完整的开播操作

  1. 登录 Bilibili 账号，确认直播间已连接。 在「点歌 → 设置」标签页扫码登录并填写直播间号。账号没登录或房间号不对，弹幕和礼物数据都无法正常获取；登录后点一下右上角「刷新直播」，让连接用上新账号。
  2. 在「点歌」页管理歌曲库和队列。 导入你的歌曲库后，观众通过弹幕发的点歌会自动排队。你也可以手动加歌、调整顺序、切歌或清空队列。标签页里还有主题美化、展示板设置和直播姬 / OBS 直播画面地址。
  3. 在「播放」页控制音乐播放。 在 QQ 音乐、网易云音乐和全民 K 歌三个音源之间切换：前两个支持推荐歌单、在线搜索和队列管理；全民 K 歌可以直接读取本机客户端的当前歌曲和逐字歌词。底部播放器可以切歌、暂停、调整进度，也可以打开全屏歌词。
  4. 在「礼物」页和「百宝箱」监控互动。 礼物页看送礼流水、盲盒盈亏和月底冲刺进度；百宝箱里，弹幕姬发弹幕、管自动回复和 AI 互动助手，加班机把礼物换算成直播时长，礼物特效投全屏动画，主播计划安排日程，性能检测看电脑资源占用。

05点歌页详解

SC 队列 + 点歌队列核心

页面顶部并排显示醒目留言（SC）和点歌队列。SC 队列显示观众付费发送的醒目留言，点歌队列显示排队中的歌曲。每条歌曲可以置顶（提到下一首）、移除或查看详情。队列人数和歌曲数量在面板标题右侧实时显示。

  • 点歌队列右侧有「切歌」按钮——当前歌曲放完后跳到下一首。
  • 「清空全部队列」会弹出确认窗口，列出受影响的条目数，防止误操作。
  • 观众弹幕发「点歌 歌名」即可自动入队，支持模糊匹配自动补全歌名。
快速入队手动

在 SC 队列下方，折叠面板「快速入队」可以手动添加歌曲到队列。填上歌曲名和歌手（歌手可选），点歌人默认填「主播」，点击发送即可。适合主播自己临时想放某首歌的场景。

歌库管理数据库

歌库是所有可点歌曲的数据库。你可以添加、编辑、删除歌曲，设置歌曲的分类、标签和是否可点。支持按分类和标签多选筛选，快速定位目标歌曲。表格带「语言」列方便核对。

  • 删除歌曲使用确认弹窗而非浏览器原生弹窗，避免误删。
  • 不可点的歌曲（isEnabled = false）不会出现在随机点歌的候选池中。
随机点歌弹幕互动

观众在直播间发送「随机点歌」或「随机点歌 关键词」即可从歌库中随机抽取一首。支持多种筛选方式，用 + 号组合多个条件（AND 逻辑）：

  • 按语言：日语、韩语、英语、粤语、国语
  • 按分类：流行、R&B、说唱、摇滚、民谣、舞曲、影视原声
  • 按歌手：直接输入歌手名
  • 按标签：国风、小甜歌、影视OST、K-Pop 等
  • 组合示例：「随机点歌 日语+流行」「随机点歌 说唱 苦情」
子标签页配置

歌库表格下方有一排子标签页，用于配置各项参数：

  • 设置：Bilibili 账号登录、直播间号、弹幕监听开关、暂停接收点歌、队列上限、用户冷却秒数、是否允许重复点歌、是否只允许歌库歌曲。
  • 点歌板：直播姬 / OBS 投屏队列的视觉主题——颜色、字号、毛玻璃、发光、滚动模式和滚动速度等。
  • 展示板：歌单展示板的滚动速率、歌曲排序方式和主题配色。
  • 直播画面：复制队列、歌单、歌词三个投屏链接（盲盒盈亏榜的链接在礼物页配置）。
  • 导入导出：CSV/XLSX 格式的歌曲批量导入导出。
  • 桌面歌词设置：配置歌词浏览器源的字体、颜色、字号、描边和透明度，并实时预览最终效果。

06播放页详解

三平台音源平台

页面顶部在 QQ 音乐、网易云音乐和全民 K 歌之间切换。QQ 音乐和网易云音乐需要分别登录（右上角按钮），并提供「检查接口」和「清理缓存」排查连接问题；全民 K 歌在全民自己的客户端登录账号，LIRA 内无需登录，直接读取本机客户端的播放状态。

快捷入口发现

为你推荐、每日推荐、心动 / 电台、我喜欢、我的歌单、收藏歌单、最近播放——点击卡片直接浏览对应歌曲列表，找到想放的一键加入队列。「心动 / 电台」会在队列低于阈值时自动补充 10 首，适合长时间直播挂着放。

在线搜索搜索

跟随当前选中的平台搜索歌曲，返回数量可在 1–30 条之间调整。搜索结果一键加入播放队列，点「清除」快速开始下一次搜索。

全民 K 歌歌词现场全民K歌

选择本机全民 K 歌的 WeSingCache 缓存目录后开始检测，页面实时显示客户端正在播放的歌曲、进度和逐字 QRC 歌词。歌词对不上伴奏时，用「歌词时间偏移」滑块（±3 秒）微调校准。适合用全民 K 歌开伴奏直播的场景。

点歌匹配诊断工具

默认折叠的低频工具。输入歌名（可带歌手和时长）测试本地歌库的匹配结果，用来排查“观众点了歌却没匹配上”的问题。

播放器控制栏停靠栏

播放器固定在页面底部，显示封面、歌名歌手（超长自动跑马灯）和可拖拽的进度条。支持上一首 / 下一首、播放暂停、播放模式（顺序 / 随机 / 单曲循环）切换，也可以把当前歌曲加入音乐平台歌单。不用时点顶部按钮折叠收起，再次点击恢复。

全屏歌词歌词

播放页面内有全屏歌词视图。歌词支持逐字高亮进度显示，还有独立的「罗」（罗马音）和「译」（中文翻译）按钮各自开关。切歌时歌词模式自动重置。

桌面歌词浏览器源投屏

在「点歌 → 桌面歌词设置」中调整样式并实时预览，点击「复制桌面歌词」获取浏览器源地址。将地址添加到直播姬的「浏览器」或 OBS 的「浏览器源」后，会按预览样式显示完整歌词时间轴、翻译、罗马音、逐字高亮和播放进度。

  • 浏览器源背景透明，尺寸由直播姬或 OBS 中设置的源宽高决定。
  • 歌词区域可独立滚动；手动查看其他歌词后会暂停跟随，稍后自动回到当前行。

07礼物页详解

礼物检测开关

页面顶部有礼物检测总开关。开启后系统开始接收和记录直播间的礼物事件，关闭后礼物数据停止更新。开关状态实时保存，无需额外确认。

礼物提示通知

独立于礼物检测的通知开关。开启后，每当收到礼物时右下角弹出桌面通知（Toast），显示送礼人、礼物名和金额。可以单独关闭通知而不影响礼物数据的记录。

最近礼物展示

以卡片网格展示最近收到的礼物，最多显示 6 行，窗口缩放时行数自动调整。卡片包含送礼人头像/名字、礼物图标/名称、金额和赠送时间。盲盒卡片有独立的配色标识。点击「查看全部」打开礼物流水抽屉，可翻看更早的历史记录。

月底冲刺目标

设定月度礼物收入目标（金额），页面实时显示已收金额、还差多少、折合多少个水晶球（2333 元/个）。可随时重置本轮计数，礼物流水不受影响。

今日盲盒盈亏统计

按观众汇总展示今日盲盒开盒情况——每位观众的开盒数、盒型种类、总成本和开出价值，净盈亏一目了然。内置盲盒类型使用各自的独立配色。点击某位观众可查看其完整开盒记录，点击「查看全部」进入完整的盲盒分析工作区。

  • 盲盒分析工作区支持按观众/按盲盒类型/按开盒记录三种视图切换。
  • 支持筛选、排序和分页，收到新礼物时自动刷新（500ms 防抖）。
盲盒盈亏榜投屏OBS

给观众看的盲盒盈亏排行榜画面，在礼物页直接配置：自定义投屏标题、排行人数（-1 显示全部、0 仅显示汇总、1–10 显示对应人数）、仅显示盈利、仅显示心动盲盒。复制链接可用于直播姬或 OBS，画面跟随捕捉窗口自动调整布局。

盲盒映射配置

页面底部的「盲盒映射」面板管理每种盲盒的成本，以及可开出的礼物和对应价格——直接填表添加即可，也可以展开「高级」编辑完整 JSON。映射决定了盲盒盈亏的计算口径，新增盲盒类型记得在这里补上。

08百宝箱详解

百宝箱是辅助工具的集合地。点左侧顶部的折叠按钮可以收起侧边栏，只留图标；侧边栏收起后，这份文档会自动变成双栏——目录固定在左边，正文保持适合阅读的宽度。上方有弹幕姬和礼物姬的快捷入口，下方依次是加班机、礼物特效、主播计划、性能、使用文档和桌面更新。

弹幕姬弹幕

使用已登录的 Bilibili 账号向直播间发送弹幕。面板分为三个区域：

  • 连接状态：显示当前发送账号（含昵称）、目标直播间（含房间名）和发送状态（是否可发送）。
  • 自动回复：四个独立开关——「随机点歌回复」在观众点歌条件无匹配时自动 @ 提醒；「签到机器人」回复累计签到天数和随机祝福语；「抽签机器人」按观众和日期回复每日一签；「DIY 关键词回复」按自定义关键词回复固定文案。DIY 规则、签到祝福语和抽签词库都可以在下方折叠面板中添加、删除、修改。
  • 发送弹幕：输入框 + 发送按钮，Ctrl+Enter 快捷发送。字符计数实时显示，超长弹幕自动拆分为多条连续发送。发送结果在底部状态栏实时反馈。
AI 互动助手AI

弹幕姬面板里的智能回复区域。观众弹幕包含触发关键词（默认「小米」）时，助手调用你配置的模型服务生成回复并发送到直播间。

  • 模型服务：供应商预设支持 DeepSeek、OpenAI、Claude、Gemini 或自定义 OpenAI 兼容地址；接口协议可自动识别。API Key 加密保存、不会回显。
  • 回复规则：触发关键词、回复长度偏好、联网搜索和模型推理（支持的服务可调推理强度）。
  • 扩展能力：按需接入和风天气、高德地图，让助手能回答天气、地点和路线问题。
  • 高级设置：并行查询数、单用户冷却、全房间每分钟上限和小猫人格预设。配置完先点「测试模型服务」确认可用。
礼物姬礼物

礼物相关工具的集中展示入口，功能陆续上线中。

加班机倒计时

把观众送的礼物换算成直播加时。为每种礼物设置时间规则（按连击组或按具体数量结算），点「启用加班机」后按「开始」启动倒计时，收到礼物自动加时。

  • 支持手动设置初始时长；「最近结算」保留最近 20 组已完成或忽略的礼物记录。
  • 「直播画面」区域可复制投屏地址、打开实时预览；背景可透明或选内置样式，透明背景适合直接叠加到直播姬或 OBS。
  • 顶部状态灯显示共享收礼核心、礼物统计和加班机的运行情况；「待结算」计数不为 0 说明有礼物正在等待结算。
礼物特效特效

收到指定礼物时在直播画面上播放全屏动画。输入礼物 ID 点「播放特效」即可测试效果；「直播投屏」卡片里的地址固定不变，复制到直播姬的「浏览器」或 OBS 的「浏览器源」后，收到对应礼物会自动播放，平时画面透明不占位置。也可以点「打开预览」直接在浏览器里查看。

主播计划计划

主播自己的日程清单。记下要做的事，选择「今天 / 本周 / 本月」和分类（学歌、开播准备、内容发布、直播复盘），内容只保存在这台电脑。不会写可以点下方的示例模板（学一首歌、开播前检查等）再改成自己的。

性能检测诊断

查看电脑的资源占用情况，帮助判断直播软件是否带得动：

  • 整机监控：CPU、GPU、内存的总体使用率（所有程序合计）。
  • 本软件监控：LIRA自身占用的 CPU、GPU、内存。
  • 支持单次检测（5 秒采样）和持续检测两种模式。底部显示采样窗口、检测时间和当前服务进程 PID。
桌面更新桌面版

仅桌面版可见。检查是否有新版本，支持下载和安装更新。更新卡住时关闭面板重新打开再试通常就能恢复。

09AI 助手：配置 DeepSeek

AI 互动助手需要接入一个模型服务才能工作，推荐 DeepSeek 官方：注册简单、价格低、中文效果好。整个流程分两步——先去 DeepSeek 开放平台拿到 API Key，再回到 LIRA 的弹幕姬面板里粘贴配置，几分钟就能完成。

1. 登录 DeepSeek 开放平台官网

浏览器打开 platform.deepseek.com，用微信扫码或手机号验证码登录。

2. 邮箱绑定可以跳过官网

新账号登录后如果弹出绑定邮箱的提示，点「稍后再说」即可，不影响创建和使用 API Key。

3. 进入 API keys 页面官网

在左侧菜单点击「API keys」，然后点击「创建 API key」按钮。

4. 命名并创建官网

给 Key 起一个能认出来的名字（比如 LIRA），点击「创建」。

5. 复制并妥善保存 Key官网

创建成功后会弹出完整的 API Key，点「复制」。Key 只会完整显示这一次，关掉弹窗后列表里只能看到首尾几位，请务必先复制保存好。

6. 选择「DeepSeek 官方」LIRA

回到 LIRA，打开「百宝箱 → 弹幕姬」，找到「AI 互动助手」区域。模型供应商下拉框选择「DeepSeek 官方」，API 请求地址会自动锁定为官方地址，不用手动填写。

7. 粘贴 API KeyLIRA

把刚复制的 Key 粘贴到「API Key」输入框。内容会自动保存（状态栏会提示「等待自动保存 / 已保存」），也可以点保存按钮立即保存。Key 加密存储，界面上只显示掩码，不会明文回显。

8. 获取并选择模型LIRA

点击「获取模型」，从返回的列表中选择想用的模型，建议 deepseek-v4-flash（速度快、价格低，日常互动完全够用）。其余选项保持默认即可，配置完可以点「测试模型服务」确认可用。

9. 查看用量、余额不足时充值官网

API 调用量、Token 数和消费金额都在 DeepSeek 开放平台的「用量信息」页面查看（数据约有 5 分钟延迟）。余额不足时在「充值」页面扫码充值，支持支付宝和微信，10 元起充。

10直播姬 / OBS 投屏设置

LIRA 提供了多个直播画面链接，添加到直播姬的「浏览器」或 OBS 的「浏览器源」中即可在直播画面上显示：

点歌队列画面

显示排队中的歌曲列表。支持两种视觉风格——经典毛玻璃卡片风和带粉丝勋章的点歌板风。在「点歌板」标签页配置颜色、字号、毛玻璃效果和滚动速度。

歌单展示板

循环滚动展示歌库中的所有歌曲，适合在直播间隔或休息时播放。滚动速度和主题配色在「展示板」标签页独立设置。

歌词画面

显示当前播放歌曲的歌词，支持逐字高亮。适合放在直播画面角落，或作为独立的歌词面板使用。

盲盒盈亏榜

实时展示观众的盲盒开盒盈亏排名。标题、排行人数、仅显示盈利和仅显示心动盲盒都在礼物页的「盲盒盈亏榜」卡片配置。

加班机画面

显示直播加时倒计时。地址在「百宝箱 → 加班机 → 直播画面」复制；背景可透明或选内置样式，透明背景适合直接叠加在直播画面上。

礼物特效画面

全屏礼物动画的固定地址，在「百宝箱 → 礼物特效」复制。加入直播姬或 OBS 后，收到对应礼物会自动播放特效，无内容时画面透明。

11常用设置速查

点歌规则

直播间号、弹幕监听开关、暂停接收点歌、队列上限、用户冷却秒数、是否允许重复点歌、是否只允许歌库歌曲——都在点歌页的「设置」标签页调整。

主题美化

点歌板的颜色主题、背景透明度、毛玻璃模糊程度、发光强度、渐变色——在「点歌板」标签页。支持一键预设和「一键毛玻璃美化」按钮快速出效果。

投屏文字

队列的字号（歌名、标题、点歌人独立调节）、字体、字重、滚动模式（弹跳/连续）和滚动速度——都在「点歌板」标签页。

礼物与盲盒

礼物检测开关、通知开关、冲刺目标在礼物页直接操作。盲盒的成本和开出物配置在礼物页底部的「盲盒映射」面板，盈亏榜投屏在同页的「盲盒盈亏榜」卡片。

签到与回复

签到机器人、抽签机器人、随机点歌回复和 DIY 关键词回复的开关都在百宝箱 → 弹幕姬面板，规则和词库在同一面板的折叠区域编辑；AI 互动助手的触发词、模型和密钥也在弹幕姬面板配置。

歌单展示板

滚动速率（1 最慢、100 最快）、歌曲排序方式、字号以及是否同步点歌板主题——在「展示板」标签页配置。

12常见问题

页面空白或点了按钮没反应

先确认没有停在别的功能页，检查页面是否加载完整。最简单的办法是刷新浏览器后重新进入对应功能区。如果持续出现，检查浏览器控制台是否有红色报错。

弹幕发不出去

确认三件事：① Bilibili 账号已登录（点歌 → 设置标签页可查看）；② 直播间已连接（右上角状态指示灯）；③ 弹幕姬面板的发送状态不是断线或暂停。都正常的话，重连一次直播间通常能恢复。

签到机器人没有自动回复

去百宝箱 → 弹幕姬面板，检查「签到机器人」开关是否打开。开关关闭时观众发「签到」弹幕不会触发回复。也确认一下祝福语列表是否为空。

AI 互动助手不回复

按顺序排查：① 弹幕姬面板里「启用 AI」开关已打开；② 模型供应商、API Key 和模型 ID 已填写，点「测试模型服务」能通过；③ 观众弹幕里包含触发关键词（默认「小米」）；④ 没有触发单用户冷却或全房间每分钟上限。状态区的「等待队列」可以看到排队中的回复数。

随机点歌条件没反应或匹配不到歌

确认歌库中有符合条件的歌曲（可用播放页的「点歌匹配诊断」实测）。如果开了「随机点歌回复」，条件不匹配时弹幕姬会自动发弹幕提醒点歌人。检查百宝箱 → 弹幕姬的「随机点歌回复」开关状态。

礼物列表不更新

确认礼物页的「礼物检测」开关已开启、直播连接正常。如果最近礼物和礼物流水都没有变化，点一下右上角的「刷新直播」即可。不需要手动重启程序。

加班机时间不增加

确认面板顶部已「启用加班机」且倒计时处于开始状态；再检查收到的礼物是否已添加进「礼物时间规则」。顶部状态灯能看到共享收礼核心、礼物统计和加班机是否都在运行，「待结算」计数不为 0 说明礼物已收到、正在等待结算。

直播姬 / OBS 投屏画面不显示或尺寸不对

先确认投屏地址是从「点歌页 → 直播画面」标签页复制的正确链接（以 127.0.0.1 开头）。直播姬或 OBS 中的浏览器源宽度建议至少 400px。窗口第一次缩放后画面会自动适配全宽，所以刚添加时可能偏窄，调整浏览器源边框即可触发自适应。

桌面版更新卡住

仅影响桌面版。确认电脑能正常上网后，重新点击「检查更新」。如果下载中断，关闭百宝箱的更新面板再重新打开即可，通常比一直等着更快。

歌曲导入失败（XLSX 格式）

部分 Excel 版本导出的 XLSX 文件格式可能不兼容。尝试用 Excel 重新保存为标准的 .xlsx 格式，或者改用 CSV 格式导入。确保文件包含「歌曲名字」列。
