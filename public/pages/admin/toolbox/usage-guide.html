使用文档

欢迎使用LIRA！这份文档覆盖了从入门到日常使用的全部内容。建议先通读「快速上手」和「主流程」，再根据自己的需要跳到对应章节。

快速上手

先确认连接状态

页面右上角有连接状态指示灯。前端未连接或弹幕监听未启用时，先点「刷新直播」等状态稳定再操作，否则弹幕和礼物数据不会更新。

四个主页面各司其职

点歌、播放、礼物、百宝箱——日常最常用的是点歌和播放，礼物页盯礼物流水，百宝箱里放辅助工具。不用一次全学会，用到哪个看哪个。

卡住了回到这一页

不确定哪里出问题时，回到使用文档看对应章节的说明，或者翻到最下面的「常见问题」。通常比到处乱点试错更高效。

电脑上已经安装过LIRA

1. 直接点击“下一步”无需卸载

如果安装程序提示当前用户已经安装过LIRA，保持“仅为我安装”选中，直接点击“下一步”。

2. 保持原位置并点击“安装”保持默认

安装位置不用修改，直接点击“安装”即可重新安装或升级。

小提示：“下一步”和“安装”按钮在窗口底部的同一位置，保持默认选项连续点击即可。

主流程：一次完整的开播操作

  1. 登录 Bilibili 账号，确认直播间已连接。 账号没登录或房间号不对，弹幕和礼物数据都无法正常获取。桌面版支持扫码登录，登录后建议点一下「刷新直播」让连接用上新账号。
  2. 在「点歌」页管理歌曲库和队列。 导入你的歌曲库后，观众通过弹幕发的点歌会自动排队。你也可以手动加歌、调整顺序、切歌或清空队列。标签页里还有主题美化、展示板设置和 OBS 直播画面地址。
  3. 在「播放」页控制音乐播放。 查看当前播放的歌曲、队列列表和歌词。播放器面板可以切歌、暂停、调整进度，也可以打开全屏歌词。
  4. 在「礼物」页和「百宝箱」监控互动。 礼物页看送礼流水、盲盒盈亏和月底冲刺进度；百宝箱的弹幕姬用来手动发弹幕和管理自动回复（签到机器人、点歌提醒），性能检测帮你看电脑资源占用。

点歌页详解

SC 队列 + 点歌队列核心

页面顶部并排显示醒目留言（SC）和点歌队列。SC 队列显示观众付费发送的醒目留言，点歌队列显示排队中的歌曲。每条歌曲可以置顶（提到下一首）、移除或查看详情。队列人数和歌曲数量在面板标题右侧实时显示。

  • 点歌队列右侧有「切歌」按钮——当前歌曲放完后跳到下一首。
  • 「清空全部队列」会弹出确认窗口，列出受影响的条目数，防止误操作。
  • 观众弹幕发「点歌 歌名」即可自动入队，支持模糊匹配自动补全歌名。
快速入队手动

在 SC 队列下方，折叠面板「快速入队」可以手动添加歌曲到队列。填上歌曲名和歌手（歌手可选），点歌人默认填「主播」，点击发送即可。适合主播自己临时想放某首歌的场景。

歌库管理数据库

歌库是所有可点歌曲的数据库。你可以添加、编辑、删除歌曲，设置歌曲的分类、标签和是否可点。支持按分类和标签多选筛选，快速定位目标歌曲。表格新增「语言」列方便核对。

  • 删除歌曲使用确认弹窗而非浏览器原生弹窗，避免误删。
  • 不可点的歌曲（isEnabled = false）不会出现在随机点歌的候选池中。
随机点歌弹幕互动

观众在直播间发送「随机点歌」或「随机点歌 关键词」即可从歌库中随机抽取一首。支持多种筛选方式，用 + 号组合多个条件（AND 逻辑）：

  • 按语言：日语、韩语、英语、粤语、国语
  • 按分类：流行、R&B、说唱、摇滚、民谣、舞曲、影视原声
  • 按歌手：直接输入歌手名
  • 按标签：国风、小甜歌、影视OST、K-Pop 等
  • 组合示例：「随机点歌 日语+流行」「随机点歌 说唱 苦情」
子标签页配置

歌库表格下方有一排子标签页，用于配置各项参数：

  • 设置：队列上限、冷却时间、是否允许重复点歌、礼物检测开关等基础参数。
  • 点歌板：OBS 投屏队列的视觉主题——颜色、字号、毛玻璃效果、滚动速度等。
  • 展示板：歌单展示板的滚动速度和独立主题配色。
  • 直播画面：复制各投屏链接（队列、歌单、歌词、盲盒盈亏榜）。
  • 导入导出：CSV/XLSX 格式的歌曲批量导入导出。
  • 桌面歌词设置：配置歌词浏览器源的字体、颜色、字号、描边和透明度，并实时预览最终效果。

播放页详解

播放器控制栏停靠栏

播放器固定在页面底部，左侧显示当前歌曲信息（歌名跑马灯滚动）、右侧为播放控制按钮。支持切歌、播放/暂停、打开队列弹窗。播放器可以折叠——点击折叠按钮后面板收起，再次点击恢复。

搜索与队列播放

搜索框支持从已连接的平台（QQ 音乐 / 网易云音乐）搜索歌曲，找到后一键加入播放队列。队列弹窗显示当前播放列表，支持拖拽排序和移除。播放进度条可以拖拽跳转。

全屏歌词歌词

播放页面内有全屏歌词视图。歌词支持逐字高亮进度显示，还有独立的「罗」（罗马音）和「译」（中文翻译）按钮各自开关。切歌时歌词模式自动重置。

桌面歌词浏览器源OBS

在「点歌 → 桌面歌词」中调整样式并实时预览，点击「复制桌面歌词」获取浏览器源地址。将地址添加到 OBS 浏览器源后，会按预览样式显示完整歌词时间轴、翻译、罗马音、逐字高亮和播放进度。

  • 浏览器源背景透明，尺寸由浏览器或 OBS 的源宽高决定。
  • 歌词区域可独立滚动；手动查看其他歌词后会暂停跟随，稍后自动回到当前行。

礼物页详解

礼物检测开关

页面顶部有礼物检测总开关。开启后系统开始接收和记录直播间的礼物事件，关闭后礼物数据停止更新。开关状态实时保存，无需额外确认。

礼物提示通知

独立于礼物检测的通知开关。开启后，每当收到礼物时右下角弹出桌面通知（Toast），显示送礼人、礼物名和金额。可以单独关闭通知而不影响礼物数据的记录。

最近礼物展示

以卡片网格展示最近收到的礼物，最多显示 6 行，窗口缩放时行数自动调整。卡片包含送礼人头像/名字、礼物图标/名称、金额和赠送时间。盲盒卡片有独立的配色标识。点击「查看全部」打开礼物流水抽屉，可翻看更早的历史记录。

月底冲刺目标

设定月度礼物收入目标（金额），页面实时显示已收金额、还差多少、折合多少个水晶球（2333 元/个）。可随时重置本轮计数，礼物流水不受影响。

今日盲盒盈亏统计

按观众汇总展示今日盲盒开盒情况——每位观众的开盒数、盒型种类、总成本和开出价值，净盈亏一目了然。内置盲盒类型使用各自的独立配色。点击某位观众可查看其完整开盒记录，点击「查看全部」进入完整的盲盒分析工作区。

  • 盲盒分析工作区支持按观众/按盲盒类型/按开盒记录三种视图切换。
  • 支持筛选、排序和分页，收到新礼物时自动刷新（500ms 防抖）。

百宝箱详解

百宝箱是辅助工具的集合地。左侧侧边栏可以折叠（点击顶部的折叠按钮），折叠后只显示图标节省空间。上方有弹幕姬和礼物姬的快捷入口，下方标签页切换不同工具。

弹幕姬弹幕

使用已登录的 Bilibili 账号向直播间发送弹幕。面板分为三个区域：

  • 连接状态：显示当前发送账号（含昵称）、目标直播间（含房间名）和发送状态（是否可发送）。
  • 自动回复：四个独立开关——「随机点歌回复」在观众点歌条件无匹配时自动 @ 提醒；「签到机器人」回复累计签到天数和随机祝福语；「抽签机器人」按观众和日期回复每日一签；「DIY 关键词回复」按自定义关键词回复固定文案。DIY 规则、签到祝福语和抽签词库都可以在下方折叠面板中添加、删除、修改。
  • 发送弹幕：输入框 + 发送按钮，Ctrl+Enter 快捷发送。字符计数实时显示，超长弹幕自动拆分为多条连续发送。发送结果在底部状态栏实时反馈。
礼物姬礼物

礼物相关工具的集中展示入口，功能陆续上线中。

性能检测诊断

查看电脑的资源占用情况，帮助判断直播软件是否带得动：

  • 整机监控：CPU、GPU、内存的总体使用率（所有程序合计）。
  • 本软件监控：LIRA自身占用的 CPU、GPU、内存。
  • 支持单次检测（5 秒采样）和持续检测两种模式。底部显示采样窗口、检测时间和当前服务进程 PID。
桌面更新桌面版

仅桌面版可见。检查是否有新版本，支持下载和安装更新。更新卡住时关闭面板重新打开再试通常就能恢复。

OBS 投屏设置

LIRA提供了多个直播画面链接，添加到 OBS 的「浏览器源」中即可在直播画面上显示：

点歌队列画面

显示排队中的歌曲列表。支持两种视觉风格——经典毛玻璃卡片风和带粉丝勋章的点歌板风。在「点歌板」标签页配置颜色、字号、毛玻璃效果和滚动速度。

歌单展示板

循环滚动展示歌库中的所有歌曲，适合在直播间隔或休息时播放。滚动速度和主题配色在「展示板」标签页独立设置。

歌词画面

显示当前播放歌曲的歌词，支持逐字高亮。适合放在直播画面角落，或作为独立的歌词面板使用。

盲盒盈亏榜

实时展示观众的盲盒开盒盈亏排名。支持按盲盒类型筛选（如仅显示心动盲盒），排行人数可调。在礼物页的盲盒投屏面板中配置。

常用设置速查

点歌规则

队列上限（默认 50 首）、用户冷却时间、是否允许重复点歌、是否只允许歌库内歌曲、是否允许精简格式点歌——这些都在点歌页的「设置」标签页调整。

主题美化

点歌板的颜色主题、背景透明度、毛玻璃模糊程度、发光强度、渐变色——在「点歌板」标签页。支持一键预设和「一键美化」按钮快速出效果。

投屏文字

队列的字号（歌名、标题、点歌人独立调节）、字体、字重、滚动模式（弹跳/连续）和滚动速度——都在「点歌板」标签页。

礼物与盲盒

礼物检测开关、通知开关、冲刺目标在礼物页直接操作。盲盒配置（成本、可开出的礼物及价格）在「设置」标签页管理。

签到与回复

签到机器人、抽签机器人、随机点歌回复和 DIY 关键词回复的开关都在百宝箱 → 弹幕姬面板。DIY 规则、签到祝福语和抽签词库也在同一面板的折叠区域编辑。

歌单展示板

滚动速度（1-100 秒/屏）、排序方式、字号以及是否同步点歌板主题——在「展示板」标签页配置。

常见问题

页面空白或点了按钮没反应

先确认没有停在别的功能页，检查页面是否加载完整。最简单的办法是刷新浏览器后重新进入对应功能区。如果持续出现，检查浏览器控制台是否有红色报错。

弹幕发不出去

确认三件事：① Bilibili 账号已登录（设置页可查看）；② 直播间已连接（右上角状态指示灯）；③ 弹幕姬面板的发送状态不是断线或暂停。都正常的话，重连一次直播间通常能恢复。

签到机器人没有自动回复

去百宝箱 → 弹幕姬面板，检查「签到机器人」开关是否打开。开关关闭时观众发「签到」弹幕不会触发回复。也确认一下祝福语列表是否为空。

随机点歌条件没反应或匹配不到歌

确认歌库中有符合条件的歌曲。如果开了「随机点歌回复」，条件不匹配时弹幕姬会自动发弹幕提醒点歌人。检查百宝箱 → 弹幕姬的「随机点歌回复」开关状态。

礼物列表不更新

确认礼物页的「礼物检测」开关已开启、直播连接正常。如果最近礼物和礼物流水都没有变化，点一下右上角的「刷新直播」即可。不需要手动重启程序。

OBS 投屏画面不显示或尺寸不对

先确认投屏地址是从「点歌页 → 直播画面」标签页复制的正确链接（以 127.0.0.1 开头）。OBS 浏览器源的宽度建议至少 400px。窗口第一次缩放后画面会自动适配全宽，所以刚添加时可能偏窄，拖动 OBS 源边框即可触发自适应。

桌面版更新卡住

仅影响桌面版。确认电脑能正常上网后，重新点击「检查更新」。如果下载中断，关闭百宝箱的更新面板再重新打开即可，通常比一直等着更快。

歌曲导入失败（XLSX 格式）

部分 Excel 版本导出的 XLSX 文件格式可能不兼容。尝试用 Excel 重新保存为标准的 .xlsx 格式，或者改用 CSV 格式导入。确保文件包含「歌曲名字」列。
