5.2 点歌与歌词组件

点歌板显示等待演唱的队列，歌曲展示板展示歌库，直播歌词跟着正在播放的歌曲走。按你需要的画面，找到下面对应的设置入口。

5.2.1 点歌板
  1. 打开「点歌 → 点歌板」，先选风格。共有六种，例如「点歌板风格 1（经典队列展示）」。
  2. 调整歌名、标题和点歌人的字号，再调颜色、背景不透明度、毛玻璃、发光和渐变。可以先从「配色方案」挑一套，再微调；每种风格能调的参数不一样。
  3. 点「保存点歌板主题」应用修改。
  4. 在「点歌板」或「点歌 → 浏览器源」复制地址，加到 OBS 或直播姬的浏览器源，宽高按所选风格的说明设置。

到 OBS 或直播姬确认点歌板已经出现，显示的是当前等待演唱的歌曲和点歌人。这里不会播放歌曲；观众点歌规则和点歌屏蔽词见点歌规则。

文字、滚动和屏幕取色

歌名、标题和点歌人可以设置字号、字体与字重。风格 1、2 在「字体设置」中分别选择自己的字体，可选「共享字体库」和「本机字体」，默认均为微软雅黑；切换风格不会改变另一种风格的字体。队列滚动模式可选「循环滚动（首尾相接）」或「往返滚动（到底后返回）」，滚动速率 1 最慢、100 最快。改好后点「保存点歌板主题」。

直播歌词等页面也可以这样取色：点击颜色框，再点「取色」，就能从电脑整个屏幕选颜色，包括 LIRA 窗口外和其他显示器。取色期间画面暂时静止，移动鼠标查看放大后的像素，单击确认；按 Esc 或右键取消。取色只改变颜色，保留原来的不透明度。

误取色或改色后，点「撤回」恢复上一次操作前的颜色和不透明度；一次连续拖动算一步。撤回只保留本次打开期间的上一步，关闭面板后清空。这里的外观设置不影响网页歌单，网页歌单的背景和外观要到对应设置里修改。

5.2.2 歌曲展示板
  1. 打开「点歌 → 展示板」，设置歌曲排序方式、字号和滚动速率。速率范围为 1–100，数值越大越快，不随展示板高度变化。
  2. 想沿用点歌板的主题，开启「同步点歌板主题」，标题也会同步。展示板外观与画布中同样式的组件共用。
  3. 修改后会自动保存并应用；也可点「保存展示板」手动保存，或在失败后重试。
  4. 在「展示板」或「点歌 → 浏览器源」复制地址，加到 OBS 或直播姬的浏览器源，宽高按面板说明设置。

到直播软件里确认画面在循环展示歌库，而不是等待演唱的点歌队列。这里的排序只影响展示画面，不会改动播放队列的顺序。

5.2.3 直播歌词
  1. 打开设置：进入「点歌 → 直播歌词」，在 LIRA 内置播放器，或同一台 Windows 电脑上的 QQ 音乐、网易云音乐、全民 K 歌里播放一首有歌词的歌。
  2. 确认正在跟随哪首歌：看「当前跟随」和当前曲目是否与你播放的一致。LIRA 会持续检测；只有一个播放器播放时，会自动跟随，不必先在这里选中它。多个播放器同时播放时，可在「歌词跟随」里选择偏好，具体规则见下面的说明。
  3. 调整样式：设置字体、字号、颜色、描边、透明度和逐字效果，直接看页面里的预览。
  4. 放进直播画面：点预览顶部的「复制地址」，加到 OBS 的「浏览器源」或直播姬的「浏览器」。背景透明，显示范围由直播软件里设置的宽高决定。

样式修改会实时预览并自动保存，与画布中同样式的组件共用。恢复默认前会询问，确认后覆盖已保存的歌词设置并应用；全民 K 歌歌词源设置保留。

到 OBS 或直播姬确认歌词能跟着歌曲前进，外观与预览一致。画面可显示歌词、翻译、罗马音和逐字高亮，不显示歌曲总进度条；实际内容取决于当前歌曲和歌词来源。没播放有歌词的歌曲时，画面空白是正常的。

多个播放器、歌词来源与重新检测

「歌词跟随」分为「内置播放器」「外部播放器」「全民 K 歌」三类。选中「外部播放器」后，再选「智能」「QQ 音乐」或「网易云音乐」；切回外部分类会保留本页上次选择。

默认使用「外部播放器 → 智能」：多个播放器同时播放时保持当前跟随，当前播放器停止后自动切换。选定具体播放器后，它与其他播放器同时播放时会被优先跟随。改变跟随偏好不会暂停、播放或关闭任何播放器；偏好只在本次运行中有效，重启后恢复智能模式。「当前跟随」和当前曲目始终显示实际来源。

外部 QQ 只获取 QQ 音乐的歌词，外部网易云只获取网易云音乐的歌词。LIRA 按检测到的曲目从对应平台获取歌词，并跟随播放进度；在线获取需要联网，翻译和歌词版本取决于平台返回内容。无匹配歌词或进度不可读时，不会显示上一首。

选中「外部播放器」后，可查看两个客户端各自的状态，必要时点对应的「重新检测」。网易云优先读取独立的播放状态和进度，切换普通页面或唱片样式不需要重新配置歌词。客户端更新后持续无法读取时，先重新检测；当前版本不兼容时，可临时显示普通页面的进度条，让 LIRA 改从界面读取。

选中「全民 K 歌」后，分类下方会展开首选歌词源和「智能选词」，只在全民 K 歌本地 QRC 不可用时生效。智能选词先匹配歌名、歌手和版本，再比较时长与歌词完整度，仍相同时使用首选源；已知歌手没有匹配版本时，不会借用其他歌手的歌词。这些设置不影响外部 QQ、外部网易云，也不决定跟随哪个播放器。切换到其他分类只收起该设置，不清空已保存的偏好。

歌词来源与缓存检测见全民 K 歌歌词同步。歌词画面时间偏移范围为 ±5000 毫秒，使用全民 K 歌时与其播放页的时间调整叠加。

逐字效果、配色、显示行数与字体

内置与外部网易云都优先使用平台的逐字歌词；歌曲只有普通歌词时，会按每句的时间和字词长度估算，让「连续填充」和「逐字高亮」也能跟随播放。估算可能与实际演唱略有偏差；暂停、拖动和切歌仍以播放器的实际进度为准。

直播歌词会随整首歌词提前载入逐字时间。无论跟随内置播放器、QQ 音乐、网易云音乐还是全民 K 歌，换句后都会按播放进度开始首字高亮，无需调整动画速度或另外设置等待时间。

  • 配色：在「显示策略 → 逐字高亮方式」设置。「未唱颜色」就是原来的文字颜色，保留之前的选择，同时用于普通整句、翻译和罗马音；「已唱颜色」用于当前句的逐字高亮，取消「跟随样式」后可单独选择，重新勾选可恢复样式配色。修改会自动保存并实时预览，两种高亮模式都适用；关闭逐字时整句使用未唱颜色。颜色按钮中的不透明度只调该颜色，「可见性与同步 → 歌词文字不透明度」统一影响两种颜色。
  • 显示行数：在「基础样式 → 显示歌词行数」设置浏览器源与预览显示几行：0 显示整首，1 只显示当前句，2 显示当前句与下一句。歌词区域可以单独滚动；手动翻看其他歌词后会暂停跟随，过一会儿自动回到当前行。
  • 底板和描边：「可见性与同步 → 当前行底板」控制当前句背后的底板与光晕，默认关闭，不影响逐字高亮；旧设置会保留，仍看到底板时可关闭这个开关。文字描边默认关闭，可在「描边与阴影」中开启，已保存的选择保持不变。
  • 换句与动画：正常播放换到下一句时会自动平滑衔接，无需开启「弹性动画」；这个开关只控制额外的弹簧跟随效果。直播繁忙时会自动减少逐字轻跳等装饰效果，保留所选的连续填充或按字点亮方式；系统的减少动态效果设置仍然生效。

字体默认使用「荆南麦圆」。播放器、歌词、弹幕、点歌板、展示板和画布共用「共享字体库」，还包含站酷快乐体、得意黑、小赖字体、猫啃什锦黑、志莽行、马善政和霞鹜文楷。八款完整字体随安装包内置，首次使用无需联网或 VPN，也无需安装到系统；字体更新跟随软件版本。

字体加载成功后自动加入菜单，尚未就绪的已有选择会标记「未就绪」并保留设置。若安装资源异常而触发字体修复，可在「百宝箱 → 桌面更新」查看下载进度，失败可点提示中的「重试」；正常使用不需要下载。「本机字体」单独列出，换直播电脑时需安装对应字体。

支持中、英、日、韩及更多语言的歌词，缺字自动补齐，无需设置备用字体。阿拉伯文等连写文字保留整行排版并跟随播放。
