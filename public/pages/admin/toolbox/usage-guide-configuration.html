5.2 点歌与歌词组件

点歌板显示等待演唱的队列，歌曲展示板展示歌库，直播歌词跟着正在播放的歌曲走。按你需要的画面，找到下面对应的设置入口。

5.2.1 点歌板
  1. 打开「点歌 → 点歌板」，先选风格。共有六种，例如「点歌板风格 1（经典队列展示）」。
  2. 调整歌名、标题和点歌人的字号，再调颜色、背景不透明度、毛玻璃、发光和渐变。可以先从「配色方案」挑一套，再微调；每种风格能调的参数不一样。
  3. 点「保存点歌板主题」应用修改。
  4. 在「点歌板」或「点歌 → 浏览器源」复制地址，加到 OBS 或直播姬的浏览器源，宽高按所选风格的说明设置。

到 OBS 或直播姬确认点歌板已经出现，显示的是当前等待演唱的歌曲和点歌人。这里不会播放歌曲；观众点歌规则和点歌屏蔽词见点歌规则。

文字、滚动和屏幕取色

歌名、标题和点歌人可以设置字号、字体与字重。风格 1、2 在「字体设置」中分别选择自己的字体，可选「软件字体库」和「系统字体库」，默认均为微软雅黑；切换风格不会改变另一种风格的字体。队列滚动模式可选「循环滚动（首尾相接）」或「往返滚动（到底后返回）」，滚动速度 1 最慢、100 最快。改好后点「保存点歌板主题」。

直播歌词等页面也可以这样取色：点击颜色框，再点「取色」，就能从电脑整个屏幕选颜色，包括 LIRA 窗口外和其他显示器。取色期间画面暂时静止，移动鼠标查看放大后的像素，单击确认；按 Esc 或右键取消。取色只改变颜色，保留原来的不透明度。

取错或改错颜色后，点「撤回」恢复上一次操作前的颜色和不透明度；一次连续拖动算一步。撤回只保留本次打开期间的上一步，关闭面板后清空。这里的外观设置不影响网页歌单，网页歌单的背景和外观要到对应设置里修改。

5.2.2 歌曲展示板
  1. 打开「点歌 → 展示板」，设置歌曲排序方式、字号和滚动速度。速率范围为 1–100，数值越大越快，不随展示板高度变化。
  2. 想沿用点歌板的主题，开启「同步点歌板主题」，标题也会同步。展示板外观与画布中同样式的组件共用。
  3. 修改后会自动保存并应用；也可点「保存展示板」手动保存，或在失败后重试。
  4. 在「展示板」或「点歌 → 浏览器源」复制地址，加到 OBS 或直播姬的浏览器源，宽高按面板说明设置。

到直播软件里确认画面在循环展示歌库，而不是等待演唱的点歌队列。这里的排序只影响展示画面，不会改动播放队列的顺序。

5.2.3 直播歌词
  1. 打开设置：进入「组件 → 音乐展示 → 直播歌词」，在 LIRA 内置播放器中，或在同一台 Windows 电脑上的 QQ 音乐、网易云音乐、全民 K 歌中播放一首有歌词的歌。
  2. 确认正在跟随哪首歌：左侧顶部的「音乐跟随」和播放器检测由基础、高级样式共用，下面的页签只切换歌词样式设置。看当前曲目和右侧歌词预览是否与你播放的一致。LIRA 会持续检测；只有一个播放器播放时，会自动跟随，不必先在这里选中它。多个播放器同时播放时，可在「音乐跟随」里选择偏好，具体规则见下面的说明。
  3. 选择编辑界面：「基础样式」保留多行滚动与逐字高亮；「高级样式」按「搭配 / 编排 / 外观 / 动效」分类。「搭配」提供「纸片展开」「轮廓成字」「残影收束」「字块接力」「弧光流转」「星屑聚字」，以及聚焦镜头、翻页诗行等完整编排；「景深长镜」「电影宽银幕」「竖排诗卷」「日系色块」「流向推移」「幻彩夜航」是偏 MV 风格的整套搭配，可直接套用再微调。「随句编排」按句长选择编排，随演唱速度和停顿调整动作，重复歌词保留一致的视觉特征；「镜头组曲」仍按句顺序轮换。短句少分组、快句收敛动作。到「外观」选字体和三色搭配，到「动效」调节节奏与幅度。切换内置搭配保留舞台宽度、缩放、位置和旋转，自存搭配仍完整恢复。「自由组合搭配」和「自由构图」保留四角、竖排、气泡等组合。页签同步切换设置、实时预览和右侧可点击复制的歌词地址。
  4. 跟随当前歌曲调整：右侧预览使用当前检测到并正在跟随的播放器歌词；没有歌曲时显示等待播放。有真实逐字时间时，「长音舒展」让字面随音长持有后归位；开启「字内进度」后，「柔边填色」让高亮沿横排或竖排方向柔和推进。「外观 → 显示内容」中，「隐藏未唱到的字」默认开启：完整编排随唱展开，普通 LRC 或不完整时间按估算节奏整组出现；关闭后展示最终构图。旁边的「字内进度」默认关闭，唱到即整字填色；开启后才在字内连续填色，不影响逐字出现和动作。编排只使用歌词时间，不识别音频重音或情绪；退场只使用尾音后的空隙，连续演唱时直接换句。
  5. 微调与保存：基础字号为 24–72px，窄画面自动换行。高级样式的分类栏会固定在顶部，各小组收起时在标题右侧显示当前值。「外观 → 字体」默认展开，可选择字体、字重、正体或斜体、字号上限和字间距；「换行行距」只调整同一词组换行后的间距，长句仍按构图空间缩放。展开「投影」可调颜色、距离、方向和柔和度，「光效与特效」可调发光范围、浓度和其他字效；「文字材质」中有方向或纹理的材质还会显示对应调节项。降低「演唱填色浓度」可让条纹、粉笔等文字材质继续透出，设为 0 仍保留逐字动作。自由构图还能分别搭配进出场和停留动作。点击排版卡片上的「+ 轮换」可加入或移出轮换，轮换开关和顺序位于「编排与构图」顶部；自由构图的入场也支持轮换。整套外观可在「搭配」顶部命名保存为「我的搭配」，当前正在使用的搭配会高亮。画布沿用相同的四分类高级编辑器，原生外观、轮换和命名搭配与客户端同步；导入歌词样式继续保存自己的外观。
  6. 摆放歌词：在高级预览中拖动歌词位置，松开后自动保存；也可到「编排 → 位置与尺寸」调整数值，点击「水平居中」或「垂直居中」只对齐对应方向。「重置位置」将两个方向都恢复居中，保留配色、动效、宽度和缩放。
  7. 检查预览：基础与高级模式在宽窗口中均为左侧较宽的设置区、右侧较窄的实时预览，右侧自动填满面板可用高度，切换样式保持两栏位置；窄窗口将预览放到参数上方。基础歌词在预览里缩小显示，直播画面仍按设置字号输出。
  8. 放进直播画面：选择「基础样式」或「高级样式」，点击右侧对应的「复制基础歌词地址」或「复制高级歌词地址」，添加到 OBS / 哔哩哔哩直播姬的浏览器源。需要两种歌词时分别复制并添加，即可独立摆放；也可在画布中添加歌词组件，再选择「歌词显示层」。背景透明，显示范围由直播软件里设置的宽高决定。

样式修改会实时预览并自动保存，与画布中同样式的组件共用。基础和高级分别恢复自己的默认外观，恢复前会询问；另一套样式和全民 K 歌歌词源设置保留。画布的「歌词显示层」可选择两层、仅基础或仅高级。

预览默认使用固定中灰纯色底板，也可切换为网格；基础与高级样式使用相同底色，切换搭配或文字颜色不会改变底板明暗，直播输出仍为透明背景。长前奏或唱完后至少 6 秒的间奏，才会在下一句前最后 3 秒显示三个点。限定显示行数时，提示占用已唱完那句的位置，不会额外挤出一行；缺少可靠结束时间的歌词不推测间奏。

到 OBS 或直播姬确认歌词能随歌曲进度更新，外观与预览一致。画面可显示歌词、翻译、罗马音和逐字高亮，不显示歌曲总进度条；实际内容取决于当前歌曲和歌词来源。没播放有歌词的歌曲时，画面空白是正常的。

多个播放器、歌词来源与重新检测

「音乐跟随」分为「内置播放器」「外部播放器」「全民 K 歌」三类。选中「外部播放器」后，再选「智能」「QQ 音乐」或「网易云音乐」；切回外部分类会保留本页上次选择。

默认使用「外部播放器 → 智能」：多个播放器同时播放时保持当前跟随，当前播放器停止后自动切换。选定具体播放器后，它与其他播放器同时播放时会被优先跟随。改变跟随偏好不会暂停、播放或关闭任何播放器；偏好只在本次运行中有效，重启后恢复智能模式。当前曲目和歌词预览来自实际跟随的播放器。

外部 QQ 只获取 QQ 音乐的歌词，外部网易云只获取网易云音乐的歌词。LIRA 按检测到的曲目从对应平台获取歌词，并跟随播放进度；在线获取需要联网，翻译和歌词版本取决于平台返回内容。无匹配歌词或进度不可读时，不会显示上一首。

选中「外部播放器」后，可查看两个客户端各自的状态，必要时点对应的「重新检测」。网易云优先读取独立的播放状态和进度，切换普通页面或唱片样式不需要重新配置歌词。客户端更新后持续无法读取时，先重新检测；当前版本不兼容时，可临时显示普通页面的进度条，让 LIRA 改从界面读取。

选中「全民 K 歌」后，分类下方会展开首选歌词源和「智能匹配歌词」，只在全民 K 歌本地 QRC 不可用时生效。智能匹配歌词先匹配歌名、歌手和版本，再比较时长与歌词完整度，仍相同时使用首选源；已知歌手没有匹配版本时，不会借用其他歌手的歌词。这些设置不影响外部 QQ、外部网易云，也不决定跟随哪个播放器。切换到其他分类只收起该设置，不清空已保存的偏好。

歌词来源与缓存检测见全民 K 歌歌词同步。歌词画面时间偏移范围为 ±5000 毫秒，使用全民 K 歌时与其播放页的时间调整叠加。

逐字效果、配色、显示行数与字体

内置与外部网易云都优先使用平台的逐字歌词；歌曲只有普通歌词时，会按每句的时间和字词长度估算，让「连续填充」和「逐字高亮」也能跟随播放。估算可能与实际演唱略有偏差；暂停、拖动和切歌仍以播放器的实际进度为准。

直播歌词会随整首歌词一起提前载入逐字时间。无论跟随内置播放器、QQ 音乐、网易云音乐还是全民 K 歌，换句后都会按播放进度开始首字高亮，无需调整动画速度或另外设置等待时间。

  • 配色：在「高亮与配色 → 逐字高亮方式」设置。「未唱颜色」就是原来的文字颜色，保留之前的选择，同时用于普通整句、翻译和罗马音；「已唱颜色」用于当前句的逐字高亮，取消「跟随样式」后可单独选择，重新勾选可恢复样式配色。修改会自动保存并实时预览，两种高亮模式都适用；关闭逐字时整句使用未唱颜色。颜色按钮中的不透明度只调该颜色，同组的「歌词文字不透明度」统一影响两种颜色。
  • 显示行数：在「显示内容 → 显示行数」选择整首、当前句、当前句和下一句，或选择「自定义行数」再输入数值；浏览器源与预览同步应用。歌词区域可以单独滚动；手动翻看其他歌词后会暂停跟随，过一会儿自动回到当前行。
  • 译文与罗马音：在基础样式的「显示内容」中，分别开启或关闭「显示翻译歌词」和「显示罗马音」，可只保留一种、同时显示或都不显示。罗马音是用拉丁字母标注的发音。想只看中文译文时，保留翻译并关闭罗马音；实际提供的译文语言和罗马音取决于歌词来源。选择会自动保存，并同步到预览、直播画面和同样式画布组件。两种副行共用字号比例，译文另有不透明度设置。
  • 底板和描边：「高亮与配色 → 当前行底板」控制当前句背后的底板与光晕，默认关闭，不影响逐字高亮；旧设置会保留，仍看到底板时可关闭这个开关。文字描边默认关闭，可在「描边与阴影」中开启。描边、阴影和背景的细项随开关展开，关闭不会清除原来的值；字间距、阴影位置和 3D 倾斜等细调项收在各组的展开入口中。
  • 换句与动画：正常播放换到下一句时会自动平滑衔接，无需开启「弹性动画」；这个开关只控制额外的弹簧跟随效果。直播繁忙时会自动减少逐字轻跳等装饰效果，保留所选的连续填充或按字点亮方式；系统的减少动态效果设置仍然生效。

字体默认使用「荆南麦圆」。播放器、歌词、弹幕、点歌板、展示板和画布共用「软件字体库」，还包含站酷快乐体、得意黑、小赖字体、悠哉字体、猫啃什锦黑、志莽行、马善政、霞鹜文楷、Nunito、Noto Sans、Gowun Dodum 和 Noto Serif Tibetan。共享完整字库和高清地图等公共图片不随安装包分发，首次使用需联网自动补齐，无需安装到系统；以后每次启动检查一次，只下载缺失或更新的字体包和图片。

字体加载成功后自动加入菜单，已选择但尚未就绪的字体会标记「未就绪」并保留设置。下载与礼物准备并行，首次准备页和通知显示进度，也可在「百宝箱 → 设置 → 关于与更新」查看；失败可点提示中的「重试」，已有资源继续使用。没有下载任务时不提示。默认字体或跟随样式的选项位于菜单顶部；样式默认项显示对应字体名称与“（默认）”，切换样式时同步更新；「系统字体库」只列出本机已安装并允许读取的字体，换直播电脑时需安装对应字体。旧系统预设不再重复列出，已有选择继续保留；无法匹配时显示在「当前设置」中。

支持中、英、日、韩及更多语言的歌词，缺字自动补齐，无需设置备用字体。阿拉伯文等连写文字保留整行排版并跟随播放。

5.2.4 歌曲信息
  1. 打开「组件 → 音乐展示 → 歌曲信息」。它与同组的「直播歌词」共用音乐来源；点「调整音乐来源」可查看跟随设置。
  2. 同一页分别设置「唱片」与「歌名 / 歌手」。唱片可选择黑胶、圆形封面或唱片机，调整大小与转速；文字可调整字体、字号、颜色及歌名／歌手显示开关。
  3. 两块预览默认跟随当前歌曲；没有播放时，可在顶部切到「示例歌曲」调试样式。示例只出现在预览里。点「保存外观」应用设置。
  4. 分别点各组件的「在画布中调整」，独立设置位置、宽高和显隐，再保存并应用；也可分别「复制浏览器源」，直接加入 OBS 或哔哩哔哩直播姬，按复制提示设置来源尺寸。旧组合地址和旧画布组件继续可用。

歌曲实际播放时唱片旋转，暂停时停在当前角度。纯音乐或暂时没有匹配歌词仍能显示歌名、歌手；封面取不到时使用默认唱片。是否在暂停或没有歌曲时隐藏、整体不透明度，可在「共同显示规则」设置。
