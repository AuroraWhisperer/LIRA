05.2 点歌与歌词组件

05.2.1 点歌板

在「点歌 → 浏览器源」或「点歌板」复制。点歌板有六种风格，例如「点歌板风格 1（经典队列展示）」；字号、配色和滚动在点歌板页调整，宽高按所选风格说明设置。显示的是等待演唱的点歌队列。

「点歌 → 点歌板」：先选点歌板风格，再调颜色、背景透明度、毛玻璃、发光和渐变。每种风格能调的参数不一样。可以先从「配色方案」挑一套，再微调。网页歌单的背景和外观在别处设置。

「点歌 → 点歌板」：设置歌名、标题和点歌人的字号，以及字体、字重。队列滚动模式可选「循环滚动（首尾相接）」或「往返滚动（到底后返回）」。滚动速率 1 最慢，100 最快。

05.2.2 歌曲展示板

在「浏览器源」或「展示板」复制，循环展示歌库歌曲。到「点歌 → 展示板」设置滚动速率、排序、字号以及是否同步点歌板主题；源尺寸按该面板说明调整。它与点歌队列是两个画面。

「点歌 → 展示板」：滚动速率 1–100、歌曲排序方式、字号和「同步点歌板主题」。这里改的是歌库展示画面，播放队列的顺序不受影响。

05.2.3 直播歌词

在「点歌 → 桌面歌词设置」里调样式，能实时预览。点「复制桌面歌词」拿到浏览器源地址，加到直播姬的「浏览器」或 OBS 的「浏览器源」。画面会按预览的样式显示完整歌词、翻译、罗马音、逐字高亮和播放进度。

  • 浏览器源背景透明，大小由直播姬或 OBS 里设置的宽高决定。
  • 歌词区域可以单独滚动。手动翻看其他歌词后会暂停跟随，过一会儿自动回到当前行。

可调整字体、字号、颜色、描边、透明度和逐字效果；歌词来源与缓存检测见音乐平台与歌词同步。直播歌词时间偏移范围为 ±5000 毫秒。没播放有歌词的歌曲时，画面空白是正常的。
