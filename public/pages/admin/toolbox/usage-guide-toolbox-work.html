粉丝档案

入口是「百宝箱 → 主播工作 → 粉丝档案」。档案、提醒、设置三个标签分别用于维护资料、查看提醒和管理备份；内容保存在当前电脑。

  1. 在「档案」页选择「当前档案」或「已归档」，用「搜索昵称、备注名或 UID」找人；可选全部、在舰、曾上舰、特别关注、待补资料、待核实六种筛选。搜索和筛选只作用于所选范围。
  2. 点击「新建档案」，在基本信息中填写昵称、UID、备注名等，并按需添加标签和特别关注。
  3. 「生日与偏好」可填生日历法、生日、出生年份、提前提醒、星座和 MBTI；「备注与提醒」记录下次想聊什么、个人备注和大航海提醒。完成后保存。
  4. 选中档案查看详情；有需要时到「提醒」页查看生日和其他已设置的提醒。

归档与找回

暂时不需要在日常列表中维护的档案，可以在详情的“更多”中选择“归档档案”。归档不会删除资料与记录，但归档期间不显示该档案的提醒。需要找回时，在档案页切换到“已归档”，搜索并选中档案，点击“恢复到主列表”，再切换到“当前档案”查看。归档与永久删除不同，不需要通过备份恢复。

同步、备份与档案管理

  • 同步与更新：可「同步大航海名单」或「重新加载档案」。要每天核对大航海身份，进入「设置自动更新」，单独勾选「每天自动更新大航海身份」（默认不勾选）。客户端开着时于北京时间 12:10 核对；错过后，当天首次打开软件时补更新。普通「自动更新」选项不等于已开启这项定时核对；这里也不会把私人档案同步到另一台电脑。
  • 导出与备份：「导出档案表格」便于查看；「保存完整备份」用于保留完整资料。需要恢复时选「从备份文件恢复」或「恢复到之前的状态」，先仔细看确认说明。
  • 档案管理：可查看「不再自动建档的粉丝」，以及「清除全部档案」。清除前先保存完整备份。
主播工作台

打开「百宝箱 → 主播工作 → 主播工作台」。日历可点「上个月 / 下个月 / 今天」切换；点「新建日程」填写「日程名称」、日期和时间（也可选「全天」），选择直播、工作或个人分类，按需补充备注后点「保存日程」。

备忘分为随手记、观众约定、复盘；需要落实的事情可作为待办，完成后勾选。留意「已保存到本机」提示，这些内容只在当前电脑保存。

性能检测

打开「百宝箱 → 性能」，点击「开始检测」，等待 5 秒采样窗口完成。页面同时放置六张卡：电脑整体与 LIRA 各自的处理器、显卡、内存占用；这里没有「电脑 / LIRA」切换按钮。

「本机硬件」区可查看型号、核心数、内存条等信息，GPU 温度仅在检测时读取。电脑整体包含其他程序，LIRA 卡只反映本软件；直播卡顿时可以据此分辨占用来源。

桌面更新
  1. 打开「百宝箱 → 桌面更新」，点击「检查更新」。
  2. 有新版本时会开始下载；如果显示「下载更新」，点击后继续下载。
  3. 下载完成后，点击「重启并更新」。

更新失败时，可从「项目主页」下载安装包，按本页「更新或重新安装」操作。需要反馈问题时，可以在「日志目录」找到错误记录。

「自动更新」开关按你的习惯选择。页面还分别提供「数据目录」与「日志目录」的「打开目录」按钮；反馈故障建议从这里打开日志目录，不要把数据目录当作日志目录。
