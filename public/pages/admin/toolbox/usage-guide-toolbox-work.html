粉丝档案

打开「百宝箱 → 主播工作 → 粉丝档案」。上方有三个标签：「档案」记资料，「提醒」看提醒，「设置」管同步和备份。资料保存在这台电脑上。

  1. 在「档案」页选「当前档案」或「已归档」，再用「搜索昵称、备注名或 UID」找人。筛选有六种：全部、在舰、曾上舰、特别关注、待补资料、待核实。搜索和筛选只在你选的范围里生效。
  2. 点「新建档案」。在「基本信息」里填「常用称呼」，B 站 UID、标签、特别关注等可以按需补充。
  3. 「生日与性格」里能填生日历法、生日、出生年份、星座和 MBTI，也能勾选「提前 7 天提醒生日」。「备注与提醒」里记下次想聊什么、个人备注和大航海提醒。填完点「创建档案」。
  4. 选中档案能看详情。生日和其他提醒到「提醒」页看。

归档与找回

暂时不用管的档案可以归档：选中档案，点「更多 → 归档档案」。归档不会删掉资料和记录，但归档期间不显示该档案的提醒。

要找回时，切到「已归档」，搜到这份档案并选中，点「恢复到主列表」，再切回「当前档案」查看。归档与永久删除不同，不需要通过备份恢复。

同步、备份与档案管理

  • 同步与更新：「同步大航海名单」会为当前大航海成员建档。资料没及时显示时，用「重新加载档案」。
  • 每天核对大航海身份：点「设置自动更新」，勾选「每天自动更新大航海身份」（默认不勾选）。LIRA 开着时，每天北京时间 12:10 核对；错过了，当天第一次打开软件时补上。只勾选其他自动更新选项，不会开启这项每天核对。
  • 导出与备份：「导出档案表格」方便查看。要留全部资料，用「保存完整备份」。恢复时用「从备份文件恢复」或「恢复到之前的状态」，先看清确认说明。档案不会自动同步到另一台电脑。
  • 档案管理：「不再自动建档的粉丝」里能看被排除的粉丝。「清除全部档案」会永久删除档案，清除前先保存完整备份。
主播工作台

打开「百宝箱 → 主播工作 → 主播工作台」。左边是日历，右边是备忘录和待办。

  1. 日历用「上个月」「下个月」「今天」切换月份。
  2. 点「新建日程」，填「日程名称」、日期和时间。整天的事可以勾「全天」。
  3. 选直播、工作或个人分类，需要的话写备注，再点「保存日程」。

备忘分随手记、观众约定、复盘三类。要办的事加到待办，做完勾掉。看到「已保存到本机」就是存好了，这些内容只存在这台电脑上。
