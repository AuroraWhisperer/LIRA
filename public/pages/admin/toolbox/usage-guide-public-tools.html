05.7 素材与样式库

05.7.1 图片与视频

在对应组件「＋ 添加样式」点击「选择文件」，程序自动识别样式包、网页、图片或视频，并带上网页的配套资源。收到网址或代码时，展开「粘贴网址或代码」直接粘贴。名称和尺寸通常不用改，配套文件夹可在「更多设置」中选择。普通素材 ZIP 请先解压到独立文件夹，保留作者的目录结构。

预览时拖动虚线框，给弹幕、时间或许愿内容留出位置，填好名称后点「添加样式」。点击新卡片加入画布，再「保存并应用」。支持 PNG、JPEG、GIF、WebP、MP4 和 WebM。

05.7.2 网页与 CSS

弹幕 CSS 自动识别常见 blivechat / BLC 样式；需要原工具后端或专用网页的样式，使用作者的配套 HTML 或展示地址。缺少配套文件时会提示具体路径。全屏礼物感谢图片/视频沿用 LIRA 的触发设置；成片已带固定文字时可关闭「显示感谢文字」。

网页、CSS 或网址也从对应组件「＋ 添加样式」导入，保留作者配套文件的目录结构。想嵌入正在运行的外部浏览器源，见外部网页源。

05.7.3 样式包与套装
  1. 在「点歌 → 浏览器源 → 直播场景」点「编辑场景」，进入「添加组件 → 套装」后点「导入套装」，直接选择作者提供的 ZIP，无需解压或手动放文件夹。
  2. 核对套装名称、版本和成员清单，再点「导入套装」。导入只增加可选样式，当前直播画面保持原样。

当前月渡花汀套装包含静态背景、动态背景、开播动画、时钟、弹幕姬、礼物许愿、点歌板和桌面歌词共 8 款样式，背景可二选一，其他成员也可单独使用。具体版本及其他套装的种类和数量以导入清单为准。

月渡花汀需先导入才会出现在样式库。若没有导入入口，或提示需要更新客户端，请安装支持该套装的更新版本。

ZIP 必须从对应入口导入：背景样式包在「背景 → 添加样式」，跨组件套装在「套装 → 导入套装」。选错入口会拒绝添加并提示正确路径，点击「前往…导入」可带着刚选的文件继续操作。

导入后按添加组件与选用样式选用成员、摆放并应用。

单组件样式包从该组件「＋ 添加样式 → 选择文件」导入。例如全屏礼物感谢使用「林间花信-全屏礼物感谢样式-1.0.0.zip」，无需解压；导入不改变原启用状态和触发金额。

05.7.4 更新版本

点「更新套装」选择作者提供的新版 ZIP，核对替换版本后确认；安装成功后样式库只显示新版本，失败则保留旧版。已有场景保留原效果，需要升级的图层请更换样式后保存应用。误删后重新导入原 ZIP 可恢复整套，重复导入不会产生副本。

若提示相同版本内容冲突，请作者提高版本号后重新打包。

05.7.5 移除与重新导入

每套显示名称、版本和组件数量。点标题旁「删除套装」并确认，可整套移出样式库；内部卡片只负责选用。独立添加的样式仍可用右上角 × 删除。已有场景继续可用，不会立即清理磁盘文件；要从直播画面移除组件，请在画布删除图层，再「保存并应用」。

05.7.6 清理未使用文件

从「组件」左侧导航底部或画布编辑器顶部打开「素材管理」，可查看类型、名称、版本和占用空间，单组件多变体包也能整包更新、移除。清理未使用文件前会再次检查场景引用；其他预设有未保存草稿时请先保存或放弃修改。

换机前的完整备份与恢复见素材和场景备份与恢复。
