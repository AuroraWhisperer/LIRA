13礼物图鉴与网页小游戏

这两个网站直接用浏览器打开，不用登录 LIRA 账号。想查礼物资料就看图鉴，想试试模拟玩法就进网页小游戏。

礼物图鉴与概率资料

查礼物编号、图片与特效
  1. 打开 礼物图鉴（礼物特效档案），输入礼物名称或编号，点搜索。
  2. 按需要选付费或「免费 / 银瓜子」，再筛背包、非背包礼物。只想找有特效的，就勾「只看有特效」。
  3. 点开礼物，能看编号、图片、价格，有特效的还能预览。想在客户端设这个礼物的触发特效，就复制它的编号，再回客户端填。

有图片不一定有特效，能看什么以礼物详情为准。想设直播时的特效，打开客户端「百宝箱 → 礼物特效」。

看盲盒概率和礼物期望

有概率资料的盲盒，详情里能看到奖励和概率。有多个档位或历史版本时，先选你想看的那一档，再看数字。不是每个礼物都有概率资料。

「礼物期望」按所选档位的礼物标价和概率算：每种礼物的价值乘以概率，再加起来，就是期望价值；再除以盒价，就是回报率。遇到五盒组合奖励，先看页面里的计算说明，分清整组和折合每盒的数值。

这些数字算的是理论平均值，不保证你这一次或这几次能抽到什么，也不是现金收益。历史档位留着供你查，别当成当前活动的概率。

网页小游戏与本地记录

打开网页小游戏

打开 LIRA 网页小游戏，选一款：「成名之路」「玲珑宝斋」「星座回响」「盲盒模拟器」「唤灵契约」或「秘宝合成」。进去后先看规则，再按提示开始。

盲盒模拟器先选盒子和倍率，再开盒。其他游戏按各自的规则点亮、开容器、召唤、翻牌或合成，到结算时再看结果。页面里的电池、收支和礼物都是模拟的，不花真实电池，也不会收到真实礼物。这些游戏不连接直播间。

想让直播间观众发弹幕一起玩，要用客户端「百宝箱 → 小游戏」里的互动功能，和这里的网页游戏分开。

看背包、查记录和清除数据

游戏进度存在你现在用的浏览器里，不跟着 LIRA 账号同步。换浏览器、换电脑或清除网站数据后，原来的记录不会自动找回来。

  • 「成名之路」「玲珑宝斋」「星座回响」「唤灵契约」都有「背包」和「玩法记录」。记录只留最近 50 局结算结果，不会每操作一步就记一局。点清除会直接清空这一局、礼物、消耗和历史，没有二次确认，点之前先确认这些都不要了。
  • 「盲盒模拟器」能看近 7 天的开盒记录。点「清空记录」会删掉这些记录；再勾上「同时清空累计统计、礼物数量与五盒进度（保留电池）」，这几项也会一起清空，模拟电池余额还在。
  • 游戏里的清除按钮和浏览器的「清除网站数据」管的范围不一样。清除网站数据，还会删掉这个网站存在浏览器里的其他内容。
