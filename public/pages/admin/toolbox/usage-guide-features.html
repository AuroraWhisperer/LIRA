05点歌页详解

SC 队列 + 点歌队列

「点歌」页顶部是醒目留言（SC）和点歌队列。SC 是观众付费发送的留言；观众发送「点歌 歌名」即可点歌，歌名不完整时也会尝试匹配歌库。

  • 置顶 / 取消置顶：调整点歌顺序；条目旁另有「复制歌名」和「删除」。
  • 切歌：把点歌队列第一首标为完成。要切换正在播放的音乐，请使用播放页的播放器。
  • 清空全部队列：只移除点歌队列，不会删除歌库。
  • 队列满了：新的点歌不会继续加入；先唱完或删除部分歌曲，也可在「设置」调整最多排队歌曲数。

点歌队列记录观众想听什么，播放队列决定播放器接下来放什么。去「播放 → 播放队列 → 导入点歌」，才能将点歌列表导入播放器。

出现「收到点歌请求」通知时，先核对歌名、匹配信息和点歌人，再选「下一首播放」或「跳过」。这张通知用于决定是否加入播放器。

歌库管理

打开「点歌 → 歌库」。顶部表单用于新增歌曲；填好歌曲名字、原唱/首发歌手后，按需要填写分类、语言、标签、点歌价格与歌切等信息，再保存。

  • 查找：可搜索歌名、歌手、分类或标签，配合分类、语言、歌手、标签和「只看可点」筛选。
  • 修改与删除：在歌曲行使用相应操作。设为「不可点」的歌曲不会公开，也不会被随机点歌选中。
  • 批量修改：可到「导入导出」用表格的「更新匹配歌曲（先预览）」批量更新，确认差异后再应用。
  • 同步：联网后歌库修改会同步到同一账号的其他电脑和网页歌单；删除也会同步。点歌队列和播放队列不会同步。
查看歌库列表与筛选入口
随机点歌

观众发送「随机点歌」可随机抽一首歌，也可以加上语言、分类、歌手或标签。多个条件用 + 连接，歌曲需要同时满足这些条件：

  • 按语言：日语、韩语、英语、粤语、国语
  • 按分类：流行、R&B、说唱、摇滚、民谣、舞曲、影视原声
  • 按歌手：直接输入歌手名
  • 按标签：国风、小甜歌、影视OST、K-Pop 等
  • 组合示例：「随机点歌 日语+流行」「随机点歌 说唱 苦情」
点歌页还有哪些功能

点击点歌页中的对应标签即可打开：

  • 设置：直播账号登录、直播间号、接收弹幕和礼物下拉框、暂停接收点歌、队列上限、同一观众点歌间隔（秒）、是否允许重复点歌、是否只允许歌库歌曲。
  • 点歌板：直播姬 / OBS 投屏队列的视觉主题——颜色、字号、毛玻璃、发光、滚动模式和滚动速度等。
  • 展示板：歌单展示板的滚动速率、歌曲排序方式和主题配色。
  • 浏览器源：集中复制 11 个常用 OBS / 直播姬浏览器源地址，并按点歌与音乐、直播互动、场景与氛围分类；需要参数的功能仍在对应页面生成详细设置。
  • 导入导出：导入 XLSX、CSV、TSV 或粘贴表格，也可下载导入模板、导出歌库 Excel。
  • 桌面歌词设置：设置歌词浏览器源的字体、颜色、字号、描边和透明度，并实时预览最终效果。

「浏览器源」页列出常用的 11 个地址，其他地址在对应功能面板复制。服务器弹幕姬链接需要 LIRA 授权及服务器配置读取成功；直播消息接收还需配置直播账号。

设置点歌规则

打开「点歌 → 设置」，修改后点击「保存设置」并等待成功提示。直播账号和直播间的首次连接操作见「账号与设备」。

  • 接收弹幕和礼物：这是下拉框，选「暂不启用」或「启用」。
  • 暂停接收点歌：选择「接收点歌」或「暂停点歌」，与停止接收全部直播消息不同。
  • 最多排队歌曲数：默认 50，可填 1–300。
  • 同一观众点歌间隔（秒）：默认 0，可填 0–3600；0 表示不设间隔。
  • 只允许点歌库歌曲 / 允许重复点歌：按直播规则选择对应选项。
导入和导出歌库表格
  1. 打开「点歌 → 导入导出」，点击「下载导入模板」。按模板列名填表：歌曲名字、原唱/首发歌手、歌曲分类、歌曲标签、是否可点、语言、点歌价格、歌切、核对平台、核对备注。
  2. 选择 XLSX、CSV 或 TSV 文件，或从 Excel 复制表格后粘贴到输入框。多个歌手、分类、语言和平台用「/」分隔，多个标签用逗号分隔。
  3. 日常补歌选「仅新增，跳过已有歌曲」，点击「导入歌库」。同名同歌手的已有歌曲会跳过，不会更新价格。
  4. 需要批量修改时，选「更新匹配歌曲（先预览）」并点击「预览更新」，核对新增、更新和冲突后再点「确认更新歌库」。未提供的列不修改；不要随意勾选「用表格中的空白内容清除原有信息」。
  5. 查看结果提示中的新增、更新、重复跳过或错误计数。重复跳过不等于导入失败；有错误时先检查对应行和表头。
  6. 需要备份表格时，点「导出歌库 Excel」。导出的表格按歌曲逐行列出，可用于检查和再次导入。

歌名和歌手都相同才会更新原歌曲；改名或换歌手会当作新歌。点歌价格可填免费、30元SC、舰长等说明，不要把说明当成自动收款规则。

云端歌单同步

登录 LIRA 并联网后，歌库会自动同步到同一账号的其他电脑。给观众的网页歌单入口和手动同步步骤见「网页歌单同步」。

先核对再覆盖：「同步到网页」会用这台电脑的歌库替换云端歌库；同账号其他电脑也会更新，不会自动合并。

歌单页背景

「点歌 → 导入导出 → 歌单背景」可上传公开歌单的背景图；单张不超过 5 MB。点击「恢复默认背景」恢复默认水彩背景。完整操作见「网页歌单名称与背景」。

06播放页详解

三平台音源

打开「播放」，在顶部选 QQ 音乐、网易云音乐或全民 K 歌。QQ 音乐和网易云音乐需分别使用自己的平台账号登录；LIRA 登录和 B 站登录不能替代音乐平台登录。连接有问题时点击「检查音乐平台连接」。

全民 K 歌需先打开它自己的电脑版并登录，再让 LIRA 读取当前歌曲和歌词。音乐平台的「我喜欢 / 收藏歌单」跟随相应平台账号，本机最近播放记录则留在当前电脑。

快捷入口

点击「为你推荐」「每日推荐」「我喜欢」「收藏歌单」或「最近播放」，右侧会滑出「浏览内容」抽屉。选单曲播放，或用「播放全部 / 随机播放」播放列表；「返回」回上一层，「关闭」收起抽屉。

推荐等支持刷新的内容可点「换一批」；最近播放没有这个按钮。「心动 / 电台」会在快放完时自动添加 10 首。

在线搜索

跟随当前选中的平台搜索歌曲，返回数量可在 1–30 条之间调整。搜索结果一键加入播放队列，点「清除」快速开始下一次搜索。

结果数量默认 9 条。搜索前先确认当前平台；清除搜索结果不会清空播放队列。

同步全民 K 歌歌词
  1. 打开全民 K 歌电脑版，登录并播放伴奏。
  2. 在 LIRA 的「播放 → 全民 K 歌」中，选择全民 K 歌使用的 WeSingCache 文件夹，点击「保存并检测」。
  3. 歌词和伴奏对不上时，用「歌词时间调整」向前或向后微调，范围为 ±3000 毫秒（±3 秒），每次微调 50 毫秒。
播放器控制栏

播放器固定在页面底部，显示封面、歌名歌手（超长自动跑马灯）和可拖拽的进度条。支持上一首 / 下一首、播放暂停、播放模式（顺序 / 随机 / 单曲循环）切换，也可以把当前歌曲加入音乐平台歌单。不用时点顶部按钮折叠收起，再次点击恢复。

音量默认 30%，音质默认「标准」，按需要调整。点击歌曲封面可打开全屏播放视图，查看大幅歌词并继续控制播放。

播放队列
  1. 先导入点歌：在底部播放器右侧打开「播放队列」，点击「导入点歌」，每次读取点歌队列的前 30 条并尝试加入播放队列；请留意匹配结果或待确认提示。队列超过 30 首时，不要以为已一次全部导入。
  2. 安排下一首：从搜索或内容列表点「入队」加到队尾，点「插队」放到当前歌曲之后。队列中的待确认点歌可选「确认」或「忽略」。
  3. 开始播放：选择队列里的歌曲，使用播放器上一首、下一首、暂停等按钮。
  4. 清空：点击「清空」或「清空队列」会停止播放并移除待播歌曲，不删除歌库或音乐平台收藏。

播放器右侧的「播放队列」会打开右侧弹窗（也常叫队列抽屉），用于整理待播歌曲。「浏览内容」抽屉从推荐、歌单或最近播放卡片打开；点击播放器封面则进入全屏歌词视图。三个入口用途不同，播放队列仍由底部的队列按钮打开。

点歌匹配诊断

如果点歌匹配不符合预期，在「播放」页展开「点歌匹配诊断」，填入歌名、歌手和时长（单位毫秒，3 分钟填 180000），点击「测试匹配」，查看候选与诊断信息。

「未找到候选」不等于你的歌库没有这首歌；先检查当前音乐平台连接和输入信息。

全屏歌词

播放页面内有全屏歌词视图。歌词支持逐字高亮进度显示，还有独立的「罗」（罗马音）和「译」（中文翻译）按钮各自开关。切歌时歌词模式自动重置。

桌面歌词浏览器源

在「点歌 → 桌面歌词设置」中调整样式并实时预览，点击「复制桌面歌词」获取浏览器源地址。将地址添加到直播姬的「浏览器」或 OBS 的「浏览器源」后，会按预览样式显示完整歌词、翻译、罗马音、逐字高亮和播放进度。

  • 浏览器源背景透明，尺寸由直播姬或 OBS 中设置的源宽高决定。
  • 歌词区域可独立滚动；手动查看其他歌词后会暂停跟随，稍后自动回到当前行。

07礼物页详解

礼物统计

「礼物统计」控制这台电脑是否统计礼物。「礼物提示」只控制是否弹出通知，它们与加班机分别设置。

注意：关闭礼物统计，不会关闭加班机，也不会停止云端接收。要停止接收，请到「点歌 → 设置」关闭「接收弹幕和礼物」或退出直播账号，等待保存成功。

礼物提示

开启后，收到礼物会在 LIRA 右上角显示送礼人、礼物和金额。只关闭提示，不影响礼物记录。

自动答谢礼物与弹幕查询

在「礼物」页分别开启「自动答谢礼物」和「弹幕查询礼物统计」。先在「点歌 → 设置」完成直播账号登录并保存接收设置，确认账号已同步、服务器与直播间连接正常。

  • 自动答谢：答谢付费礼物和已确认的免费礼物，不含醒目留言（SC）。消息由系统固定生成，例如「@观众A 感谢投喂小花花×1」；付费礼物还会按实际记录带出金额，开通大航海使用「感谢开通」。没有需要填写的答谢模板。
  • 观众查询：观众发送「今日礼物」「本月礼物」「累计礼物」等支持的查询弹幕，可收到自己已记录的付费礼物数量与金额；涉及盲盒时还会显示可确认的差额。回复示意为「@观众A 今天…×数量；共…电池」，以实际记录为准。
  • 关闭查询：停止回应这类查询，不会删除礼物历史，也不会代替礼物统计开关。

这两项「由服务器持续运行，退出软件后仍有效。」关闭窗口不会关闭它们；要停用，请关闭对应功能并确认设置保存成功。

最近礼物

查看最近收到的礼物、送礼人、金额和时间。点「查看全部」打开全部礼物记录。

可按用户名称、礼物名称、「金额大于（元）」、开始日期和结束日期筛选，再点「查询」；「今天」快速选当天，「重置」清除筛选。「金额大于」按单条记录总金额判断，不包含等于门槛的记录。

把礼物记录导出为 PNG 图片
  1. 打开「礼物 → 最近礼物 → 查看全部」，先筛选要展示的记录。
  2. 勾选记录，也可以拖动框选、按住 Ctrl 拖动追加，或点「选择全部筛选结果」。核对「已选」条数后点「导出所选」。
  3. 在导出页选择输出方式：「拼成一张」适合整张答谢图，「每条一张」适合分别使用。
  4. 选择透明或白色图片背景，并选择保存文件夹。查看预览；选错了可「返回选择」重选记录。
  5. 点击「导出 PNG」，等界面提示完成后，再点「打开文件夹」检查保存的图片。

礼物历史同步与清理

礼物记录会自动更新。显示「正在更新礼物记录…」时请稍等；断网时可以查看已保存的记录，联网后会继续更新。

如果提示「当前仅能查看部分历史记录」，说明记录还不完整。加载失败时点击「重新加载」或「重试」。

无法恢复：「清空全部记录」会永久删除这个账号在本机和云端的全部礼物记录，其他设备同步后也会清空。无法恢复，请确认后再操作。

月底冲刺

设定月度礼物收入目标（金额），页面实时显示已收金额、还差多少、折合多少个水晶球（100 元/个）。可随时重置本轮计数，礼物记录不受影响。

今日盲盒盈亏

按观众汇总展示今日盲盒开盒情况——每位观众的开盒数、盒型种类、总成本和开出价值，净盈亏一目了然。内置盲盒类型使用各自的独立配色。点击某位观众可查看其完整开盒记录，点击「查看全部」进入完整的盲盒分析工作区。

  • 盲盒分析工作区支持按观众/按盲盒类型/按开盒记录三种视图切换。
  • 支持筛选、排序和分页，收到新礼物时自动刷新。成本未知的盲盒不能按零成本估算盈利。
查看按盲盒与逐条开盒记录
盲盒盈亏榜投屏

给观众看的盲盒盈亏排行榜画面，在礼物页直接配置：自定义投屏标题、排行人数（-1 显示全部，0 仅显示汇总，1 至 10 显示对应人数）、仅显示盈利、仅显示心动盲盒。复制链接可用于直播姬或 OBS，画面跟随捕捉窗口自动调整布局。

默认标题为「今日盲盒盈亏」、排行人数为 3，「仅显示盈利」默认勾选。修改筛选后复制对应链接；不要把没有符合条件的记录误当成加载失败。

盲盒设置

常见盲盒的成本和可能开出的礼物会自动获取，不用逐个填写。需要补充时，到「盲盒设置」添加自定义盲盒、成本和可能开出的礼物。

这些设置会同步到同一账号。修改只影响之后的记录，不会重新计算旧记录。
