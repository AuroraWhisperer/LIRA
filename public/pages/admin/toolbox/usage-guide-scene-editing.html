5.1 画布与场景

点击颜色控件可调整 RGB、HEX 和「不透明度」（A）：0% 全透明，100% 完全不透明，棋盘格用于预览透明区域。已有背景、阴影等不透明度沿用当前保存值；其他颜色默认 100%。对应的独立不透明度控制会合并到选色面板，「整体不透明度」仍控制整个组件。调整后按所在页面原有的保存或应用步骤生效。

5.1.1 添加组件与选用样式

在「组件」左侧点击「打开画布」，或在「浏览器源 → 直播场景」点击「编辑场景」打开场景编辑器。顶部添加组件，下方选择图层，右侧展开调参；收起参数可放大画布。画布分辨率统一设置，保存后恢复已有布局。

右侧「位置与尺寸」和各参数分组都可展开或收起。歌词沿用客户端的「基础样式」「显示策略」「描边与阴影」等分组，其他组件按内容、外观等用途分组；数值可拖滑块或直接输入，颜色和开关的用法与客户端相同。普通歌词新建为 960 × 360 像素，已有图层和导入样式保留原尺寸。

各组件的「打开画布」「在画布中预览」「预览与调整」或「在画布中调整」共用当前编辑会话；已有对应图层时会直接选中，没有时会加入一个未保存图层，点「保存并应用」才会发布布局。导入 OBS 或直播姬时，用画布里的「复制场景地址」，不要复制浏览器地址栏，并按复制提示填写浏览器源宽高；以后修改再「保存并应用」，原直播地址会自动更新。关闭编辑网页不影响输出，直播期间保持 LIRA 开启。

「添加组件」左栏沿用客户端组件的顺序，内置、单独导入和套装中的样式放在各自组件分类中。展开「礼物姬」，分别选择全屏礼物感谢、滚动礼物、礼物许愿、月底冲刺、盲盒盈亏榜和大航海感谢；展开「点歌」，选择点歌板、展示板或直播歌词。点击右侧「添加样式」可导入更多样式。弹幕投票、观众评分各有独立分类；直播小游戏中选择直播间互动或转盘。弹幕姬按固定弹幕、随机弹幕或飘窗弹幕选择，添加后右侧只调整当前样式参数；需要其他样式时再添加对应组件。

其他支持更换样式的组件，在画布选中原图层，点右侧「更换样式 / 添加素材」选择新样式。名称、位置、大小和层级会保留，最后点「保存并应用」。锁定的图层需先解锁。

旧场景使用了此前内置的月渡花汀时，先导入月渡花汀 ZIP。弹幕姬重新添加对应样式；其他组件可按上述步骤为原图层选择对应成员。若提示资源缺失，也可重新导入对应套装后重新选择。

导入的样式用于本机场景，不会修改服务器弹幕姬链接。直播软件与 LIRA 需在同一电脑上，直播期间保持 LIRA 开启。

组件库加入场景的图层各自保存样式选择、位置和尺寸。公共参数按参数区提示生效：内置时钟、点歌板、弹幕姬和加班机需「保存并应用」；明确标为自动保存的参数会即时同步到客户端及同样式组件，「放弃修改」不会撤回已自动保存的参数。布局修改仍需「保存并应用」。想更换单组件默认样式，可在客户端对应面板选择并保存。

在「添加组件 → 套装」找到已导入的套装，点击需要的成员；也可从对应组件分类选择。每点一个成员添加一个组件，摆好后点「保存并应用」。

5.1.2 摆位置、改大小和调整图层
  • 拖组件内部改位置，拖边框改大小。想填准确的数值，到右侧参数区改。画布宽高和直播软件里这个浏览器源的宽高要一样。
  • 点击画布内的空白或画布四周的留白，取消组件选择。背景铺满整个画布时，点击外围留白即可。
  • 下方图层栏里，越靠左越在画面前面，越靠右越在后面。新加的组件在最前面。背景挡住其他东西了，就把背景图层往右拖。
  • 点图层旁的更多菜单，可以隐藏、显示、锁定或解锁。锁定后不能拖动、改大小或删除，想再改就先解锁。
  • 顶部「撤销」「重做」可回退或恢复布局修改，也可用 Ctrl + Z、Ctrl + Y（或 Ctrl + Shift + Z）。拖到一半按 Esc 可以取消这次拖动。预览的棋盘格、浅色和深色背景只是方便你看清画面，不会出现在直播里。

改好后点「保存并应用」，再到 OBS 或直播姬看一眼效果。只想存下来备用，就点「保存场景」。

参数不合法、保存失败或连接异常时，画布网页右上角会弹出提示并说明原因；按提示修正后再重试。

复制地址后，点击地址框外部、按 Esc 或再次点击同一复制按钮可收起地址框；框内仍可选中文字手动复制。

5.1.3 把不同布局存成场景

打开「点歌 → 浏览器源 → 直播场景 → 编辑场景」。点场景旁的「⋯」打开「场景操作」，选择「新建场景」从空白画布开始，也可以选择「复制场景」照着已有的布局改。保存、删除场景也在这个菜单里。想改名字，点顶部的画布图标，到「场景名称」里填，最多 10 个字符。

  • 保存场景：把这套布局存下来，直播继续使用当前布局。与客户端共用的参数在保存后会同步到同样式组件。
  • 删除场景：选中场景，点「删除场景」并确认，未保存修改也会删除，随后自动选择剩余场景。删除「当前输出」时，会切换到剩余场景的已保存版本；最后一个删完后输出透明空画面。原直播源地址保留，其他场景的未保存修改不会自动应用。删空后可从「场景操作 → 新建场景」重新开始。
  • 保存并应用：直播画面换成这一套。地址还是原来的，OBS 或直播姬里不用重新粘贴。
  • 切换场景：这次编辑中没保存的内容会暂时留着，可以切到别的场景再回来改，离开前记得保存。「当前输出」标记最后一次保存并应用的场景，与正在编辑的场景可以不同；它不代表 OBS 或直播姬正在显示该来源。「未保存」表示还有修改尚未应用。

看到「恢复上次草稿」时，可以先恢复，看看组件和位置对不对，再点「保存并应用」。应用失败会保留原布局；此前已保存的共享参数仍会生效。

首次加载失败时，提示会指出未就绪图层并自动重试。先确认 LIRA 正在运行，再检查提示中的素材或网页来源。更新失败时保留已显示的画面，新版准备好后再切换。

5.1.4 把其他工具的网页源加进来
  1. 在画布里点「添加组件」，再点分类列表最下面的「更多」。
  2. 填组件名称，粘贴完整的 HTTP 或 HTTPS 浏览器源地址，再填网页宽高，默认 800 × 600。
  3. 点「添加到画布」，摆好位置和大小，再点「保存并应用」。可以复制整个场景的地址，也可以选中这个组件，只复制它的直播源地址。

「网页宽高」是让原网页按多大的窗口排版，画布上的大小是它在直播里占多大，两处改起来效果不一样。想改网页里面的内容和样式，还是去提供链接的那个工具里改。

这个网页要允许放进其他页面。需要单独登录、要原工具一直开着，或者不允许嵌入的网页，可能显示不出来。画面空白时，先看原工具对浏览器源的使用说明。
