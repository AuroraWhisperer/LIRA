4礼物记录与分析

这里管理礼物账本、成本分析、答谢弹幕和金额目标。感谢动画、许愿、冲刺文字、盈亏榜及加班机见礼物组件和加班机。

4.1 礼物记录

4.1.1 礼物统计

「礼物统计」决定这台电脑统不统计礼物。「礼物提示」只管弹不弹通知。加班机另有自己的开关。

注意：关掉礼物统计，加班机不会跟着关，云端也还在收礼物。要停收新礼物，关掉本页的「监控礼物」，再等同步完成。弹幕监控是另一个开关。

4.1.2 礼物提示

打开后，收到礼物时 LIRA 右上角会弹出送礼人、礼物和金额。只关提示，礼物照样记录。

4.1.3 最近礼物

这里列出最近收到的礼物、送礼人、金额和时间。点「查看全部」能看全部礼物记录。

想找某几条，可以按用户名称、礼物名称、「金额大于（元）」、开始日期和结束日期筛选，再点「查询」。「今天」一键选当天，「重置」清掉筛选。

「金额大于」看的是单条记录的总金额，正好等于这个数的不算。

4.1.4 把礼物记录导出为 PNG 图片
  1. 打开「礼物 → 最近礼物 → 查看全部」，先筛出要导出的记录。
  2. 勾选记录。也可以拖动框选，按住 Ctrl 拖动追加，或点「选择全部筛选结果」。看一眼「已选」条数，再点「导出所选」。
  3. 选输出方式：要一整张答谢图选「拼成一张」，要分开用选「每条一张」。
  4. 选图片背景（透明或白色）和保存文件夹，看一下预览。选错了记录，点「返回选择」重选。
  5. 点「导出 PNG」，等提示完成，再点「打开文件夹」看看图片。
查看导出预览与保存设置
4.1.5 礼物历史同步与清理

礼物记录会自动更新。看到「正在更新礼物记录…」就稍等一下。断网时能看已经存下的记录，联网后会接着更新。

提示「当前仅能查看部分历史记录」，说明记录还没拿全。加载失败就点「重新加载」或「重试」。

无法恢复：「清空全部记录」会永久删掉这个账号在这台电脑和云端的全部礼物记录，其他电脑同步后也会清空。删了就找不回来，确认后再点。

4.2 盲盒与数据分析

4.2.1 盲盒设置

常见盲盒的成本和能开出的礼物会自动获取，不用一个个填。

需要补充时，到「盲盒设置」添加自定义盲盒、成本和能开出的礼物。

这些设置会同步到同一账号。改了只影响之后的记录，旧记录不会重算。

4.2.2 今日盲盒盈亏

这里按观众汇总今天的开盒情况：开了几个盒、什么盒型、总成本、开出价值，盈亏一眼就能看出来。每种内置盲盒有自己的颜色。

点某位观众，能看他的全部开盒记录。点「查看全部」，打开完整的盲盒分析。

  • 盲盒分析可以切换「按观众看」「按盲盒看」「开盒记录」三种视图。
  • 能筛选、排序、翻页，收到新礼物会自动刷新。
  • 不知道成本的盲盒，不能当成零成本来算盈利。
查看按盲盒与逐条开盒记录
4.2.3 礼物构成与盲盒明细怎么读
  • 礼物流水：按时间、送礼人、礼物筛选记录，翻页查看。网页上不能导出 PNG，要导出请到礼物页。
  • 数据分析：选日期，看收礼趋势、收礼概览和礼物价值构成。换了日期，先看清统计范围，再比金额。
  • 网页歌单与分享：名称、背景、外观和二维码。
  • 直播弹幕姬：复制地址与应用样式。
查看礼物流水和数据分析的画面

记录是空的：先清空筛选，核对日期和登录的账号，再到客户端看看直播间连上没有。服务器只能显示已经记下来的礼物，页面空白不代表历史礼物都补齐了。

在网页主播中心打开礼物记录或数据分析，选好日期和筛选条件，再展开「礼物构成」。想把流水和图表放在一起看，先确认两边选的是同一段时间。

  1. 「统计日期」默认选「本月」，和上面的查询日期分开。想用同一段时间，就选「跟随查询」。自己选起止日期时，选「自定义日期」，填完再点「应用日期」。
  2. 点「按价值」看礼物价值占了多少，点「按件数」看数量占了多少。同样送 10 件，不同礼物的价值可能差很多。
  3. 先看普通礼物、大航海和盲盒的分类，再看「盲盒构成」。想看某个盒子，在「盲盒详情」里选；盒子多时，可以搜名字或从列表里找。
  4. 选好盒子，下面能看开出了什么、多少件、值多少、占多少。再看「已知成本」「对应开出价值」「开出价值差额」，别漏看旁边关于成本是否完整的提示。

日期按北京时间算，只统计 LIRA 已经记下来的付费礼物。「礼物价值」按礼物标价算，不是平台结算后你能拿到的钱。提示数据没拿全或成本不完整时，别把缺的部分当成 0，也别拿已有的差额当全部盈亏。

4.3 礼物答谢与查询弹幕

4.3.1 自动答谢礼物与弹幕查询

在「礼物」页打开「自动答谢」和「弹幕查询」。打开前，先到「点歌 → 设置」登录 B 站账号并保存设置，确认账号已同步、直播间连上了。

  • 自动答谢：答谢付费礼物和已确认的免费礼物，醒目留言（SC）不答谢。答谢内容是固定的，比如「@观众A 感谢投喂小花花×1」。付费礼物会带上实际金额，开通大航海会写「感谢开通」。没有答谢模板要填。
  • 弹幕查询：观众发「今日礼物」「本月礼物」「累计礼物」这类弹幕，就能查到自己送过的付费礼物数量和金额。送过盲盒的，还会显示能算清的盈亏差额。回复大致是「@观众A 今天…×数量；共…电池」。
  • 关掉查询：只是不再回复这类弹幕。礼物记录不会删，礼物统计也不受影响。

这两项由服务器运行，退出软件后也一直有效。要停用，就关掉对应开关，并确认保存成功。

4.4 月底冲刺目标

4.4.1 月底冲刺

在「组件 → 礼物姬 → 月底冲刺」设定月度礼物收入目标（金额）并保存。页面会实时显示已收多少、还差多少、折合几个水晶球（100 元/个）。

随时可以点「重置本轮」重新计数，礼物记录不受影响。

直播画面显示进度用月底冲刺文字。礼物许愿设置的是指定礼物数量，和这里的收入金额目标分开。

4.5 礼物资料查询

4.5.1 查礼物编号、图片与特效

礼物图鉴直接用浏览器打开，不用登录 LIRA 账号。

  1. 打开 礼物图鉴（礼物特效档案），输入礼物名称或编号，点搜索。
  2. 按需要选付费或「免费 / 银瓜子」，再筛背包、非背包礼物。只想找有特效的，就勾「只看有特效」。
  3. 点开礼物，能看编号、图片、价格，有特效的还能预览。想在客户端设这个礼物的触发特效，就复制它的编号，再回客户端填。

有图片不一定有特效，能看什么以礼物详情为准。想设直播时的特效，打开客户端「百宝箱 → 礼物特效」。

4.5.2 看盲盒概率和礼物期望

有概率资料的盲盒，详情里能看到奖励和概率。有多个档位或历史版本时，先选你想看的那一档，再看数字。不是每个礼物都有概率资料。

「礼物期望」按所选档位的礼物标价和概率算：每种礼物的价值乘以概率，再加起来，就是期望价值；再除以盒价，就是回报率。遇到五盒组合奖励，先看页面里的计算说明，分清整组和折合每盒的数值。

这些数字算的是理论平均值，不保证你这一次或这几次能抽到什么，也不是现金收益。历史档位留着供你查，别当成当前活动的概率。
