4礼物记录与分析

这里管理礼物账本、成本分析、答谢弹幕和金额目标。感谢动画、许愿、冲刺文字、盈亏榜及加班机见礼物组件和加班机。

4.1 礼物记录

4.1.1 礼物统计

「礼物统计」决定这台电脑统不统计礼物。「礼物提示」只管弹不弹通知。加班机另有自己的开关。

注意：关掉礼物统计，加班机不会跟着关，云端也还在收礼物。要停收新礼物，关掉本页的「监控礼物」，再等同步完成。弹幕监控是另一个开关。

4.1.2 礼物提示

打开后，收到礼物时 LIRA 右上角会弹出通知，显示送礼人、礼物和金额。只关提示，礼物照样记录。

4.1.3 最近礼物

这里列出最近收到的礼物、送礼人、金额和时间，也包含云端恢复的记录。恢复历史不会重新弹出收礼通知或计入本机冲刺、加班。点「查看全部」可筛选保留期内的逐笔记录。

想找某几条，可以按用户名称、礼物名称、「金额大于（元）」、开始日期和结束日期筛选，再点「查询」。「今天」一键选当天，「清除筛选」清掉筛选。

「金额大于」看的是单条记录的总金额，正好等于这个数的不算。

本机保留已接收的约一年明细，清空本机数据后重装或换电脑可从服务器恢复约 90 天明细，具体可用范围以列表提示为准。更早的金额、笔数和盲盒汇总仍保留，可在网页主播中心按日期查询，也可使用弹幕查询指令。超过保留期的逐笔记录无法再查看或导出。

4.1.4 把礼物记录导出为 PNG 图片

可导出范围见礼物记录保留范围。换电脑或长期离线后，较早日期可能只有部分明细；列表会提示缺口或过期。已有的 200 天前记录仍可导出，一次最多选择 10,000 条；汇总不能还原成逐笔图片。一年外的本机盲盒记录按日汇总，变更电脑时区后会提示日期精度限制。

  1. 打开「礼物 → 最近礼物 → 查看全部」，先筛出要导出的记录。
  2. 点击礼物行或勾选框可选中或取消记录，也可以拖动框选本页。按住 Ctrl 点击或从礼物行、勾选框开始拖动，会切换所点或框内记录的勾选：已选的取消，未选的加入，框外和其他页的选择保留。拖动时「本次 + / -」分别显示新增和取消的条数；缩小选框时，移出框的记录恢复本次拖动前的状态。要选中所有匹配记录，可点「选择全部筛选结果」。核对「已选」总数后，点「导出所选」。
  3. 选输出方式：要拼图选「拼成长图」，要按卡片分开导出选「每条一张」。
  4. 在「图片背景」下面选排序。默认按时间从新到旧，选「按金额」会把总金额最高的卡片放在最前，同额按时间排列。
  5. 当前长图恰好有两张卡片时，可拖动「词条间距」查看效果。滑块中点是默认的 16 px，最左是 0 px，最右是 32 px。
  6. 想把同一位观众送的同款礼物合在一起时，打开「合并同种礼物」。当天和以前的记录都可以合并。
  7. 选图片背景（透明或白色）和保存位置，看一下预览。选错了记录，点「返回选择」重选。
  8. 点导出 PNG 按钮，等出现导出完成的提示，再点「打开文件夹」查看图片。
  9. 导出图片沿用「组件 → 礼物姬 → 滚动礼物」中已保存的价格分色和卡片外观。需要修改样式时，先在该页面保存，再重新点「导出所选」。

卡片外形、纹理与颜色设置见滚动礼物；导出预览和 PNG 始终保持静态，不播放白色扫光。

「合并同种礼物」默认关闭，会记住上次选择。关闭时每笔结算显示一张，连击已结算为 ×5 的仍是一张 ×5。开启后，同一位观众分三天各送了 100 个小花花，勾选这三笔就会合成一张 ×300。按时间排序时，这张卡片排在最近一笔的位置。按金额排序时，使用三笔的合计金额。服务器无法确认归属的记录会单独保留。

导出预览优先使用送礼当天已知的头像。当天没有头像但能确认观众的 B 站账号时，服务器会尝试读取该账号当前的头像。仍取不到头像或图片下载失败时，卡片会显示默认头像。同步或网络恢复后，可以返回礼物记录重新选择并导出。

例如，选中今天的 3 笔记录，关闭合并时就有 3 张卡片。如果其中 2 笔是同一位观众的同款礼物，开启后预览会显示 3 条记录、2 张卡片。此时选「每条一张」导出 2 张 PNG，选「拼成长图」导出 1 张。拼图过长时会自动分成多张，实际输出数量以预览显示为准。

4.1.5 礼物历史同步与清理

礼物记录会自动更新。看到「正在更新礼物记录…」就稍等一下。断网时能看已经存下的记录，联网后会接着更新。

提示「当前仅能查看部分历史记录」，说明记录还没拿全。加载失败就点「重新加载」或「重试」。

无法恢复：「清空全部记录」会永久删掉这个账号在这台电脑和云端的全部礼物记录，其他电脑同步后也会清空。删了就找不回来，确认后再点。

4.2 盲盒与数据分析

4.2.1 盲盒设置

常见盲盒的成本和能开出的礼物会自动获取，不用一个个填。

最近礼物和盲盒设置中的同一盒型使用相同的固定配色，不受客户端外观影响；没有专属配色的盲盒使用紫色。

需要补充时，到「盲盒设置」添加自定义盲盒、成本和能开出的礼物。如果添加时展开了高级编辑并提示 JSON 格式错误，先修正原数组，再点「添加」。已有配置和本次填写的内容都会保留。

删除自定义盲盒前会要求确认，只删除该项手工配置，保留已有礼物记录。

这些设置会同步到同一账号。改了只影响之后的记录，旧记录不会重算。

4.2.2 今日盲盒盈亏

这里按观众汇总今天的开盒情况：开了几个盒、什么盒型、总成本、开出价值，盈亏一眼就能看出来。每种内置盲盒有自己的颜色。软件未运行或安装前，服务器已记录的当日盲盒也会在同步完成后计入；日期按实际送礼时间和电脑本机时间判断。

点某位观众，能看他在保留期内的开盒记录。点「查看全部」，打开完整的盲盒分析。

  • 盲盒分析可以切换「按观众看」「按盲盒看」「开盒记录」三种视图。
  • 点带箭头的表头可排序，再点一次切换升序和降序。三个视图都能按「观众盈亏」排序。筛选后可翻页，收到新礼物会自动刷新。
  • 排序读取失败时，再点刚才的表头或「重新读取」，都会重试刚才选择的方向。同一礼物来源重连后沿用上次成功的排序，切换来源后恢复当前视图的默认排序。
  • 日期按电脑本机时间筛选。若提示含旧版历史汇总，单日统计可能存在时区偏差；已删除明细的时间分布无法恢复。
  • 不知道成本的盲盒，不能当成零成本来算盈利。

4.2.3 礼物构成与盲盒明细怎么读
  • 礼物流水：按时间、送礼人、礼物筛选保留期内的逐笔记录，翻页查看。页面会提示明细从哪天起保留；所选日期早于保留期时，可能没有明细，历史金额和笔数仍可在统计中查询。网页上不能导出 PNG，客户端的导出步骤见把礼物记录导出为 PNG 图片。
  • 数据分析：选日期，看收礼趋势、收礼概览和礼物价值构成。换了日期，先看清统计范围，再比金额。
查看礼物流水和数据分析的画面

记录是空的：先清空筛选，核对日期和登录的账号，再到客户端看看直播间连上没有。服务器只能显示已经记下来的礼物，页面空白不代表历史礼物都补齐了。

在网页主播中心打开礼物记录或数据分析，选好日期和筛选条件，再展开「礼物构成」。想把流水和图表放在一起看，先确认两边选的是同一段时间。

  1. 「统计日期」默认选「本月」，和上面的查询日期分开。想用同一段时间，就选「跟随查询」。自己选起止日期时，选「自定义日期」，填完再点「应用日期」。
  2. 点「按价值」看礼物价值占了多少，点「按件数」看数量占了多少。同样送 10 件，不同礼物的价值可能差很多。
  3. 先看普通礼物、大航海和盲盒的分类，再看「盲盒构成」。想看某个盒子，在「盲盒详情」里选；盒子多时，可以搜名字或从列表里找。
  4. 选好盒子，下面能看开出了什么、多少件、值多少、占多少。再看「已知成本」「对应开出价值」「开出价值差额」，别漏看旁边关于成本是否完整的提示。

日期按北京时间算，只统计 LIRA 已经记下来的付费礼物。「礼物价值」按礼物标价算，不是平台结算后你能拿到的钱。提示数据没拿全或成本不完整时，别把缺的部分当成 0，也别拿已有的差额当全部盈亏。

4.3 礼物答谢与查询弹幕

4.3.1 自动答谢礼物与弹幕查询

登录 B 站并同步直播间后，在「百宝箱 → 弹幕互动」设置礼物答谢和查询回复。礼物页的「前往弹幕互动设置」可直接跳转。

关闭回复开关不会删除礼物记录，也不影响礼物统计；云端设置需确认同步后再退出客户端。

4.4 月底冲刺目标

4.4.1 月底冲刺

在「组件 → 礼物姬 → 月底冲刺」设定月度礼物收入目标（金额）并保存。页面会实时显示已收多少、还差多少、折合几个水晶球。换算与画面规则见月底冲刺文字。

随时可以点「重置本轮」重新计数，礼物记录不受影响。

直播画面显示进度用月底冲刺文字。礼物许愿设置的是指定礼物数量，和这里的收入金额目标分开。

4.5 礼物资料查询

4.5.1 查礼物编号、图片与特效

礼物图鉴直接用浏览器打开，不用登录 LIRA 账号。

  1. 打开 礼物图鉴（礼物特效档案），输入礼物名称或编号，点搜索。
  2. 按需要选付费或「免费 / 银瓜子」，再筛背包、非背包礼物。只想找有特效的，就勾「只看有特效」。
  3. 点开礼物，能看编号、图片、价格，有特效的还能预览。想在客户端设这个礼物的触发特效，就复制它的编号，再回客户端填。

有图片不一定有特效，能看什么以礼物详情为准。想设直播时的特效，打开客户端「百宝箱 → 礼物特效」。

4.5.2 看盲盒概率和礼物期望

有概率资料的盲盒，详情里能看到奖励和概率。有多个档位或历史版本时，先选你想看的那一档，再看数字。不是每个礼物都有概率资料。

「礼物期望」按所选档位的礼物标价和概率算：每种礼物的价值乘以概率，再加起来，就是期望价值；再除以盒价，就是回报率。遇到五盒组合奖励，先看页面里的计算说明，分清整组和折合每盒的数值。

这些数字算的是理论平均值，不保证你这一次或这几次能抽到什么，也不是现金收益。历史档位留着供你查，别当成当前活动的概率。
