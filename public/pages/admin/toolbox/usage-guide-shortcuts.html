功能位置索引

常用设置位置

主界面顶部有「点歌」「播放」「礼物」「组件」「百宝箱」。按要操作的对象查找：

  • 账号与连接：点歌 → 设置
  • 点歌规则：点歌 → 点歌板
  • 歌库导入导出与同步：点歌 → 导入导出
  • AI 互动助手：百宝箱 → 弹幕互动
  • 礼物与盲盒：礼物
  • 粉丝档案与工作台：百宝箱 → 日常管理

点歌页下方的页签：

  • 设置：B 站账号登录和直播间号。弹幕监控开关在弹幕姬，礼物监控开关在礼物页。
  • 点歌板：点歌规则、点歌板黑名单，以及直播画面上点歌板的颜色、字号、滚动模式等样式。
  • 展示板：歌单展示板的滚动速率、歌曲排序方式和主题配色。
  • 浏览器源：打开场景编辑器、复制直播场景地址，也能直接复制单个组件的浏览器源地址，加到 OBS 或直播姬。不需要统一管理时，单个组件会使用已保存的样式。
  • 导入导出：导入 XLSX、CSV、TSV 文件或粘贴表格，也能下载导入模板、导出歌库 Excel。
  • 桌面歌词设置：设置歌词浏览器源的字体、颜色、字号、描边和透明度，并实时预览。

「浏览器源」页只列常用地址，其他地址到对应功能里复制。在线弹幕姬链接要先通过 LIRA 授权、读到服务器配置才能用。要收到直播消息，还要登录 B 站账号。

外观设置位置
  • 客户端配色：百宝箱 → 设置 → 客户端外观
  • 点歌板：点歌 → 点歌板
  • 歌曲展示板：点歌 → 展示板
  • 直播歌词：点歌 → 桌面歌词设置
  • 弹幕姬：组件 → 弹幕姬
  • 礼物组件：组件 → 礼物姬
  • 时钟：组件 → 时钟
  • 开播动画：组件 → 开播动画
  • 网页歌单：网页主播中心 → 网页歌单
  • 投票与评分画面：百宝箱 → 小游戏

点歌板显示排队等着唱的歌，歌曲展示板展示歌库。两个都能放进直播画面，但内容不一样。

其他效果图和设置图见组件与百宝箱；复制地址和画面尺寸见直播姬 / OBS 投屏。

名词小词典

点歌队列与播放队列

点歌队列是观众点的歌。播放队列是播放器接下来要放的歌。「导入点歌」把点歌队列加进播放队列。详见播放页。

点歌板与展示板

点歌板给观众看排队的歌，歌曲展示板滚动展示歌库。两个都不能放歌。

桌面歌词与逐字歌词

桌面歌词是单独显示歌词的画面，也能用浏览器源加进 OBS 或直播姬。逐字歌词会跟着演唱一个字一个字高亮，要歌曲本身带这种歌词才行。

弹幕姬

在「组件」中设置弹幕画面的样式和过滤，直播画面使用服务器地址。发送、回复和机器人功能位于「百宝箱 → 弹幕互动」。

礼物姬

设置全屏礼物感谢、大航海感谢、滚动礼物和礼物许愿的地方。查礼物记录要去顶部的「礼物」页。

加班机

用倒计时显示还要播多久。收到符合规则的礼物，可以加减时间或触发别的效果。先设好初始时间和礼物规则。

盲盒与盈亏

盲盒会开出不同价值的礼物。盈亏 = 开出礼物的价值 − 开盒成本，正数是赚，负数是亏。它不等于主播实际到账的收入。

大航海与 SC

大航海是 B 站的舰长、提督、总督这些付费身份。SC 是醒目留言（Super Chat），是付了钱的留言，和普通弹幕不一样。

浏览器源与投屏地址

OBS 的「浏览器源」或直播姬的「浏览器」能把一个网页放进直播画面。把 LIRA 给的地址粘进去就行，不用录整个软件窗口。

本机与服务器

本机就是你正在用的这台电脑。服务器是联网后帮你保存数据、运行部分功能的那一端。带 127.0.0.1 的地址只能在运行 LIRA 的那台电脑上用。

网页歌单与主播中心

网页歌单公开给观众挑歌。主播中心要用 LIRA 账号登录，用来看礼物、改网页歌单外观、复制服务器弹幕姬地址。

注册激活码 短效登录码 密码重置码

注册激活码：第一次注册账号用。短效登录码：换电脑或重装后登录客户端用。密码重置码：在网页上重置忘记的密码用。都找管理员要，不能混着用。
