08.5 场景、组件与素材异常

08.5.1 直播姬 / OBS 投屏画面不显示或尺寸不对
  1. 到对应功能面板重新复制链接，在直播姬或 OBS 里添加为浏览器源。别用网页歌单链接代替。
  2. 链接里有 127.0.0.1 的，LIRA 要在同一台电脑上运行，并且保持开着。
  3. 按功能说明设好源的宽高。没有点歌、正在播放的歌词、许愿或礼物时，画面透明可能是正常的。
  4. 更新或重启 LIRA 后，刷新一次浏览器源。还不显示，核对功能有没有开、地址对不对，见投屏设置。
08.5.2 弹幕姬画面不更新，或者改了样式直播画面没变化
  1. 在「组件 → 弹幕姬」改完样式，要点「应用到直播画面」，等结果提示出来。只改预览不算应用。
  2. 服务器弹幕姬还要服务器和直播间连接正常。先看连接状态、目标直播间和屏蔽设置，再发一条测试弹幕试试。
  3. 保存或应用成功、地址也对，画面还是旧样式：刷新一次浏览器源。
  4. 场景编辑器里的修改要点「保存并应用」。只改组件默认样式，不会自动重新发布整个场景。
08.5.3 加班机规则已配置，收礼后仍未增加时间
  1. 按礼物规则与结算核对礼物、规则类型和启用状态；减少、清零或文字展板本来就不会加时间。
  2. 连击还没结束时先等待，结束后检查「待结算」和「最近结算」，确认是否被忽略。目录未刷新或提示重新选择礼物时，刷新在售礼物并重新选择。
  3. 仍无结算时，记录礼物 ID、收到时间、规则和结算提示，按问题反馈提供信息。
08.5.4 歌单背景图传不上去
  1. 先按网页歌单背景确认格式与 5 MB 大小限制。
  2. 提示网络或授权失效：先恢复连接或处理授权。还失败，记下具体提示。别反复改图片扩展名。
08.5.5 有地址但提示复制失败
  1. 有地址但复制不了，会提示「复制失败，请手动复制地址」。这时手动选中地址复制。别用示例截图里的地址。
  2. 在直播软件的地址框核对粘贴结果。仍无法使用时，保留复制失败的提示和当前功能名称反馈。
08.5.6 导入网页样式时提示缺少配套文件
  1. 看提示列出的具体路径。普通素材 ZIP 先解压到独立文件夹，保留作者原有目录结构；不要只取出 HTML 文件。
  2. 在「更多设置」重新选择包含配套资源的文件夹。依赖原工具后端或专用网页的样式，使用作者提供的配套 HTML 或展示地址。
  3. 确认文件齐全后重新预览；仍缺资源时，把缺失路径和素材版本发给作者或管理员，不反复导入同一份不完整文件。正常导入入口见素材与样式库。

08.6 同步与数据异常

08.6.1 清空后还看到“云端记录已清空，本机记录尚未更新。”
  1. 不用再清空一次。这条提示说明云端已经删完，这台电脑还在等更新，不是清空失败。
  2. 恢复连接后重新加载礼物记录，等这台电脑和云端一致。
  3. 还看到旧记录，把提示发给管理员。注意：清空云端账本会影响同一账号的设备。
08.6.2 歌单表格导入失败
  1. 用「点歌 → 导入导出」里的模板，保留「歌曲名字」等表头。只改文件后缀没用。
  2. 读不出来：用 Excel 重新另存为 .xlsx，或者把表格内容复制粘贴到导入框。CSV、TSV 也能导入。导入完看一下新增、更新、跳过、失败的结果，再核对歌库。
  3. 还是失败，把结果提示和几行去掉个人信息的示例发给管理员。别反复导入整个文件。
08.6.3 歌数未超限制，仍提示同步数据太大
  1. 如果提示的是数据太大，就算歌数没超，也要缩短过长的备注、点歌价格或歌切内容。

歌曲数量限制与整理方法见表格导入与批量更新。

08.6.4 同步到一半断网，不知道成功没有
  1. 网络恢复后，先看网页上的歌曲数量和实际歌单，再核对这台电脑上的完整歌库。
  2. 看到「同步失败」或超时，不能当成功，也不能断定服务器一定没收到。只有同步成功，「本机上次同步」的时间和数量才会更新。
  3. 要重试，先确认这台电脑上的歌库是对的：「同步到网页」会覆盖云端歌库，不会自动合并。见数据保存与换电脑。
08.6.5 两台电脑的歌库不一样，换机后也少了设置
  1. 别同时在两台电脑上改歌库。登录同一账号联网后歌库会同步，但最后同步成功的会替换之前的版本，不会自动合并。
  2. 两边先都停下别改，各自核对、导出要留的版本，再定下完整歌库。别马上用歌少的那台电脑覆盖同步。
  3. 点歌队列、播放队列、音乐平台登录、歌词缓存位置，以及这台电脑上的画面样式，都不会跟着歌库过去。按数据保存与换电脑重新核对。

08.7 其他报错与问题反馈

08.7.1 报错后，日志在哪里找、怎么交给管理员
  1. 目录入口见数据目录与日志入口，反馈时选择日志目录。
  2. 记下出问题的时间、当前版本、操作步骤和界面上的完整提示，按管理员说的方式发那段时间的日志。
  3. 只发排查需要的文件，别发整个数据目录、密码或 API 密钥。进不了软件的话，先把屏幕上的错误和版本号发给管理员。
