投屏与直播软件

弹幕姬链接是灰的，或者复制不了
  1. 等 LIRA 授权有效、读到服务器配置后，链接才能复制。先检查 LIRA 和服务器连上没有，等地址出来再复制。
  2. 有地址但复制不了，会提示「复制失败，请手动复制地址」。这时手动选中地址复制。别用示例截图里的地址。
  3. 没登录 B 站会影响收直播消息，但链接读不出来不一定是这个原因。还是灰的，记下页面提示发给管理员。
直播姬 / OBS 投屏画面不显示或尺寸不对
  1. 到对应功能面板重新复制链接，在直播姬或 OBS 里添加为浏览器源。别用网页歌单链接代替。
  2. 链接里有 127.0.0.1 的，LIRA 要在同一台电脑上运行，并且保持开着。
  3. 按功能说明设好源的宽高。没有点歌、正在播放的歌词、许愿或礼物时，画面透明可能是正常的。
  4. 更新或重启 LIRA 后，刷新一次浏览器源。还不显示，核对功能有没有开、地址对不对，见投屏设置。
弹幕姬画面不更新，或者改了样式直播画面没变化
  1. 在「百宝箱 → 弹幕姬」改完样式，要点「应用到直播画面」，等结果提示出来。只改预览不算应用。
  2. 服务器弹幕姬还要服务器和直播间连接正常。先看连接状态、目标直播间和屏蔽设置，再发一条测试弹幕试试。
  3. 保存或应用成功、地址也对，画面还是旧样式：刷新一次浏览器源。
  4. 场景编辑器里的修改要点「保存并应用」。只改组件默认样式，不会自动重新发布整个场景。
换电脑后，原来的画面链接还能用吗
  1. 链接里的 127.0.0.1 指的是这台电脑。换电脑后，要在新电脑上运行 LIRA，再核对复制出来的地址、端口和画面设置。地址不一定会变。
  2. 到新电脑的各功能页核对源宽高、样式和歌词来源。只复制直播软件里的场景，不等于全都搬过来了。
  3. 服务器弹幕姬用的是在线地址，另外核对账号授权和服务器连接。两类画面各自需要什么，见投屏设置。
弹幕发不出去
  1. 到「百宝箱 → 弹幕姬」看发送账号、目标直播间和发送结果。只显示「本机已登录」不代表能正常发送。
  2. 登录过期：到「点歌 → 设置」重新扫码登录并保存，等账号同步成功。连接异常就点「刷新直播」再试。
  3. 还发不出去，把发送结果和目标直播间发给管理员。先别反复批量发送。

云端功能、AI 与维护

自动答谢、弹幕查询等开关点了没反应
  1. 先到「点歌 → 设置」检查 B 站登录和云端连接。提示「请先登录 B 站，再同步到服务器。」或「连接云端账号后可设置」时，都这样处理。
  2. 提示「B 站登录已失效，请重新登录并同步。」：重新扫码登录并保存，等账号自动同步成功，再打开要用的功能。不用另外手动同步 B 站账号。
  3. 等出现「已同步到服务器」。状态一直没确认，就按面板提示刷新核对；还失败，把提示发给管理员。
已经关了功能，为什么提示服务器可能仍在运行
  1. 恢复网络和云端连接后，刷新状态，再关一次，等出现「已同步到服务器」。
  2. 「关闭还没同步，服务器可能仍在运行。」的意思是服务器还没确认关闭。开关看着是关的，或者退出了客户端，都不代表已经关了。
  3. 一直确认不了，找管理员核查服务器状态。
签到机器人没有回复
  1. 先到「百宝箱 → 弹幕姬 → 固定回复」，看「签到机器人」开了没有、云端状态有没有确认。
  2. 确认祝福语列表有内容、直播账号和直播间连接正常，再让观众发「签到」试试。
  3. 还没回复，刷新云端状态，留着提示。别靠反复开关来判断服务器有没有生效。
AI 互动助手不回复
  1. 到「百宝箱 → 弹幕姬 → AI 互动助手」检查「启用 AI」、平台、密钥和模型，再点「测试 AI 连接」。
  2. 保存自定义触发关键词，再发一条带这个关键词的弹幕试试。关键词留空不会触发。
  3. 看看「等待队列」、同一观众提问间隔和每分钟提问上限。发得太频繁，就稍等再试。
  4. 测试失败：按结果检查服务地址、模型或平台余额。测试通过还不回复：检查直播账号和发送状态。配置步骤见配置 AI 助手。
报错后，日志在哪里找、怎么交给管理员
  1. 到「百宝箱 → 桌面更新」找到「日志目录」，点旁边的「打开目录」。别和「数据目录」搞混。
  2. 记下出问题的时间、当前版本、操作步骤和界面上的完整提示，按管理员说的方式发那段时间的日志。
  3. 只发排查需要的文件，别发整个数据目录、密码或 API 密钥。进不了软件的话，先把屏幕上的错误和版本号发给管理员。
想彻底清空数据或换一个 LIRA 账号
  1. 客户端里没有切换或退出 LIRA 账号的按钮。「点歌 → 设置」里的「退出登录」只退出 B 站账号。
  2. 先按数据保存与换电脑备份你要留的资料，再找管理员确认账号和设备怎么处理。
  3. 别直接删数据目录，也别复制别人的目录来换号。这台电脑上的数据和服务器上的账本是分开的，删这台电脑上的文件，不会清空服务器上的数据。
