09配置 AI 助手

先到 AI 平台拿到密钥（API Key），再回到 LIRA 选平台、粘贴密钥、选模型，最后测试连接。下面以 DeepSeek 为例。

1. 以 DeepSeek 为例完成配置

先在 DeepSeek 开放平台创建密钥，再回到 LIRA 设置。DeepSeek 网站改版后，按钮位置可能不同。

1. 登录 DeepSeek 开放平台

打开 DeepSeek 开放平台，按页面上的方式注册或登录。

2. 完成账号验证

页面要求绑定邮箱或验证账号时，按提示操作，再继续。

3. 进入 API keys 页面

在左侧菜单点「API keys」，再点「创建 API key」。

4. 命名并创建

给密钥起个好认的名字，比如 LIRA，再点「创建」。

5. 复制并保存密钥

创建后点「复制」，把完整密钥存好。密钥别发给别人。

6. 选择「DeepSeek 官方」

回到「百宝箱 → 弹幕互动 → AI 互动助手」，在「AI 平台」里选「DeepSeek 官方」，地址会自动填好。

7. 粘贴密钥（API Key）

把密钥粘贴到「密钥（API Key）」输入框，等它显示「已保存」，也可以点「保存设置」。保存后，密钥不会完整显示。

8. 获取并选择模型
  1. 点「获取模型」，选一个可用模型，再点「测试 AI 连接」。
  2. 在「回复规则」的「触发关键词」里填一个你自己定的词，等它显示「已保存」。
  3. 测试通过后，打开「启用 AI」。发一条带关键词的弹幕，看看有没有回复。

各个模型的说明见 DeepSeek 官方文档。

9. 查看用量、余额不足时充值

打开 DeepSeek 用量与余额，能看用量和余额，不够了再充值。充值后回到 LIRA，点「测试 AI 连接」。

用之前先看一下 DeepSeek 官方价格。实际费用和余额看 DeepSeek 平台上的显示。

查看充值页面

2. 平台、角色包与回复设置

打开「百宝箱 → 弹幕互动 → AI 互动助手」。顶部的「配置状态」「等待队列」「运行模型」显示当前情况。改完设置，等它显示「已保存」，也可以点「保存设置」。

选择平台与模型

「AI 平台」有六个选项：自动识别（兼容旧设置）、DeepSeek 官方、OpenAI 官方、Claude 官方兼容、Gemini 官方兼容、自定义 / 第三方兼容。选官方平台，地址会自动填好。用第三方服务，就按提供方的说明填「API 请求地址」和密钥。拿不准「接口协议」时，保持「自动识别」。

点「获取模型」能列出当前服务支持的模型，也可以直接填提供方给的模型 ID。能不能用「联网」「深度思考」，要看平台和模型，面板上会提示。开启深度思考后，才能调「思考强度」。看到开关不代表已经连上，要用「测试 AI 连接」确认。

选择或保存角色包

新配置默认「通用助手」，也可以切换成「小猫」。在「性格和说话方式」里写 20–8000 字的人设， 编辑后会转为自定义角色；给角色起个名字，再点「保存为角色包」，以后就能随时切换。

「导出当前角色」可保存为 LIRA JSON 文件，再用「导入角色包」恢复或分享。文件最多 64 KB， 最多保存 20 个自建或导入包。重复标识不会覆盖原包；内置角色不能删除。 角色包只包含人设，不包含密钥、聊天记录，也不会替你开启工具。

原有自定义人设会保留。切换角色或修改人设后，助手不会带入另一角色的短期记忆。

让观众唤醒 AI

在「触发关键词」里填一个词，最多 12 个字，比如“小助手”。保存后，观众发“小助手，晚上好”就能唤醒 AI。弹幕里要带上已保存的关键词才会触发；关键词留空就不回复。

「回复长度偏好」可填 10–50，默认 50。这只是长度偏好，内容多时，回复可能分成两条或三条弹幕。

  • 「同时处理的提问数」：1–5，默认 3。排队的提问看「等待队列」。
  • 「同一观众提问间隔（秒）」：0–3600，默认 0。
  • 「每分钟提问上限」：1–120，默认 20。
  • 「发送间隔（毫秒）」不能改：不同回复之间随机隔 500–2000 毫秒，同一回复的分段之间随机隔 200–600 毫秒。
普通问答与可选工具

只做普通问答，可以关闭联网和工具调用，不需要天气或地图账号。新配置默认关闭这些能力，已有设置会保留。 需要天气、地点或路线时，展开「可选工具」，先开启「允许模型调用工具」，再启用对应查询。

和风天气填专属 API Host 和密钥；高德地图填 Web 服务 API Host 和 Web 服务 Key。 这些密钥与模型密钥分开，填好后可分别测试。关闭工具会保留已保存配置；没有完整凭据的工具不会被调用。

平台原生搜索由「联网搜索」控制；显示「LIRA 联网搜索」时，还需要开启工具调用。 是否支持搜索或工具，以实际模型为准。不能核实时，助手会被要求说明不确定，不编造实时结果。

先让「测试 AI 连接」通过，再打开「启用 AI」，用真实弹幕试一下。测试成功却不回复，就检查直播账号、触发关键词和提问频率，见常见问题。
