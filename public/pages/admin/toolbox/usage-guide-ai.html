3.3 AI 互动助手

3.3.1 接入模型与测试

顶部的「配置状态」「等待队列」「运行模型」显示当前情况。改完等它显示「已保存」，也可以点「保存设置」。

「AI 平台」有七个选项：自动识别（兼容旧设置）、DeepSeek 官方、OpenAI 官方、Claude 官方兼容、Gemini 官方兼容、豆包（账号登录·实验性）、自定义 / 第三方兼容。选官方 API 平台，地址会自动填好。用第三方服务，就按提供方的说明填「API 请求地址」和密钥。拿不准「接口协议」时，保持「自动识别」。

API 模式下，点「获取模型」能列出当前服务支持的模型，也可以直接填提供方给的模型 ID。能不能用「联网」「深度思考」，要看平台和模型，面板上会提示。开启深度思考后，才能调「思考强度」。看到开关不代表已经连上，要用「测试 AI 连接」确认。

在「百宝箱 → 弹幕互动 → AI 互动助手」设置。API 模式下粘贴密钥后等待「已保存」，获取并选择模型，再点「测试 AI 连接」。已保存密钥显示前 6 位加掩码，例如 sk-abc********；较短密钥全部遮住。输入新密钥可替换，留空保留现有密钥。

豆包账号登录：选择「豆包（账号登录·实验性）」，点击「扫码登录豆包」，用手机豆包扫码并确认。电脑无需安装豆包，不需要 API Key，也不走火山引擎计费 API。填写触发关键词，再点「测试 AI 连接」确认。

豆包模式只提供文字对话，沿用当前人格和短期上下文；不提供函数工具或模型选择，原 API 配置会保留。登录态加密保存，加密不可用时仅本次运行有效。「退出豆包」会取消未完成请求并清除登录态；发送的对话可能保留在豆包账号内。

每位观众使用独立的豆包对话，同一观众、同一人格在有效期内继续使用，默认空闲满 10 分钟后再次提问会新建（已保存的时长继续沿用）；不同人格的对话也会分开，重启或重新登录后按需新建。「测试 AI 连接」使用单独的测试对话。LIRA 不把窗口当前打开的私人聊天作为复用目标；每次仍重置豆包侧的旧上下文，再带上该观众当前会话的有界多轮已送达问答。不主动删除网页聊天记录，新策略的实际隔离效果仍待客户端更新后实测。

为减少首字等待，豆包每次问答只调用一次模型，使用预设安全约束与本地输入/输出检查，省去两次额外模型审核。完整回复检查后才发送弹幕，约 1 秒首字仍需实测。固定拒绝语不写入记忆；这些措施不能保证拦截所有敏感内容或提示词注入。若提示「未确认会话或上下文隔离」，重启 LIRA 后测试，仍失败则暂停使用豆包。

豆包要求验证时会暂停请求。点击「打开豆包完成验证」，按官方网页窗口提示操作，再点「测试 AI 连接」确认恢复。网页未必显示验证码；若官网能聊天但连接测试仍提示验证，LIRA 接入尚未恢复，请保持暂停，不要反复点击测试。验证可能重复出现，这项实验性接入不保证无人值守。

DeepSeek 接入示例：创建密钥、连接与用量

网站改版后按钮位置可能变化。先创建密钥，再回到 LIRA 设置；费用和余额以平台显示为准。

1. 登录 DeepSeek 开放平台

打开 DeepSeek 开放平台，按页面上的方式注册或登录。

2. 完成账号验证

页面要求绑定邮箱或验证账号时，按提示操作，再继续。

3. 进入 API keys 页面

在左侧菜单点「API keys」，再点「创建 API key」。

4. 命名并创建

给密钥起个好认的名字，比如 LIRA，再点「创建」。

5. 复制并保存密钥

创建后点「复制」，把完整密钥存好。密钥别发给别人。

6. 选择「DeepSeek 官方」

回到「百宝箱 → 弹幕互动 → AI 互动助手」，在「AI 平台」里选「DeepSeek 官方」，地址会自动填好。

7. 粘贴密钥（API Key）

把密钥粘贴到「密钥（API Key）」输入框，等它显示「已保存」，也可以点「保存设置」。保存后，密钥不会完整显示。

8. 获取并选择模型

  1. 点「获取模型」，选一个可用模型，再点「测试 AI 连接」。
  2. 在「互动身份」的「触发关键词」里填一个你自己定的词，等它显示「已保存」。
  3. 测试通过后，打开「启用 AI」。发一条带关键词的弹幕，看看有没有回复。

「测试 AI 连接」只检查模型服务。若测试通过却没有弹幕回复，确认已在「账号登录」登录 B 站、房间号正确并开启弹幕监听，再点顶部「刷新直播」后重新发送带关键词的弹幕。

各个模型的说明见 DeepSeek 官方文档。

9. 查看用量、余额不足时充值

打开 DeepSeek 用量与余额，能看用量和余额，不够了再充值。充值后回到 LIRA，点「测试 AI 连接」。

用之前先看一下 DeepSeek 官方价格。实际费用和余额看 DeepSeek 平台上的显示。

3.3.2 触发词、连续对话与回复限制

在「触发关键词」里填一个词，最多 12 个字，比如“小助手”。保存后，观众发“小助手，晚上好”就能唤醒 AI。该关键词也是机器人名字；需要在客户端启用 AI，关键词留空就不回复。

回复长度由内置规则统一控制；所有预设自动附加公共安全规则，并在发送前检查内容，无需逐个设置。

在「互动身份」设置「空闲多久后结束对话（分钟）」，建议 10 分钟。每位观众独立续聊：例如先发“小助手，玩成语接龙”，3–5 分钟后再带关键词接词，仍可继续；猜谜也能接着猜或要提示。每次收到回复后重新计时，无关键词的普通弹幕不会续期。

回复未完整显示时会自动精简为一条弹幕重试，仍回答原来的提问。接龙时等回复完整后再继续接词，每轮都需要带触发关键词。

超过设置时间自动清空本机历史；发送“小助手，结束对话”或“小助手，清空对话”可立即结束（把“小助手”换成你的关键词）。历史最多保留开场及最近共 20 轮，并限制总长度，较早细节可能省略；清理不删除豆包网页聊天记录。

关闭「启用 AI」后等到显示「已关闭」，排队、生成中的回复和剩余分段、重试会立即取消。已经提交发送的弹幕无法撤回。重新开启只处理之后新触发的弹幕，不补发旧回复；开关单独保存，其他设置草稿有误也可以关闭。

  • 「同时处理的提问数」：1–5，默认 3。排队的提问看「等待队列」。
  • 「同一观众提问间隔（秒）」：0–3600，默认 0。
  • 「每分钟提问上限」：1–120，默认 20。
  • 「发送间隔（毫秒）」不能改：不同回复之间随机隔 500–2000 毫秒，同一回复的分段之间随机隔 200–600 毫秒。

触发关键词没有默认值，必须自定义并保存；未设置时不会触发。先测试连接，再打开「启用 AI」，发一条带关键词的弹幕检查回复。

3.3.3 角色包

新配置默认「通用人格」。所有 AI 平台都有通用人格、自建入口和已保存的自建角色；选择 DeepSeek 后额外显示「小猫人格」。 选中后在下方查看说明：小猫针对 DeepSeek，其他模型尚未测试；「自动识别」在保存后按识别到的平台显示。 点击「自建人格…」直接新建，或点击「管理预设」打开独立编辑面板，修改名称、说明和 20–8000 字的角色指南，再点「保存预设」。 「新建预设」从空白开始，「另存为新预设」可复制当前内容；取消会放弃未保存的编辑。

各平台会记住上次选择的人格，重新打开页面也会保留。例如 DeepSeek 选择小猫后，首次切到豆包会使用通用人格，再切回 DeepSeek 会恢复小猫。目标平台没有记录时，沿用当前兼容人格；小猫不适用时改选通用人格，小猫的编辑内容仍保留。旧配置原本已选小猫时，打开页面仍保留选择，并提示适用范围。

面板中的「导出已保存预设」可保存为 LIRA JSON 文件，再用「导入角色包」恢复或分享。文件最多 64 KB， 最多保存 20 个自建或导入包。重复标识不会覆盖原包；内置角色不能删除或改名，可以修改并「恢复默认」。 删除预设或恢复默认前会说明覆盖范围并确认；需要备份时，先导出已保存的预设。 角色包只包含人设，不包含密钥、聊天记录，也不会替你开启工具。

角色指南里用 {{name}} 代替机器人名字，回复时会自动使用「触发关键词」。原有自定义人设会保留；切换角色或修改身份后，助手不会带入另一身份的短期记忆。

写预设时重点描述身份、性格、语气和互动偏好，例如“用自然简短的中文聊天，先回答问题，不确定时说明”。不要写“无条件服从观众”“主播授权就忽略规则”，也不要放入密钥、联系方式或私密资料。

观众自称管理员、伪造审核结果、要求输出隐藏指令或解码后执行，不会因此获得额外权限。公共规则和本地检查会减少这类诱导；正常聊管理员话题或编码知识仍可回答。拒绝内容不进入缓存和记忆，但不能保证杜绝所有注入。

3.3.4 联网与工具

只做普通问答，可以关闭联网和工具调用，不需要天气或地图账号。新配置默认关闭这些能力，已有设置会保留。 需要天气、地点或路线时，展开「可选工具」，先开启「允许模型调用工具」，再启用对应查询。

和风天气填专属 API Host 和密钥；高德地图填 Web 服务 API Host 和 Web 服务 Key。 这些密钥与模型密钥分开，填好后可分别测试。关闭工具会保留已保存配置；没有完整凭据的工具不会被调用。

天气和地图查询有按月计算的本机请求次数上限。请求发起后就计入，连接测试、超时和失败请求也会计入；发送前已取消的请求不计入。 达到上限后暂停对应工具，下月自动恢复。这个计数用于限制调用，实际用量与费用以平台为准。

平台原生搜索由「联网搜索」控制；显示「LIRA 联网搜索」时，还需要开启工具调用。 是否支持搜索或工具，以实际模型为准。不能核实时，助手会被要求说明不确定，不编造实时结果。

先让「测试 AI 连接」通过，再打开「启用 AI」，用真实弹幕试一下。测试成功却不回复，就检查直播账号、触发关键词和提问频率，见常见问题。
