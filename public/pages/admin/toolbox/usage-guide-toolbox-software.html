7.1 客户端设置与性能

7.1.1 客户端配色

打开「百宝箱 → 设置 → 客户端外观」，选一套配色，点「应用配色」。看到「配色已应用」，卡片上标了「当前使用」，就换好了。

这里改 LIRA 软件界面的颜色。想改直播画面或观众网页歌单，去下面各自的设置里改。

7.1.2 性能检测

打开「百宝箱 → 性能」，点「开始检测」，等 5 秒采样完成。

页面上有六张卡：电脑整体和 LIRA 各自的处理器、显卡、内存占用。电脑整体包含其他程序，LIRA 卡只算这个软件。直播卡顿时，对比一下就知道是谁占的。

「本机硬件」里能看型号、核心数、内存条等信息。GPU 温度只在检测时读取。

7.2 更新、重装与卸载

更新或重装时保持原安装位置。截图中的版本号可能与你的不同，不影响操作。

7.2.1 桌面更新
  1. 打开「百宝箱 → 桌面更新」，点「检查更新」。
  2. 有新版本会自动开始下载。如果显示「下载更新」，点它继续下载。
  3. 下载完成后，点「重启并更新」。

更新失败时，从项目主页或管理员那里拿新的安装包，按「更新、重新安装与卸载」覆盖安装。

「自动更新」开关按你的习惯选。要反馈问题，点「日志目录」那一行的「打开目录」，错误记录在里面。别把「数据目录」当成日志目录。

查看下载与重启两种状态
7.2.2 覆盖重装：下一步

安装程序提示已经装过 LIRA 时，保持「仅为我安装」选中，直接点「下一步」。

7.2.3 覆盖重装：安装位置

安装位置保持原样，直接点「安装」，就会覆盖成新版本。

小提示：「下一步」和「安装」在窗口底部同一个位置，依次点下去就行。

7.2.4 卸载 LIRA

先关掉 LIRA，再打开 Windows 的「设置 → 应用」，找到 LIRA，点「卸载」。

也可以到你安装 LIRA 的文件夹（比如 D:\Apps\LIRA）里，双击 Uninstall LIRA.exe。

只是想更新的话，不用卸载，按上面的步骤覆盖安装就行。卸载前想留着数据，先看「数据保存与换电脑」，备份好再卸。
