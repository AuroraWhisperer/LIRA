7.1 客户端设置与性能

7.1.1 客户端配色

打开「百宝箱 → 设置 → 客户端外观」，选一套配色，点「应用配色」。看到「配色已应用」，卡片上标了「当前使用」，就换好了。

喜欢柔和的灰粉色，可以选「烟粉 · 灰玫瑰」；喜欢更明亮的粉色渐变，可以选「玫瑰映光」。

这里改 LIRA 软件界面的颜色。想改直播画面或观众网页歌单，去下面各自的设置里改。

7.1.2 性能检测

打开「百宝箱 → 性能」，点「开始检测」。检测包含 5 秒采样，显卡结果可能稍晚返回，请等页面提示检测完成。

页面上有六张卡：电脑整体和 LIRA 各自的处理器、显卡、内存占用。电脑整体包含其他程序，LIRA 卡只算这个软件。直播卡顿时，对比一下就知道是谁占的。

「本机信息」顶部会自动显示 Windows 名称、版本号和 OS 内部版本，无需先点检测；下面能看硬件型号、核心数、内存条等信息。显存展示专用或预留容量，核显还可按需使用共享系统内存；GPU 温度只在检测时读取。

7.1.3 内置播放器输出

打开「百宝箱 → 设置 → 内置播放器输出」，在「输出通道」里选择耳机、扬声器或声卡通道。默认选「系统默认输出」；看到「输出通道已切换并保存。」就设置好了，下次打开 LIRA 继续使用。

这项设置控制 LIRA 内置播放器的声音。QQ 音乐和网易云音乐客户端仍在各自的设置里选择输出设备。

列表按电脑实际设备和驱动显示。WASAPI、DirectSound、WaveOut 是不同的播放方式，同一声卡可能有多项；通常先用「系统默认输出」或 WASAPI。安装了 ASIO 驱动时也会出现对应选项，标为「连接待检查」的驱动要成功打开后才显示实际输出声道。接入声卡、安装驱动后点「刷新设备」，列表数量会随电脑变化。

音频格式自动适配。麦克风、线路输入和声卡回送请到电音助手的设备输入选择。ASIO 播放不保证能被系统声音采集接住，需要声卡提供的硬件回送；想直接配合进程采集时优先使用 WASAPI。

配合电音助手时，这里的输出通道与助手的「原声通道」选同一个设备，「最终输出」另选一个独立通道。处理内置播放时，要先关闭「当前歌曲」，再切换输出通道。具体步骤见电音助手。

如果选中的设备被拔掉或暂时不可用，LIRA 会保留原选择并暂停播放。重新接好设备，或在这里换一个可用的输出通道后，再继续播放。

7.2 更新、重装与卸载

更新或重装时保持原安装位置。截图中的版本号可能与你的不同，不影响操作。

7.2.1 桌面更新
  1. 打开「百宝箱 → 桌面更新」，点「检查并下载更新」。
  2. 有新版本会自动开始下载，等待下载进度完成。下载失败时，可再次点击「检查并下载更新」重试。
  3. 下载完成后，点「重启并更新」。

更新失败时，联系管理员取得新的安装包，按「更新、重新安装与卸载」覆盖安装。

「启动时自动检查更新」只决定打开 LIRA 时是否检查；手动检查发现新版也会自动下载，下载完成后退出程序即安装。要反馈问题，点「日志目录」那一行的「打开目录」，错误记录在里面。别把「数据目录」当成日志目录。

查看下载与重启两种状态
7.2.2 覆盖重装：下一步

安装程序提示已经装过 LIRA 时，保持「仅为我安装」选中，直接点「下一步」。

7.2.3 覆盖重装：安装位置

安装位置保持原样，直接点「安装」，就会覆盖成新版本。

小提示：「下一步」和「安装」在窗口底部同一个位置，依次点下去就行。

7.2.4 卸载 LIRA

先关掉 LIRA，再打开 Windows 的「设置 → 应用」，找到 LIRA，点「卸载」。

也可以到你安装 LIRA 的文件夹（比如 D:\Apps\LIRA）里，双击 Uninstall LIRA.exe。

只是想更新的话，不用卸载，按上面的步骤覆盖安装就行。卸载前想留着数据，先看「数据保存与备份」，备份好再卸。
