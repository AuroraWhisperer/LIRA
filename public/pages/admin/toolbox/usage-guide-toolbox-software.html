7.1 客户端设置与性能

7.1.1 客户端配色

打开「百宝箱 → 设置 → 外观与声音」，点选一套配色，看到「配色已保存」就换好了；保存失败会恢复原选择，可以重新点选。

喜欢柔和的灰粉色，可以选「烟粉 · 灰玫瑰」；喜欢更明亮的粉色渐变，可以选「玫瑰映光」。

喜欢清爽的浅色，可以选「雾苔 · 亚麻」，亚麻白搭配柔和苔绿；喜欢温暖的深色，可以选「墨咖 · 香槟」，暖咖灰搭配香槟色。

这里改 LIRA 软件界面的颜色。想改直播画面或观众网页歌单，去下面各自的设置里改。

7.1.2 性能检测

打开「百宝箱 → 性能」，点「开始检测」。检测包含 5 秒采样，显卡结果可能稍晚返回，请等页面提示检测完成。

页面上有六张卡：电脑整体和 LIRA 各自的处理器、显卡、内存占用。电脑整体包含其他程序，LIRA 卡只算这个软件。直播卡顿时，对比一下就知道是谁占的。

「本机信息」顶部会自动显示 Windows 名称、版本号和 OS 内部版本，无需先点检测；下面能看硬件型号、核心数、内存条等信息。显存展示专用或预留容量，核显还可按需使用共享系统内存；GPU 温度只在检测时读取。

7.1.3 内置播放器输出

打开「百宝箱 → 设置 → 外观与声音 → 内置播放器输出」，在「输出通道」里选择耳机、扬声器或声卡通道。默认选「系统默认输出」；看到「输出通道已切换并保存。」就设置好了，下次打开 LIRA 继续使用。

这项设置控制 LIRA 内置播放器的声音。QQ 音乐和网易云音乐客户端仍在各自的设置里选择输出设备。

列表按电脑实际设备和驱动显示。WASAPI、DirectSound、WaveOut 是不同的播放方式，同一声卡可能有多项；通常先用「系统默认输出」或 WASAPI。安装了 ASIO 驱动时也会出现对应选项，标为「连接待检查」的驱动要成功打开后才显示实际输出声道。接入声卡、安装驱动后点「刷新设备」，列表数量会随电脑变化。

音频格式自动适配。麦克风、线路输入和声卡回送请到电音助手的设备输入选择。系统声音采集不一定能采到 ASIO 播放的声音；如需采集，需要声卡提供硬件回送。想直接配合进程采集时，优先使用 WASAPI。

配合电音助手时，这里的输出通道与助手的「原声通道」选同一个设备，「最终输出」另选一个独立通道。处理内置播放时，要先关闭「当前歌曲」，再切换输出通道。具体步骤见电音助手。

如果选中的设备被拔掉或暂时不可用，LIRA 会保留原选择并暂停播放。重新接好设备，或在这里换一个可用的输出通道后，再继续播放。

7.1.4 系统通知

打开「百宝箱 → 设置 → 通知提醒」，修改后自动保存到本机。「工作台日程提醒」默认开启，只提醒在工作台勾选了「系统通知提醒」的日程；关闭后保留日程，再次开启不补发已过期的提醒。

「大额礼物通知」默认关闭。开启后可修改「通知金额」，默认 1000 元；单次礼物结算总额大于该金额时，通过 Windows 通知显示观众、礼物与总额，等于门槛时不提醒。门槛可填非负金额，最多两位小数；启动或重新开启前的旧礼物不补发通知。

系统通知支持 Windows 10 和 Windows 11，LIRA 需保持运行，切换页面或最小化不影响提醒。若没有弹出，请检查 Windows 的 LIRA 通知权限、横幅与勿扰或专注助手设置。礼物页内的礼物提示仍由该页原有开关控制。

7.2 更新、重装与卸载

更新或重装时保持原安装位置。截图中的账号、设备与更新版本为示例，与你的环境可能不同，不影响操作。

7.2.1 桌面更新
  1. 打开「百宝箱 → 设置 → 关于与更新」，点「检查并下载更新」。
  2. 有新版本会自动开始下载，等待下载进度完成。下载失败时，可再次点击「检查并下载更新」重试。
  3. 下载完成后，点「重启并安装更新」。LIRA 退出后会显示更新安装进度窗口；完成后窗口自动关闭，并重新打开 LIRA。

更新失败时，可下载官方安装包，按「更新、重装与卸载」中的步骤覆盖安装。

「启动时自动检查更新」只决定打开 LIRA 时是否检查；手动检查发现新版也会自动下载。下载完成后直接退出程序也会显示安装进度，完成后保持 LIRA 关闭。要反馈问题，在「本地数据与支持」点「日志目录」那一行的「打开目录」，更新错误详情在 errors/desktop.log，终端警告与错误在 errors/terminal.log。别把「数据目录」当成日志目录。

7.2.2 覆盖重装：用户协议与隐私政策

安装程序第一页提供简要说明，点击《用户协议》或《隐私政策》可前往官网分别阅读全文。默认选中「我不同意」，「下一步」暂时不可用。阅读后，选择「我同意用户协议，并已阅读隐私政策」，再点「下一步」。

不同意就点「取消」退出安装，原来装好的 LIRA 不受影响。

下方安装截图来自旧版，仅示意操作位置；协议图是手动同意后的状态。当前版本、产品名称和默认选项以安装程序为准。

7.2.3 覆盖重装：下一步

安装程序提示已经装过 LIRA 时，保持「仅为我安装」选中，直接点「下一步」。

7.2.4 覆盖重装：安装位置

安装位置保持原样，直接点「安装」，就会覆盖成新版本。

小提示：「下一步」和「安装」在窗口底部同一个位置，依次点下去就行。

7.2.5 卸载 LIRA

先关掉 LIRA，再打开 Windows 的「设置 → 应用」，找到 LIRA，点「卸载」。

也可以到你安装 LIRA 的文件夹（比如 D:\Apps\LIRA）里，双击 Uninstall LIRA.exe。

本版卸载程序只清理明确的程序文件、日志和更新缓存，默认保留 data 以及帮助识别重装目录的 lira-installation.ini。手工放入的其他文件会留下；勾选“同时删除用户数据”并再次确认才会删除用户数据。旧版卸载器可能没有这项文件保护，混放过其他资料时请先备份，再用新版安装包覆盖更新。

只是想更新的话，不用卸载，按上面的步骤覆盖安装就行。卸载前想留着数据，先看「数据保存与备份」，备份好再卸。
