7软件维护与数据

更新软件、保存资料、换机前后核对状态。首次安装见安装、账号与连接。

7.3 数据保存与备份

7.3.1 数据保存范围

跟着 LIRA 账号走：需要联网同步

  • 歌库。
  • 直播间号、弹幕监控和礼物监控。点歌规则包括点歌接收状态、接受 SC 点歌、指令必须带空格、允许观众取消点歌、歌名匹配方式、总队列与个人排队上限、不同身份的点歌间隔与每日上限、粉丝牌与大航海资格、单首歌曲冷却、大航海优先插队、只允许歌库歌曲和禁止同名点歌。
  • 点歌用户黑名单按观众的 B 站 UID 拦截，随 LIRA 账号同步。
  • B 站直播账号的登录状态、盲盒配置、网页歌单背景图。
  • 弹幕触发礼物特效、自动答谢礼物、弹幕查询礼物统计这三个开关。

同步歌库会整份覆盖。两台电脑都改过歌库时，请先备份要保留的版本。

只保存在本机：换机前单独保存

  • 点歌屏蔽词只保存在这台电脑，按「点歌」后面的内容完整匹配。换机前请另存词表。
  • 点歌队列、播放队列、LIRA 里的播放历史。
  • 点歌板、展示板、直播歌词、歌曲信息、实时榜单、开播动画、时钟、全屏礼物感谢、大航海感谢、滚动礼物、礼物许愿、心动盲盒和盲盒盈亏榜的画面设置，以及投票与评分的外观。
  • 直播场景、文本框和导入的素材库。
  • 弹幕姬外观：按当前账号保存在本机，包括样式、参数和区域随机弹幕的停留时间。完整修改自动保存，失败时保留输入并提供重试入口；只改预览不会保存。
  • 礼物导出目录、月底冲刺目标、礼物提示开关。
  • QQ 音乐和网易云的登录状态、全民 K 歌缓存路径。换电脑后要重新登录音乐平台，重新选缓存位置。
  • 日历、备忘、待办、粉丝档案、周表生成器模板与素材、世界地图城市列表、电音助手与客户端设置、小游戏历史，以及动态抽奖最新的一场活动和所有未结束活动。

QQ 音乐和网易云的「我喜欢」「收藏歌单」存在音乐平台账号里，不在 LIRA。重新登录对应平台就能看到。

服务器记录与持续运行的功能见关闭客户端后的运行范围。网页模拟游戏的进度保存在当前浏览器中，不随 LIRA 账号同步；清除网站数据会丢失游戏进度。登录同一账号不是整机备份。

7.3.2 粉丝档案备份与恢复

打开「百宝箱 → 主播工具 → 粉丝档案 → 设置」。

导出与备份：「导出档案表格」方便查看，不能用于恢复。要保留全部资料，在「保存完整备份」下点「保存备份」。每个账号只保留在恢复或合并前自动生成的最新两个恢复点；需要长期保存的版本，请另行导出完整备份。档案不会自动同步到另一台电脑。完整备份文件最多支持 10000 份档案、16 MB；超出时会提示并停止导出，不会生成无法恢复的文件，本机资料仍保留。本机恢复点不受这两个文件限制。

换机后，用「从备份文件恢复」导入完整备份，先核对预览中的资料冲突及可能新增的屏蔽影响。选「保留本机档案」会保留已有档案的当前显示或屏蔽状态，新补回的档案仍使用备份中的屏蔽状态。如果恢复的是合并前的备份，可补回草稿，已移入其他档案的手记和点歌汇总留在当前位置，再次合并不会重复累计这些点歌。选「用备份中的档案完整替换」会按备份恢复冲突档案、记录和归属，也可能按预览新增屏蔽；两种方式都不会自动解除当前黑名单。

如果提示旧备份的点歌来源无法确认，或汇总与本机记录部分重叠，本次恢复会停止，当前资料和恢复点保持原样。核对后，用包含原先两份档案的完整合并前备份选择「用备份中的档案完整替换」，或从本机恢复点恢复后再合并。

要使用本机恢复点，选「恢复到之前的状态」，它会恢复该账号当时的全部档案，也会先保存现在的状态。归档找回见归档与找回，无需通过备份恢复。

7.3.3 素材和场景备份与恢复
  1. 先保存样式参数和场景，在「组件 → 素材管理」点「导出素材与场景备份」，另外保留作者原始 ZIP。
  2. 在新电脑的「素材管理」中选择「从备份恢复为副本」，核对清单后恢复素材和参数，并将场景恢复为副本。
  3. 重新填写外部浏览器源、选择本地加班机背景，检查布局后「保存并应用」。没有专用备份时，可重新导入作者 ZIP 并手动调整布局。

备份不包含未保存草稿、外部浏览器源及本地加班机背景路径。歌库表格另用导出歌库 Excel保存。

7.4 换电脑与迁移

7.4.1 换电脑前后检查
  1. 在旧电脑核对要保留的歌库，导出歌库并确认云端版本。
  2. 保存粉丝档案完整备份和素材与场景备份。
  3. 在新电脑用原账号登录，等待账号数据读完，核对歌库和直播间设置。
  4. 重新登录音乐平台、选择歌词缓存位置；恢复专用备份，按保存范围核对本机设置。
  5. 按投屏设置核对新电脑的地址、尺寸、样式和歌词来源；只复制直播软件场景不能迁移本机素材与设置。

别把旧电脑的整个数据文件夹复制到新电脑。里面有这台电脑的授权和本机状态。歌库导出和粉丝档案备份只包含各自的内容，替代不了全部数据。

7.5 数据目录与日志入口

7.5.1 打开数据目录与日志目录

打开「百宝箱 → 设置 → 系统与关于」，在「本地数据与诊断」点数据目录或日志目录旁的「打开目录」。两者用途不同，反馈报错时按问题反馈准备提示原文、时间和日志。
