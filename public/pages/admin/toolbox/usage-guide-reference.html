07软件维护与数据

更新软件、保存资料、换机前后核对状态。首次安装见安装、账号与连接。

07.3 数据保存与备份

07.3.1 数据保存范围

跟着 LIRA 账号走：需要联网同步

  • 歌库。
  • 点歌设置：直播间号、弹幕监控、礼物监控、暂停点歌、最多排队歌曲数、点歌间隔、只允许歌库歌曲、允许重复点歌。
  • B 站直播账号的登录状态、盲盒配置、网页歌单背景图。
  • 弹幕姬已应用的样式和参数，包括区域随机弹幕的停留时间。没点「应用到直播画面」的改动不会保存。
  • 弹幕触发礼物特效、自动答谢礼物、弹幕查询礼物统计这三个开关。

歌库是整份覆盖，不会自动合并两台电脑的修改。盲盒配置会同步，但月底冲刺目标、全屏礼物感谢这些礼物设置不会。

只保存在本机：换机前单独保存

  • 点歌队列、播放队列、LIRA 里的播放历史。
  • 点歌板、展示板、桌面歌词、开播动画、萌时钟、全屏礼物感谢、滚动礼物、礼物许愿的设置，投票与评分的外观。
  • 直播场景、文本框和导入的素材库。
  • 礼物导出目录、月底冲刺目标、礼物提示开关。
  • QQ 音乐和网易云的登录状态、全民 K 歌缓存路径。换电脑后要重新登录音乐平台，重新选缓存位置。
  • 日历、备忘、待办、粉丝档案、小游戏历史、动态抽奖最近 50 场记录。

QQ 音乐和网易云的「我喜欢」「收藏歌单」存在音乐平台账号里，不在 LIRA。重新登录对应平台就能看到。

服务器记录与持续运行的功能见关闭客户端后的运行范围。网页模拟游戏存在当前浏览器，不随 LIRA 账号同步；清除网站数据会丢失游戏进度。登录同一账号不是整机备份。

07.3.2 粉丝档案备份与恢复

打开「百宝箱 → 粉丝档案 → 设置」。

导出与备份：「导出档案表格」方便查看。要留全部资料，用「保存完整备份」。恢复时用「从备份文件恢复」或「恢复到之前的状态」，先看清确认说明。档案不会自动同步到另一台电脑。

在「保存完整备份」下点「保存备份」。换机后从「从备份文件恢复」导入，或按需使用「恢复到之前的状态」；先核对确认说明。归档找回见归档与找回，不需要备份恢复。

07.3.3 素材和场景备份与恢复
  1. 先保存样式参数和场景，在「组件 → 素材管理」点「导出素材与场景备份」，另外保留作者原始 ZIP。
  2. 新电脑在「素材管理」选择「恢复备份」，核对清单后恢复素材、参数及场景副本。
  3. 重新填写外部浏览器源、选择本地加班机背景，检查布局后「保存并应用」。没有专用备份时，可重新导入作者 ZIP 并手动调整布局。

备份不包含未保存草稿、外部浏览器源及本地加班机背景路径。歌库表格另用导出歌库 Excel保存。

07.4 换电脑与迁移

07.4.1 换电脑前后检查
  1. 在旧电脑核对要保留的歌库，导出歌库并确认云端版本。
  2. 保存粉丝档案完整备份和素材与场景备份。
  3. 在新电脑用原账号登录，等待账号数据读完，核对歌库和直播间设置。
  4. 重新登录音乐平台、选择歌词缓存位置；恢复专用备份，按保存范围核对本机设置。
  5. 重新复制画面地址，到 OBS 或直播姬检查尺寸、样式和歌词来源。

别把旧电脑的整个数据文件夹复制到新电脑。里面有这台电脑的授权和本机状态。歌库导出和粉丝档案备份只包含各自的内容，替代不了全部数据。

  1. 链接里的 127.0.0.1 指的是这台电脑。换电脑后，要在新电脑上运行 LIRA，再核对复制出来的地址、端口和画面设置。地址不一定会变。
  2. 到新电脑的各功能页核对源宽高、样式和歌词来源。只复制直播软件里的场景，不等于全都搬过来了。
  3. 服务器弹幕姬用的是在线地址，另外核对账号授权和服务器连接。两类画面各自需要什么，见投屏设置。

07.5 数据目录与日志入口

07.5.1 打开数据目录与日志目录

打开「百宝箱 → 桌面更新」，点数据目录或日志目录旁的「打开目录」。两者用途不同，反馈报错时按问题反馈准备提示原文、时间和日志。
