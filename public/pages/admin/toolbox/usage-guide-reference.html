14数据保存与换电脑

登录同一个 LIRA 账号，能找回一部分数据，但这不是整台电脑的备份。换电脑前，先分清下面三类。

跟着 LIRA 账号走的数据需要联网同步
  • 歌库。
  • 点歌设置：直播间号、弹幕监控、礼物监控、暂停点歌、最多排队歌曲数、点歌间隔、只允许歌库歌曲、允许重复点歌。
  • B 站直播账号的登录状态、盲盒配置、网页歌单背景图。
  • 弹幕姬已应用的样式和参数，包括区域随机弹幕的停留时间。没点「应用到直播画面」的改动不会保存。
  • 弹幕触发礼物特效、自动答谢礼物、弹幕查询礼物统计这三个开关。

歌库是整份覆盖，不会自动合并两台电脑的修改。盲盒配置会同步，但月底冲刺目标、礼物边框这些礼物设置不会。

只保存在这台电脑的数据换机前单独保存
  • 点歌队列、播放队列、LIRA 里的播放历史。
  • 点歌板、展示板、桌面歌词、开播动画、萌时钟、礼物边框、滚动礼物、礼物许愿的设置，投票与评分的外观。
  • 直播场景布局、场景预设、文本框和导入的素材库。
  • 礼物导出目录、月底冲刺目标、礼物提示开关。
  • QQ 音乐和网易云的登录状态、全民 K 歌缓存路径。换电脑后要重新登录音乐平台，重新选缓存位置。
  • 日历、备忘、待办、粉丝档案、小游戏历史、动态抽奖最近 50 场记录。

QQ 音乐和网易云的「我喜欢」「收藏歌单」存在音乐平台账号里，不在 LIRA。重新登录对应平台就能看到。

在服务器持续运行的内容退出客户端仍可运行

礼物记录存在服务器上。自动答谢、弹幕查询礼物统计、签到机器人、抽签机器人、PK 对手信息播报、进场欢迎都在服务器上运行。服务器弹幕姬也不需要客户端一直开着。

这些功能要服务器和直播间都连着才能用。只关掉客户端，服务器上的功能不会停。想停止接收直播消息，就分别关掉弹幕姬的「监控弹幕」和礼物页的「监控礼物」，再确认设置已经同步。

弹幕不能长期回查，断线期间的弹幕也不会补发。礼物有没有记全要看同步提示，重新打开客户端不代表已经补齐。

换电脑前后各做一次检查
  1. 在旧电脑打开「点歌 → 导入导出」，导出歌库。确认云端歌库是你要留的那份。
  2. 打开「百宝箱 → 粉丝档案 → 设置」，在「保存完整备份」下点「保存备份」。另外保存套装原始 ZIP、图片、视频和导出文件，并记录要沿用的画面布局与设置。
  3. 找管理员要短效登录码，在新电脑上选「登录已有账号」。别重新注册。
  4. 等账号数据读完，核对歌库和直播间设置。重新登录音乐平台，恢复粉丝档案备份，再把画面设置重新调一遍。
  5. 需要本机素材时，在新电脑重新导入套装 ZIP 或添加原图片、视频，再在画布中选用并核对布局，最后点「保存并应用」。素材导入不会自动恢复旧电脑的布局。
  6. 在新电脑上，从对应面板重新复制投屏地址，到直播姬或 OBS 里检查画面。

别把旧电脑的整个数据文件夹复制到新电脑。里面有这台电脑的授权和本机状态。歌库导出和粉丝档案备份只包含各自的内容，替代不了全部数据。

找数据和日志：打开「百宝箱 → 桌面更新」，点数据目录或日志目录旁边的「打开目录」。反馈问题时，附上提示原文和发生时间。日志按管理员的要求提供，别公开账号凭证。

15外观速查

先找到你想改的画面，再去对应的设置。直播画面和观众网页歌单的外观在不同地方改。

客户端配色

打开「百宝箱 → 设置 → 客户端外观」，选一套配色，点「应用配色」。看到「配色已应用」，卡片上标了「当前使用」，就换好了。

这里改 LIRA 软件界面的颜色。想改直播画面或观众网页歌单，去下面各自的设置里改。

点歌板

「点歌 → 点歌板」：先在 6 种「点歌板风格」里选一种，再调配色、字号和滚动。详见点歌页。

歌曲展示板

「点歌 → 展示板」：调字号、滚动速率和排序，也可以同步点歌板的主题。它展示的是歌库，不是排队的歌。

桌面歌词

「点歌 → 桌面歌词设置」：调字体、颜色、描边、透明度和逐字效果。先放一首有歌词的歌再看效果，没放歌时一片空白是正常的。

弹幕姬

「百宝箱 → 弹幕姬」：先选固定位置或区域随机样式，再调参数，点「应用到直播画面」。网页主播中心只提供服务器弹幕姬地址，样式在客户端设置。

礼物画面

「百宝箱 → 礼物姬」：切到「礼物边框」「滚动礼物」「礼物许愿」，按各页提示保存和预览。许愿有礼物卡片、文字版、圆形徽章三种；文字版怎么插图片和数量，见礼物许愿说明。

时钟与开播动画

「百宝箱 → 萌时钟」：选风格，改完点「保存时钟设置」。「开播动画」能改文字、人物图、音乐和画质，总开关同时管预览和投屏。

观众网页歌单

客户端「点歌 → 导入导出」能改背景；网页主播中心能改名称、背景、字体和配色。详见网页歌单外观。

投票与评分

「百宝箱 → 小游戏 → 投票与评分」：设置活动和画面外观，用单独的浏览器源。外观只存在这台电脑上。

先分清点歌板和歌曲展示板

点歌板显示排队等着唱的歌，歌曲展示板展示歌库。两个都能放进直播画面，但内容不一样。

其他效果图和设置图见百宝箱；复制地址和画面尺寸见直播姬 / OBS 投屏。

16名词小词典

看到不熟悉的词，可以直接在文档搜索框里搜。

点歌队列与播放队列

点歌队列是观众点的歌。播放队列是播放器接下来要放的歌。「导入点歌」把点歌队列加进播放队列。详见播放页。

点歌板与展示板

点歌板给观众看排队的歌，歌曲展示板滚动展示歌库。两个都不能放歌。

桌面歌词与逐字歌词

桌面歌词是单独显示歌词的画面，也能用浏览器源加进 OBS 或直播姬。逐字歌词会跟着演唱一个字一个字高亮，要歌曲本身带这种歌词才行。

弹幕姬

把直播间弹幕显示成气泡或文字，还能设置回复、屏蔽和机器人。直播画面用的是服务器地址。

礼物姬

设置礼物边框、滚动礼物和礼物许愿的地方。查礼物记录要去顶部的「礼物」页。

加班机

用倒计时显示还要播多久。收到符合规则的礼物，可以加减时间或触发别的效果。先设好初始时间和礼物规则。

盲盒与盈亏

盲盒会开出不同价值的礼物。盈亏 = 开出礼物的价值 − 开盒成本，正数是赚，负数是亏。它不等于主播实际到账的收入。

大航海与 SC

大航海是 B 站的舰长、提督、总督这些付费身份。SC 是醒目留言（Super Chat），是付了钱的留言，和普通弹幕不一样。

浏览器源与投屏地址

OBS 的「浏览器源」或直播姬的「浏览器」能把一个网页放进直播画面。把 LIRA 给的地址粘进去就行，不用录整个软件窗口。

本机与服务器

本机就是你正在用的这台电脑。服务器是联网后帮你保存数据、运行部分功能的那一端。带 127.0.0.1 的地址只能在运行 LIRA 的那台电脑上用。

网页歌单与主播中心

网页歌单公开给观众挑歌。主播中心要用 LIRA 账号登录，用来看礼物、改网页歌单外观、复制服务器弹幕姬地址。

注册激活码 短效登录码 密码重置码

注册激活码：第一次注册账号用。短效登录码：换电脑或重装后登录客户端用。密码重置码：在网页上重置忘记的密码用。都找管理员要，不能混着用。
