08.1 安装、登录与授权异常

08.1.1 打开软件时无法登录
  1. 看到「无法连接授权服务器，请检查网络后重试。」或连接超时：先恢复网络，再点「重试连接」。
  2. 选对模式：第一次用选「注册新账号」；重装或换电脑选「登录已有账号」。两种模式要填的码不一样。
  3. 显示「准备未完成」：按页面提示重试。这和用户名、密码填错不是一回事，不用反复注册。
  4. 还是不行，就记下完整提示。如果是账号停用、授权撤销或设备绑定不一致，找管理员处理，别自己删登录文件。完整步骤见快速上手。
  5. 看到「本机授权已通过，可继续准备。」时点「继续准备」。提示数据不兼容时，把提示发给管理员，不要重新注册。

08.1.2 提示用户名保留或已被使用
  1. 看到「此用户名为系统保留名称，请更换。」：换一个名字。
  2. 看到「此用户名已被使用；已有账号请选择“登录已有账号”。」：这是你的账号，就切到「登录已有账号」；不确定是谁的，找管理员。

用户名和密码的完整要求见注册与激活；忘记密码见重置密码。

08.1.3 管理员给的码用不了，或提示过期、已使用
  1. 先确认码和模式对得上：「注册新账号」填注册激活码；「登录已有账号」填短效登录码，用户名也要是这串码对应的账号。密码重置码不能当登录码用。
  2. 检查码有没有复制完整。
  3. 看到「此激活密钥已过期，请联系管理员重新生成。」或「此激活密钥已使用或已撤销。」：这串码不能再用了。把错误提示发给管理员，领一个新的对应的码，不用另建账号。
08.1.4 提示设备授权被撤销、协议不兼容或构建校验失败
  1. 看到「当前设备授权已被管理员撤销。」：找管理员核对授权。
  2. 看到「本机保留的旧设备授权已撤销，请获取新的短效登录码后重新登录。」：找管理员要新的短效登录码，再用原账号登录。
  3. 提示客户端协议不兼容、构建校验失败，或「当前客户端版本不可使用，请更新 LIRA。」：用管理员给的新版安装包更新。
  4. 更新后还是失败，把完整错误和版本号发给管理员。别删数据或改程序文件来跳过校验。
08.1.5 提示“当前设备已由另一个 LIRA 进程登录”
  1. 同一台电脑上开了不止一个 LIRA，就会出现这个提示。关掉多余的窗口，只留要用的那个，再点「重试连接」。
  2. LIRA 窗口都关了还在提示：按 Ctrl + Shift + Esc 打开任务管理器，确认残留的是 LIRA，选中后点「结束任务」，再重新打开 LIRA。结束前先保存没做完的操作。
  3. 还提示会话被替换，找管理员核查，不用重新注册。
08.1.6 安装包被 Windows 或杀毒软件拦截
  1. 先确认安装包来自项目主页，或者管理员给的可信渠道。
  2. 把拦截提示截图、文件名和版本号发给管理员，确认后再按管理员说的处理。别关掉整套防护，也别去不明网站重新下载。
  3. 可以装到 D 盘，比如 D:\Apps\LIRA。安装和更新步骤见快速上手。
08.1.7 装完双击没反应，或页面空白
  1. 先看看是不是已经有 LIRA 窗口、没关的弹窗，或者还在准备中。系统弹出拦截或错误提示的话，先按提示处理。
  2. 关掉重复打开或残留在后台的 LIRA，再重新打开。只是画面不正常，可以检查 Windows 和显卡厂商的驱动更新。别先清空数据。
  3. 如果提示缺少模块（Cannot find module），使用新的完整安装包安装回原目录。没有窗口却提示无法关闭 LIRA 时，先保存未完成的操作，在任务管理器中结束此安装目录残留的 LIRA，再重试安装；也可重启电脑后直接安装。不要先卸载或清空数据。
  4. 反复出现的话，记下电脑环境、操作步骤和错误提示。能进软件时，到「百宝箱 → 桌面更新」，点「日志目录」旁边的「打开目录」，把日志发给管理员。
08.1.8 更新一直卡住
  1. 打开「百宝箱 → 桌面更新」，看现在是在检查、下载，还是等重启。
  2. 网络恢复后，重新点「检查更新」或「下载更新」。下载完才能点「重启并更新」。
  3. 一直失败：先保存没做完的工作，再用项目主页或管理员给的安装包，装回原来的位置。
  4. 把更新提示和日志发给管理员。卸载或删数据不是常规修法。
