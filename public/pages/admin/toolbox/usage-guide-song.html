2.1 歌库管理

2.1.1 新增、编辑与查找

打开「点歌 → 歌库」。上方的表单用来加歌：填好「歌曲名字」和「原唱/首发歌手」，再按需要填分类、语言、标签、点歌价格、歌切等，最后点「保存歌曲」。

  • 查找：搜索框能搜歌名、歌手、分类或标签。还能按分类、语言、歌手、标签筛选，或选「只看可点」。
  • 修改与删除：点歌曲行最右边的 ··· 按钮，选「编辑」或「删除」。把「是否可点」设为「否」，歌就会停用：不公开，也不会被随机点歌抽到。
  • 批量修改：到「导入导出」选「更新匹配歌曲（先预览）」，核对差异后再确认更新。
  • 同步：联网后，歌库的修改（包括删除）会同步到同一账号的其他电脑和网页歌单。点歌队列和播放队列不同步。
查看歌库列表和筛选
2.1.2 表格导入与批量更新
  1. 打开「点歌 → 导入导出」，点「下载导入模板」。按模板的列名填表：歌曲名字、原唱/首发歌手、歌曲分类、歌曲标签、是否可点、语言、点歌价格、歌切、核对平台、核对备注。
  2. 选择 XLSX、CSV 或 TSV 文件，或者从 Excel 复制表格，粘贴到输入框。多个歌手、分类、语言和平台用「/」分隔，多个标签用逗号分隔。
  3. 平时补歌，选「仅新增，跳过已有歌曲」，再点「导入歌库」。歌名和歌手都相同的已有歌曲会跳过，价格也不会更新。
  4. 要批量修改，选「更新匹配歌曲（先预览）」，点「预览更新」。核对新增、更新和冲突，再点「确认更新歌库」。表格里没有的列不会改动。「用表格中的空白内容清除原有信息」没把握就别勾。
  5. 看结果提示里新增、更新、重复跳过和失败的数量。重复跳过说明歌库里已经有这首歌，不算失败。有失败时，先检查对应的行和表头。

歌名和歌手都相同，才会更新原来的歌；改了歌名或歌手，会当成新歌。点歌价格可以填免费、30元SC、舰长这类说明，它只是给观众看的文字，不会自动收款。

查看导入结果提示

歌库最多 5000 首，更新导入时原有歌曲和新增歌曲一起计算。超过上限时先导出备份，再整理重复或不再使用的歌。表头和文件格式要与模板一致，只改扩展名无效。

超过数量上限会提示「歌库超过 5000 首限制。」或「结果歌库超过 5000 首，无法完整同步；请先在歌库整理至 5000 首以内。」。整理后重新核对再同步。

2.1.3 导出与账号同步

登录 LIRA 并联网后，歌库会自动同步到同一账号的其他电脑。以下操作用于导出备份或手动覆盖同步。

想备份表格，点「导出歌库 Excel」。导出的表格一首歌一行，可以拿来检查，也能再导入。

歌曲在客户端「点歌 → 歌库」里加和改。歌库跟着 LIRA 账号同步。网页主播中心只能看歌，不能改歌。

  1. 先确认这台电脑的歌库是全的。要手动同步，就打开「点歌 → 导入导出」。
  2. 点「同步到网页」，看完覆盖提醒再确认。
  3. 等同步结果出来，再点「查看网页歌单」看看。失败了就按提示检查网络或歌曲信息，再试一次。

整份替换，不会合并。同步会用这台电脑的歌库替换云端歌库，网页歌单和同一账号的其他电脑也会跟着变。歌库最多 5000 首。别在两台电脑上同时改歌库。

「本机上次同步」只记你手动点「同步到网页」的时间。不能靠它判断这台电脑和云端是否完全一样。

2.2 点歌管理

2.2.1 SC 队列 + 点歌队列

「点歌」页上方左边是 SC 队列，右边是点歌队列。SC（醒目留言）是观众付费发的留言。观众发「点歌 歌名」就能点歌，歌名不完整也会尝试匹配歌库。

  • 置顶 / 取消置顶：调整点歌顺序。每首歌旁边还有「复制歌名」和「删除」。
  • 完成队首：把点歌队列的第一首标为完成。要切换正在放的音乐，用播放页的播放器。
  • 清空点歌队列：移除队首和全部等待点歌，歌库不受影响。
  • 重启恢复：关闭或更新 LIRA 后重新打开，未完成点歌会按原顺序恢复。开始新一场时可点「清空点歌队列」。
  • 队列满了：新的点歌进不来。先唱完或删掉几首，也可以到「点歌板」调大「最多排队歌曲数」。

点歌队列记的是观众想听什么，播放队列决定接下来放什么。完整导入操作见管理播放队列与导入点歌。

弹出「收到点歌请求」时，先看歌名、匹配到的歌和点歌人，再选「下一首播放」或「跳过」。「下一首播放」会把歌曲排到当前歌曲之后，当前音乐继续播放；播放器空闲时，点播放按钮开始。

2.2.2 设置点歌规则

打开「点歌 → 点歌板」，上方就是点歌规则和黑名单。改完点底部的「保存点歌设置」。再往下是「点歌板样式」。B 站账号和直播间号仍在「设置」页。

  • 暂停接收点歌：选「接收点歌」或「暂停点歌」。暂停点歌只停接点歌，不会停止接收其他直播消息。
  • 最多排队歌曲数：默认 50，可填 1–300。
  • 同一观众点歌间隔（秒）：默认 0，也就是不设间隔；可填 0–3600。
  • 只允许点歌库歌曲 / 允许重复点歌：按你的直播规则选。
  • 点歌板黑名单：点「添加词条」后直接输入，可以编辑和删除。词条太长时，在输入框里选中文字或移动光标查看。只有「点歌」后面的内容和词条完全一样才会拦截：比如词条 78 会拦截「点歌78」，不拦截「点歌78号公路」。要取消拦截，删掉全部词条再保存。

看到「点歌队列已达到上限。」时，先唱完或删掉已处理的点歌，再让观众重试。清空会删除全部等待歌曲，不必为了腾一个位置就清空。

「队列里已经有这首歌。」按「允许重复点歌」处理；「当前已暂停接收点歌。」需改回「接收点歌」并保存。改好后让观众重发，暂停期间被拒的点歌不会自动补回。

同一观众点歌间隔未到时，请求会被悄悄拦下。点歌规则跟着账号同步；暂停点歌不会停止接收礼物。

2.2.3 随机点歌

观众发「随机点歌」，会从歌库里随机抽一首。后面还可以加语言、分类、歌手或标签。多个条件用 + 或空格隔开，抽到的歌会同时满足所有条件：

  • 按语言：日语、韩语、英语、粤语、国语
  • 按分类：流行、R&B、说唱、摇滚、民谣、舞曲、影视原声
  • 按歌手：直接输入歌手名
  • 按标签：国风、小甜歌、影视OST、K-Pop 等
  • 组合示例：「随机点歌 日语+流行」「随机点歌 说唱 苦情」

随机点歌需要先登录 B 站账号，歌曲须可点。多个条件要同时满足，可先减少条件核对。到「百宝箱 → 弹幕互动」打开「随机点歌回复」后，没有符合条件的歌曲会自动 @ 提醒观众。
