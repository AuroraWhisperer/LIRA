05点歌页详解

SC 队列 + 点歌队列

「点歌」页顶部是醒目留言（SC）和点歌队列。SC 是观众付费发送的留言；观众发送「点歌 歌名」即可点歌，歌名不完整时也会尝试匹配歌库。

  • 置顶 / 取消置顶：调整点歌顺序；条目旁另有「复制歌名」和「删除」。
  • 切歌：把点歌队列第一首标为完成。要切换正在播放的音乐，请使用播放页的播放器。
  • 清空全部队列：只移除点歌队列，不会删除歌库。
  • 队列满了：新的点歌不会继续加入；先唱完或删除部分歌曲，也可在「点歌板」调整最多排队歌曲数。

点歌队列记录观众想听什么，播放队列决定播放器接下来放什么。去「播放 → 播放队列 → 导入点歌」，才能将点歌列表导入播放器。

出现「收到点歌请求」通知时，先核对歌名、匹配信息和点歌人，再选「下一首播放」或「跳过」。这张通知用于决定是否加入播放器。

歌库管理

打开「点歌 → 歌库」。顶部表单用于新增歌曲；填好歌曲名字、原唱/首发歌手后，按需要填写分类、语言、标签、点歌价格与歌切等信息，再保存。

  • 查找：可搜索歌名、歌手、分类或标签，配合分类、语言、歌手、标签和「只看可点」筛选。
  • 修改与删除：在歌曲行使用相应操作。设为「不可点」的歌曲不会公开，也不会被随机点歌选中。
  • 批量修改：可到「导入导出」用表格的「更新匹配歌曲（先预览）」批量更新，确认差异后再应用。
  • 同步：联网后歌库修改会同步到同一账号的其他电脑和网页歌单；删除也会同步。点歌队列和播放队列不会同步。

随机点歌

观众发送「随机点歌」可随机抽一首歌，也可以加上语言、分类、歌手或标签。多个条件用 + 连接，歌曲需要同时满足这些条件：

  • 按语言：日语、韩语、英语、粤语、国语
  • 按分类：流行、R&B、说唱、摇滚、民谣、舞曲、影视原声
  • 按歌手：直接输入歌手名
  • 按标签：国风、小甜歌、影视OST、K-Pop 等
  • 组合示例：「随机点歌 日语+流行」「随机点歌 说唱 苦情」
点歌页还有哪些功能

点击点歌页中的对应标签即可打开：

  • 设置：直播账号登录和直播间号。弹幕监控在弹幕姬页面，礼物监控在礼物页面。
  • 点歌板：点歌规则、点歌板黑名单，以及直播姬 / OBS 投屏队列的颜色、字号、滚动模式等样式。
  • 展示板：歌单展示板的滚动速率、歌曲排序方式和主题配色。
  • 浏览器源：打开场景编辑器、复制直播场景地址，或直接复制各组件的独立 OBS / 直播姬浏览器源地址；无需统一管理时，独立组件使用已保存样式即可。
  • 导入导出：导入 XLSX、CSV、TSV 或粘贴表格，也可下载导入模板、导出歌库 Excel。
  • 桌面歌词设置：设置歌词浏览器源的字体、颜色、字号、描边和透明度，并实时预览最终效果。

「浏览器源」页集中列出常用地址，其他地址在对应功能面板复制。服务器弹幕姬链接需要 LIRA 授权及服务器配置读取成功；直播消息接收还需配置直播账号。

设置点歌规则

打开「点歌 → 点歌板」，点歌规则和黑名单会直接展示。修改后点击面板底部的「保存点歌设置」；下方可调整「点歌板样式」。直播账号、直播间和接收消息总开关仍在「设置」页。

  • 暂停接收点歌：选择「接收点歌」或「暂停点歌」，与停止接收全部直播消息不同。
  • 最多排队歌曲数：默认 50，可填 1–300。
  • 同一观众点歌间隔（秒）：默认 0，可填 0–3600；0 表示不设间隔。
  • 只允许点歌库歌曲 / 允许重复点歌：按直播规则选择对应选项。
  • 点歌板黑名单：点击「添加词条」后直接输入，支持编辑和删除；长词可在输入框内选中文字或移动光标查看。仅拦截「点歌」后内容与词条完全一致的请求，例如 78 拦截「点歌78」，不拦截「点歌78号公路」。删除全部词条并保存即可取消拦截。
导入和导出歌库表格
  1. 打开「点歌 → 导入导出」，点击「下载导入模板」。按模板列名填表：歌曲名字、原唱/首发歌手、歌曲分类、歌曲标签、是否可点、语言、点歌价格、歌切、核对平台、核对备注。
  2. 选择 XLSX、CSV 或 TSV 文件，或从 Excel 复制表格后粘贴到输入框。多个歌手、分类、语言和平台用「/」分隔，多个标签用逗号分隔。
  3. 日常补歌选「仅新增，跳过已有歌曲」，点击「导入歌库」。同名同歌手的已有歌曲会跳过，不会更新价格。
  4. 需要批量修改时，选「更新匹配歌曲（先预览）」并点击「预览更新」，核对新增、更新和冲突后再点「确认更新歌库」。未提供的列不修改；不要随意勾选「用表格中的空白内容清除原有信息」。
  5. 查看结果提示中的新增、更新、重复跳过或错误计数。重复跳过不等于导入失败；有错误时先检查对应行和表头。
  6. 需要备份表格时，点「导出歌库 Excel」。导出的表格按歌曲逐行列出，可用于检查和再次导入。

歌名和歌手都相同才会更新原歌曲；改名或换歌手会当作新歌。点歌价格可填免费、30元SC、舰长等说明，不要把说明当成自动收款规则。

云端歌单同步

登录 LIRA 并联网后，歌库会自动同步到同一账号的其他电脑。给观众的网页歌单入口和手动同步步骤见「网页歌单同步」。

先核对再覆盖：「同步到网页」会用这台电脑的歌库替换云端歌库；同账号其他电脑也会更新，不会自动合并。

歌单页背景

「点歌 → 导入导出 → 歌单背景」可上传公开歌单的背景图；单张不超过 5 MB。点击「恢复默认背景」恢复默认水彩背景。完整操作见「网页歌单名称与背景」。
