08百宝箱详解

左侧工具按四组排列，可展开或折叠：直播互动（弹幕姬、礼物姬、动态抽奖、小游戏）；直播画面（加班机、礼物特效、开播动画、萌时钟）；主播工作（粉丝档案、主播工作台）；软件与帮助（设置、性能、使用文档、桌面更新）。

账号与安全

在「百宝箱 → 设置 → 账户与网站」查看当前 LIRA 账号和设备信息，也可打开 LIRA 官网（lirahub.cn）和账号登录网页（admin.lirahub.cn）。忘记密码、添加或移除设备，请联系管理员。

换电脑：安装后选「登录已有账号」，填写原用户名、密码和管理员新发的短效登录码。注册激活码不能重复使用；桌面客户端没有切换或退出 LIRA 账号的入口。

歌库和部分设置跟随账号同步；点歌与播放队列、音乐平台登录、本机画面样式、日历和粉丝档案等需分别处理。服务器弹幕姬已应用的样式会跟随账号，详见「数据保存与换电脑」。

注意：不要直接复制旧电脑的数据文件夹；在新电脑登录原账号，本地资料使用所属功能的备份入口保存。

弹幕姬

打开「百宝箱 → 直播互动 → 弹幕姬」。先看连接状态区的发送账号、目标直播间和是否可发送，必要时点右侧刷新。未登录或未设置直播间时，先回「点歌 → 设置」完成配置。

  1. 选样式：固定位置共 6 种（聊天气泡、深色面板、蝴蝶结、经典样式、透明文字、头像横卡）；全屏随机共 3 种（简洁白卡、奶油气泡、流光气泡）。
  2. 调节对应参数。例如「深色面板」可改字体、正文字号（18–48 px）、弹幕文字颜色、背景不透明度和礼物通知图片。全屏随机样式另有 2–30 秒停留时间。
  3. 点击「预览效果」看示例。满意后点「应用到直播画面」，将「直播画面链接」添加到 OBS 或直播姬。

只预览不会改变直播画面；应用后不用重新复制链接。服务器弹幕姬不依赖桌面进程持续运行，但仍需要服务器与直播间连接正常。

屏蔽不想显示的内容

「用户黑名单」按 UID 添加，也可从当前直播间在线榜读取观众；「敏感词屏蔽」用于屏蔽指定词语。点「一键清空屏蔽词」会移除已有屏蔽词，请先确认。

发送弹幕与自动回复

在发送区输入文字，按 Ctrl + Enter 发送，并查看发送结果；这里还可设置自动钓鱼 / 打劫。该区域没有独立网页地址。

「回复与辅助」包括随机点歌回复、签到机器人、抽签机器人、自定义关键词回复、进场欢迎、PK 对手信息播报和昵称生僻字自动注音。按需要开启；自定义关键词需填写关键词与回复后保存，欢迎与 PK 的参数在各自设置中展开。

随机点歌回复可在观众所给条件没有匹配歌曲时自动 @ 提醒。签到、抽签、进场欢迎和 PK 播报由服务器运行，关闭客户端不会自动停止。

AI 互动助手

触发关键词没有默认值，需要主播自定义并保存。观众发送的弹幕包含已保存的触发关键词时，AI 会生成回复并发送到直播间；未设置关键词时不会触发回复。

  • AI 平台：选择你使用的平台，填写它提供的密钥（API Key），再获取并选择模型。密钥保存后不会完整显示。
  • 回复规则：填写自定义触发关键词，等待显示「已保存」，再设置回复长度、联网搜索和深度思考。是否支持这些功能，以所选平台和模型为准。
  • 扩展能力：按需接入和风天气、高德地图，让助手能回答天气、地点和路线问题。
  • 高级设置：调整同时处理的提问数、同一观众提问间隔、每分钟提问上限，以及 AI 的性格和说话方式。设置好后，点击「测试 AI 连接」。
查看 AI 配置入口
礼物姬

打开「百宝箱 → 直播互动 → 礼物姬」，有「礼物边框」「滚动礼物」「礼物许愿」三个页签。它们各自提供直播画面地址。

礼物边框

默认页签。触发金额默认 20 元，填 0 表示所有付费礼物；动效可选「跟随系统 / 完整动效 / 简化动效」。设置后点「保存礼物边框设置」，用「播放预览」试效果，再复制地址添加到直播软件。

滚动礼物

按四档金额区间设置配色，调整显示行数（1–10）、滚动速率（1–50）和最小礼物金额（0 表示不限制）。「本日礼物循环」在零点换日。

修改先进入草稿，点「保存滚动与样式设置」后应用；「恢复默认」和「取消修改」按需要使用。复制地址后，浏览器源建议宽 900，高度随行数调整。金额配色也会用于之后的礼物图片导出。

查看滚动礼物设置
礼物许愿
  1. 打开「百宝箱 → 礼物姬 → 礼物许愿」，先选周期：「长效许愿」从每条创建时累计；「本日许愿」北京时间零点换日；「本场直播许愿」下次开播重新计数。
  2. 点击「选择心愿礼物」，从本直播间或全部缓存礼物里按名称 / ID 查找。注意区分盲盒本体与盲盒开出的礼物。
  3. 填写目标数量（整数，默认 10，可填 1–999999999），选择礼物卡片、纯文字或圆形徽章，点击「添加许愿」。备注选填，不会显示在直播画面。
  4. 在已保存的预览中查看已收数量 / 目标数量，必要时点「刷新进度」。进度按所选周期内该礼物的已记录数量计算，不按金额；修改目标会保留已收进度。
  5. 在「放进直播画面」点「复制地址」，添加到 OBS / 直播姬浏览器源，建议宽 440，高度随内容调整。三个周期各有地址，可分别添加。

纯文字样式可使用 {礼物}、{已收}、{目标} 自动显示名称和数量，例如「许愿{礼物}（{已收}/{目标}）」。

查看纯文字许愿设置
动态抽奖
  1. 进入「百宝箱 → 直播互动 → 动态抽奖」，点击「登录账号」，使用内容作者的 B 站账号。这里独立登录，不影响直播账号。
  2. 粘贴动态或视频链接，填写中奖人数（默认 10，可填 1–100）。
  3. 按内容类型选择参与条件。动态可按界面选关注作者、点赞、转发等；视频只支持评论与关注，不能核验视频点赞和分享名单。所有勾选条件必须同时满足。
  4. 点击「获取参与名单」，等所选名单全部获取完成后再开奖。只统计点击按钮之前发布的评论；关注条件在开奖时核验。
  5. 查看「中奖结果」与「开奖凭证」，需要回看时打开「查看抽奖记录」，本机保留最近 50 场。

如果提示「B站限制了获取速度，请稍等」，等待名单继续获取；名单不完整时会暂停，不会自动降低你选择的条件。

小游戏

打开「百宝箱 → 直播互动 → 小游戏」，先把「游戏网页」地址添加到直播软件。数字炸弹、五子棋、你画我猜共用这一画面；结束当前游戏后再开下一局。

  • 数字炸弹：可指定 1 位观众，也可选择「不限观众数量」，按面板设置范围并开始，让观众按提示猜数字。
  • 五子棋：主播执黑先行并点击棋盘；指定观众执白，用 B2 这样的弹幕坐标落子。
  • 你画我猜：选择回合（1–12）、每局时长（15–300 秒）和本场词库（可多选），再开始。题词只在主播面板显示；主播在游戏网页作画，观众发答案弹幕。按需要「结束作画」「公布答案」「下一题」。

画板快捷键：B 画笔、E 橡皮、L 直线、R 矩形、O 圆形、I 取色，Ctrl + Z 撤销。直播时避免把带题词的主播面板直接投给观众。

查看你画我猜设置与主持区

转转盘

转盘有独立地址。填写至少两个选项，为每项设置份数，保存后开始抽取；某项份数占总份数的比例就是它的抽中概率。

查看转盘设置
投票与评分

在「百宝箱 → 小游戏」找到「投票与评分」，先复制这里的「浏览器源」到直播软件，建议尺寸 800 × 600。投票与评分共用这个画面，每次只能运行一场，与三款小游戏及转盘的地址不同。

  1. 弹幕投票：填投票主题（选填，最多 60 字符）和选项（每项最多 10 字符），设置分钟 / 秒或选择时长预设，点击「开始投票」。让观众按画面提示发送选项。
  2. 观众评分：切到评分，填写主题；评分固定为 1–10 整数。需要避免互相影响时，勾选「收集中不显示平均分」，再点「开始评分」。
  3. 收集期间查看状态；到时或点击「结束本场」后查看结果。先结束当前场次，再开始另一种互动。
查看评分设置
加班机

先设置初始时长和礼物规则，再点「启用加班机」，最后点「开始」启动倒计时。收到符合规则的礼物时，剩余时间会按规则调整。

  • 规则可选「直接改时间」「随机抽结果」或「文字展板」。时间操作支持增加、减少、乘除倍数和清零；文字展板只展示文字，不改变剩余时间。
  • 「按连击组」每组结算一次；「按具体数量」收到数量 ×N 就结算 N 次。
  • 可通过「刷新在售礼物」更新可选礼物目录；设置初始时长或点击「重置」会恢复初始时长并暂停倒计时。「最近结算」保留最近 20 组已完成或忽略的礼物记录。
  • 「直播画面」区域可复制投屏地址、打开实时预览；背景可透明或选内置样式，透明背景适合直接叠加到直播姬或 OBS。
  • 注意：「暂停」只会停下倒计时，收到礼物仍可能改变时间。要停止礼物改时，请关闭加班机。「待结算」表示还在等待处理的礼物。

初始时长可以手动按「时:分」输入，也可分别选择小时和分钟，再点「设置初始时间」。看到「在售目录：未刷新」时，先点「刷新在售礼物」，再选择礼物编辑规则。

礼物特效

收到指定礼物时在直播画面上播放全屏动画。输入礼物 ID 点「播放特效」即可测试效果；「直播投屏」卡片里的地址固定不变，复制到直播姬的「浏览器」或 OBS 的「浏览器源」后，收到对应礼物会自动播放，平时画面透明不占位置。也可以点「打开预览」直接在浏览器里查看。

不知道礼物 ID 时，点面板的「查找礼物 ID」前往 gifts.lirahub.cn。开启弹幕触发后，观众可用四种写法：礼物特效 32132、礼物特效32132、🎁 32132、🎁32132；请替换为需要的礼物 ID。

开播动画与萌时钟

开播动画

打开「百宝箱 → 直播画面 → 开播动画」，填写主标题（最多 20 字）、副标题、主播名和底部文案。画质有「普通 · 推荐」「高 · 更多氛围粒子」「低 · 轻量模式」，轨道动效有三种，另可开关漂浮音符与音乐律动。

可上传人物图（不超过 16 MB）和开场音乐，音乐音量默认 35%。「显示整套特效」同时控制预览和投屏。将固定浏览器源地址加入直播软件，画面按 16:9 设置。

查看人物、音乐与地址

萌时钟

选择桃桃便签、星夜软糖、汽水小鸭、横向刻度、竖向刻度或白字数显。按需要调整显示日期、显示秒数、小时格式和角标文案（最多 16 字）。修改会自动保存，不需要另找保存按钮。

复制「萌时钟网址」到浏览器源，推荐尺寸 580 × 210；它与开播动画使用不同地址。

粉丝档案

入口是「百宝箱 → 主播工作 → 粉丝档案」。档案、提醒、设置三个标签分别用于维护资料、查看提醒和管理备份；内容保存在当前电脑。

  1. 在「档案」页用「搜索昵称、备注名或 UID」找人；可选全部、在舰、曾上舰、特别关注、待补资料、待核实六种筛选。
  2. 点击「新建档案」，在基本信息中填写昵称、UID、备注名等，并按需添加标签和特别关注。
  3. 「生日与偏好」可填生日历法、生日、出生年份、提前提醒、星座和 MBTI；「备注与提醒」记录下次想聊什么、个人备注和大航海提醒。完成后保存。
  4. 选中档案查看详情；有需要时到「提醒」页查看生日和其他已设置的提醒。
查看新建档案与详情

同步、备份与档案管理

  • 同步与更新：可「同步大航海名单」或「重新加载档案」。要每天核对大航海身份，进入「设置自动更新」，单独勾选「每天自动更新大航海身份」（默认不勾选）。客户端开着时于北京时间 12:10 核对；错过后，当天首次打开软件时补更新。普通「自动更新」选项不等于已开启这项定时核对；这里也不会把私人档案同步到另一台电脑。
  • 导出与备份：「导出档案表格」便于查看；「保存完整备份」用于保留完整资料。需要恢复时选「从备份文件恢复」或「恢复到之前的状态」，先仔细看确认说明。
  • 档案管理：可查看「不再自动建档的粉丝」「已归档的档案」，以及「清除全部档案」。清除前先保存完整备份。
主播工作台

打开「百宝箱 → 主播工作 → 主播工作台」。日历可点「上个月 / 下个月 / 今天」切换；点「新建日程」填写「日程名称」、日期和时间（也可选「全天」），选择直播、工作或个人分类，按需补充备注后点「保存日程」。

备忘分为随手记、观众约定、复盘；需要落实的事情可作为待办，完成后勾选。留意「已保存到本机」提示，这些内容只在当前电脑保存。

性能检测

打开「百宝箱 → 性能」，点击「开始检测」，等待 5 秒采样窗口完成。页面同时放置六张卡：电脑整体与 LIRA 各自的处理器、显卡、内存占用；这里没有「电脑 / LIRA」切换按钮。

「本机硬件」区可查看型号、核心数、内存条等信息，GPU 温度仅在检测时读取。电脑整体包含其他程序，LIRA 卡只反映本软件；直播卡顿时可以据此分辨占用来源。

桌面更新
  1. 打开「百宝箱 → 桌面更新」，点击「检查更新」。
  2. 有新版本时会开始下载；如果显示「下载更新」，点击后继续下载。
  3. 下载完成后，点击「重启并更新」。

更新失败时，可从「项目主页」下载安装包，按本页「更新或重新安装」操作。需要反馈问题时，可以在「日志目录」找到错误记录。

「自动更新」开关按你的习惯选择。页面还分别提供「数据目录」与「日志目录」的「打开目录」按钮；反馈故障建议从这里打开日志目录，不要把数据目录当作日志目录。
