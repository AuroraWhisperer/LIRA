01快速上手

LIRA 帮你在 B 站直播时处理点歌、放歌和礼物，也能把这些内容做成直播画面，加到 OBS 或哔哩哔哩直播姬里。第一次用，先把下面四件事做好。点截图可以放大。

安装时：路径里别带中文首次安装

装到 D:\Apps\LIRA、C:\Apps\LIRA 这类文件夹就行，完整路径里不要有中文或表情。

像 D:\直播工具\LIRA、C:\Users\小明\Apps\LIRA 都带中文，最好换掉。

已经装好、用着没问题的，不用挪。以后更新也装回原来的位置。

登录 LIRA

第一次用，选「注册新账号」，填用户名、密码和管理员给你的注册激活码。已经有账号，就选「登录已有账号」。换了电脑或清空数据重装后，还要找管理员要一个新的短效登录码。

连接直播间

打开「点歌 → 设置」，扫码登录 B 站账号，填上你的直播间号，再点「保存设置」。连上之后就能收到弹幕和礼物。

添加歌曲

打开「点歌 → 导入导出」，下载模板，把歌填进去再导入。也可以在「歌库」里一首首手动加。

选择音乐平台

打开「播放」，选你常用的平台。QQ 音乐和网易云音乐在 LIRA 里登录；全民 K 歌要在它自己的电脑版里登录。

02账号与设备：先登录 LIRA，再连直播间

一共有三个账号，要分别登录：LIRA 账号用来登录软件，B 站账号用来收弹幕和礼物，音乐平台账号用来放歌。

第一步：注册或登录 LIRA首次必做

第一次打开 LIRA，会弹出下面这个登录窗口。

  1. 选「注册新账号」。
  2. 填上你想用的用户名和密码，再填管理员发给你的「注册激活码」。
  3. 点「注册并进入」。

用户名：会变成你网页歌单网址的开头，所以只能用英文字母、数字和中划线（-），2–32 个字符。不能用中文，中划线不能放在开头或结尾。大写字母会自动变成小写。

密码：8–64 个字符，大写字母、小写字母、中文、数字、符号里至少用三类。可以有空格，别用太常见的密码。

「注册激活码」框里的 XXXX-XXXX-XXXX-XXXX 只是格式示意，要换成管理员发给你的激活码。每个激活码只能用一次，用户名也不能和别人重复。

查看用户名、密码和注册码的说明

已经有账号：换了电脑或清空数据重装后，选「登录已有账号」，填原来的用户名、密码和管理员新发的「短效登录码」，再点「登录并进入」。别重新注册。

注册激活码和短效登录码都只能用一次，记得在管理员说的有效期内用掉。

登录之后：等它准备好

登录后会显示「正在为你准备直播工具」。保持联网，等进度走完。这台电脑登录过一次，以后打开会自动登录。

遇到这些提示，这样处理：

  • 连不上：先检查网络，再点「重试连接」。提示账号停用的话，找管理员。
  • 「准备未完成」：看一眼错误提示，检查网络后点「重试」。如果提示数据不兼容，把这条提示发给管理员，不用重新注册。
  • 看到「本机授权已通过，可继续准备。」：点「继续准备」。
  • 看到「本机保留的旧设备授权已撤销，请获取新的短效登录码后重新登录。」：找管理员要新的短效登录码，用原账号重新登录。别自己去删登录文件。
查看连接失败和准备失败的画面

关掉软件不等于退出账号：客户端里没有切换或退出 LIRA 账号的按钮。右上角「×」只是关掉软件；「点歌 → 设置」里的「退出登录」退出的是 B 站账号；网页主播中心另有自己的「退出登录」。

第二步：登录 B 站账号，填上你的直播间号直播必做
  1. 打开「点歌 → 设置」，点「扫码登录 B 站账号」，用手机上的哔哩哔哩 App 扫弹出来的二维码，再在手机上确认。
  2. 在「连接你的 B 站直播间」里填你的直播间号，也可以直接粘贴直播间链接。
  3. 点「保存设置」，等提示保存成功，再看一眼右上角的直播状态。连不上就点右上角的「刷新直播」。
查看「设置」在窗口中的位置

看到「本机已登录」只是扫码成功了，还要点「保存设置」，并确认直播间连上了。

弹幕和礼物默认一直在收。开关分别是弹幕姬的「监控弹幕」和礼物页的「监控礼物」，切换后自动保存。只想暂时不接点歌，就到「点歌 → 点歌板」把「暂停接收点歌」改成「暂停点歌」，再点「保存点歌设置」。

注意：关掉 LIRA 后，弹幕和礼物还会继续收。要停下来，就分别关掉弹幕姬的「监控弹幕」和礼物页的「监控礼物」，或者退出 B 站账号，再等同步完成。

第三步：登录你常用的音乐平台可选

用哪个平台，就在哪里登录：

  • QQ 音乐、网易云音乐：在 LIRA 里登录。到播放页顶部切换到对应平台，点右上角的「登录QQ音乐」或「登录网易云音乐」，按提示操作。
  • 全民 K 歌：在全民 K 歌自己的电脑版里登录，不用在 LIRA 里登。LIRA 只读取它正在播放的歌和逐字歌词。

03更新、重新安装与卸载

更新或重装时，运行新的安装程序，保持默认选项一路点下去就行。截图里的版本号可能和你的不一样，不影响操作。

1. 直接点「下一步」

安装程序提示已经装过 LIRA 时，保持「仅为我安装」选中，直接点「下一步」。

2. 位置不用改，点「安装」

安装位置保持原样，直接点「安装」，就会覆盖成新版本。

小提示：「下一步」和「安装」在窗口底部同一个位置，依次点下去就行。

卸载 LIRA

先关掉 LIRA，再打开 Windows 的「设置 → 应用」，找到 LIRA，点「卸载」。

也可以到你安装 LIRA 的文件夹（比如 D:\Apps\LIRA）里，双击 Uninstall LIRA.exe。

只是想更新的话，不用卸载，按上面的步骤覆盖安装就行。卸载前想留着数据，先看「数据保存与换电脑」，备份好再卸。

04日常开播：按这个顺序来

主界面顶部有五个页面：「点歌」「播放」「礼物」「组件」「百宝箱」。右上角能看直播间连接状态，也有「刷新直播」和关闭按钮。

第一次打开：跟着高亮区域操作新手引导

第一次进主界面，会自动弹出新手引导，带你登录 B 站账号、连直播间、导入歌单、认识组件和画布、选音乐平台。引导会实际打开「组件」，介绍左侧六个组件的入口。

照着气泡提示做完，再点「下一步」。跳过的步骤，用到之前要补上。走完引导不等于都设置好了。

想再看一遍，点「百宝箱 → 使用文档 → 重新查看新手引导」。

  1. 打开并登录 LIRA。 登录过的电脑会自动登录。连不上就检查网络，点「重试连接」。
  2. 确认直播间连上了。 到「点歌 → 设置」看看 B 站账号和直播间号对不对，改过就点「保存设置」。再确认弹幕姬的「监控弹幕」是开着的。
  3. 准备好歌库，开始接点歌。 观众发「点歌 歌名」，歌就会进点歌队列。你可以调顺序，也可以删掉。
  4. 放歌。 在「播放」页选平台、搜歌，加进播放队列。也可以打开播放队列点「导入点歌」，把观众点的歌加进来。底部播放器能暂停、切歌、拖进度。
  5. 按需打开其他工具。 「礼物」看送礼记录；「组件」配置弹幕姬、加班机等直播画面；「百宝箱」管理弹幕互动、小游戏等工具。想放到直播画面上，就复制对应功能的链接，加到直播姬或 OBS。
