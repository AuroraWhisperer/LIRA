1安装、账号与连接

三个账号分别登录：LIRA 账号用于进入软件，B 站账号用于直播间消息，音乐平台账号用于播放歌曲。

首次使用清单

LIRA 帮你在 B 站直播时处理点歌、放歌和礼物，也能把内容加到 OBS 或哔哩哔哩直播姬。先完成账号和连接，再按需准备歌曲与直播画面。点截图可以放大。

  1. 注册或登录 LIRA，等首次准备完成。
  2. 登录 B 站并连接直播间，确认监控状态。
  3. 导入歌库，也可手动添加歌曲。
  4. 选择音乐平台；暂时不用的功能可以跳过。

1.1 首次安装

1.1.1 安装时：路径里别带中文
首次安装

装到 D:\Apps\LIRA、C:\Apps\LIRA 这类文件夹就行，完整路径里不要有中文或表情。

像 D:\直播工具\LIRA、C:\Users\小明\Apps\LIRA 都带中文，最好换掉。

已经装好、用着没问题的，不用挪。以后更新也装回原来的位置。

1.2 LIRA 账号与设备

1.2.1 注册与激活
首次必做

第一次打开 LIRA，会弹出下面这个登录窗口。

  1. 选「注册新账号」。
  2. 填上你想用的用户名和密码，再填管理员发给你的「注册激活码」。
  3. 点「注册并进入」。

用户名：会变成你网页歌单网址的开头，所以只能用英文字母、数字和中划线（-），2–32 个字符。不能用中文，中划线不能放在开头或结尾。大写字母会自动变成小写。

密码：8–64 个字符，大写字母、小写字母、中文、数字、符号里至少用三类。可以有空格，别用太常见的密码。

「注册激活码」框里的 XXXX-XXXX-XXXX-XXXX 只是格式示意，要换成管理员发给你的激活码。每个激活码只能用一次，用户名也不能和别人重复。

查看用户名、密码和注册码的说明

已经有账号：换了电脑或清空数据重装后，选「登录已有账号」，填原来的用户名、密码和管理员新发的「短效登录码」，再点「登录并进入」。别重新注册。

注册激活码和短效登录码都只能用一次，记得在管理员说的有效期内用掉。

密码的 UTF-8 编码不能超过 72 字节；中文和符号多时尤其要注意。别加换行或看不见的字符。

看到用户名格式提示时，可按以上规则使用 demo-singer 这类名字。用户名不能含空格。

1.2.2 登录与设备授权

登录后会显示「正在为你准备直播工具」。保持联网，等进度走完。这台电脑登录过一次，以后打开会自动登录。

关掉软件不等于退出账号：客户端里没有切换或退出 LIRA 账号的按钮。右上角「×」只是关掉软件；「点歌 → 设置」里的「退出登录」退出的是 B 站账号；网页主播中心另有自己的「退出登录」。

1.2.3 账号与设备管理

打开「百宝箱 → 设置」，能看到当前登录的 LIRA 账号和这台电脑的设备名。这里也能打开 LIRA 官网（lirahub.cn）和账号登录网页（admin.lirahub.cn）。

忘记密码、添加或移除设备，找管理员。

查看设置页的账号信息

换电脑用原账号登录，具体顺序见换电脑与迁移。账号资料与本机资料的保存范围见数据保存与备份。

客户端没有切换或退出 LIRA 账号的按钮。要更换账号，先备份资料，再找管理员确认账号和设备如何处理。别直接删数据目录，也别复制别人的目录来换号；删本机文件不会清空服务器账本。

1.3 B 站登录与直播间

1.3.1 扫码登录、连接与刷新
直播必做
  1. 打开「点歌 → 设置」，点「扫码登录 B 站账号」，用手机上的哔哩哔哩 App 扫弹出来的二维码，再在手机上确认。
  2. 在「连接你的 B 站直播间」里填你的直播间号，也可以直接粘贴直播间链接。
  3. 点「保存设置」，等提示保存成功，再看一眼右上角的直播状态。连不上就点右上角的「刷新直播」。
查看「设置」在窗口中的位置

看到「本机已登录」只是扫码成功了，还要点「保存设置」，并确认直播间连上了。

1.4 监控与运行状态

1.4.1 弹幕和礼物监控

弹幕和礼物默认一直在收。开关分别是弹幕姬的「监控弹幕」和礼物页的「监控礼物」，切换后自动保存。只想暂时不接点歌，就到「点歌 → 点歌板」把「暂停接收点歌」改成「暂停点歌」，再点「保存点歌设置」。

注意：关掉 LIRA 后，弹幕和礼物还会继续收。要停下来，就分别关掉弹幕姬的「监控弹幕」和礼物页的「监控礼物」，或者退出 B 站账号，再等同步完成。

1.4.2 关闭客户端后的运行范围

礼物记录存在服务器上。自动答谢、弹幕查询礼物统计、签到机器人、抽签机器人、PK 对手信息播报、进场欢迎都在服务器上运行。服务器弹幕姬也不需要客户端一直开着。

这些功能要服务器和直播间都连着才能用。只关掉客户端，服务器上的功能不会停。想停止接收直播消息，就分别关掉弹幕姬的「监控弹幕」和礼物页的「监控礼物」，再确认设置已经同步。

弹幕不能长期回查，断线期间的弹幕也不会补发。礼物有没有记全要看同步提示，重新打开客户端不代表已经补齐。

本机加班机、礼物特效和本机画面需要 LIRA 开着。查看最新账本可用网页礼物流水，或重新打开客户端联网同步；断网时本机显示已保存的记录。

1.5 网页登录与密码重置

1.5.1 登录网页主播中心

打开「百宝箱 → 设置」，点「账号登录」。也可以直接打开 网页账号登录入口。用你的 LIRA 用户名和密码登录，就能进入主播中心。网页上的「退出登录」只退出网页。

登录后可查看礼物记录与分析、管理网页歌单，或复制直播弹幕姬地址。B 站账号和直播间仍在客户端设置。

1.5.2 忘记 LIRA 密码怎么办
  1. 找管理员要密码重置码。它只用来改密码，不能填进客户端的「短效登录码」框。
  2. 打开网页账号登录入口，点「使用重置码」。
  3. 「账号」填你的用户名，再填重置码、新密码和「确认密码」。点「确认重置」，成功后用新密码登录。

重置码有效期很短，只能用一次，要在管理员说的时间内用掉。提示过期或已用过，就找管理员要新的。重置码别发给别人。新密码的要求和注册时一样，见账号与设备。

开播检查与新手引导

主界面顶部有五个页面：「点歌」「播放」「礼物」「组件」「百宝箱」。右上角能看直播间连接状态，也有「刷新直播」和关闭按钮。

第一次打开：跟着高亮区域操作新手引导

第一次进主界面，会自动弹出新手引导，带你登录 B 站账号、连直播间、导入歌单、认识组件和画布、选音乐平台。引导会实际打开「组件」，介绍左侧六个组件的入口。

照着气泡提示做完，再点「下一步」。跳过的步骤，用到之前要补上。走完引导不等于都设置好了。

想再看一遍，点「百宝箱 → 使用文档 → 重新查看新手引导」。

  1. 登录 LIRA并等待准备完成。
  2. 确认直播间连接及弹幕和礼物监控。
  3. 核对点歌规则，准备开始接点歌。
  4. 整理播放队列并播放，按需导入观众点歌。
  5. 检查场景与组件，到 OBS 或直播姬确认画面。
