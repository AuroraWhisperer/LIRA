1安装、账号与连接

LIRA、B 站和音乐平台分别登录：LIRA 账号用于进入软件，B 站账号用于直播间消息，音乐平台账号用于播放歌曲。大航海到期同步可另外登录主播账号。

首次使用清单

LIRA 帮你在 B 站直播时处理点歌、放歌和礼物，也能把内容加到 OBS 或哔哩哔哩直播姬。先完成账号和连接，再按需准备歌曲与直播画面。点截图可以放大。跳转后，可点右下角的左箭头返回原阅读位置；上箭头返回顶部。

  1. 注册或登录 LIRA，等首次准备完成。
  2. 登录 B 站并连接直播间，确认监控状态。
  3. 导入歌库，也可手动添加歌曲。
  4. 选择音乐平台；暂时不用的功能可以跳过。

1.1 首次安装

1.1.1 安装时：路径里别带中文
首次安装

安装时可点击说明中的《用户协议》和《隐私政策》前往官网分别阅读全文；默认选择「我不同意」，确认同意后再继续安装。

双击安装包即可。即使选择「以管理员身份运行」，LIRA 也只为当前 Windows 用户安装。首次安装请选一个平时能在里面新建文件的空文件夹，不要选链接到其他位置的文件夹。更新时选原安装文件夹。卸载时保留过数据的，重装时也选原位置。

如果安装程序无法确认文件夹里已有文件的归属，会停止安装并保留原文件。请核对安装位置，切勿为继续安装而删除旧的 data 文件夹。如果提示旧版是为所有用户安装的，请先备份 data，卸载旧版时保留用户数据，再用日常使用的 Windows 账号安装。

装到 D:\Apps\LIRA、C:\Apps\LIRA 这类文件夹就行，完整路径里不要有中文或表情。

像 D:\直播工具\LIRA、C:\Users\小明\Apps\LIRA 都带中文，最好换掉。

已经装好、用着没问题的，不用挪。以后更新也装回原来的位置。

1.2 LIRA 账号与设备

1.2.1 注册与激活
首次必做

第一次打开 LIRA，会弹出下面这个登录窗口。

  1. 选「注册新账号」。
  2. 填上你想用的用户名和密码，再填管理员发给你的「注册激活码」。
  3. 点「注册并进入」。

用户名会出现在网页歌单的域名开头。选一个还没人用的名字，注册后无法在客户端改名。可用英文字母、数字和中划线（-），共 2–32 个字符。中划线只能放在中间，大写字母会转成小写。

新密码用 8–64 个字符，大写字母、小写字母、数字、汉字和符号中至少用三种。含中文或表情时，没到 64 个字符也可能太长。

「注册激活码」框里的 XXXX-XXXX-XXXX-XXXX 是格式示意。请填管理员发给你的激活码，每个码只能用一次。

已经有账号：换了电脑或清空数据重装后，选「登录已有账号」，填原来的用户名、密码和管理员新发的「短效登录码」，再点「登录并进入」。别重新注册。

短效登录码也只能用一次。两种码都要在管理员告知的有效期内使用。

登录已有账号时，请按原样输入密码，包括密码开头或结尾原有的空格。

看到用户名格式提示时，可按以上规则使用 demo-singer 这类名字。用户名不能含空格。

1.2.2 登录与设备授权

登录后会显示「正在为你准备直播工具」。保持联网，直播数据准备完成后会自动进入；字体和图片若未下载完，会在后台继续。这台电脑登录过一次，以后打开会自动登录。

若保存时提示「当前账号的设置尚未恢复」，请保持联网，等待该账号设置恢复后，再保存直播间设置或点歌规则。

关掉软件不等于退出账号：客户端里没有切换或退出 LIRA 账号的按钮。右上角「×」只是关掉软件；「点歌 → 账号登录」里的「退出登录」退出的是 B 站账号；网页主播中心另有自己的「退出登录」。

1.2.3 账号与设备管理

打开「百宝箱 → 设置 → 账号与连接」，能看到当前登录的 LIRA 账号和这台电脑的设备名，也能打开网页主播中心（admin.lirahub.cn）。

忘记密码、添加或移除设备，找管理员。

打开「百宝箱 → 设置 → 系统与关于」，点「LIRA 官网」可访问官网。点「用户协议」或「隐私政策」可在弹窗里阅读全文，离线也能查看。

查看设置页的账号信息

换电脑用原账号登录，具体顺序见换电脑与迁移。账号资料与本机资料的保存范围见数据保存与备份。

要更换账号，先备份资料，再找管理员确认账号和设备如何处理。别直接删数据目录，也别复制别人的目录来换号；删本机文件不会清空服务器账本。

1.3 B 站登录与直播间

1.3.1 扫码登录、连接与刷新
直播必做
  1. 打开「点歌 → 账号登录」，点「扫码登录 B 站账号」，用手机上的哔哩哔哩 App 扫弹出来的二维码，再在手机上确认。登录或退出后会自动刷新弹幕连接。
  2. 在「连接你的 B 站直播间」里填你的直播间号，也可以直接粘贴直播间链接。
  3. 点「保存设置」，等提示保存成功，再看一眼右上角的直播状态。连接异常会自动重试；若持续未恢复，可点右上角的「重新连接直播间」。若提示登录失效，需要重新扫码登录。
查看「账号登录」在窗口中的位置

看到「本机已登录」只是扫码成功了，还要点「保存设置」，并确认直播间连上了。

保存后，下方资料栏显示直播标题、房间号、开播状态，以及房主头像、昵称、主播等级、粉丝数、UID、粉丝牌、分区和公告。点「刷新资料」可更新这些信息，不会重新连接直播间。这里的「直播中／未开播／轮播中」是 B 站房间状态，与弹幕、礼物监听是否正常连接分开；上方登录的账号可以是机器人账号，不一定是房主。

需要同步大航海到期时间时，在本页的「大航海到期同步（可选）」选择「账号来源」。上方登录的是主播本人账号，就选「使用上方登录账号」。如果用机器人小号收发弹幕，选「单独登录主播账号（可选）」，再点「登录主播账号」。单独登录只用于同步到期时间，收发弹幕和记录礼物仍用原账号。切回「使用上方登录账号」会清除单独保存的主播登录。

在网页主播中心首页的「大航海到期提醒」下，展开「7 日内即将到期」或「已到期 7 日内」即可查看对应名单。客户端「粉丝档案」只给匹配到的观众标出剩余 0–3 天的提醒。

1.4 监控与运行状态

1.4.1 弹幕和礼物监控

弹幕和礼物默认一直在收。开关分别是弹幕姬的「监控弹幕」和礼物页的「监控礼物」，切换后自动保存。只想暂时不接点歌，就到「点歌 → 点歌规则」把「点歌接收状态」设为「暂停点歌」，修改后会自动保存。

注意：关掉 LIRA 后，弹幕和礼物还会继续收。要停下来，就分别关掉弹幕姬的「监控弹幕」和礼物页的「监控礼物」，或者退出 B 站账号，再等同步完成。

1.4.2 关闭客户端后的运行范围

礼物记录存在服务器上。云端的签到、抽签、昵称管理和礼物答谢在未开播时也可用。弹幕查询礼物统计、PK 对手信息播报、进场欢迎、完整匹配回复（完整触发词与菜单）和定时／随机弹幕只在直播中生效，下播后会保留开关状态。

这些功能要服务器和直播间都连着才能用。需要停收消息时，按上方监控说明关闭相应开关并确认同步。

弹幕不能长期回查，断线期间的弹幕也不会补发。礼物有没有记全要看同步提示，重新打开客户端不代表已经补齐。

点歌、点歌回复、关键词回复、AI 互动助手，以及本机加班机、礼物特效和本机画面需要 LIRA 开着。「关键词回复」按包含词匹配，与上面的完整触发词回复分开。查看最新账本可用网页礼物流水，或重新打开客户端联网同步；断网时本机显示已保存的记录。

1.5 网页登录与密码重置

1.5.1 登录网页主播中心

打开「百宝箱 → 设置 → 账号与连接」，点「网页主播中心」旁的「打开主播中心」。也可以直接打开 网页账号登录入口。用你的 LIRA 用户名和密码登录，就能进入主播中心。网页上的「退出登录」只退出网页。

左侧可切换首页、礼物流水与数据分析、网页歌单。B 站账号和直播间在客户端设置，弹幕直播画面也使用客户端提供的本机地址。

1.5.2 忘记 LIRA 密码怎么办
  1. 找管理员要密码重置码。它只用来改密码，不能填进客户端的「短效登录码」框。
  2. 打开网页账号登录入口，点「使用重置码」。
  3. 「账号」填你的用户名，再填重置码、新密码和「确认密码」。点「确认重置」，成功后用新密码登录。

重置码有效期很短，只能用一次，要在管理员说的时间内用掉。提示过期或已用过，就找管理员要新的。重置码别发给别人。新密码的要求和注册时一样，见账号与设备。

1.6 开播检查与新手引导

主界面顶部有五个页面：「点歌」「播放」「礼物」「组件」「百宝箱」。右上角简要显示已开播或未开播，点击状态可查看主播、直播间、弹幕和本机连接详情；点击详情框外部或切换到其他窗口时，详情自动收起。旁边的刷新图标用于「重新连接直播间」，鼠标悬停可查看名称。

本机服务断连时，右上角显示「本机重连中」并弹出一次提示；提示消失后仍可点击状态查看详情。恢复连接后自动回到直播状态。正常未开播不使用警告色，接收弹幕也不代表已开播。

1.6.1 第一次打开：跟着高亮区域操作新手引导

第一次进主界面，会自动弹出新手引导，带你登录 B 站账号、连接直播间和导入歌单。引导会打开「组件」页，带你认识左侧菜单，再介绍直播画布和音乐平台。

照着气泡提示做完，再点「下一步」。跳过的步骤，之后用到对应功能前要补上。走完引导不等于都设置好了。

想再看一遍，点「百宝箱 → 使用文档 → 重新查看新手引导」。

1.6.2 开播前检查清单

每次开播前，按下面几项检查一遍。点击链接可查看对应的操作说明。

  1. 登录 LIRA并等待准备完成。
  2. 确认直播间连接及弹幕和礼物监控。
  3. 核对点歌规则，准备开始接点歌。
  4. 整理播放队列并播放，按需导入观众点歌。
  5. 检查场景与组件，到 OBS 或直播姬确认画面。
