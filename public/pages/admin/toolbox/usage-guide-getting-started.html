01快速上手

安装前：建议使用英文路径首次安装

建议安装到 D:\Apps\LIRA 或 C:\Apps\LIRA 这样的文件夹，完整地址里不要有中文或表情。

例如，D:\直播工具\LIRA 和 C:\Users\小明\Apps\LIRA 都含有中文，不建议使用。

已经安装且使用正常，可以继续使用原位置；更新时不用改安装位置。

登录 LIRA

第一次使用，选择「注册新账号」，填写用户名、密码和管理员提供的注册激活码。已有账号，选择「登录已有账号」。如果换了电脑或清除数据后重装，还需要向管理员领取新的短效登录码。

连接直播间

打开「点歌 → 设置」，扫码登录直播账号，填写自己的直播间号，开启「接收弹幕和礼物」，再点击「保存设置」。确认连接正常后，就能接收弹幕和礼物。

添加歌曲

打开「点歌 → 导入导出」，下载模板、填写歌曲，再导入歌库。也可以在「歌库」中手动添加。

选择音乐平台

打开「播放」，选择常用的音乐平台。QQ 音乐和网易云音乐在 LIRA 中登录；全民 K 歌请在它自己的电脑版中登录。

02账号与设备：先登录 LIRA，再连接直播间

LIRA 账号用于登录软件；直播账号用于接收弹幕和礼物；音乐账号用于播放平台歌曲。它们需要分别登录。

第一步：在 LIRA 登录窗口注册或登录首次必做

首次打开会看到下面的 LIRA 登录窗口，这是桌面客户端自己的窗口。直接填写账号即可，不需要打开浏览器，也不用填写服务器地址。

  1. 第一次使用，选择「注册新账号」，标题会显示「注册 LIRA」，下方提示「创建账号并授权这台电脑」。
  2. 填写自己想用的用户名和密码，再填管理员发给你的「注册激活码」。
  3. 检查三个字段，点击「注册并进入」。

用户名规则：用户名会作为之后网页歌单地址的前缀（子域名）。支持 2–32 个英文字母、数字和中划线（-），不支持中文，中划线不能放在开头或结尾。大写字母会自动转为小写。

密码规则：新密码需 8–64 个字符，包含大写字母、小写字母、中文、数字、符号中的至少三类。可使用空格，请勿使用常见弱密码。

「注册激活码」输入框中的 XXXX-XXXX-XXXX-XXXX 只是格式提示，请替换为管理员发给你的实际注册码。它是一次性注册码，用户名也不能与其他人重复。

已有账号：换电脑或清除数据后重装时，选择「登录已有账号」。标题会变成「登录 LIRA」，提示「重装或使用新电脑，请向管理员获取短效登录码」。填写原用户名、密码和管理员新发的「短效登录码」，再点「登录并进入」。

注册激活码和短效登录码都只能成功使用一次，请在管理员告知的有效期内使用。

登录后等待准备；遇到提示，按对应步骤处理

登录后显示「正在为你准备直播工具」时，保持网络连接，等待进度完成。这台电脑登录过后，下次打开会自动登录。

登录窗口连接失败：先检查网络，再点「重试连接」。如果提示账号停用，请联系管理员。

「准备未完成」：根据错误提示检查网络，点击「重试」重新准备；如果提示数据不兼容，请把提示发给管理员，不用重新注册。

  • 看到「本机授权已通过，可继续准备。」：点击「继续准备」即可。
  • 看到「本机保留的旧设备授权已撤销，请获取新的短效登录码后重新登录。」：向管理员领取新的短效登录码，再用原账号登录；不要自行删除登录文件。

关闭软件与退出账号是两件事：桌面客户端没有切换或退出 LIRA 账号的入口。关闭客户端用右上角「×」；「点歌 → 设置」里的「退出登录」只退出 B 站直播账号；网页主播中心还有自己的「退出登录」。

第二步：登录直播账号，填写本直播间号直播必做
  1. 打开「点歌 → 设置」，点击「扫码登录直播账号」，用手机上的哔哩哔哩应用扫描弹出的二维码，按手机提示确认。
  2. 填写自己的「直播间号或链接」，开启「接收弹幕和礼物」。
  3. 点击「保存设置」，等待保存成功，再查看连接状态。连接异常时，点击右上角「刷新直播」。

把「接收弹幕和礼物」选为「启用」，再保存设置。想暂时不让观众点歌，可以单独把「暂停接收点歌」选为「暂停点歌」。

显示「本机已登录」只说明扫码成功，还需要保存设置并确认直播间连接正常。

注意：关闭 LIRA 后，仍会继续接收弹幕和礼物。需要停止时，关闭「接收弹幕和礼物」并保存，或退出直播账号，等待保存成功。

第三步：登录你常用的音乐平台可选

选择你要用的音乐平台，再到对应位置登录：

  • QQ 音乐、网易云音乐：在 LIRA 里登录——播放页顶部切换到对应平台，点右上角的「登录」按钮按提示操作。
  • 全民 K 歌：在全民 K 歌自己的电脑客户端里登录，不在 LIRA 里操作；LIRA 只读取本机客户端正在播放的歌曲和逐字歌词。

03更新、重新安装与卸载

以下安装截图来自旧版，只用于说明安装步骤；名称与版本以你下载的安装程序为准。

1. 直接点击“下一步”

如果安装程序提示当前用户已经安装过 LIRA，保持“仅为我安装”选中，直接点击“下一步”。

2. 保持原位置并点击“安装”

安装位置不用修改，直接点击“安装”即可重新安装或升级。

小提示：“下一步”和“安装”按钮在窗口底部的同一位置，保持默认选项连续点击即可。

需要卸载 LIRA 时

先关闭 LIRA，再打开 Windows 的「设置 → 应用」，找到 LIRA 并选择「卸载」，按提示完成。

也可以打开自己安装 LIRA 时选择的文件夹，双击 Uninstall LIRA.exe。例如安装在 D:\Apps\LIRA，就在这个文件夹里找；截图只用于辨认文件名，不代表固定安装位置。

若只是更新版本，按上方步骤覆盖安装即可。需要保留的数据，请先查看「数据保存与换电脑」，确认本机内容已备份后再处理。

04主流程：一次完整的开播操作

进入主界面后，顶部四个入口分别是「点歌」「播放」「礼物」「百宝箱」。右上角可查看直播连接状态、刷新直播和关闭窗口。

第一次打开：跟着高亮区域操作新手引导

首次进入主界面会自动弹出高亮引导，共 8 步加 1 个完成页：欢迎 → 顶部导航 → 登录直播账号 → 填写直播间 → 连接直播间 → 导入歌单 → 选择音乐平台 → 查看帮助。

按气泡提示完成操作，再点「下一步」。暂时跳过的登录、连接或导入步骤，仍需在使用对应功能前补好；看到完成页不代表这些设置已经全部完成。

以后想再看，打开「百宝箱 → 使用文档 → 重新查看新手引导」，会从头重开同一套指引。

  1. 打开并登录 LIRA。 已登录过的电脑会自动登录。连接失败时检查网络，点击「重试连接」。
  2. 确认直播间已连接。 在「点歌 → 设置」检查直播账号、直播间号和「接收弹幕和礼物」，修改后点击「保存设置」。
  3. 准备好歌库，开始接收点歌。 观众发送「点歌 歌名」后，歌曲会进入点歌队列。你可以调整顺序或移除歌曲。
  4. 选择音乐并播放。 在「播放」页选择平台、搜索歌曲，再加入播放队列；也可以打开播放队列，点击「导入点歌」把观众的点歌加入待播列表。底部播放器可以暂停、切换歌曲和调整进度。
  5. 按需要打开直播工具。 「礼物」查看送礼记录；「百宝箱」中可以使用弹幕姬、加班机、小游戏等。需要显示在直播画面上时，复制对应功能的链接，添加到直播姬或 OBS。
