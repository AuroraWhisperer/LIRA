12网页歌单与主播中心

网页歌单给观众挑歌。网页主播中心给你看礼物记录、管理网页歌单和直播弹幕姬。B 站账号和直播间还是在 LIRA 客户端里设置。

打开自己的网页歌单观众入口
  1. 打开「点歌 → 导入导出」，找到「网页歌单同步」。
  2. 等「绑定账号」读出来，点「查看网页歌单」。网址的开头就是你注册 LIRA 时填的用户名。
  3. 看一眼歌对不对，再复制你自己的网址，发给观众。

观众可以在手机上搜歌、筛选，也可以随机选一首，或者复制点歌指令。复制指令不会自动发出去，观众还要回到直播间发弹幕。

想要二维码：登录网页主播中心，打开「网页歌单」，展开「二维码」，再点「下载二维码」。

查看网页主播中心的分享区
  • 找不到「查看网页歌单」：先检查网络和 LIRA 登录状态。
  • 网页是空白的：先重新打开你自己的链接，再看「网页歌曲」的数量对不对。
更新网页上的歌曲

歌曲在客户端「点歌 → 歌库」里加和改。歌库跟着 LIRA 账号同步。网页主播中心只能看歌，不能改歌。

  1. 先确认这台电脑的歌库是全的。要手动同步，就打开「点歌 → 导入导出」。
  2. 点「同步到网页」，看完覆盖提醒再确认。
  3. 等同步结果出来，再点「查看网页歌单」看看。失败了就按提示检查网络或歌曲信息，再试一次。

整份替换，不会合并。同步会用这台电脑的歌库替换云端歌库，网页歌单和同一账号的其他电脑也会跟着变。歌库最多 5000 首。别在两台电脑上同时改歌库。

「本机上次同步」只记你手动点「同步到网页」的时间。不能靠它判断这台电脑和云端是否完全一样。

改网页歌单的名称与外观
  1. 登录网页主播中心，打开「网页歌单」。
  2. 改名称：在「歌单名称」里填新名字，点「保存」。点「恢复默认」会直接保存。
  3. 改背景：在「歌单背景」里点「上传背景」，选好图片就会马上替换。
  4. 改外观：在「歌单外观」里调背景效果、字体和配色，点「保存外观」，再点「打开网页歌单」看效果。

客户端也能改背景：打开「点歌 → 导入导出」，在「歌单背景」里点「上传背景」。支持 PNG、JPG、WebP、GIF，最大 5 MB，选好就会上传。想换回原来的水彩背景，点「恢复默认背景」。

每个主播只保留最新的一张背景，新图会替换旧图。这里改的是观众看的网页歌单。直播画面里的点歌板样式，要到「点歌 → 点歌板」里改。

登录网页主播中心主播入口

打开「百宝箱 → 设置」，点「账号登录」。也可以直接打开 网页账号登录入口。用你的 LIRA 用户名和密码登录，就能进入主播中心。网页上的「退出登录」只退出网页。

  • 礼物流水：按时间、送礼人、礼物筛选记录，翻页查看。网页上不能导出 PNG，要导出请到礼物页。
  • 数据分析：选日期，看收礼趋势、收礼概览和礼物价值构成。换了日期，先看清统计范围，再比金额。
  • 网页歌单：看同步上来的歌，改名称、背景和外观，复制网址或下载二维码。
  • 直播弹幕姬：选样式并预览，点「保存样式」更新直播画面。再复制地址，加到 OBS 或直播姬的浏览器源。它和客户端弹幕姬用的是同一份服务器设置。
查看礼物流水、数据分析和弹幕姬的画面

记录是空的：先清空筛选，核对日期和登录的账号，再到客户端看看直播间连上没有。服务器只能显示已经记下来的礼物，页面空白不代表历史礼物都补齐了。

忘记 LIRA 密码怎么办
  1. 找管理员要密码重置码。它只用来改密码，不能填进客户端的「短效登录码」框。
  2. 打开网页账号登录入口，点「使用重置码」。
  3. 「账号」填你的用户名，再填重置码、新密码和「确认密码」。点「确认重置」，成功后用新密码登录。

重置码有效期很短，只能用一次，要在管理员说的时间内用掉。提示过期或已用过，就找管理员要新的。重置码别发给别人。新密码的要求和注册时一样，见账号与设备。
