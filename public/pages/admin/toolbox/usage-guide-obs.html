10直播姬 / OBS 投屏与套装

LIRA 面向 B 站直播，OBS 与哔哩哔哩直播姬（简称直播姬）均可使用。复制需要的画面地址，添加到直播姬的「浏览器」或 OBS 的「浏览器源」。网页歌单用于让观众查歌，使用另外的链接，见网页歌单与分享。

  1. 在「点歌 → 浏览器源」找到需要的地址。统一摆放多个组件时选择「直播场景」；单独使用时直接复制对应组件地址，无需编辑场景。
  2. 在直播软件中添加浏览器源，粘贴地址，按功能面板的说明设置源的宽度和高度，再把画面摆到需要的位置。
  3. 在 LIRA 中按需调整样式，并点击对应面板的保存或应用按钮。场景编辑器点「保存并应用」；使用已有样式无需再次调参。没有内容时，歌词、礼物特效等源可能是透明的。
直播场景，一个地址导入

在「浏览器源 → 直播场景」点击「编辑场景」打开场景编辑器。顶部添加组件，下方选择图层，右侧展开调参；收起参数可放大画布。画布分辨率统一设置，保存后恢复已有布局。

点击右上角「保存并应用」，再从客户端「复制地址」或网页「复制直播源地址」。将整个场景导入一个浏览器源，源宽高与画布一致。后续应用沿用原地址，关闭编辑网页后也能显示。

直播软件使用复制得到的 /scene 地址；浏览器地址栏中的 /component-preview 是编辑页面，不用于投屏。

独立组件，直接复制使用

无需组合布局时，直接复制「点歌板」「萌时钟」「加班机」或「弹幕姬 · 本机组件」地址。它们读取已保存的默认样式，无需创建或发布场景。

组件库加入场景的图层默认使用独立外观，修改它只影响该场景。想更换单组件默认样式，可直接在客户端对应面板选择并保存。

导入套装与第三方素材

导入月渡花汀等 LIRA 套装 ZIP
  1. 在「点歌 → 浏览器源 → 直播场景」点「编辑场景」，进入「添加组件 → 套装」后点「导入套装」，直接选择作者提供的 ZIP，无需解压或手动放文件夹。
  2. 核对套装名称、版本和成员清单，再点「导入套装」。导入只增加可选样式，当前直播画面保持原样。
  3. 打开「直播场景 → 编辑场景」，在「添加组件 → 套装」找到已导入的套装，点击需要的成员；也可从对应组件分类选择。
  4. 每点一个成员添加一个组件。调整位置和大小后点「保存并应用」，直播软件中的场景才会更新。

月渡花汀 1.0.0 包含静态背景、动态背景、开播动画、时钟、弹幕姬、礼物许愿共 6 款样式，背景可二选一，其他成员也可单独使用。其他套装的种类和数量以导入清单为准。

月渡花汀需先导入才会出现在样式库。若没有导入入口，或提示需要更新客户端，请安装支持该套装的更新版本。

第三方 HTML、CSS、网页与图片视频

普通素材 ZIP 先解压到独立文件夹，保留作者的目录结构。在对应组件「＋ 添加样式」选择 HTML/CSS 文件，自动导入配套资源；也可粘贴 CSS 并选择资源文件夹，或直接填写浏览器源地址。无需编写套装清单。

预览时拖动虚线框，给弹幕、时间或许愿内容留出位置，填好名称后点「添加样式」。点击新卡片加入画布，再「保存并应用」。支持 PNG、JPEG、GIF、WebP、MP4 和 WebM。

弹幕 CSS 自动识别常见 blivechat / BLC 样式；需要原工具后端或专用网页的样式，使用作者的配套 HTML 或展示地址。缺少配套文件时会提示具体路径。礼物感谢图片/视频沿用 LIRA 的触发设置；成片已带固定文字时可关闭「显示感谢文字」。

更换样式，保留已经摆好的位置

在画布选中原图层，点右侧「更换样式 / 添加素材」选择新样式。名称、位置、大小和层级会保留，最后点「保存并应用」。锁定的图层需先解锁。

旧场景使用了此前内置的月渡花汀时，先导入月渡花汀 ZIP，再按上述步骤为原图层选择对应成员。若提示资源缺失，也可重新导入对应套装后重新选择。

导入的样式用于本机场景，不会修改服务器弹幕姬链接。直播软件与 LIRA 需在同一电脑上，直播期间保持 LIRA 开启。

删除、恢复与更新套装样式

样式卡片右上角 × 只从可选列表移除，已有场景仍能使用；这一步不会立即清理磁盘文件。要从直播画面移除组件，请在画布删除图层，再「保存并应用」。

误删套装样式后，重新导入原来的同一版本 ZIP 可恢复卡片，重复导入不会产生副本。新旧版本可以并存，更新后请在需要的图层上更换样式。

若提示相同版本内容冲突，请作者提高版本号后重新打包。换电脑前保留原套装 ZIP 和图片、视频，在新电脑重新导入并核对画布布局；具体步骤见数据保存与换电脑。

先分清本机画面和服务器弹幕姬

直播场景和各本机独立组件使用 127.0.0.1 地址，必须在运行 LIRA 的电脑上加载，并保持 LIRA 开启。退出后不能重新加载或继续获取实时数据；已加载的画面是否保留最后内容取决于该功能。

服务器弹幕姬不依赖桌面进程持续运行，但仍依赖服务器和直播间连接。复制它的链接需要 LIRA 授权与服务器配置读取成功；接收直播消息还需要配置直播账号。这两项要分开检查。

点歌队列画面 · 本机

在「点歌 → 浏览器源」或「点歌板」复制。点歌板有六种风格，例如「点歌板风格 1（经典队列展示）」；字号、配色和滚动在点歌板页调整，宽高按所选风格说明设置。显示的是等待演唱的点歌队列。

歌曲展示板 · 本机

在「浏览器源」或「展示板」复制，循环展示歌库歌曲。到「点歌 → 展示板」设置滚动速率、排序、字号以及是否同步点歌板主题；源尺寸按该面板说明调整。它与点歌队列是两个画面。

歌词画面 · 本机

在「浏览器源」或桌面歌词设置页复制。浏览器源的宽高决定歌词画面的空间；字体、颜色、描边与逐字高亮在「点歌 → 桌面歌词设置」中调整。先播放有歌词的歌曲，再检查投屏效果。

盲盒盈亏榜 · 本机

在「礼物 → 盲盒盈亏榜」卡片复制。设置标题、排行人数、仅显示盈利和仅显示心动盲盒后使用对应链接；排行人数 -1 为全部，0 仅汇总，1–10 指定人数，默认 3。画面自动适配捕捉窗口。

加班机画面 · 本机

在「百宝箱 → 加班机 → 直播画面」复制。背景与适配方式在面板选择，尺寸按画面设置调整；透明背景适合叠在直播画面上。倒计时是否暂停、礼物是否改时，由加班机本身的状态与规则决定。

礼物特效、边框、滚动与许愿 · 本机

礼物特效在「百宝箱 → 礼物特效」复制；边框、滚动、许愿在「礼物姬」对应页签复制。特效与边框适合全屏；滚动礼物建议宽 900，高度随行数；许愿建议宽 440，高度随内容调整，同一个地址统一展示长效、本日和本场直播许愿。 切换许愿统计周期只影响面板中的编辑与管理。滚动礼物修改后点「保存」，也可「恢复默认」或「取消修改」。

弹幕姬 · 服务器

在「百宝箱 → 弹幕姬」或「点歌 → 浏览器源」复制。固定位置六种、全屏随机三种样式，按样式说明设置源尺寸。改完样式和参数要点「应用到直播画面」。能复制地址不代表已收到直播弹幕；还需看连接状态。

游戏、开场与时钟 · 本机

三款小游戏共用「游戏网页」；转盘有独立地址；投票与评分共用一个独立「浏览器源」，推荐 800 × 600。开播动画复制「固定浏览器源地址」，使用 16:9 画面，总开关同时控制预览与投屏。萌时钟复制「萌时钟网址」，推荐 580 × 210，修改后点击「保存」。常用地址也可从「点歌 → 浏览器源」复制。

换电脑后，请在新电脑重新核对复制地址、端口、源尺寸和本机样式；不能只凭旧链接相同就认为设置也已迁移。地址复制失败时可按提示手动复制，画面仍异常见投屏与直播软件常见问题。
