8.2 直播连接与发送异常

8.2.1 弹幕姬地址一直是灰色
  1. 等 LIRA 授权有效、读到服务器配置后，链接才能复制。先检查 LIRA 和服务器连上没有，等地址出来再复制。
  2. 没登录 B 站会影响收直播消息，但链接读不出来不一定是这个原因。还是灰的，记下页面提示发给管理员。
8.2.2 弹幕发不出去
  1. 到「百宝箱 → 弹幕互动」看发送账号、目标直播间和发送结果。只显示「本机已登录」不代表能正常发送。
  2. 登录过期：到「点歌 → 账号登录」重新扫码登录并保存，等账号同步成功。连接异常就点「重新连接直播间」再试。
  3. 还发不出去，把发送结果和目标直播间发给管理员。先别反复批量发送。

8.3 点歌、播放与歌词异常

8.3.1 观众点了歌，但没有任何反应
  1. 到「点歌 → 账号登录」检查 B 站账号和直播间号，再确认弹幕姬的「监控弹幕」开着。
  2. 到「点歌 → 点歌规则」看是不是暂停了点歌，再核对点歌指令和歌名。「点歌屏蔽词」会将「点歌」后面的内容与词条进行完全匹配，不按观众身份拦截。
  3. 看看「点歌间隔」中的非大航海及大航海设置，每位观众分别计时。间隔没到时，点歌会被悄悄拦下，等时间过了再试。不过没反应不一定都是这个原因。
  4. 还没反应，到弹幕姬看连接状态，连接异常就点「重新连接直播间」。记下观众发的原文和发送时间，方便管理员查。
8.3.2 随机点歌没反应，或找不到符合条件的歌
  1. 显示「请先登录直播账号后再随机点歌。」：到「点歌 → 账号登录」登录 B 站账号。其他情况，先检查歌库里的歌能不能点。
  2. 语言、分类、标签这些条件要同时满足。先少设几个条件试试。在「百宝箱 → 弹幕互动」打开「点歌回复」后，找不到符合条件的歌会提醒观众。
  3. 歌已经进队列但版本不对：到「播放」页按歌名和歌手搜索。「点歌匹配诊断」没结果，不代表歌库里没有这首歌。
8.3.3 已在播放队列点击播放，仍没有声音
  1. 入队与播放的区别见管理队列与导入点歌。已经点击播放仍无声时，依次检查下面几项。
  2. 检查播放器有没有暂停或静音、音量多大，再看 Windows 的音量合成器。然后确认 QQ 音乐或网易云音乐账号还登录着，这首歌也有能播放的音源。
  3. 使用 LIRA 内置播放器时，到「百宝箱 → 设置」检查内置播放器输出。所选设备断开或暂时不可用时，LIRA 会暂停播放；接回设备后再点播放。要换输出通道，先关闭电音助手的「当前歌曲」，再选一个可用设备。
  4. 使用电音助手时，先关闭「当前歌曲」，再核对通道：原声通道与正在使用的 QQ 音乐、网易云音乐或 LIRA 内置播放器的输出通道一致；最终输出手动选另一个独立通道。重新开启处理后，原声通道会静音，请从最终输出监听或采集声音。具体步骤见电音助手。
  5. 接入麦克风、线路或声卡回送时，检查设备输入：选对「输入设备」，输入声道先用「自动」。输入电平不动时检查连接、Windows 麦克风访问设置和声卡路由；输入有电平但听不到时再检查最终输出。使用设备回送时，不能将声音送回正在采集的同一播放设备。
  6. 只有一首不行：重新按歌名和歌手搜索，换一个能播的版本。所有歌都不行：点「检查音乐平台连接」，记下错误提示。详见播放页。
8.3.4 QQ 音乐或网易云登录过期了
  1. 到「播放」页切到这个平台，用平台自己的登录按钮重新登录。LIRA 账号和 B 站账号不能代替音乐平台账号。
  2. 登录后点「检查音乐平台连接」，再试一首能播的歌。
  3. 还是失败，记下平台名和连接结果，别反复清空歌库。音乐平台登录只保存在这台电脑，换电脑要重新登录。
8.3.5 已设置缓存目录，歌词仍检测失败或不同步
  1. 按全民 K 歌歌词同步核对实际缓存目录，确认全民 K 歌正在播放伴奏，再点「保存并检测」。保留检测提示，区分是没有读到歌词，还是歌词时间存在偏移。
  2. 提示已读到歌词，但歌曲时间停住或一直「等待歌词」：让全民 K 歌播放到有声音的部分，点「重新检测」左侧的「播放诊断」，保持同一首歌播放约 20 秒。查看歌词读取、进度与音频采样结果；仍不正常时点「导出诊断」，文件会保存到 LIRA 日志文件夹，名称为 wesing-playback-diagnostic-日期_时间.json（本机时间，含毫秒）。按界面显示的路径找到文件，交给开发者排查。LIRA 会自动检测内置输出、耳机、独立声卡和虚拟声卡，不必切换 Windows 默认声卡。
  3. 有歌词但快慢不对：用「歌词时间调整」微调，范围 ±3000 毫秒，每次 50 毫秒。还不对，记下检测提示和歌名。「点歌 → 直播歌词」另有 ±5000 毫秒的画面偏移，两处偏移会叠加。
