5.4 礼物组件

在「组件」左侧的「礼物姬」下选择全屏礼物感谢、滚动礼物、礼物许愿、心动盲盒、月底冲刺、盲盒盈亏榜或大航海感谢，分别进入对应页面。子导航默认展开，点击「礼物姬」可折叠或展开，当前页面保持不变。全屏礼物感谢点击「预览」、大航海感谢点击「在画布中预览」，作为两个独立组件编排；礼物许愿、心动盲盒和月底冲刺点击「打开画布」编排，也可复制各自的浏览器源地址。滚动礼物可直接复制浏览器源地址。

5.4.1 全屏礼物感谢

页面把每款效果排成一组卡片：先是内置的「礼物掉落」「礼物摇摇乐」，再是已导入的样式，最后一项是「添加样式」。每张卡片有自己的启用开关、触发金额和预览入口，互不影响，可同时启用。内置两款修改后自动保存，顶部启用开关右侧为「预览」；导入样式仍需点该卡片的「保存设置」。触发金额按单次最终结算总额判断，等于金额也触发，填 0 表示所有付费礼物。参数生效后只影响之后收到的礼物；内置效果自动保存失败时会提示，保留当前修改，下一次编辑可重试。

礼物掉落和礼物摇摇乐各自的标题下都显示带底色和细边框的网址框，点击即可复制对应效果的独立地址，无需先打开画布。启用和参数修改会自动保存，再将地址添加到 OBS 或哔哩哔哩直播姬的浏览器源／网页来源：礼物掉落推荐 1920×1080，摇摇乐推荐 1920×420。来源跟随自动保存的设置，复制只取得地址；直播时保持 LIRA 运行。

画布中选中礼物掉落或礼物摇摇乐，也能调整启用、触发金额和下述全部外观与动效参数，修改后自动保存并与客户端同款效果同步。客户端顶部「预览」使用当前参数展示示例；正式直播使用已保存参数。

礼物摇摇乐每次在图层底部随机出现，优先选择空隙，按礼物、文字及摇晃范围留出间距；礼物较多、空间不足时仍可能重叠。直杆会随机伸缩并左右摇摆，礼物和文字随杆顶上下起伏，大小不变，各张礼物的节奏也不同。新添加到画布的摇摇乐图层默认宽 1920、高 420，并贴齐画布底边；缩短图层高度不会缩小礼物。已有图层可在画布中自行调整位置和尺寸。

掉落与摇摇乐均使用礼物图片的静态首帧。掉落可调整数量倍率、礼物大小、停留时长、掉落速度与弹跳力度。礼物大小默认 72px，可调 24–180px。数量倍率默认 8 倍，可调 3–20 倍：收到 1 个礼物默认掉落 8 张图片，实际送礼数量不变。预览使用 3 种礼物、每种 5 份，对应每种 15–100 张图片，默认每种 40 张、合计 120 张。只有金额保留窄输入框，其他数值拖动带范围的滑动条调节，旁边直接显示当前值和单位。弹跳设为 0 时不反弹。同批掉落图片在结算后的 2 秒内随机错开下落，预览中的三种礼物也共用这一个 2 秒窗口，各自停留相同时长后继续向下掉落，并在 0.6 秒内渐隐消失；先下落的先退场，底层开始退场时，上面的礼物随之往下落。开启系统的减少动态效果时，退场只渐隐。摇摇乐从软件捕捉到结算时开始计时。改变倍率、速度、图片准备或等待画面都不会重新计时。单次大量连送最多取 60 张代表图按倍率复制，超出部分的真实余量标在最后一张；同屏最多 400 张，满时不提前挤走旧礼物。摇摇乐使用没有底座的直杆，可独立调整礼物大小、停留时长、摆动幅度与摇摆速度，默认摆幅 36 度、速度 100%，摆幅控制左右摇晃的最大角度，速度同时控制摆动和伸缩的快慢；已有保存的数值保持不变。送礼人、礼物名和数量可分别勾选，全部取消就只显示礼物图片和竖杆，同屏最多 80 张。速度数值越大，运动越快。点击卡片顶部的「预览」查看当前参数，首次会加入对应的未保存图层；画布「添加组件 → 礼物姬 → 全屏礼物感谢」也可选择这两款，要同时显示就各添加一层。

林间花信等样式需要先导入：点页面最下方的「＋ 添加样式」，选择作者提供的 ZIP 或图片、视频、网页素材，详见样式包与套装。没导入时页面不显示林间花信；导入后它作为新的一张卡片排在摇摇乐后面，金额默认 20 元，每次播放 8 秒。 导入的图片、视频各自一张卡片，有自己的开关和金额（新导入的默认关闭），可填写观众、礼物和数量做预览示例。卡片上的「添加到画布」每次加入一个新图层，默认 1920×1080；「在画布中预览」选中已有的同款图层，没有时加入未保存图层；「移除」只从样式库移除，画布中已有的图层不受影响。网页样式按网页自身内容运行，不使用触发金额。 林间花信连续触发依次播完，最多等待 50 条，排满后忽略新触发，已排队项不会因等待时间被跳过。已有林间花信图层导入后可继续播放；调整位置和大小后在画布「保存并应用」，再把直播源地址添加到 OBS 或哔哩哔哩直播姬。

5.4.2 大航海感谢

打开「组件 → 礼物姬 → 大航海感谢」。观众开通或续费舰长、提督、总督时，收到上舰消息后就能在直播画面里播感谢动画。

  1. 选样式：「辉光」显示等级和月数；「经典 · 徽章」还会显示观众头像和昵称。
  2. 在想用的样式上打开「启用」，选中文、英文或中英双语，再点这张卡片里的「保存设置」。两种样式各自保存，都开着就依次播放。
  3. 在「画布预览」里选等级、填月数（1–999），再点「在画布中预览」。经典样式还能填示例观众名。画布会选中已有图层，没有时加入未保存图层；点击「保存并应用」后才发布，不会真的送礼。
  4. 打开直播场景的编辑画布，添加大航海感谢组件。摆好位置和大小，点「保存并应用」。复制整个场景地址，或选中组件复制它的直播源地址，再加到 OBS 或直播姬。

航海旗帜是大航海感谢组件的一款样式。在本页「＋ 添加样式 → 选择文件」选择「航海旗帜-大航海感谢样式-1.0.1.zip」。添加后与辉光、经典并列显示完整设置条目，可直接独立启用和模拟预览三档上舰效果；展开「外观设置」调整头像、昵称显示及昵称字号。「保存设置」保存样式默认值并同步使用该样式的组件；「在画布中预览」选中当前场景的同款图层，没有时添加，再点「保存并应用」。已有图层可在画布中调整共享参数或更换样式，位置和尺寸仍独立保存。航海旗帜按真实上舰等级播放，同一笔上舰只播一次，无需同时开启辉光或经典。旗帜上的中文来自原素材，不随语言切换。

先确认礼物监控连着，直播时保持 LIRA 开着。这里管本机画面里的感谢动画；想让服务器发答谢弹幕，要在「百宝箱 → 弹幕互动 → 欢迎答谢」开启「礼物答谢」。

5.4.3 滚动礼物

两列设置下方的「卡片外观」可分别选择「尾部样式」和「条带内部」，两者可自由组合。尾部有经典斜切、双色燕尾和折叠飘带，默认仍是经典斜切与原纯色；内部另有丝缎流光、星屑幻彩、几何拼片、菱格织纹、糖纸波点五种样式，选择后下方立即预览。画布中也可调整这两个选项，保存后的外观同时用于滚动礼物和之后的礼物图片导出。

按四档金额区间设置配色，调整显示行数（1–10）、滚动速度（1–50）和「累计金额超过（元）」（0 表示不限制）。「本日礼物循环」在零点换日。

能确认观众身份时，今天同一人送出的同一种礼物会合并显示；金额配色和最低金额筛选按合并后的总金额计算。具体规则见礼物图片导出中的说明。

修改后会先作为草稿保留，点「保存滚动与样式设置」后应用；有未保存修改时会显示「取消修改」，点击恢复上次保存的设置。复制地址后，浏览器源建议宽 900，高度随行数调整。金额配色也会用于之后的礼物图片导出。

5.4.4 礼物许愿
  1. 打开「组件 → 礼物姬 → 礼物许愿」，先选周期：「长效」从每条许愿创建时开始累计；「本日」北京时间零点换日；「本场直播」下次开播重新计数。
  2. 点击「选个礼物」，从本直播间或全部缓存礼物里按名称 / ID 查找。注意区分盲盒本体与盲盒开出的礼物。
  3. 填写目标数量（整数，默认 10，可填 1–999999999），选择「礼物卡片」「文字版」或「圆形徽章」。月渡花汀需先导入套装，再到画布选择对应许愿样式。文字版可按下方说明加入图片和数量，确认效果后点击「添加许愿」。备注选填，不会显示在直播画面。
  4. 在已保存的预览中查看已收数量 / 目标数量，必要时点「刷新进度」。进度按所选周期内该礼物的已记录数量计算，不按金额；修改目标会保留已收进度。
  5. 点击「打开画布」编排许愿，画布会读取已保存的内容、颜色与进度；周期筛选与直播相同。保存并应用后复制直播源地址，添加到 OBS 或哔哩哔哩直播姬。也可点击顶部网址块复制完整地址，建议宽 440，高度随内容调整；该地址同时展示三个周期的许愿。

在画布「添加组件 → 礼物姬 → 礼物许愿」选择「流光彩带」，可使用带动态斜纹的横条进度，普通礼物、舰长、提督等均可使用。右侧「彩带外观」调整条高、边框粗细与圆角、彩带配色；「右下角装饰」可选无、原奶油条、蝴蝶结、樱花、爱心糖或流星，各款已有适合的倾斜角度；「文字与数字」分别调整名称与数量字号，以及文字和描边颜色，数字字号留空时跟随名称；「彩带动效」调整条纹粗细、向左或向右流动，以及流动周期。周期设为 0 时静止，数值越小流动越快。边框、图标和字号会随条高及宽度适配，避免挤压或截断计数；想放大长计数，可增加组件宽度。保存并应用后使用场景直播源地址，礼物和目标数量仍在许愿页管理。

文字版：用同一种方法插入图片、礼物名称和数量

  1. 先选择心愿礼物，再把展示样式切到「文字版」。在「展示文字」框里输入自己想说的话。
  2. 点文字框中想插入的位置，再点下方的「礼物图片」「礼物名称」「已收数量」或「目标数量」。 按钮会加入一个完整的彩色块，不用输入花括号；旁边的「实时预览」会显示实际效果。 文字在预览和直播画面中默认不描边。
  3. 选中文字或彩色块后，可用上方工具栏修改字体、字号、加粗、斜体、下划线和颜色。同字号的彩色块与正文使用相同字形大小，实时预览同步显示选区的文字效果；新插入的彩色块和粘贴文字沿用光标处的格式。
  4. 点击彩色块就能选中，按退格键可整体删除。用 Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴来调整位置； Ctrl+Z 撤销，Ctrl+Y 重做。删掉所有「礼物图片」块后就是不带图的文字版。
  5. 插入图片后，可在「礼物图片效果」选择「动态原图」或「静态图片」。 原图自带动画时才会动；静态图片显示固定画面。不需要另外上传图片，会自动使用当前心愿礼物的图片。
  6. 在「文字颜色」点击「今天未收到」或「今天已收到」下的色块，即可分别选色。 默认未收到时为雾蓝，已收到时为翠绿。每条许愿可以单独设置；想重新使用推荐配色，点「恢复默认颜色」。 保存后，独立浏览器源与画布里的许愿组件都使用这条许愿的颜色；画布不再单独设置一套文字颜色。
  7. 在「实时预览」右上角切换「今天未收到」和「今天已收到」，检查收礼前后的颜色。这里只模拟颜色，不改变已收数量或实际收礼状态。
  8. 确认效果后点「添加许愿」；编辑已有许愿时点「保存修改」。只改文字框里的内容还不会更新直播画面。
  • {图片}：当前心愿礼物的图片；每插入一次，就显示一张。
  • {礼物}：当前心愿礼物的名称。
  • {已收}：所选统计周期内已收到的数量，会自动更新。
  • {目标}：设置的目标数量。

可以直接复制这些例子到「展示文字」中，再按喜好修改普通文字：

  • 图片在前：{图片}许愿{礼物}（{已收}/{目标}）
  • 图片在后：许愿{礼物}（{已收}/{目标}）{图片}
  • 图片在文字中间：今天想要{图片}{礼物}，已收{已收}/{目标}

选中文字或内容块后，可以用上方工具栏设置字体、字号、加粗、斜体、下划线、颜色、描边和阴影；字体来自与文本框相同的软件字体库，也可搜索系统字体库中的本机字体。选择「默认字体」或「清除格式」可恢复默认外观，改好后点「添加许愿」或「保存修改」。 「展示文字」旁的问号也能查看用法。如果今天收到过这份礼物，未单独设色的文字会切换为设置的「今天已收到」颜色，不必达到目标数量； 选区颜色会覆盖这段文字的状态色，选择工具栏里的「默认颜色」可恢复随收礼状态变色。北京时间零点按新一天重新判断。这与 {已收} 的统计周期独立，例如长效许愿保留累计数量，文字颜色仍按今天是否收到判断。

心动盲盒收集任务
  1. 打开「组件 → 礼物姬 → 心动盲盒」查看本期进度。北京时间每周六 00:00 至周四 24:00 为收集时间，本期已经记录的心动盲盒自动计入；开出浪漫城堡不清零。日期旁的问号可查看收集规则。
  2. 使用 LIRA 前有遗漏数量时，在右侧「本期累计」填入本期实际总数，点击「校准进度」。之后捕捉到的盲盒会在校准后的进度上增加；可以向上或向下修正。校准在重启后保留，仅对当前主播、本期有效，不改动礼物流水或盈亏。如果填写期间进度或账号发生变化，页面会提示并回填最新数量，请核对后重新输入。
  3. 20、40、80、120 个分别解锁「4 倍限开 1 个」「4 倍限开 2 个」「5 倍限开 1 个」「5 倍限开 2 个」。已解锁节点点亮，标题中的目标自动切到下一档；超过 120 个仍保留真实数量。
  4. 在「显示设置 → 背景样式」选择经典白、樱花粉、奶油杏、薰衣草或午夜紫，文字和奖励卡片会随背景配色。背景自动保存，并同步到画布中的「心动收集」与新复制的浏览器源；紧凑进度保留原有深色外观。
  5. 关闭「显示倍率和限开数量」可隐藏下方城堡奖励区，保留收集进度。客户端与画布共用此开关，修改后自动保存，两种样式和新复制的来源都会同步；保存失败可重试。旧来源地址已明确指定显隐时继续按该地址显示。
  6. 点击「打开画布」，在「心动盲盒」中选择「心动收集」或「紧凑进度」，调整位置后「保存并应用」。画布是示例进度，直播源自动显示当前账号本期记录；也可复制本页浏览器源地址直接添加到 OBS 或哔哩哔哩直播姬，建议宽 620、高 280。
  7. 周五显示本期最终进度和「收集已结束」，周六 00:00 自动开始新一期，旧校准不再生效。出现同步提示时先等待礼物记录同步完成，或点击「刷新进度」；自动补计只涵盖 LIRA 已记录的数据，仍缺少的数量可手动校准。
5.4.5 月底冲刺文字版

在「组件 → 礼物姬 → 月底冲刺」设置金额目标并保存，点击「打开画布」调整位置和尺寸，保存并应用后复制直播源地址。也可在画布「添加组件 → 礼物许愿 → 月底冲刺」中添加。默认尺寸 600 × 80，透明底显示“还差 N 个水晶球”。

目标、已收金额、剩余进度和「重置本轮」都在本页。文字共用已有的金额目标、收礼进度和「重置本轮」结果，每 100 元剩余金额折合 1 个水晶球，不足 1 个按 1 个计。未设目标时不显示；达标后显示绿色的“还差 0 个水晶球”。

金额目标与重置的操作见设置冲刺目标。

5.4.6 礼物特效

主播手动测试或观众发送指定弹幕时，在直播画面上播一段全屏动画。

  1. 不知道礼物 ID，点「查找礼物 ID」，到 gifts.lirahub.cn 查。
  2. 在「直播画面测试」里填礼物 ID，点「在直播画面播放」。已连接的 OBS / 直播姬浏览器源会立即播放，直播中观众也能看到。
  3. 在「直播投屏」里点击网址块复制，加到直播姬的「浏览器」或 OBS 的「浏览器源」。这个地址固定不变。也可以点「预览」，直接在浏览器里看。

这个工具通过手动测试或弹幕命令播放，不会因收到对应礼物而自动播放。平时画面是透明的；它与全屏礼物感谢共用浏览器源地址，无需重复添加。

打开弹幕触发后，观众发这四种写法都行：礼物特效 32132、礼物特效32132、🎁 32132、🎁32132。把 32132 换成你要的礼物 ID。

5.4.7 盲盒盈亏榜投屏

这是给观众看的盲盒盈亏排行榜，默认宽 720px，文字最小 30px，倍数和数量默认 36px。顶部第一行显示标题和总盈亏，第二行显示开盒数、花费和开出价值；“开出价值”是开出的礼物总价值。在「组件 → 礼物姬 → 盲盒盈亏榜」设置：

榜单包含服务器已记录、同步完成的当日盲盒，软件未运行或安装前收到的也会计入。日期按实际送礼时间和电脑本机时间判断，重复同步不会重复累计。

  • 投屏标题：可以自己改，默认是「今日盲盒盈亏」。
  • 排行人数：默认 3。填 -1 显示全部，0 仅显示汇总，1 至 10 显示对应人数。前三名显示带数字的金、银、铜奖牌，第四名起显示普通数字。
  • 仅显示盈利：只显示盈利的观众，默认打开。
  • 仅显示心动盲盒：只统计今天开的心动盲盒，打开后在下方出现「心动盲盒」设置。

填写「今天几倍堡」后，榜单顶部会显示「今天 N 倍堡」，留空则隐藏。「还剩几个堡」由你手动填写，打开左侧开关后才显示；打开「出堡后已开盒数」则自动统计今天上一次开出浪漫城堡后又开了多少个心动盲盒。今天还没出堡时显示今日累计，每次开出浪漫城堡后归零重新计算，直送城堡不计入。画布展示示例盒数，实际投屏按真实记录更新。

点击顶部「浏览器源地址」下的网址即可复制，再添加到直播姬或 OBS。右侧「打开画布」会打开盲盒盈亏榜，可调整位置和尺寸。画面会跟着捕捉窗口自动调整布局。看不到记录时，可能只是没有符合条件的，不是加载失败。

下方「外观」分三行调整：排版（字体、字重、字号比例）、配色（背景、文字、主色、强调色）和布局（紧凑布局、自动翻页）。背景的不透明度在背景颜色的取色器里调整。这些参数与画布里的参数双向同步。字体和配色与点歌板共用；修改后自动保存，同步影响点歌板和使用该主题的组件，保存状态显示在标题右侧。成本和盈亏含义见礼物记录与分析。
