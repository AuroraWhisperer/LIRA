05.4 礼物组件

在「组件」左侧的「礼物姬」下选择全屏礼物感谢、滚动礼物、礼物许愿、月底冲刺、盲盒盈亏榜或大航海感谢，分别进入对应页面。子导航默认展开，点击「礼物姬」可折叠或展开，当前页面保持不变。全屏礼物感谢和大航海感谢点击「预览」，作为两个独立组件编排；礼物许愿和月底冲刺点击「打开画布」编排，也可复制各自的浏览器源地址。滚动礼物可直接复制浏览器源地址。

05.4.1 全屏礼物感谢

在「组件 → 礼物姬 → 全屏礼物感谢」选用已安装样式；林间花信的安装见样式包与套装。 导入保留原启用状态和触发金额，默认金额为 20 元；填 0 表示所有付费礼物，每次播放 8 秒。 点击样式卡片添加到画布，默认 1920×1080，保留原花叶、头像与感谢文字布局；本页仍可「保存设置」和「预览」。 已有林间花信图层导入后可继续播放。预览可调整位置和大小，保存并应用后复制直播源地址添加到直播软件。 连续触发依次播完，最多等待 50 条，排满后忽略新触发，已排队项不会因等待时间被跳过。

05.4.2 大航海感谢

打开「组件 → 礼物姬 → 大航海感谢」。观众开通或续费舰长、提督、总督时，收到上舰消息后就能在直播画面里播感谢动画。

  1. 选样式：「辉光」显示等级和月数；「经典 · 徽章」还会显示观众头像和昵称。
  2. 在想用的样式上打开「启用」，选中文、英文或中英双语，再点这张卡片里的「保存设置」。两种样式各自保存，都开着就依次播放。
  3. 在「模拟预览」里选等级、填月数（1–999），再点「预览」。经典样式还能填示例观众名。预览只看效果，不会真的送礼。
  4. 打开直播场景的编辑画布，添加大航海感谢组件。摆好位置和大小，点「保存并应用」。复制整个场景地址，或选中组件复制它的直播源地址，再加到 OBS 或直播姬。

航海旗帜是大航海感谢组件的一款样式。在本页「更多样式 → ＋ 添加样式 → 选择文件」选择「航海旗帜-大航海感谢样式-1.0.1.zip」。添加后点击样式卡片，可独立启用、调整头像与昵称显示及昵称字号，并模拟预览三档上舰效果。「保存设置」保存样式默认值并同步使用该样式的组件；点击「在画布中使用」后再「保存并应用」。已有图层可在画布中调整共享参数或更换样式，位置和尺寸仍独立保存，避免重复添加。航海旗帜按真实上舰等级播放，同一笔上舰只播一次，无需同时开启辉光或经典。旗帜上的中文来自原素材，不随语言切换。

先确认礼物监控连着，直播时保持 LIRA 开着。这里管本机画面里的感谢动画；想让服务器发答谢弹幕，要去礼物页开「自动答谢礼物」。

05.4.3 滚动礼物

按四档金额区间设置配色，调整显示行数（1–10）、滚动速率（1–50）和最小礼物金额（0 表示不限制）。「本日礼物循环」在零点换日。

修改先进入草稿，点「保存滚动与样式设置」后应用；有未保存修改时会显示「取消修改」，点击恢复上次保存的设置。复制地址后，浏览器源建议宽 900，高度随行数调整。金额配色也会用于之后的礼物图片导出。

查看滚动礼物设置

需要重新使用默认样式时可点「恢复默认」。

05.4.4 礼物许愿
  1. 打开「组件 → 礼物姬 → 礼物许愿」，先选周期：「长效许愿」从每条创建时累计；「本日许愿」北京时间零点换日；「本场直播许愿」下次开播重新计数。
  2. 点击「选个礼物」，从本直播间或全部缓存礼物里按名称 / ID 查找。注意区分盲盒本体与盲盒开出的礼物。
  3. 填写目标数量（整数，默认 10，可填 1–999999999），选择「礼物卡片」「文字版」或「圆形徽章」。月渡花汀需先导入套装，再到画布选择对应许愿样式。文字版可按下方说明加入图片和数量，确认效果后点击「添加许愿」。备注选填，不会显示在直播画面。
  4. 在已保存的预览中查看已收数量 / 目标数量，必要时点「刷新进度」。进度按所选周期内该礼物的已记录数量计算，不按金额；修改目标会保留已收进度。
  5. 点击「打开画布」编排许愿，保存并应用后复制直播源地址，添加到 OBS 或哔哩哔哩直播姬。也可直接复制面板中的浏览器源地址，建议宽 440，高度随内容调整；该地址同时展示三个周期的许愿。

文字版：用同一种方法插入图片、礼物名称和数量

  1. 先选择心愿礼物，再把展示样式切到「文字版」。在「展示文字」框里输入自己想说的话。
  2. 点文字框中想插入的位置，再点下方的「礼物图片」「礼物名称」「已收数量」或「目标数量」。 按钮会加入一个完整的彩色块，不用输入花括号；旁边的「实时预览」会显示实际效果。
  3. 点击彩色块就能选中，按退格键可整体删除。用 Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴来调整位置； Ctrl+Z 撤销，Ctrl+Y 重做。删掉所有「礼物图片」块后就是不带图的文字版。
  4. 插入图片后，可在「礼物图片效果」选择「动态原图」或「静态图片」。 原图自带动画时才会动；静态图片显示固定画面。不需要另外上传图片，会自动使用当前心愿礼物的图片。
  5. 在「文字颜色」点击「今天未收到」或「今天已收到」下的色块，即可分别选色。 默认未收到时为雾蓝，已收到时为翠绿。每条许愿可以单独设置；想重新使用推荐配色，点「恢复默认颜色」。
  6. 在「实时预览」右上角切换「今天未收到」和「今天已收到」，检查收礼前后的颜色。这里只模拟颜色，不改变已收数量或实际收礼状态。
  7. 确认效果后点「添加许愿」；编辑已有许愿时点「保存修改」。只改文字框里的内容还不会更新直播画面。
  • {图片}：当前心愿礼物的图片；每插入一次，就显示一张。
  • {礼物}：当前心愿礼物的名称。
  • {已收}：所选统计周期内已收到的数量，会自动更新。
  • {目标}：设置的目标数量。

可以直接复制这些例子到「展示文字」中，再按喜好修改普通文字：

  • 图片在前：{图片}许愿{礼物}（{已收}/{目标}）
  • 图片在后：许愿{礼物}（{已收}/{目标}）{图片}
  • 图片在文字中间：今天想要{图片}{礼物}，已收{已收}/{目标}

「展示文字」旁的问号也能查看用法。今天收到过这份礼物，文字会切换为设置的「今天已收到」颜色，不必达到目标数量； 北京时间零点按新一天重新判断。这与 {已收} 的统计周期独立，例如长效许愿保留累计数量，文字颜色仍按今天是否收到判断。

查看文字版模板示例

切换统计周期只影响面板里的编辑与管理，同一个独立地址展示三个周期。月底冲刺另按金额累计，不使用这里的礼物数量目标。

05.4.5 月底冲刺文字版

在「组件 → 礼物姬 → 月底冲刺」设置金额目标并保存，点击「打开画布」调整位置和尺寸，保存并应用后复制直播源地址。也可在画布「添加组件 → 礼物许愿 → 月底冲刺」中添加。默认尺寸 600 × 80，透明底显示“还差 N 个水晶球”。

目标、已收金额、剩余进度和「重置本轮」都在本页。文字共用已有的金额目标、收礼进度和「重置本轮」结果，每 100 元剩余金额折合 1 个水晶球，不足 1 个按 1 个计。未设目标时不显示；达标后显示绿色的“还差 0 个水晶球”。

金额目标与重置的操作见设置冲刺目标。

05.4.6 礼物特效

收到指定礼物时，在直播画面上播一段全屏动画。

  1. 不知道礼物 ID，点「查找礼物 ID」，到 gifts.lirahub.cn 查。
  2. 在「测试播放」里填礼物 ID，点「播放特效」看看效果。
  3. 在「直播投屏」里点「复制地址」，加到直播姬的「浏览器」或 OBS 的「浏览器源」。这个地址固定不变。也可以点「预览」，直接在浏览器里看。

加好以后，收到对应礼物会自动播放。平时画面是透明的，不挡东西。

打开弹幕触发后，观众发这四种写法都行：礼物特效 32132、礼物特效32132、🎁 32132、🎁32132。把 32132 换成你要的礼物 ID。

05.4.7 盲盒盈亏榜投屏

这是给观众看的盲盒盈亏排行榜，默认宽 720px，文字最小 30px，倍数和数量默认 36px。顶部第一行显示标题和总盈亏，第二行显示开盒数、花费和开出价值；“开出价值”是开出的礼物总价值。在「组件 → 礼物姬 → 盲盒盈亏榜」设置：

  • 投屏标题：可以自己改，默认是「今日盲盒盈亏」。
  • 排行人数：默认 3。填 -1 显示全部，0 仅显示汇总，1 至 10 显示对应人数。前三名显示带数字的金、银、铜奖牌，第四名起显示普通数字。
  • 仅显示盈利：只显示盈利的观众，默认勾选。
  • 仅显示心动盲盒：只统计今天开的心动盲盒，勾选后展开城堡相关设置。

填写倍数后，榜单顶部会显示「今天 N 倍堡」，留空则隐藏。「还有 N 个堡」由你手动填写，可以单独勾选显示；「显示已开盒数」则自动统计今天上一个浪漫城堡之后开了多少个心动盲盒。今天还没出堡时显示今日累计，每次开出浪漫城堡后归零重新计算，直送城堡不计入。画布展示示例盒数，实际投屏按真实记录更新。

改好后点击「浏览器源地址」下的网址即可复制，再添加到直播姬或 OBS。右侧「预览」会在画布中打开盲盒盈亏榜，可调整位置和尺寸。画面会跟着捕捉窗口自动调整布局。看不到记录时，可能只是没有符合条件的，不是加载失败。

展开「外观设置」还可调整紧凑布局、自动翻页、字体、字重、字号比例、背景和配色；与画布里的参数双向同步。字体与配色沿用共享主题。成本和盈亏含义见礼物记录与分析。
