5.6.1 文本框

打开「组件 → 文本框」。直播公告、标题、带图片的说明都能在这里做。每个文本框单独编辑，也能放进直播场景。

  1. 点「新建文本框」，起个名字，再输入正文。想改另一份，就在上方列表里选。点「创建副本」会按这份内容新建并选中一份副本，点「删除」会删掉选中的文本框。
  2. 选中文字，会出现工具栏，可以改字体、字号、加粗、斜体、下划线、颜色，也能加描边、阴影或清除格式。对齐方式和行距在下方「文字排版」中改。
  3. 想放礼物图片，就在「本房间礼物」或「全部礼物」里搜到礼物，再插入。也可以上传自己的图片，或点「颜文字 / 表情」选一个。
  4. 想让公告自动循环，在「自动滚动」中打开「横向滚动」或「纵向滚动」。横向滚动按单行向左播放，换行符会转为空格；纵向滚动保留换行并向上播放。一次只能开一个方向，两个都关就静止。正文完全移出后，会从另一侧重新进入。
  5. 开启滚动后，用开关下方的「滚动速度」调快或调慢，范围是 10–200 像素/秒，默认 40。两个方向共用速率，切换方向或暂时关闭滚动后仍会保留；拖动滑杆时预览继续播放。问号里可以查看滚动方式和速率的说明。
  6. 点「在画布中调整」，摆好位置和大小，再点「保存并应用」。想单独投屏，就点「复制直播地址」，把地址加到 OBS 或直播姬的浏览器源。

字体菜单可以搜索共享字体库和本机字体；选择「默认字体」恢复原字体。仅选中的文字会改变，保存并应用后直播画面同步显示。

编辑时，礼物图片是一整块，不能拆开改；投到直播画面后会显示图片。自己上传的图片支持 PNG、JPEG、GIF、WebP，单张最大 5 MB。GIF 和动态 WebP 的动画会保留。

快捷键、保存与放弃修改
  • Ctrl + B 加粗、Ctrl + I 斜体、Ctrl + U 下划线，Ctrl + Z 撤销，Ctrl + Shift + Z 重做。从别处粘贴文字，只保留文字，不带原来的格式。
  • 几千字或上万字正文可以直接粘贴，多行内容保留换行。编辑区可以手动滚动查看，自动滚动只影响预览和直播画面；切换方向后，仍可撤销刚才的文字编辑。
  • 新建后先点「保存并应用」，才能复制直播地址。只看预览不算保存。不想要刚才的修改，就点「放弃修改」，回到上次保存的内容。
  • 顶部显示「正在编辑」和「当前输出」的场景。「保存并应用」会发布整个正在编辑的场景，包含已保存但尚未应用的内容；如果正在编辑的场景与当前输出不同，或场景中还有其他未保存的修改，会先提醒。取消提醒不改变当前输出。
  • 「放弃修改」会还原整个正在编辑的场景草稿。还有文本框以外的修改时会先提醒；已发布的画面不受影响。
  • 这里和画布里改的是同一个文本框。点「在画布中调整」会选中已有的那一份，不用再加一次。拖动边框改大小，里面的内容也会一起缩放。
