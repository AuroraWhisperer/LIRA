5.6.1 文本框

打开「组件 → 文本框」。直播公告、标题、带图片的说明都能在这里做。每个文本框单独编辑，拥有各自的独立浏览器源，也能放进直播场景合排。

  1. 点顶部「＋（新建文本框）」创建新文本框，直接在左卡片顶部点击名称改名，再输入正文。上方胶囊标签用于切换不同文本框（绿点表示已发布独立源，黄点表示待保存）；名称右侧图标按钮可「创建副本」或「删除」。
  2. 选中文字会出现格式工具栏，可改字体、字号、加粗、斜体、下划线、颜色、描边、阴影或清除格式。底部统一属性栏提供「对齐」（左 / 中 / 右图标切换）和「行距」。
  3. 「背景」默认透明，可打开颜色面板设置底色与不透明度；设置了可见底色后会出现「恢复透明」。右侧实时预览框左下角的 3 颗圆点可切换透明棋盘、深色或浅色底以便检查文字清晰度，不会输出到直播；右下角角标显示当前画面尺寸。
  4. 点击编辑框下方的「礼物」「图片」「表情」：点「礼物」可在「本直播间 / 全部礼物」中按名称、ID 或分类挑选，选中后点「插入礼物图片」；点「图片」可上传本地图片（支持 PNG、JPEG、GIF、WebP，单张 ≤ 5 MB，保留动图）；点「表情」可插入颜文字与表情。
  5. 在底部属性栏的「自动滚动」中直接切换「静止」「横向」或「纵向」。横向按单行向左循环播放，换行符会转为空格；纵向保留换行并向上循环播放。正文完全移出后，会从另一侧重新进入。
  6. 选择「横向」或「纵向」后会展开「滚动速度」滑杆（10–200 像素/秒，默认 40）。两个方向共用速率，切回「静止」后仍保留设定值；拖动滑杆时预览继续播放。
  7. 点「在画布中调整」可摆好位置和大小，再点右上角「保存并应用」。想把单个文本框独立投屏，切换到对应文本框后，直接查看实时预览正下方的「独立浏览器源」：新建未保存时点「保存并生成」，生效后点击地址或「复制地址」，粘贴到 OBS 或哔哩哔哩直播姬的浏览器源，并按预览右下角显示的尺寸设置来源宽高。每个文本框及其副本都有独立地址。场景来源凭据更新后，再点一次地址或「复制地址」即可取得新地址。

「保存并应用」会发布整个场景；如果场景中还有其他组件的未保存修改或图层顺序变动，请先核对弹窗提示中的整场改动再确认。正文导致整场超过 256 KiB 时，客户端和画布都会提示需要缩短的文本框，直播画面继续显示上次发布的内容；在当前窗口切回该标签或图层，缩短正文后再保存。点右上角「放弃」（在画布中为「放弃修改」）会恢复整场已保存的草稿。

字体菜单可以搜索软件字体库和系统字体库；选择「默认字体」恢复原字体。仅选中的文字会改变，保存并应用后直播画面同步显示。

编辑时，礼物图片是一整块，不能拆开改；投到直播画面后会显示图片。自己上传的图片支持 PNG、JPEG、GIF、WebP，单张最大 5 MB。GIF 和动态 WebP 的动画会保留。

快捷键、保存与放弃修改
  • Ctrl + B 加粗、Ctrl + I 斜体、Ctrl + U 下划线，Ctrl + Z 撤销，Ctrl + Shift + Z 重做。从别处粘贴文字，只保留文字，不带原来的格式。
  • 几千字或上万字正文可以直接粘贴，多行内容保留换行。编辑区可以手动滚动查看，自动滚动只影响预览和直播画面；切换方向后，仍可撤销刚才的文字编辑。
  • 修改会即时更新预览，手动「保存并应用」后才更新直播画面。新建或复制的文本框也需先保存并应用（或点独立浏览器源栏的「保存并生成」），才会生成专属直播地址。不想要刚才的修改，就点右上角「放弃」，回到上次保存的内容。
  • 当正在编辑的场景与当前直播输出不同时，顶栏下方会显示场景提醒。「保存并应用」会发布整个正在编辑的场景；如果涉及切换输出场景或包含文本框以外的未保存修改，会先弹窗确认。取消确认不改变当前输出。
  • 「放弃」会还原整个正在编辑的场景草稿。还有文本框以外的修改时会先弹窗提醒；已发布的画面不受影响。
  • 这里和画布里改的是同一个文本框。点「在画布中调整」会选中已有的那一份，不用再加一次。拖动边框改大小，里面的内容也会一起缩放。
