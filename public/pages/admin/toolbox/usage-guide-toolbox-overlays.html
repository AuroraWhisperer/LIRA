礼物特效

收到指定礼物时在直播画面上播放全屏动画。输入礼物 ID 点「播放特效」即可测试效果；「直播投屏」卡片里的地址固定不变，复制到直播姬的「浏览器」或 OBS 的「浏览器源」后，收到对应礼物会自动播放，平时画面透明不占位置。也可以点「打开预览」直接在浏览器里查看。

不知道礼物 ID 时，点面板的「查找礼物 ID」前往 gifts.lirahub.cn。开启弹幕触发后，观众可用四种写法：礼物特效 32132、礼物特效32132、🎁 32132、🎁32132；请替换为需要的礼物 ID。

开播动画与萌时钟

开播动画

打开「百宝箱 → 直播画面 → 开播动画」，填写主标题（最多 20 字）、副标题、主播名和底部文案。画质有「普通 · 推荐」「高 · 更多氛围粒子」「低 · 轻量模式」，轨道动效有三种，另可开关漂浮音符与氛围律动。

可上传人物图（不超过 16 MB）和开场音乐，音乐音量默认 35%。「显示整套特效」同时控制预览和投屏。将固定浏览器源地址加入直播软件，画面按 16:9 设置。

查看人物、音乐与地址

萌时钟

选择桃桃便签、星夜软糖、汽水小鸭、横向刻度、竖向刻度或白字数显。按需要调整显示日期、显示秒数、小时格式和角标文案（最多 16 字）。修改后点击「保存」，下次继续使用已保存样式。

复制「萌时钟网址」到浏览器源，推荐尺寸 580 × 210；它与开播动画使用不同地址。
