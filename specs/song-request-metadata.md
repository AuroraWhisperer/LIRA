# Feature: 点歌价格与歌切编辑

Status: Implemented

## Goal

落实用户授权的 song-request-conditions-design-report 全部客户端范围：价格是单个自由文本，新增、编辑、清空、列表和 Excel 配套保持一致；提供歌单整份替换预览、事务应用及核对平台保存值导出。

## Architecture and compatibility

沿用 songs.js 表单、song-import.js 文本解析、song-import-schema.js 规范化及 song-service.js 导入入口。复用 requestPrice / songClip，不改数据库、同步、IPC 或导出列序。用户于 2026-10-10 明确要求管理页取消导入模式，上传表格完整替换歌库并删除未列出的旧歌曲；该要求替代此前显式批量更新 UI。旧 API 的重复跳过/部分更新语义继续兼容，核对平台导出仍为保存值。

本规范显式升级 services.md 的价格别名“取首非空”规则：点歌条件、点歌说明也是价格别名；同一行不同非空价格别名冲突时该行失败；旧新增 API 的合法行继续导入，管理页整份替换则拒绝整批，失败序号按解析后的数据行计数。其他字段的首值规则不变。文本解析保留价格别名供领域入口统一判定，不在 UI 重复业务校验。

文本保真显式替代这两个字段原有 cleanText 的空白折叠：价格和歌切采用既有 cleanTextPreserveLines，保留内部空格、换行，统一 CRLF、去除控制字符并 trim 边缘；其余字段不变。价格数值 0 保留为文本“0”。

## Requirements and acceptance criteria

- REQ-SONG-META-001：价格、歌切始终可编辑。编辑完整回填原文；显式空值清空，旧请求省略字段保留；重置清除 id、价格、歌切和快捷状态。
- AC-SONG-META-001：新增并编辑舰长、30元SC、含引号与换行的文本后保存值一致；清空不影响另一首歌曲。
- REQ-SONG-META-002：价格表单显示 UTF-16 code unit 长度，超过 1000 阻止提交，历史超长内容不截断。快捷免费、舰长、提督、总督仅替换一个文本；SC 示例使用可编辑的“金额元SC”，不设默认收费金额。
- AC-SONG-META-002：1000 可提交，1001 被阻止；历史 1001 原文回填；空价格预览和列表单元格为空。歌切作为纯文本辅助信息，不强制 URL 或自动打开地址。
- REQ-SONG-META-003：列表新增状态旁价格列；保存反馈说明本地成功与云同步状态不同；停用说明不出现在公开歌单。
- AC-SONG-META-003：保存后提示本地成功且说明网页以云端同步结果为准；列表显示实际价格、空值留空，歌切可展开查看，停用说明可见。
- REQ-SONG-META-004：CSV、TSV、粘贴、XLSX 支持同一价格别名；冲突行返回 failures；相同值或单个非空值可导入。模板五首分别为免费、30元SC、舰长、提督、总督。
- AC-SONG-META-004：固定十列与旧表头顺序保持；带引号、逗号及换行的价格不拆分；CSV 公式防护及 XLSX 文本单元格保持；旧新增 API 重复导入明确跳过，未更新旧价格；管理页完整替换更新表中价格。

## Security and non-goals

价格、预览、歌切和导入失败信息使用纯文本或既有转义。核对平台、备注不是私密字段。本变更不增加付费资格判断、价格枚举、抓取 URL、存储字段或远程服务。

## 当前歌单导入：整份替换

- REQ-SONG-IMPORT-001：管理页仅提供「预览导入 → 确认替换歌库」，不显示模式或空值选项。新表格作为完整歌库：规范化后的歌名加歌手精确匹配则完整更新，否则新增，旧库未匹配歌曲删除（包括停用歌曲）。匹配歌曲保留 id；删除歌曲保留既有点歌记录及队列文本快照并解除歌曲引用；分类目录不清空。
- REQ-SONG-IMPORT-002：确认前展示新增/更新/删除/未改变/冲突/无效数量及逐行差异和删除明细。文件内同身份同规范化内容只处理一次，其余计未改变；不同内容的所有同身份行均冲突。任一冲突或无效行禁止整批替换；空表也拒绝，不能误清空歌库。
- REQ-SONG-IMPORT-003：完整替换时空白或缺失文本字段清空，分类为「默认」、是否可点为是。非空启用值必须明确，价格新值不得超过 1000 UTF-16 code unit。无表头输入要求完整十列。旧 preview/apply 不带 replaceAll 时仍保留缺列/默认空值，allowEmptyClear 兼容原部分更新规则。
- REQ-SONG-IMPORT-004：管理页向现有 preview/apply 传 replaceAll: true。预览 token 绑定完整当前歌库、分类、原始输入及替换/空值选项。应用在存储事务内重算校验；快照或输入不同返回 409，任何写入前拒绝。冲突/无效预览返回 422。UI 改变文件或粘贴内容即清除预览，异步旧响应不能恢复它。
- REQ-SONG-IMPORT-005：有效应用在一次本地事务执行新增、修改、删除、引用解除、批次和待同步完整快照；异常全部回滚。成功仅触发一次歌曲同步和广播；预览、失败不触发同步。核对平台保存值导出，CSV 公式前缀防护保持。不增加 schema 或云端 wire contract。
- REQ-SONG-IMPORT-006：输入 1–5000 数据行；整份替换以新表格去重后的歌曲数计容量，允许将历史超限库缩减为限额内歌库。旧部分更新入口继续按最终歌库总数校验，不自动删除。
- AC-SONG-IMPORT-001：验证同名不同歌手、停用歌曲、空白/缺列覆盖、重复同值/冲突、无效价格和启用值，以及仅删除但无新增/更新的有效替换。
- AC-SONG-IMPORT-002：输入/替换选项或当前快照变化使预览过期；数据库/同步快照写失败时歌曲、分类、引用、批次和待同步状态一起回滚。
- AC-SONG-IMPORT-003：XLSX、CSV、TSV 和粘贴走同一替换流程；UI 可逐页核对删除及变更，确认前不写库，重复点击不重复提交；错误、空表和未改变表格不会替换歌库。旧 JSON/XLSX 新增及部分更新 API 保持兼容。

## Done when

聚焦表单、导入与文件编解码测试通过，所属 API、音乐服务、存储和前端文档同步；隔离 Electron 验证整份替换预览、确认、字段清空和无效表格拒绝，检查差异且不修改无关工作区内容。早期更新实现见归档计划 `specs/plans/archive/2026-09-13-song-import-update.md`；当前整份替换见 [实施计划](plans/archive/2026-10-10-song-import-replace.md)。
