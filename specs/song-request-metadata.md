# Feature: 点歌价格与歌切编辑

Status: Implemented

## Goal

落实用户授权的 song-request-conditions-design-report 全部客户端范围：价格是单个自由文本，新增、编辑、清空、列表和 Excel 配套保持一致；提供显式批量更新预览、事务应用及核对平台保存值导出。

## Architecture and compatibility

沿用 songs.js 表单、import.js 文本解析、song-import-schema.js 规范化及 song-service.js 导入入口。复用 requestPrice / songClip，不改数据库、同步、IPC 或导出列序。默认重复歌名加歌手跳过。用户于 2026-09-13 授权报告全部阶段：新增显式批量更新模式，核对平台导出升级为保存值，替代此前第一版的固定空值约定。

本规范显式升级 services.md 的价格别名“取首非空”规则：点歌条件、点歌说明也是价格别名；同一行不同非空价格别名冲突时该行失败，合法行继续导入，失败序号按解析后的数据行计数。其他字段的首值规则不变。文本解析保留价格别名供领域入口统一判定，不在 UI 重复业务校验。

文本保真显式替代这两个字段原有 cleanText 的空白折叠：价格和歌切采用既有 cleanTextPreserveLines，保留内部空格、换行，统一 CRLF、去除控制字符并 trim 边缘；其余字段不变。价格数值 0 保留为文本“0”。

## Requirements and acceptance criteria

- REQ-SONG-META-001：价格、歌切始终可编辑。编辑完整回填原文；显式空值清空，旧请求省略字段保留；重置清除 id、价格、歌切和快捷状态。
- AC-SONG-META-001：新增并编辑舰长、30元SC、含引号与换行的文本后保存值一致；清空不影响另一首歌曲。
- REQ-SONG-META-002：价格表单显示 UTF-16 code unit 长度，超过 1000 阻止提交，历史超长内容不截断。快捷免费、舰长、提督、总督仅替换一个文本；SC 示例使用可编辑的“金额元SC”，不设默认收费金额。
- AC-SONG-META-002：1000 可提交，1001 被阻止；历史 1001 原文回填；空价格预览和列表单元格为空。歌切作为纯文本辅助信息，不强制 URL 或自动打开地址。
- REQ-SONG-META-003：列表新增状态旁价格列；保存反馈说明本地成功与云同步状态不同；停用说明不出现在公开歌单。
- AC-SONG-META-003：保存后提示本地成功且说明网页以云端同步结果为准；列表显示实际价格、空值留空，歌切可展开查看，停用说明可见。
- REQ-SONG-META-004：CSV、TSV、粘贴、XLSX 支持同一价格别名；冲突行返回 failures；相同值或单个非空值可导入。模板五首分别为免费、30元SC、舰长、提督、总督。
- AC-SONG-META-004：固定十列与旧表头顺序保持；带引号、逗号及换行的价格不拆分；CSV 公式防护及 XLSX 文本单元格保持；重复导入明确跳过，未更新旧价格。

## Security and non-goals

价格、预览、歌切和导入失败信息使用纯文本或既有转义。核对平台、备注不是私密字段。本变更不增加付费资格判断、价格枚举、抓取 URL、存储字段或远程服务。

## Stage 4: explicit import updates

- REQ-SONG-IMPORT-001：默认仅新增保持原行为；显式更新按规范化后的歌名加歌手精确匹配，包括停用歌曲。不存在则新增，不按模糊歌名猜测，不删除无关歌曲。
- REQ-SONG-IMPORT-002：提交前预览新增/更新/未改变/冲突/无效数量及每行差异。文件内同身份、同指定字段内容的重复行只处理一次，其余计未改变；不同内容的所有同身份行均冲突。任一冲突或无效行禁止整批更新，先修正再预览。
- REQ-SONG-IMPORT-003：缺列保留旧值；空单元格默认保留。显式允许空单元格清空时，仅存在列可清空文本，分类空值归默认；启用状态空值仍保留，非空必须识别为明确布尔值。新增歌曲缺省值保持现有语义。无表头更新要求完整十列，避免位置猜测。
- REQ-SONG-IMPORT-004：预览 token 绑定完整当前歌库快照（包含更新时间）、原始导入内容、空值选项。应用在存储事务内重算和校验；快照或输入不同返回 409，任何写入前拒绝。冲突/无效预览返回 422。UI 改变文件、粘贴或空值选项即清除预览，异步旧响应不能恢复它。
- REQ-SONG-IMPORT-005：有效应用在一次本地事务执行，只更新指定歌曲；异常全部回滚。成功仅触发一次完整歌曲同步和广播；预览、失败不触发同步。核对平台在 CSV/XLSX 导出保存值，CSV 公式前缀防护保持。
- REQ-SONG-IMPORT-006：输入最多 5000 数据行；最终完整歌库也不得超过 5000。历史超限库的纯更新同样不可应用，提示用户先在歌库整理，不自动删除歌曲。
- AC-SONG-IMPORT-001：同歌名不同歌手、停用歌曲、缺列/空格/显式清空、重复同值/冲突、无效价格、无效启用值有确定预览；无效价格含超过 1000 UTF-16 长度的新值。
- AC-SONG-IMPORT-002：预览后任一当前歌曲值或更新时间变更均拒绝旧预览；更改导入内容或选项同样拒绝；数据库写失败回滚全部变更、分类和批次记录。
- AC-SONG-IMPORT-003：CSV、TSV、粘贴、XLSX 列存在性一致；核对平台含公式前缀安全导出；UI 可逐页查看全部差异并确认应用，默认新增入口不改变。

## Done when
