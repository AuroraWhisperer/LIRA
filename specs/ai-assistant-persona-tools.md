# Feature: 通用 AI 互动助手、角色包与可选工具

## Status

Implemented — 2026-10-09。已按先实现、查验、调研、继续改进的顺序完成；180 项 AI 测试、隔离 Electron、页面/指南、文档、语法和架构检查通过。真实模型效果未使用用户账号测试。

## Goal

提供不依赖天气或地图的通用智能问答；小猫是可选角色包；不同模型可使用纯聊天、已有搜索或按需启用的外部工具。

## Architecture

- 沿用 `src/ai/` 模块化单体和既有模型适配器，不新增依赖、进程、数据表。
- `personas.js` 拥有内置角色、纯 JSON 角色包校验、当前角色选择及导出白名单。
- `config-store.js` 在既有 `ai_configuration` 保存 `personaId` 与 `personaPacks`，沿用 `systemPrompt` 保存自定义角色文本。角色上下文按观众和角色内容隔离。
- 通用提示只拥有事实、内容安全与发送约束；角色只提供身份、语气、背景。工具声明和实际执行均检查启用状态及配置。
- 新用户默认通用角色，联网、函数调用、天气、地点、路线默认关闭；函数总开关独立于平台原生搜索。已有显式配置保留。时间通过请求上下文提供，不再默认发送时间函数。
- 输入和输出审核继续独立存在；修正本地误拦截，审核格式异常不再伪装成内容拒绝。

## Contracts And Compatibility

- 保留现有 API、配置键、密钥加密、模型请求协议、触发词、并发与投递契约。
- 新增角色包命名创建、导入、删除、导出管理接口，复用现有管理页授权和错误包络。
- 旧 `systemPrompt` 完整保留为自定义角色，不进行模糊匹配替换；已有设置但无保存人设的用户保留小猫角色。
- 角色包仅允许版本、标识、名称、说明与人设文本，不执行脚本、不携带凭据或替用户启用工具。内置包不能删除；重名标识导入不得静默覆盖。
- 新配置只给有实际使用条件的工具声明。关闭的工具即使被模型请求也不执行；不把厂商名称当作模型能力证明。
- 一条弹幕的预算沿用 40 字符含提及，最多三条；人格不能覆盖预算或审核。

## Acceptance Criteria

1. 新配置可发送完全没有工具的聊天请求；关闭外部工具不影响常识问答。
2. 缺少密钥/地址、关闭或配额耗尽的工具不会提供或执行；实际可用搜索能够作为替代。
3. 通用助手不被追加猫语、颜文字、18–22 字模板或强制非思考模式。
4. 可切换通用、小猫、自定义与已保存角色，重启后保留选择和角色包；命名创建、导入/导出/删除可从设置页完成。
5. 自定义旧人设不丢失；角色包不会泄露 API 凭据；角色切换不串用其他角色的上下文。
6. 正常安全防护保留；防范盗号等正当问题交由语义审核；审核格式失败明确报告异常。
7. 设置页与技术参考、用户指导一致，现有自动保存及密钥保护回归通过。
8. 第一版通过聚焦验证后才进行网上项目调研；记录一手资料及对第二版的具体影响，再验证最终结果。

## Verification

AI 配置、工具/提示、生成、供应商、路由、前端交互测试；文档、语法和架构门禁；隔离 Electron 设置页检查。真实模型回答不使用用户账号自动测试，不将离线测试描述为实际模型效果保证。
