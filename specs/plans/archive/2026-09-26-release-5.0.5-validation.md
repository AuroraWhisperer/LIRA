## Release sequence

验证后按 guide 提交 v5.0.5 并核对提交说明无 Claude Co-Authored-By，推送 main，执行 npm run release:win。随后使用 gh release view v5.0.5 核对正式发布、标签提交及 exe / exe.blockmap / latest.yml；核对本地产物与远端字节数和 SHA-256，以及更新清单版本和 SHA-512。发布必须使用干净的已提交源码；发布结果由脚本日志、GitHub Release 和最终回复确认，不在发布后修改标签指向。

## Failure handling / Done when

任何门禁失败即暂停后续发布动作，保留日志并解决该项；只回退本任务引入的错误增量。若已创建标签或 Release，不擅自重指向或删除。发布准备完成条件为零失败零跳过的完整测试、相关静态门禁通过与发布内容核查；整个发布任务仍须远端标签与提交一致且三个附件完整。本文件记录准备阶段，后续发布按上一节执行。
