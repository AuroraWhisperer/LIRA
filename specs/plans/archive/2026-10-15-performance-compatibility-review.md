# 性能优化的真实使用兼容复核

Status: Completed

## Goal / Constraints

复核前两轮性能优化在正常操作、状态切换和恢复边界上的显示与功能等效性；修复已证实的回归，保留优化收益。保持显示设置、动画、采样频率、公开协议与用户数据不变，保留工作区其他任务修改，不打包或操作用户运行中的应用。

## Current Behavior / Ownership

既有证据见同目录的 `2026-10-15-rendering-performance.md` 与 `2026-10-15-canvas-runtime-performance.md`。本轮以当前源码和实际调用链重新核查，不能以旧的绿色测试直接推断所有边界等效。

- 歌词：`shared/lyric-word-animator.js`、`shared/lyric-word-renderer.js`、`lyrics/desktop-lyric-renderer.js` 及全民 K 歌消费者；验证暂停、前后跳转、模式切换和隐藏恢复。
- 画布：远程预览、舞台、场景 renderer；验证确认/撤销、编辑期间远端变化、失焦、重连及 iframe 重建。
- 游戏与播放器：棋盘缓存、全屏歌词和占位内容；验证真实状态与视图生命周期。
- 后台音乐与加班机：时间轴身份和显示边界调度。天/年档 `formatClock` 的向上取秒与 `nextClockDelay` 的原始时间取余不一致，复现与修正见下方结果。

## Milestones / Verification

1. 独立审查正常调用链，用现有 fixture 对具体怀疑做优化前后对照，区分新回归与原有问题。
2. 仅修改有证据的 owner；先补最小失败复现，再修正并运行其直接测试。计时边界由共享格式化模块拥有，消费者验证实际文字变化。
3. 修改固定后组合运行两轮优化直接相关测试；必要的真实 Electron 检查复用隔离 fixture。同步受影响技术参考；操作不变则不改用户指南。
4. `npm run verify:docs`、受影响模块语法检查、`git diff --check` 与最终差异/状态检查。临时脚本、数据和输出位于 `tmp/`，关闭自建实例。

## Failure Handling / Done When

不能证明等效的优化继续复现和修正，必要时只撤回本任务对应行；不覆盖其他任务改动。完成时所有确认的问题已修复且通过直接验证，审查结论说明证据范围、剩余候选及实机限制；没有证据的扩大重构不纳入本轮。

## Results

- 加班机：新用例在修复前明确失败，重现 1 天 60 秒运行 1 秒后仍停在 `1天 00:01`。共享 helper 改为按格式化后的整数秒推导下一次文字变化，保留 25ms 下限。分钟、小时、天/年降档及浮点余数由 owning helper 覆盖，管理页和真实 overlay fixture 验证文字更新；相关 7 项已通过。
- 画布：独立复现了焦点保护与快照去重的组合回归。字段获得焦点时外部修改被暂缓回填，失焦后没有新通知；再编辑其他字段会把旧值写回。`component-preview-panel.js` 增加局部字段订阅，接入队列、弹幕及公共效果参数，在失焦或颜色编辑结束后读取包含 pending 操作的最新乐观状态。颜色选择器通知逻辑编辑结束，Escape 返回的键盘焦点继续保留；不额外发业务请求，不恢复所有重复通知。真实浏览器覆盖远端更新、Tab、两种颜色关闭、再次打开、随后只改其他字段以及延迟确认时保留本地值；释放/重新绑定覆盖重复监听和已排队回填取消。
- 歌词：隔离 Electron 使用实际 HTML/CSS/模块，对优化前后连续、按字与关闭模式往返，以及前奏、边界、前后跳转共 48 个状态，活动行、文字、高亮裁剪/颜色/变换、倒计时完全一致。隐藏时跨句、暂停后跳转再显示均恢复正确行与进度；整块播放区域可见但歌词在视口外时，时间仍继续更新，区域隐藏后停止帧绘制，恢复显示立即呈现 5000ms 的暂停位置。无 pageerror，测试实例和 HTTP fixture 已关闭。
- 全屏播放器：优化前后 26 个连续状态/交互语义相同，含切歌、翻译/罗马音、手动浏览/恢复跟随、重开、空歌词恢复、封面失败与同 URL 重试。随后沿真实 producer 确认原有边界：关闭全屏、清理音乐缓存、从搜索重播同一首歌，若上游返回相同行数但内容或时间不同的歌词，旧 DOM 没有重建。已按歌词数组引用检测真实内容替换，修前永久回归失败、修后文字/高亮/点击时间正确，相同歌词 20 次 render 不重建或重复高亮；未增加每帧序列化。音乐运行时与重建发送者恢复检查 23 项通过，未发现时间轴原地修改或新的来源顺序问题。
- 舰徽：子 iframe 重载后保持原 WindowProxy，但页面内状态已丢失，旧的 `roomGuardKey` 会阻止相同状态重新送达。修前 owning 用例失败；现于已验证来源的 `ready` 清除该 entry 缓存，下一次数据更新补发一次，再继续去重。没有扩展原有配置初始化/权限流程，场景相关 18 项通过。
- 固定生产改动后，以 `node --experimental-vm-modules --test --test-concurrency=4` 合并运行 31 个直接相关文件，255 项通过、0 失败。后续仅将新队列回归的其他字段编辑移到外部更新断言之后，避免用例内前序 input/change 的待确认操作混入后序外部更新；保留全部行为断言，画布编辑、组件契约、颜色控件三个直接文件再次 27 项通过。日志为 `combined.log`。
- 八个本轮修改的生产模块语法检查通过，`npm run verify:architecture` 27 项通过。技术参考同步至 `docs/reference/frontend/app.md`、`overlays.md` 与 `playback.md`，测试扩展在已有 owner 文件内，测试路径索引不变。功能入口、设置、显示规则与操作流程未新增或调整，用户指南无须修改。
- 独立复核覆盖远程预览 ack/flush/重连、舞台缩放和标签定位、棋盘状态/闭包、后台时间轴来源与恢复；除上述四项外未发现本轮仍须修正的问题。没有为继续追求性能扩大到权限投影、存储接口或未确认绘画笔画。文档归档后运行 `npm run verify:docs` 并检查最终 diff 与状态。
