# Astral 与公共透视实施计划

Status: Complete

## Goal

按用户选定的 [Astral 原作者演示](https://www.etsy.com/listing/1692766782/astral-chat-widget-customizable-colors)实现新的客户端内置固定弹幕；在公共外观效果中提供左右透视与距离，所有弹幕样式可使用，保留原有布局、入场及清理责任。

## Current Behavior And Ownership

当前没有 Astral。安全消息与表情由 `danmaku-renderer-core.js` 提供，各款 adapter 与 CSS 拥有构图和装饰，feed 拥有测量、移动、到期和清理。公共 `component-style-parameters.js` / `component-effect-filters.js` 已支持 X/Y/Z 旋转、倾斜及固定 1000px 透视；不能再造第二套变换。视觉参考原图和 15 秒原片保留在 `tmp/danmaku-style-research-2026-11-07/`，本任务证据在 `tmp/astral-20261108/`。

## Proposed Changes / Compatibility

- 新建 `danmaku-astral.js` / `astral.css`；注册 `astral` 参数能力、默认区域、样式库卡片及效果目标。字体复用已交付 Nunito，中文沿既有回退，不新增下载器、连接或运行依赖。
- 公共 transform 增加可选 `perspective` 距离，缺省保持 1000；公共控件提供平面、左侧、右侧预设，仍写同一 transform 档案。测量与绘制共用 `effectTransform`。
- 保留真实文字/表情、当前房间身份、礼物结算总额、完整 SC 及撤下，沿已有本地账号外观、场景和预览通道保存。旧布局补缺失区域，现有用户数据不迁移、不重置。
- 同步拥有合同的 overlays / danmaku-motion 技术参考、参数指南与应用内弹幕说明。tour 与 README 仅在步骤或入口受到影响时改动。
- 不修改 HTTP/WS/IPC、授权、服务器旧 renderer、进程生命周期，不提交、打包或发布；保留其他任务的所有差异与 output。
