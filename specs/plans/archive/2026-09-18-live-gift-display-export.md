# 本日礼物展示与 PNG 导出实施计划

状态：已完成代码实施与隔离验证（2026-09-18）。依据：`docs/reports/2026-09-15-live-gift-display-and-export-research.md`，用户已要求开始修改代码。

## Goal

在现有全部礼物流水中筛选、跨页勾选并冻结选中记录，共用 400×96 礼物横幅预览、原生批量 PNG 保存和独立 `/gift-feed` 本日循环。

## Current Behavior / Ownership

查询由 `src/bilibili/gift/query-service.js` 和 `src/storage/gift-query-store.js` 拥有；接口在 `src/server/routes/gift-routes.js`。现有范围不含 today，历史无头像/身份资料及来源代次。管理入口和六列分页位于 `public/js/admin/gifts/history*.js`。Electron 没有图片保存桥。远端处理后礼物严格白名单需以显式能力协商扩展，不能破坏旧客户端。

## Compatibility Constraints / Non-goals

保留现有查询默认值、六列含义、清空确认、授权和本地来源隔离；不改结算/盲盒金额；不合并记录。采用北京时间和 100/500/1000 元初值，400×96 CSS 像素、2× PNG、8px 行距。旧资料未知使用占位，不按昵称追补。无新依赖、服务或通用写盘桥。不提交、发布或改动真实用户数据库。保留当前两个工作区的既有改动。

## Verification

使用隔离测试数据库、合成礼物和临时输出目录。运行直接相关 node:test、`npm run check`、`npm run verify:architecture`、`npm run verify:docs`；跨项目协议运行双方受影响测试。实机 Electron 小样检查捕获尺寸、透明和中文；使用同一页面检查 OBS 循环。最终 `git diff --check` 和 `git status --short`，检查任务拥有的 diff。

## Rollback / Failure Handling

失败或取消保留已成功保存的文件并报告实际数量；渲染窗口和监听器由创建方清理。未保存草稿不持久化，来源/重建使旧选择和任务失效。回退只逐项撤销本任务改动，不执行 reset、checkout 或广泛删除。

## Done When

报告中的选择/预览/保存/循环实际贯通，共享同一横幅，相关契约文档和自动化验证通过；对必须由 OBS 或生产服务器验证的部分明确记录限制。
