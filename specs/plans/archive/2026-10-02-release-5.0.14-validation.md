# v5.0.14 Release Validation Plan

**Status:** Completed — 发布准备、临时产物清理、统一验证与最终差异复核完成；远端发布结果以发布脚本和 GitHub Release 为准。

## Goal / Current Behavior

按 RELEASE_GUIDE.md 发布客户端 5.0.14，标签 v5.0.14；延续用户对提交、推送和发布的授权，以及提交前将临时、过渡材料移入 tmp 的要求。初始 main 为 cc7cb357（v5.0.13），远端相同且无 v5.0.14 标签。暂存区为空，共 328 个待发布文件，包括 260 个已跟踪变更和 68 个新增文件；主要为画布组件扩展、编辑恢复、输出尺寸持久化、界面主题和回归覆盖。

## Ownership / Proposed Changes

同步 package.json / package-lock.json 版本，UPDATE.md 记录相对 v5.0.13 的实际功能变化。scripts/publish-release.js 负责标签、构建、安装器校验、Release 创建及附件上传验证。发布准备仅新增版本与验证记录，并处理实际阻塞发布的问题。已有 songDb v9 迁移、场景输出与本地预览协议变更通过既有隔离测试和完整门禁验收。

## Compatibility Constraints / Non-goals

保留原有用户改动和安全、存储边界，不部署服务端，不操作用户正在运行的应用或真实数据，不覆盖已发布标签。LIRA_SERVER_ROOT 复用干净的 tmp/release-5.0.13/server-contract，固定提交 01fb2b47d5e081f5dd559933991ade4819eb3428，与契约锁一致。初始文件摘要、差异、临时日志、移动记录与提交正文存于 tmp/release-5.0.14/；正式组件缩略图与有索引的文档属于产品改动。

## Milestones / Verification

- [x] 核对发布差异和来源，清理过渡文件，执行 npm version 5.0.14 --no-git-tag-version，更新说明。
- [x] 配置本机 NSIS 编译器与插件，npm run verify 完成契约、文档、语法、架构和完整测试；核对原生安装、迁移和卸载场景未跳过。
- [x] 复核最终差异、git diff --check、git status --short 与源文件摘要，完成并归档准备记录；归档后复验文档链接。

## Release Sequence / Failure Handling

以 v5.0.14 和版本摘要提交并推送 main，然后执行 npm run release:win。Git SSH 到 HTTPS 的转换仅限当前命令进程。发布以脚本正常退出并输出 All expected assets uploaded 为成功依据；将构建中间文件归入 tmp，保留最终三个附件。失败时保留证据并修复确切阻塞，不跳过门禁、不回滚用户工作；标签已推送后若需源码修改则报告新版本需求。

## Done When

准备完成要求版本一致、所有必要门禁通过、差异范围与临时文件已检查。远端发布完成还要求脚本构建、安装器和附件验证成功，最终回复报告真实结果，不将准备完成等同于已发布。
