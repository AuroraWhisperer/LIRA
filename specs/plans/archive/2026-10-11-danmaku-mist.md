# 青雾全屏随机弹幕实施计划

Status: Complete

## Goal

按用户的五张参考图新增 `mist`（青雾）：普通用户透明直角白框，大航海用户浅青渐白卡片，外置昵称与爪印、内置圆头像；礼物用金额、赠送内容与昵称胶囊。自行设计同色系的大航海感谢和 SC。用户已授权自主决定视觉细节。

## Boundaries and ownership

- 延伸现有弹幕组件，不新增页面、消息协议、存储键、依赖或服务。保留现有未提交工作。
- 渲染核心由 lira-server 的 `public/overlay/danmaku-renderer-core.js` 所有；通过既有同步脚本更新桌面快照及哈希。
- 专用展示结构在 `danmaku-mist.js`，皮肤在 `mist.css`；字体、字号、背景透明度、随机位置参数及停留时间使用现有设置。
- 样式清单、区域默认值和可调效果能力需同步桌面与服务器的 Node/browser 副本，更新服务端设置枚举及 OpenAPI。
- 普通弹幕身份依据当前直播间的 `roomGuardLevel`，不把其他房间的身份当成本直播间大航海。购买感谢依据 `giftGuardLevel`。
- 当前随机 feed、场景入口及预览均过滤 SC。仅为 `mist` 放行；复用现有定时清理、随机避让和 SC 撤回，不改变其他样式。
- 不提交、部署；不操作用户运行中的桌面、账号或真实直播数据。

## Milestones

- [x] 登记样式与向后兼容布局、实现四类卡片；验证设置、身份、安全文本、金额和消息类型分支。
- [x] 接通本地预览、场景/组件来源和服务器随机 SC；验证追加/快照、删除、过期及旧样式过滤。
- [x] 使用隔离的本地静态展示与合成消息检查 1920×1080 浏览器源，生成实际渲染的样式缩略图；检查长内容、表情及随机避让。
- [x] 同步技术参考、样式参数和使用说明；完成受影响测试、文档检查、共享源校验及最终差异检查。

## Documentation impact

桌面更新 `docs/reference/frontend/overlays.md`、`pages.md`、`docs/guides/component-style-parameters.md` 与弹幕工具使用说明；检查交互导览是否需要改动。服务端更新 overlay 所属规范/协议的样式清单与随机 SC 例外。架构和鉴权边界不变，ADR 无需改变。

## Failure handling / Done When

改动前在 `tmp/mist/` 保留涉及文件的基线，失败时只回退本任务的具体差异，不使用整体覆盖或破坏性 Git 命令。所有四类消息可在新增样式中显示，旧布局可补齐默认区域，现有样式保持原行为；相关测试通过、文档准确、两仓差异已检查即完成。运行结果在完成时记录。
