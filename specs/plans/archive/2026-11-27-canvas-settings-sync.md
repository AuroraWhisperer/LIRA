# 客户端与画布共享参数复核

Status: Completed

## 目标与边界

同一组件的共享参数从桌面或画布编辑后，另一端可以读回，编辑不同字段保留各自已保存的值。以当前工作区、合成数据及隔离的 Electron 客户端和浏览器画布复核。场景布局、模板、资源样式、示例数据和直播业务数据沿用各自的保存与授权范围。

## 实施与验收

- [x] 展示板在桌面仅提交本次编辑的字段。桌面聚焦标题时从画布更新标题，再在桌面调整字号，请求只含字号，两个值均保存。盲盒榜筛选在桌面失焦后也显示画布已保存的值。
- [x] 内置大航海「辉光」「经典」各自保存中文、英文或中英双语。延迟桌面启用请求，在画布改为英文后再放行，最终读到已启用和英文。两端切换、发布播放、旧图层和导入样式分别验证。
- [x] 原生共享文本使用所属设置的校验。两端互改超过 80 字的展示板和盲盒榜标题、超过 300 字的评分说明、含复合表情的互动标题和提示，保存其他字段、发布及重开均可读取原文。场景文档、模板和样式导入保留自己的限制。
- [x] 滚动礼物按字段合并最新设置。桌面请求暂缓期间在画布改速度及另一档金额，最终三档为 3500、12000、100000 分，速度为 34。桌面输入 `12.` 时在画布改速度，再输入 `3`，两边均显示 12.3 元，直播投影为 1230 分。原生第四档的 1000000.02 元也在重开后保留。
- [x] 暂缓投票或评分标题的桌面保存，在原输入框继续输入，同时在画布改字号。正式输出同时得到后续标题和字号 22。
- [x] 歌曲信息按改动字段合并到最新配置。暂缓桌面标题字号请求，在画布关闭歌手显示，发布后字号为 64，歌手隐藏。开播动画也按控件提交。桌面改经典舞台标题时，画布设置的标准画质得到保留。像素卡带改成低画质后，两款设置分别为 `normal`、`low`。
- [x] 横向复核了歌词、加班机、实时榜单、心动盲盒、礼物许愿的数据，以及各图层的位置、尺寸和样式归属。

## 验证与交付

六个并行复核任务与主任务使用合成数据独立复现。最终联跑 20 个直接相关测试文件，190 项全部通过，包含 7 项 Electron 测试。另用隔离 Electron 客户端、浏览器画布和发布来源核对以上交错操作。语法检查覆盖 1971 个文件。实播软件与真实 B 站账号未参与这次验证。

架构检查 28/29 通过。失败项为 `public/js/admin/desktop-lyric-preview.js` 中两个只有注释的 `catch`，已核对当前提交含相同代码。文档检查的接口和规格索引通过。收尾时，同期死代码审计的活动计划缺少状态标记，弹幕参考还指向已移除的 `identity-cache.js`。这两项影响仓库文档检查。

设置接口和金额单位见[接口参考](../../../docs/reference/backend/api.md#画布共享参数)。共享设置、场景布局及预览数据的使用边界见[组件指南](../../../docs/guides/component-sources.md#新增组件参数)和客户端投屏常见问题。
