# 星轨飞语动效与参数复核

Status: Completed

## Goal

复核星轨飞语的出现、消失与独立／公共参数，修正确认的可见性和透明度问题，保留其透明文字与星芒光尾的视觉语言。

## Evidence and ownership

实测 40px/s 下，750ms 时正文仍在 960px 视口之外（left 983.68），680ms 入场却已结束；星芒颜色 alpha 为 0 时中央白点仍是不透明白色。造型与边缘由 `public/css/overlays/danmaku/startrail.css` 拥有，`danmaku-floating.js` 拥有实际起点、避让、匀速续接与完整离场清理。参数由 `public/js/shared/danmaku-style-options.js` 及其生成的本机 Node 镜像拥有。

## Decisions and boundaries

- 焦点：让星芒与首字在可视范围内开始分层入场；字形不缩放、扭曲。样式通过内部 CSS 长度 `--danmaku-entry-inset` 向 shared feed 声明起点内缩，其余样式默认 0；快照保留按时间恢复的位置，调参或速度变化不再次应用内缩。
- 连续性：保持从右向左匀速移动，左右边缘最多 28px 柔化，窄区按 4% 限制。离场继续按完整光尾处理，无新的退场定时器和停留字段。
- 反馈：六个独立字段、既有范围和默认值保留；辉光显示百分比，颜色帮助说明覆盖星芒／光尾／星尘，星尘说明依赖光尾，入场建议 450–800ms 且只作用于新消息。公共控件复用不等于全局共用值，仍按款保存。
- 预算：复用现有测量、WAAPI 与位置器；每个 feed 一个静态渐变 mask，核心颜色跟随 alpha；无新依赖、观察器、逐帧 JS 或外部请求。
- 不修改固定 renderer 快照、远程仓库、其他样式的造型／参数范围、认证、数据库和正式 Electron fixture；不提交、打包或发布。
