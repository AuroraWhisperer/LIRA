# 心动盲盒每周收集任务

Status: Completed

## 目标与规则

在「组件 → 礼物姬」加入「心动盲盒」菜单及可添加到画布的许愿组件。北京时间每周六 00:00 至周五 00:00 收集，周五保留本期结果，下周六自动开始下一期。固定 20 / 40 / 80 / 120 档，对应 4 倍 1 个、4 倍 2 个、5 倍 1 个、5 倍 2 个；只表达解锁奖励，不虚构数值概率。开启前本期已有记录纳入计数，出城堡不重置。

## 归属与现状

- `src/bilibili/gift/heart-box-collection.js` 拥有周期、累计、解锁和来源有效性；复用 `src/storage/gift-wish-store.js` 的已定稿盲盒计数及保留汇总。稳定盒 ID 32251，旧记录仅缺 ID 时允许精确盒名。
- composition root `src/server/domain-services.js`、`src/server.js` 与 `src/server/api-context.js` 仅装配；新增只读 `/api/gifts/heart-box-collection`，投屏凭据仅获得本组件的公开累计与阶段资料。
- Admin 延续现有礼物姬导航、懒加载和显隐生命周期；共享 renderer 拥有粉色任务卡与紧凑进度样式，管理端、画布与浏览器源共用。
- 独立场景类型 `heart-box-collection` 接既有组件目录、预览、数据缓存、来源切换、失联和刷新；场景已有存储校验支持 extra component 定义，无新表、设置键或远端协议。

技术契约归 `docs/reference/backend/bilibili/gift.md`、`docs/reference/backend/api.md`、`docs/reference/frontend/pages.md` 与 `docs/reference/frontend/overlays.md`；操作说明归 `public/pages/admin/toolbox/usage-guide-guard-thanks.html`。现有三周期许愿和盲盒榜的「出堡后计数」保持各自规则。
