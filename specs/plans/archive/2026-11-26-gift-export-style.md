# 礼物 PNG 导出样式

Status: Completed

## 目标与边界

在导出右栏就地选择跟随滚动礼物或自定义。保存上次选择和导出专用外观，预览与 PNG 使用同一份静态样式。范围限定在条带外形、内部纹理和四档价格分界。直播显示、选中流水、合并身份、分图和目录命名沿用各自现有契约。

## 现状与归属

`gift-export-runtime` 在选择流水时读取滚动配置，`gift-export-controller` 持有原始快照并派生排序与合并结果。管理页预览和隐藏导出窗口各自使用同一个礼物卡片构造器。原有导出偏好无独立外观，使用指南要求前往滚动礼物页改分色。

## 实施与验证

1. 扩展现有任务配置 IPC，以一个本地设置键原子存储来源和上次自定义值。主进程校验样式，保留原始快照身份，生成预览和写图共用的有效配置。用 `node --test test/gifts/gift-export-controller.test.js` 验证切换、重开、无效写入和实际渲染入参。
2. 在合并与保存位置之间加入样式区，复用滚动礼物的目录、色板和金额规则。用 `node --test test/gifts/frontend-gift-export-settings.test.js` 检查编辑、预览、金额错误及切换恢复。使用隔离的 `scripts/verify-gift-history.cjs` 核验桌面交互和实图。
3. 同步桌面 IPC、配置存储、礼物导出参考与使用指南。运行 `npm run verify:docs`、`npm run verify:architecture`，检查本次 diff、`git diff --check` 和 `git status --short`。

## 兼容、失败处理与完成条件

旧偏好缺少新键时跟随本次滚动快照。无效配置在主进程拒绝，编辑中无效金额在界面提示并阻止保存。新键使用现有本地 KV，无表结构迁移。若需撤回，仅移除本次 UI、任务配置扩展和对应文档改动，旧客户端可忽略该键。

以上两种模式在桌面可操作，预览与写图一致，自定义可跨任务恢复，相关验证与指南同步完成后结项。

## 验证结果

70 项定向用例通过，覆盖导出控制器、金额分界、卡片渲染、滚动设置与历史页。隔离 Electron 通过正式 preload 与 IPC 保存双卡 PNG，读回尺寸为 856 × 304，并在原斜切尾部以外读到自定义胶囊的紫蓝像素。D6 手册实图已按桌面自定义状态更新。
