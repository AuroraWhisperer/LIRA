## 实施记录

- 资源缓存：在现有 `one busy pending image` 用例中挂起远程清单，确认 `.pending` 的 `EBUSY` 已发生后，首个及后来的普通路径读取仍处于 pending。只把本轮失败路径提供给等待器并在扫描失败后唤醒；按摘要读取仍可等待其他包提供同一对象。改前聚焦用例失败，改后 `node --test test/desktop/cdn-resource-library.test.js` 29/29 通过（冷暖缓存、请求数量、旧摘要、损坏对象、离线及解锁重试）。已同步 CDN 故障指南与公共缓存参考，独立复核进行中。
- 画猜会话：独立探针和主线程重放均确认“开始广播 → 停止成功 → 旧开始 HTTP 回执”会把已停止的画猜复活，而数字炸弹不会。已分配 `games.js` / `games-draw-admin.js` 与既有 `frontend-games.test.js` 修复；沿用公共会话请求代次，需同时验证正常开局、替换会话与主持词读取，文档同步由主线程处理。
- 导入：末尾空列让原十列歧义输入绕过拒绝，三种真实解析格式均可预览删除两个原 ID 并写入误解析行。共享首行判定忽略十列以外的纯空单元格，保留原有完整表头要求；导入/前端/编解码套件 61/61，三格式拒绝及带表头正常更新均通过，独立复核中。该修正只改变解析判定，不改变同步 DTO 或传输限额，跨服务器 `verify:roundtrip` 不再作为本次必要检查。
- 播放：旧存档的重复手动插入曲目没有出现编号，重播当前曲目时游标会从 3 回到 1，把已播条目排回观众点歌之前。定位复用当前有效游标，保留同来源判断和带编号条目区分；队列、抽屉及持久化 78/78，独立复核中。
- 备份：恢复副本删除后保留的固定输出记录不是可选场景，旧恢复逻辑误计为已有副本，实际只恢复 1/2。恢复碰到隐藏输出时使用确定性替代 ID，保留原输出绑定/凭据与本地草稿；真实 ZIP/HTTP 及重复恢复通过，转移套件 12/12，独立复核中。
- QQ 集合：客户端/网页响应缺少列表或业务失败时被转成空成功，喜欢会话缓存后重试不再请求。已分配 Provider 所有者修复；保留合法空集合和既有客户端到网页回退。
- 排除 QQ 旧读取成功返回候选：原探针只证明 Provider 返回旧数据；实际客户端登录/退出经 `invalidateProviderContent` → `ContentLoader.invalidatePlatform` 使缓存写入与界面请求失效。现有账号失效两个用例通过。文档要求后继请求前核对 UIN，不能据此推导每次成功读取后都需新增检查；本轮不计为已确认客户端缺陷、不加重复保护。
- 独立复核补全：资源与指标检查通过（含真实 HTTP 404→离线解锁 200、同摘要共享及旧缓存验证），备份检查通过（含固定输出仍在播放、连续两轮删除恢复和双账号）。导入发现额外非空列仍绕过相同宽度门槛，合并到原根因修正：前十列含歌名歧义时额外列不消歧，歌名标题只出现在十列以外的外部表仍按标题读取；新增正式断言先红后绿及三格式 K 列标题对照通过，重新独立复核中。
