# 音频组件独立 CDN 交付

Status: Complete

依据：当前用户确认的 6.0.0 组件复用、新安装后台补齐及交付上传文件要求。

## 目标与边界

后续安装包移出完整音频组件；6.0.0 升级先保留已有组件并校验复用，新安装在首次授权后通过独立任务下载。保留 Electron、音频算法、声卡选择及页面布局，不发布版本、不上传 CDN、不修改无关的工作区变更。

## 决策与现状

- 音频现由 `build/audio-assistant` 随 `extraResources` 打入安装包，安装后约 167.5 MiB。原生助手和原生输出共用文件，但分别持有进程。
- 客户端内置唯一可信组件描述（文件摘要、平台、包摘要），组件身份按内容生成，与客户端版本无关。CDN 只交付一个不可变 ZIP；本地完整时零 CDN 请求，不增加远程 latest 清单或轮询。
- 现有字体/图片清单不接收可执行文件。复用字节校验写入工具与 ZIP 读取依赖，音频目录完整校验、原子启用由桌面组件 owner 管理。
- 安装器现在只保留 `data`，音频恢复守护可能晚于主程序退出。迁移必须在旧资源删除前完成，并延续按本安装路径匹配进程的退出协议。
- 使用 `data/components/audio/<内容版本>` 持久保存，普通缓存清理和账号切换不影响组件；旧包暂存为 `legacy`，主进程验证后直接重命名，避免再次复制。组件不参与业务云同步。

## 实施与验收

- [x] 生成内容版本固定的音频 ZIP 和内置描述；同一输入重复导出不产生不同版本；提供明确上传路径。
- [x] 实现单实例共享准备任务；优先本地/旧版校验，只有缺失或损坏才下载。拒绝包摘要不符、额外成员、路径穿越及链接；完整成功后启用，失败和关闭不留下可运行半包。
- [x] 接入两个音频使用者、授权后的后台准备、现有下载中心与重试。组件未就绪时保留默认浏览器输出，原生输出等待明确准备状态；不擅自改变保存设备。
- [x] 安装器在删除旧程序前保留旧组件；更新和卸载识别新目录中的本实例原生进程，保留恢复握手，不强杀。
- [x] 同步 owning references、ADR、上传指南及受影响应用内帮助；执行聚焦 Node/前端/隔离 NSIS、语法、文档及架构检查；全库架构检查的既有问题见下文。
- [x] 构建隔离验证安装包，确认不包含音频二进制，并用真实导出包核对首次下载、再次启动零请求及旧包迁移复用。生成上传目录及测量结果，审阅最终任务 diff 和 `git diff --check`。

## 失败与回退

下载只写本任务临时目录；哈希/解包失败保留现有已验证版本。安装器复制失败停止升级且保留旧源与数据备份。保持旧客户端所需线上文件；交付 ZIP 上传成功后才可发布采用其内置描述的新客户端。工作区已有其他任务变更，回退只处理本计划拥有的差异，不执行整树恢复。

## 完成标准

上述验收全部有执行证据；原生功能代码未变；已有完整组件不产生 CDN 请求；首次准备与重试不重复注册或重复下载；上传文件可直接交付且无需上传新的运行时清单。只构建验证包，不将其冒充正式新版本发布。
