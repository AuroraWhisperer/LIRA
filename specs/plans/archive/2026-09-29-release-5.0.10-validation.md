# v5.0.10 Release Validation Plan

**Status:** Completed — 发布准备与验证完成；提交及远端发布结果在最终回复中报告。

## Goal / Current Behavior

按 RELEASE_GUIDE.md 发布客户端 5.0.10，使用标签 v5.0.10。用户已授权指南中的提交、推送、打标签和发布。初始 main 为 7179ab70，工作区包含星轨/翻牌时钟及平台术语与文档修订，暂存区为空。

## Ownership / Proposed Changes

package.json 与 package-lock.json 同步版本；UPDATE.md 提供提交与 GitHub Release 摘要；scripts/publish-release.js 负责标签、构建、安装器验证及上传。本任务只新增发布元数据、验证记录及实际阻塞发布时必要的最小修复。

## Compatibility Constraints / Non-goals

保留所有待发布用户改动；不改写远端历史或已有标签，不部署服务端，不操作真实账号、用户数据或正在运行的桌面应用。测试沿用隔离 fixture 与锁定服务端契约；临时材料放在 tmp/release-5.0.10/，不提交生成物或秘密。

## Milestones / Verification

- [x] 核对当前改动与上一版，更新版本及更新说明。
- [x] 核对远端 main/tag 与发布前置条件；执行 npm run verify，包含指南要求的完整 npm test。
- [x] 审查待提交 diff、git diff --check、git status --short，核对无意外文件；完成并归档发布准备记录。

## Release Sequence

使用 v5.0.10 标题与本版摘要提交；检查最新提交没有 Claude Co-Authored-By 后推送 main。执行 npm run release:win，然后用 gh release view v5.0.10 核对正式发布、说明与 exe、exe.blockmap、latest.yml 三个附件，确认远端 main/tag 与本地 HEAD 一致。

## Failure Handling / Done When

失败时保留证据，只修复阻塞原因后重跑受影响检查，不绕过验证、不删除用户工作。准备完成以版本一致、测试通过及 diff 审阅为准；远端发布结果在最终回复中报告，不能用本计划代替远端核验。
