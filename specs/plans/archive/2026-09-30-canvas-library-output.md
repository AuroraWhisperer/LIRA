# Canvas Component Library And Combined Output

**Status:** Completed on 2026-09-30. Implementation, focused verification, visual QA and final diff review are recorded below.

## Goal And Decisions

Replace the four left-side add buttons with a component list and one Add Component action. Its dialog groups existing visual styles by component category. Catalog additions own independent appearance, so two styles of the same component can coexist and be tuned on the right. Opening the common editor initially shows an empty canvas; saved layouts restore. Entering from a component preview selects or adds that component without erasing saved layers. The user explicitly confirmed first-use emptiness with later restoration.

Expose the existing combined local scene source through this browser editor. Save and Apply saves original component owners and the bound scene draft, then publishes through the existing scene owner. Copy Live Source retrieves that scene's persistent capability explicitly and produces `http://127.0.0.1:<actual-port>/scene?id=…#token=…`. Normal edits/publications reuse the source; changing the configured listener port still requires recopying.

## Ownership And Compatibility

Keep the existing scene service/store, revision checks, appearance normalization, publication staging, source capabilities and real data projections. No database migration, new service, fixed port, listener changes or weakened authorization. The preview relay permits only two additional canvas actions (`publish`, `source`) bound to the desktop adapter's scene ID; other component capabilities cannot invoke them. Source credentials appear only in the response to explicit copying, never inside a document/template. Invalid ownership generations fail before further operations.

The browser waits for all queued edits to reach desktop controllers before publishing. Original controller save failures and concurrent changes stop publication and preserve the previous live version. Requests accepted before browser closure may complete; the temporary preview capability still closes. Direct editor entry is an authorized desktop launcher without a component query; a bare URL never manufactures management access.
