# 礼物 PNG 导出跨结算合并

## 目标与边界

在客户端导出预览中增加默认关闭、自动记忆的「跨日期合并同种礼物」开关。同一观众在三个日期各送 100 个同种礼物时，开启后预览和 PNG 均展示 300 个。关闭时使用原有快照，包括北京时间今天已有的自动合并。原始流水、结算、统计与滚动展示继续沿用各自的契约。

## 实施与验证

- [x] 服务端在现有 Device 礼物模块提供一次只读的导出分组查询。设备授权决定租户，最多接收本次选择的 10,000 个公开事件 ID。相同的可靠 UID、礼物 ID 和规范名称确定一个组，响应只列出该组的已选事件 ID。分组、租户隔离及 OpenAPI 样例通过 `test/gift-card-profiles.test.js` 的 16 项测试，`npm run docs:check` 通过 60 项检查。
- [x] 桌面按需合并冻结快照，今日卡片用代表事件参与查询，数量及整数分金额沿用其合计值。旧服务或资料缺失时保留原卡片并提示。桌面定向回归 70 项通过，覆盖分组复用、关闭时取消请求和原预览恢复。
- [x] 管理页复用客户端主题开关及自动保存流程。隔离 Electron 实测三天各 100 个小花花导出一张显示 ×300 的 PNG，并用正式桌面预览更新了使用指南截图。

## 交付与回退

新设置沿用本机设置库，缺省关闭。现有设备协议继续服务旧客户端，服务端可先部署。需要还原展示时可在同一预览中关闭开关。实现和验收均使用合成流水。
