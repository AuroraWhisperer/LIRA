# 礼物 PNG 导出排序与词条间距

Status: Completed

目标是让导出预览和最终文件使用同一组卡片顺序和间距。现有预览、隐藏渲染页和桌面截图分别计算固定间距，礼物历史还能按表头排序。实施范围是桌面导出任务、设置面板和对应手册。

- [x] **冻结与排序**。导出运行时按时间从新到旧取回所选记录，在已有合并流程累计每张卡的实际结算金额。控制器在分页前按选择生成快照，同额保留时间顺序。复用任务的合并缓存。给 `settings` 和 `configure` 增加可选的 `sortBy`、`rowGap`，沿用本地设置存储和目录选择流程。旧设置使用时间排序和 16 个输出像素。
- [x] **预览与导图**。用共享布局计算单张 PNG 高度。恰好两张卡的长图可选 0–32 个输出像素，默认居中。其他页使用既有布局。滑动只更新当前页的间距和尺寸，松手保存。沿用右栏分段选项和滑块，缩减设置行上下留白。
- [x] **验收与同步**。卡片模型、运行时、控制器、预览设置、横幅与历史选择六组定向测试共 64 项通过。`scripts/verify-gift-export.cjs` 在 100% 和 150% 缩放下实测了双条 PNG 的 288、304、320 px 高度，并用第二条的起始像素与卡片分色核对间距和金额顺序。隔离桌面镜头 D6 更新了手册配图。存储和 IPC 参考已同步，文档、语法与架构检查通过。

保留现有通道、冻结选择与来源校验、导出批次和 39 行拆图上限。出现差异时按对应层的测试和像素定位，回退只涉及本次改动。完成条件为上述行为在预览与导出一致，使用指引与实测结果相符。
