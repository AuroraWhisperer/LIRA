# 月渡花汀外置套装

Status: Complete

## 目标与边界

从默认客户端/画布样式中移除月渡花汀，并从 EXE 白名单排除其图片、视频、专用字体和缩略图。交付可经现有导入入口安装的 ZIP，保留静态/动态背景、程序开播动画、时钟配色、弹幕与许愿效果。源码与原始素材保留用于维护；小型受信渲染代码仍随客户端提供，不执行 ZIP 中脚本。不发布新版本，不修改用户真实素材库。

## 归属与决策

复用 component-style-library/store 的校验、暂存、安装、删除及引用保留。增加可选资源型样式：清单声明已有渲染预设与多文件资源，导入后为每个实例保存不可变资源映射；普通单媒体样式合同保持不变。渲染器使用受限映射替换本机素材路径；CSS 仍来自客户端，ZIP 仅含媒体、必要的 SVG/WOFF2 和说明。

## 步骤与验证

- [x] 建立资源型样式合同和 ZIP 导出脚本；校验已知预设、资源完整性、媒体来源与旧格式兼容，生成月渡花汀 ZIP。
- [x] 复用原渲染器从导入资源加载，移除默认入口并保留导入后的调整能力；验证六个样式、真实显示数据、删除后引用和缺失素材提示。
- [x] 排除专用资源并用 electron-builder 文件过滤器核实；隔离测试在原资源不可访问时导入 ZIP 后的输出，记录大小、摘要和导入步骤。

## 兼容、失败与完成标准

沿用现有授权、原子安装、文件限额、场景保存应用边界和数据目录。保留旧场景样式标识；新资源路径含包 UUID 与摘要，不同版本不覆盖旧实例。失败仅清理本次临时目录。第三方普通 ZIP 仍由用户解压后单独添加。相关测试、语法/架构/文档、差异检查通过或明确既有失败后完成；ZIP 能在未提供 public 原图的隔离环境里导入并渲染。临时文件在 tmp，交付 ZIP 在 output。
