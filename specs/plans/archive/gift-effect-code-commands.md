# 礼物特效代码指令调整

**Status:** Completed — 2026-09-14（未部署）。

**Goal:** 按 2026-09-14 用户修订，只接受 `礼物特效 代码`、`🎁 代码`，触发与测试播放相同的素材和播放器。

## Decisions and scope

- 移除上一版名称匹配、服务端目录匹配和媒体下发；服务器只解析真实 giftId，按既有开关与租户范围发送临时指令。
- 复用现有 Device SSE 能力协商。上一版尚未部署的 gift-effect 载荷收窄为 type/source/eventId/giftId，同步修改双方规范、fixture 和测试。
- 客户端调用测试播放使用的 `domainServices.gifts.resolveEffect`，不修改测试播放的选择规则。
  异步解析前后检查开关与原连接授权边界，防止停用、换账号或旧连接的迟到播放。
- 保留展示站文字链接、开关保存、既有 OBS 播放器和串行队列，不改变礼物账本、权限、其他用户工作区改动，不提交或部署。
