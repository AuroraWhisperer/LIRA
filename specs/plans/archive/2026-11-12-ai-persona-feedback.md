Status: Completed

本文件是已完成的实施与实验记录；当前行为以 AI 技术参考为准。保留旧 ID 兼容决定和真实回放证据，不作为重新启动直播测试的指令。

2026-11-12 用户授权新增鲸鱼娘、保留小猫；两个角色日常均为温软、童真、可爱的小姑娘风格，不顶嘴，不以空话填充。直播测试已停止，本轮只进行本地回放与 DeepSeek API 评估。

同日追加要求：DeepSeek 为减少等待取消生成前后的两次远程模型审核；自动接话和点名问答都直接按所选预设生成，普通聊天只请求一次。保留程序本地检查；工具续接和送达重试不属于普通聊天的一次调用承诺。

## 当前证据与目标

旧内置小猫在 API 回放中将“你聊天很无趣啊”回复为“那你说点有趣的听听…喵”；多数普通回复使用同一尾缀。自动候选只携带未消费的新弹幕，较早公开前文和已发送回复的目标缺失。完成条件是两个预设可选、普通对话保留角色语感、对重复不满/明确止聊安静，DeepSeek 普通聊天只生成一次，并保留候选、身份、本地检查及其他供应商的调用边界。

## 拥有者与范围

- `src/ai/personas.js`、`prompt.js`、`auto-reply-prompt.js`：角色与表达规则，候选和公开背景分离。
- `auto-reply-controller.js`、`ai-reply-generator.js`、`ai-assistant-service.js`：复用最近 30 秒/40 条公开窗口，已送达回复关联原作者；旧消息不能再次成为目标，已拒绝输入不污染后续评估。
- `ai-reply-generator.js`：DeepSeek 两路跳过远程输入/输出审核；其他 API/订阅供应商保留原流程，豆包保留既有单次生成和会话隔离。定向缓存规则升级到 `reply-v10`。
- `config-store.js`、管理端角色控件：沿现有选择、编辑、恢复、导入导出和平台记忆接入鲸鱼娘。
- 契约为 `docs/reference/backend/ai.md`，使用说明为 `public/pages/admin/toolbox/usage-guide-ai.html`；回归位于 `test/ai/` 现有套件。

## 兼容决定

新增内置 `whale` 与旧版允许的同 ID 自建包可能冲突。仅在读取确有旧自建 `whale` 时，将其映射为不占用的 `imported-whale`（冲突时递增后缀），保持名称、正文、当前选择和各平台选择。读取不落盘；下次正常保存时将包与选择一起提交到现有事务，失败不修改原记录。没有冲突的配置不迁移。不改变包格式、数据库表、密钥处理、公共接口和默认选择。
