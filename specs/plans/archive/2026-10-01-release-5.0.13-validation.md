# v5.0.13 Release Validation Plan

**Status:** Completed — 发布准备与统一验证完成；提交及远端发布结果在最终回复中报告。

## Goal / Current Behavior

按 RELEASE_GUIDE.md 发布客户端 5.0.13，标签 v5.0.13。用户已授权提交、推送、标签及发布，并要求提交前将临时与过渡产物移入 tmp。初始 main 为 0e1ded61（v5.0.12），远端相同；暂存区为空，89 个待发布文件涉及日程提醒、显示器信息、画布与工具界面调整及回归测试。远端 v5.0.13 不存在。

## Ownership / Proposed Changes

package.json / package-lock.json 同步版本，UPDATE.md 描述相对 v5.0.12 的实际变化，提交及 Release 复用该摘要。scripts/publish-release.js 拥有标签、构建、安装器与附件验证。本次仅新增发布元数据、验证记录，以及实际阻塞发布的最小修复。

## Compatibility Constraints / Non-goals

保留既有用户改动、接口和安全边界；不部署服务端，不操作用户应用或真实数据，不移动已推送标签。服务端契约通过 tmp/release-5.0.13/server-contract 的独立 detached 检出验证，固定在锁文件指定的 01fb2b47d5e081f5dd559933991ade4819eb3428。临时日志、初始文件 SHA-256、移动记录和提交正文全部位于 tmp/release-5.0.13/。

## Milestones / Verification

- [x] 审阅改动、归档临时材料；npm version 5.0.13 --no-git-tag-version 并更新 UPDATE.md。
- [x] 配置 NSIS 编译器与插件，npm run verify 验证契约、文档、语法、架构及全部测试，检查原生安装器场景实际执行。
- [x] 复核 diff、git diff --check 和 git status --short；核对原始源文件摘要，归档准备记录。

## Release Sequence

准备完成后，以 v5.0.13 和本版摘要提交并推送 main，再执行 npm run release:win。脚本正常退出且输出 All expected assets uploaded 才算发布成功。仅在命令进程中将 Git SSH URL 转换为 HTTPS，不修改仓库远端配置。最终回复报告远端发布结果。

## Failure Handling / Done When

失败保留日志，修复实际阻塞点并重跑受影响检查，不跳过门禁或回滚用户工作。标签推送后若源码必须修改，报告需要新版本，不覆盖标签。准备完成以版本一致、统一验证通过和差异审阅完成为准；正式发布以脚本构建与附件校验成功为准。
