# 画布与常驻运行时的等效性能优化

Status: Completed

## Goal

在已完成歌词渲染优化的基础上，排查画布、其他直播组件和软件常驻功能，消除相同状态的重复处理；显示、动画、同步精度和交互能力保持原样。

## Current Behavior And Ownership

- `admin/component-preview-remote.js`：250ms 空闲读取也通知所有控制器订阅者，触发草稿复制和界面刷新。5 个连接、20 次相同快照的合成基线为 100 次无效通知、1900 次克隆。
- `admin/scene-editor-stage.js`：每次拖动通知重写所有图层文字、属性、位置，并在同次 render 中定位标签两遍。保留既有冻结快照和 iframe 复用。
- `overlays/games.js`：每秒相同对局仍重建数字炸弹/五子棋按钮；60 次相同状态额外创建 6000/15300 个节点。
- `playback/ui/fullscreen.js`：音频 timeupdate 反复写相同标题、缺省封面和歌词高亮；完整渲染仍需维持歌曲切换和翻译模式语义。
- `server/music-runtime.js`：只更新播放时钟也序列化整首时间轴两遍；120 次更新、200 行 × 15 词的合成基线为 240 次序列化。
- `overlays/scene-renderer.js`：重复向每个 iframe 发送相同 roomGuard；32 个 iframe、100 次相同状态为 3200 条无效跨 frame 消息。
- 合同归属：`docs/reference/frontend/app.md`、`frontend/overlays.md`、`frontend/playback.md`、`backend/music/services.md`。扩充现有预览、画布、游戏、播放器和来源切换测试；用户入口与设置未变，指南无须改动。

## Compatibility And Non-goals

保留刷新/采集频率、图层尺寸、动画、倒计时、落子、点击、撤销、保存/发布确认与错误恢复。保持 HTTP/WS/IPC、持久化和权限边界。保留工作区已有歌词配色及其他修改。

并行审计还发现 WS 广播编码和场景存储读取可进一步减少工作，但涉及权限投影或存储读取接口，不与本轮局部渲染优化混改。你画我猜的 Canvas 含本地未确认笔画和权威恢复，本轮不缓存笔画。弹幕、礼物滚动、许愿、盲盒、开播等已有复用或可见性控制，不降低其效果或频率。

## Proposed Changes And Milestones

1. 预览控制器只在权威状态变化或待确认命令移除时通知；保持连接错误单独通知。验证同值 edit ack 能结束 flush，保存和重连不受影响。
2. 画布只写变化的属性/文字，单次 render 只在选中状态更新后定位标签一次；fit 继续响应缩放和容器尺寸。验证拖动、调整尺寸、选择、锁定、缩放与自动高度。
3. 数字炸弹、五子棋只按棋盘实际输入去重；状态栏/结果继续更新。验证落子、回合、胜负、重置、切换与点击。
4. 全屏播放器避免相同文字/缺省内容和高亮重写；重新生成歌词后使高亮缓存失效。验证曲目切换、翻译/罗马音、前后 seek 和手动浏览。
5. 音乐运行时记住最近已比较的时间轴引用，直接跳过后续同引用比较，保留新时间轴深比较和来源切换强制发布。验证归一化后内容替换、同内容新对象、来源切换及状态递增。
6. 场景每个 iframe 仅在 roomGuard 变化时发送徽章状态；首帧、人数/房间变化、空状态及新 iframe 仍发送，其他 data/event 通道不去重。

## Verification

- 扩充并运行对应 Node 测试；保持异步确认和状态边界覆盖，避免实现镜像断言。
- 使用现有隔离 fixture 做真实浏览器/ Electron 渲染、相同状态的 DOM 操作计数和必要前后截图；不启动用户应用或使用真实数据。
- 运行受影响语法检查、`npm run verify:docs`；模块依赖未改变时只在具体影响需要时扩展门禁。
- 最后检查本轮 diff、`git diff --check`、`git status --short`；临时产物留在 `tmp/`。

## Failure Handling

任一去重遗漏真实变化时修复缓存边界或撤回该处任务改动；只对任务拥有的行逐项回退，不覆盖其他修改。隔离验证结束后关闭测试实例和服务。

## Done When

六处确认的重复工作消除，相关变化仍及时生效；聚焦测试和真实渲染证据通过，文档同步，最终差异无运行时/敏感数据。计数仅说明操作减少，不宣称未经测量的整机 CPU 降幅。

## Results

2026-10-15 完成六处优化，生产改动分别位于上述 owner。新增覆盖并入已有六个测试文件，技术参考已同步；显示参数、默认设置、用户入口及操作流程不变，用户指南无须调整。

| 32 图层、60 次移动 | 9960 次样式写入、19320 次布局属性读取、1920 次标签文字替换 | 60 次样式写入、9720 次布局属性读取、0 次标签文字替换；最终几何完全相同 |
| 数字炸弹 / 五子棋各 60 次相同状态 | 6000 / 15300 个新节点 | 两者均为 0；回合、范围、落子、胜负、重置仍更新 |
| 全屏播放器 120 次重复渲染 | 360 次子节点替换、240 次歌词节点查询 | 0 次子节点替换、120 次查询 |

### 验证与故障复盘

- 最终组合运行预览远程状态/草稿、画布编辑与浏览器草稿、歌词来源切换/外部跟随、场景渲染、全屏播放、小游戏及绘画相关 11 个文件：114 项通过，0 失败。六个生产文件的 `node --check` 通过。
- 初次组合运行有 1 项画布撤销测试失败：界面已显示图层，但测试截取的桌面权威快照尚未确认该显示操作。将预览控制器及画布脚本切回优化前版本，并对该请求加入受控 2 秒延迟，复现同一失败。测试现先等待权威可见状态同步，再采集撤销基线；原深相等断言不变。受控延迟复现检查及最终并发组合均通过，未为此更改生产行为。
- 隔离 Electron 使用真实生产渲染模块和 CSS、合成数据、独立临时 userData 与 session partition；没有启动或操作用户应用。播放器默认/翻译/罗马音/空歌词共 4 组，数字炸弹及五子棋回合/棋子/结果共 6 组，前后 PNG 字节一致。截图对照在字体就绪、滚动稳定及动画同一时刻进行。
- 画布适配、移动、50% 缩放共 3 组截图中，分别有 41/70/37 个像素的单通道最大差异为 1/255（每图 2,127,684 像素），布局几何一致；不将其描述为字节一致。32 图层性能对照使用相同初始高度和实际手势更新，避免独立内容测量造成输入不同。
- 实际播放器滚轮浏览保持当前位置，播放进度继续更新高亮，点击跟随可恢复；翻译切换生效。所有隔离页面没有 pageerror，测试 Electron 与 fixture 服务已关闭。
- `npm run verify:docs` 在技术参考同步后通过 10 项；归档后再次运行。最终差异检查与工作区状态检查用于确认临时数据未进入改动，其他任务修改保留。

### 验证边界

本轮完成的是源码优化及隔离验证；未更新安装包、提交或发布。纯渲染 Electron fixture 不证明未修改的 preload/IPC 集成，也不替代真实直播与不同硬件上的长期性能测量。未降低刷新或采集频率、像素质量、图层能力和动效；涉及权限投影、存储接口及未确认笔画的额外候选没有纳入改动。
