# 文本框组件实施计划

Status: Completed

## Goal

在百宝箱“小游戏”上方增加文本框页；复用场景的独立组件、保存、发布和预览，支持多个文本框、局部富文本、固定礼物图片块、上传图片和内置颜文字。

## Non-goals

不引入富文本框架、前端构建步骤、全局文本框单例、任意 HTML 执行或新的远程服务。不修改现有礼物许愿和加班机业务规则。

## Current Behavior / Ownership

- `scene-components.js` / `scene-component-types.js` 定义组件身份；`scene-contract.js` 与 `scene-template.js` 校验文档。
- `component-preview-canvas-controller.js` 保存/发布，`scene-item-controller.js` 负责独立实例；`scene-editor-stage.js` 与 `scene-renderer.js` 承载相同隔离 iframe。
- `gifts/wish-picker.js` 已有房间/全部礼物查询；`gifts/wish-text-editor.js` 是不可编辑块与 Chromium 撤销的参考，不改变其模板职责。
- 现有场景总数上限 32；取消文本框的数量上限，同时保留其他组件数量保护及文档 256 KiB 保护。
- 现有未提交的画布、字体和礼物展示改动保留。

## Compatibility Constraints

文本框使用新 `text-box` 独立组件；旧文档和共享组件行为不变。文本配置只存结构化节点，不存任意 HTML。上传保留原始动图，限定 PNG/JPEG/GIF/WebP、5 MiB 和固定 UUID 路径。桌面 API 沿用认证；外部画布仅通过有效 canvas attachment 的 capability 读取礼物/上传图片，不授予通用管理 API 权限。

## Proposed Changes / Interfaces

- shared `text-box-config.js`：`createTextBoxDefaults()`、`normalizeTextBoxConfig(config)`；根字段 version/fontSize/color/align/lineHeight/nodes；text/gift/image 节点。
- shared `text-box-renderer.js`：`renderTextBox(host, config, { editable })`，实际图片与文字按同一字号比例渲染。
- admin `text-box-editor.js` 和工具栏/素材模块：一套编辑器用于桌面详情和画布参数；选区格式、原子素材、纯文本粘贴及撤销。
- admin `text-box-preview.js` / `text-box.js`：接入既有 controller 与组件注册，桌面列表、独立编辑与最终预览。
- `scene-text-media-routes.js`：桌面 `/api/scenes/text-gifts|text-image`、受限 capability `/api/component-preview/text-gifts|text-image`；同一素材 owner。
