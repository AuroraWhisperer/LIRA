# 郁香海风弹幕复现

Status: Completed (2026-11-07).

## Goal

对照用户选定的[郁香海风原作视频](https://www.bilibili.com/video/BV1vHY76oEEf/)，复现常规与全屏随机两版的文字排版、身份标识、礼物/大航海/SC 展示及入退场动画，加入客户端样式库，并验证桌面保存和本地场景输出。

## Scope And Ownership

- 外观由新增的 `public/js/overlays/danmaku-sea-breeze.js` 与 `public/css/overlays/danmaku/sea-breeze.css` 共同拥有，两版共享内容构造，继续使用现有固定/随机 feed。
- 注册与参数：浏览器 `danmaku-style-options.js`、`danmaku-layout.js` 及其现有 Node 镜像、样式目录、管理页和独立预览入口。
- 合同：`docs/reference/frontend/overlays.md`、`danmaku-motion.md`；使用说明：`docs/guides/component-style-parameters.md` 与现有内置指南。
- 测试复用 renderer、样式参数、布局、appearance 套件及隔离 Electron 夹具；所有视频采样、比较图与临时工具位于 `tmp/sea-breeze-2026-11-06/`。

## Current Behavior And Constraints

任务开始时工作区干净，客户端尚无郁香海风。原作包含两版，不能把随机布局替换为普通列表。先采样原视频再确定具体几何与时序；未知的源码参数不冒充原作者参数。复用真实消息、表情、房间身份、已结算金额与本地外观保存通道；不修改上游事件、认证、存储结构、服务器 renderer 或其他样式。不提交、打包或发布。

## Milestones And Verification

1. 记录原作分段、各类消息的稳定画面与动画关键帧，量出字号/间距/对齐及时间轴；将实测结果写入本计划。
2. 实现共享 renderer 与两版 CSS，接入既有样式注册与参数；在同尺寸、同文案下截图/播放并反复对照原作，纠正排版与节奏偏差。
3. 运行相关 Node 行为测试和语法检查；通过隔离 Electron 的真实管理页选样式、调参、保存、重开，并检查画布与本地场景输出。
4. 同步受影响文档，运行 `npm run verify:docs`、`git diff --check`，审查任务增量和 `git status --short`。

## QA Inventory / Done When

- 常规版与随机版均可在客户端选择、预览、保存并重新打开，场景输出使用同一实现。
- 普通聊天、粉丝、舰长/提督/总督、普通礼物、上舰与 SC 的布局和动画分别有参考采样及实现对照；不编造身份、金额或陪伴天数。
- 文字长短、显式换行和 B 站表情正常；长文/窄区域以及密集消息两种探索场景无内容丢失、重复渲染或重叠回归。
- 默认字号、昵称/正文比例、标识位置、卡片间距和关键帧时序有可复查的视觉证据；减少动态效果和销毁沿用既有生命周期。
- 受影响合同、测试与用户指导一致；只有已实际执行的验证才记录为通过。

## Failure Handling

保留原作证据与未完成项，仅修正本任务新增文件和明确的注册行；不整体还原共享文件，不触碰用户运行中的客户端与数据，隔离实例结束后只清理本任务拥有的进程与临时会话。
