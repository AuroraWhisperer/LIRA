# 客户端审计 01–37 复核与修复

Status: Completed

## 目标与边界

以 2026-11-25 的工作树和 `tmp/client-continuous-audit.md` 所列 37 个场景为基线。按编号独立核对触发条件、预期和实际结果。对成立项修改拥有该行为的模块，并用对应场景验证修复。保留工作树已有修改、公开协议、持久化兼容和桌面权限边界。此次范围为本地客户端源码及其验证。

各组先核对代码、项目契约和已有隔离证据，优先扩展对应 `test/` 用例或复用原报告的回放。在 `tmp/` 记录实际结果。未定项写出证据差异。公共文档及跨组测试由主线程整合，避免覆盖并行修改。

最后在稳定工作树运行相关用例、`npm run check`、`npm run verify:architecture`、`npm run verify:docs` 及适用的客户端测试套件。用启动前的工作树快照逐项审查差异，再检查 `git diff --check` 与 `git status --short`。若某一组出现回归，依据该组差异和隔离证据局部修正。每项有结论、已修项验证通过、文档与行为一致后结项。

## 验收结果

37 项均复现并修正。旧歌库从 v20、v21 升级，播放队列覆盖旧快照和插队副本；场景备份覆盖真实附件、正文编号及重复恢复。周表和舰长礼物通过实际 PNG 像素对照，桌面提醒、投票及转盘通过受控时钟回放，静态资源通过双 Electron 进程条件请求验证。

`npm run verify` 核验锁定的 10 份服务端夹具，检查 1,944 个 JavaScript 文件，在 696 个测试文件中执行 5,964 项用例，全部通过。架构检查 29 项通过。编号、复现条件与证据路径保存在 `tmp/client-continuous-audit-results.md`。

扩展日程回放另有两项基线已存在的跨时区差异，分别涉及唤醒后的通知时刻和无关编辑触发的重复通知。逐项报告附有前后对照。
