# 雪狐物语弹幕样式

状态：Implemented。来源：2026-10-11 用户提供的五张截图及 B 站直播间 24393；用户确认自定义颜色联动整条普通弹幕。

## 目标与验收

- 新增固定列表样式 `snowfox`（雪狐物语），在客户端样式选择器、画布和独立预览中可选。
- 普通弹幕采用外置圆头像、狐耳装饰、昵称与当前房间粉丝牌组成的色条，以及白色向浅色过渡的细边圆角消息框。默认普通观众蓝色、舰长绿色、提督紫色、总督粉色；有本房间粉丝牌的非大航海观众用浅粉色。只使用明确的 `roomGuardLevel` / `roomMedal`，不从其他房间身份推断。
- 表情与图片继续走已有安全渲染链路，单张贴纸增高消息框，混排与长文字自然换行。
- SC 使用左侧雪屋与圆头像、右侧留言牌、上方昵称与 `CN¥` 实际金额、粉色挂饰。头部随昵称换行增高，金额在空间不足时另起一行，正文始终位于整个头部下方，避免重叠。沿用 SC 金额档位与有效上游颜色；原文完整保留，支持换行。
- 礼物使用白色冰雪横条、左侧粉色礼盒、右侧圆头像、昵称与实际结算金额，以及“投喂 礼物名 × 数量”。未知金额省略，不按数量重复乘算。
- 大航海购买读取明确的 `giftGuardLevel`，显示独立的「NEW MEMBER」欢迎卡：左侧大船锚与白色挂饰，右侧深绿标题条及白底昵称；提督紫色、总督粉色。不因送礼者自身身份把普通礼物误当成上舰。
- 新增仅此样式支持的 `styleOptions.snowfox.bubbleColor`：`default`（默认）或六／八位十六进制颜色；自定义后普通弹幕的文字、昵称条、轮廓、浅色底和头像圈联动。SC、礼物与上舰保留自身配色。已有正文颜色仍可独立覆盖文字。
- 不带新字段或新区域的旧配置继续有效；恢复当前样式默认值会恢复身份配色。默认区域 640×720；字体 18–48 px，沿用滚动方向和边缘处理。
- 普通文字／贴纸、SC、礼物和上舰分别使用气泡展开、冰牌与挂饰展开、礼盒轻弹和船锚落位的单次入场动画。动效在一秒内收尾，只作用于内部图文和礼物底板透明度；列表移位仍由 feed 负责，追加消息不重播已有词条。减少动态效果时直接显示完整静态卡片。长昵称、金额和装饰在入场及结束时均不互相挤占。

## 所有权与兼容

服务端 `public/overlay/danmaku-renderer-core.js` 继续拥有公共消息 DOM，客户端按 ADR-0020 导入固定快照。样式装饰与 CSS 在各仓现有位置维护，配置校验在 Node / 浏览器合同镜像中同步。沿用现有草稿、保存、推送、字体、头像、表情、画布及 feed 生命周期，不新增服务、依赖或数据迁移。

用户输入只通过 DOM 文本 API 渲染，头像与表情继续使用既有 URL 解析器。装饰是本地静态 SVG，不从直播间复制身份信息、头像或专有素材。直播视频的外框和背景不属于弹幕样式。
