## 已确认缺陷

| ID | 功能 | 触发条件与实际结果 | 修复归属与验收条件 |
| --- | --- | --- | --- |
| F1 | 清空全部数据 / 加班机 | 加班机运行时清空全部数据，数据库时间归零，内存仍运行；随后暂停又将约 120 秒旧状态写回。 | `domain-services.js`、`overtime-service.js`：成功清空后重载已提交状态，停止旧计时器；后续操作不能恢复清空前的数据。 |
| F2 | OBS 自动重连 | 重启后端后会话 token 轮换，已打开页面继续使用旧 token；API 返回 401，WebSocket 重连失败。 | 页面会话包装层：确认本地会话失效后重新加载页面以取得新 token；普通断网不刷新、不降低鉴权要求。 |
| F3 | 清空播放队列 | 播放地址请求未完成时清空队列，迟到的请求仍把歌曲设为当前歌曲并开始播放。 | 播放控制与队列组合：清空动作使旧播放请求失效，迟到结果不能写回播放状态。 |
| F4 | 音质切换 | A 的音质请求尚未返回时切到 B，迟到的 A 地址覆盖音频，造成显示 B、实际播放 A。 | 播放控制：音质切换与切歌共享请求有效性判断；迟到结果及回调不能修改新歌曲。 |
| F5 | 网易云“从我喜欢中删除” | 前端发送 `playlist.id = 'liked'`，网易云 Provider 要求数字 ID，固定报“缺少网易云歌单 ID”。 | 网易云 Provider：在登录用户范围解析真实“我喜欢”歌单，再执行删除；QQ 和普通歌单行为保持兼容。 |
| F6 | AI 回答缓存 | 模型与问题构成全局缓存键，忽略用户和上下文；甲在北京、乙在上海，同问“我在哪个城市”，乙收到甲的回答。 | AI 服务：缓存键纳入回答所依赖的用户、对话与配置；保持 TTL 和存储格式兼容。 |
| F7 | WebSocket 请求处理 | 畸形 Host 进入 `new URL()` 后抛出未捕获异常，隔离后端子进程退出码为 1。 | HTTP 升级入口：无效 URL 返回失败并关闭连接，后端继续处理合法请求，鉴权仍生效。 |

上述缺陷均已通过真实模块配合隔离数据库、延迟 Promise、模拟上游或本地测试服务复现。没有操作真实用户数据。

## 打包路径问题

P1：`src/electron/main.js` 查找 `ROOT_DIR/build/icon.png`，但 `package.json` 的打包清单没有包含它，现有 `app.asar` 中也不存在该文件。Windows 可执行文件仍有嵌入图标；窗口显示受影响的程度尚未通过 GUI 验证。修复只补齐明确缺失的运行时图标资源，不调整窗口或权限设置。

模块相对导入、HTML/CSS 本地引用扫描未发现其他确认断链。现有 asar 包含生产依赖及 `@clamber_l/crypto` 的 WASM 文件；本地依赖初始化成功。

## 修复记录

| ID | 已实施修改 | 回归证据 |
| --- | --- | --- |
| F1 | 加班机提供内部 `reloadState`；`data.clearAll` 只在完整成功后重载状态并同步定时器。 | 真实数据库清空后立即禁用且剩余为零；后续暂停不能写回旧值；假时钟推进超过旧截止点不再产生完成事件；部分提交失败保留运行状态。 |
| F2 | OBS HTML 注入层在本地 WS 断开/API 401 后，使用旧 token 单飞探测现有 `/api/state`；确认 401 才刷新，5 秒超时，离页取消。 | 两个真实本地 runtime 在同一临时端口先后启动；旧 token 仍返回 401，触发刷新后，新 token 的 WS/API 均恢复。临时离线、有效会话、外部请求及管理页不刷新；重复事件只触发一次刷新。 |
| F3 | 清空队列通过内部回调使播放控制器的在途请求失效。 | 迟到下一首 URL 返回后仍无当前歌曲、音频源为空并保持暂停。 |
| F4 | 音质切换、切歌共用请求代际；流解析用曲目副本，有效请求才合并元数据；异步 `play`、metadata、错误处理均验证有效性。 | A 音质迟到不能覆盖 B；同曲旧音质不能覆盖新音质；旧 metadata 和迟到 `play()` 完成不能改变新曲进度；旧错误不显示。 |
| F5 | 网易云列表读取和特殊歌单写入复用 `getLikedPlaylistId`，解析当前登录用户的真实数字 ID。 | 前端实际 `liked` 参数成功路由到数字歌单；找不到目标时拒绝写入；普通 Provider 测试保持通过。 |
| F6 | 缓存键升级为带用户、上下文、配置及工具可用状态的 `reply-v2`，仍由现有 store 哈希保存。 | 两名观众同问分别使用自己的上下文；相同输入可命中，改变上下文、人格或模型端点时重新生成。 |
| F7 | WebSocket upgrade 捕获无效 URL 并以 400 关闭当前连接。 | 畸形 Host 和畸形 URL 不再逃逸为未捕获异常，之后合法 upgrade 仍进入处理器。 |
| P1 | `package.json` 明确包含 `build/icon.png`，不加入其他 build 原始资源。 | electron-builder 实际 FileMatcher 允许 `build` 目录及窗口图标，仍排除 `icon-source.png`。 |
