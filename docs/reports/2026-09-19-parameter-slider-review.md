# LIRA 滑块样式统一简报

日期：2026-09-19。依据：用户截图、当前工作区源码及下列官方设计文档。本次为设计评估，未修改产品代码，未运行 Electron 做交互或对比度验收。

**建议做一次小范围统一。现有“滑块＋数字输入”结构值得保留，普通参数的颜色、粗细和形状应收敛。** 截图中的控件属于数值滑块（Slider）；页面边缘用于浏览内容的滚动条（Scrollbar）是另一类控件。

## 当前情况

- 已有共享组件，并非各页面完全各写一套。[parameter-range.css](../../public/css/components/parameter-range.css) 定义了速度、尺寸、强度、正负偏移四类变体：速度为橙色、5px 轨道；尺寸为紫色、4px 轨道；强度为绿色、7px 轨道，并使用不同滑块形状。这些是源码中的 CSS 尺寸，不是截图像素测量。
- 截图对应[点歌板主题设置](../../public/pages/admin/song/queue-theme.html)。标签、帮助和右侧数字框较清楚；字号范围为 9–78、速度范围为 1–100，字号单位及速度范围主要放在帮助里。数字框已有[双向同步逻辑](../../public/js/admin/forms.js)，应继续利用。
- 当前分类有设计意图，但“紫色＝尺寸、橙色＝速度”需要用户额外学习。截图里两个普通设置项出现不同视觉权重，收益有限；字号轨道横跨整行，也使滑块与数字框相距较远。这是本次设计判断，尚无用户测试证明它造成操作困难。

## 官方设计体系可借鉴什么

| 参考 | 官方做法 | 对 LIRA 的启发 |
| --- | --- | --- |
| [Microsoft Fluent 2](https://fluent2.microsoft.design/components/web/react/core/slider/usage) | 滑块适合近似调节；精确数字适合输入框；标签应说明含义与范围 | 拖动用于快速调整，数字输入用于精调；速度可直接标“慢／快” |
| [IBM Carbon：使用](https://carbondesignsystem.com/components/slider/usage/)与[样式](https://carbondesignsystem.com/components/slider/style/) | 默认滑块包含标签、数值输入与范围信息；使用统一颜色变量和交互状态；默认轨道 4px，建议轨道宽度 200–640px | 学习克制的工具界面与明确的尺寸规则；宽屏中限制调节区域长度 |
| [Ant Design](https://ant.design/components/slider/) | 提供 Slider 与 InputNumber 组合；轨道、滑块及悬浮状态由组件 Token 管理 | 沿用现有共享组件，集中管理样式；无需引入其框架或组件库 |

我的取舍是：借鉴 Fluent 的操作习惯和 Carbon 的克制程度，保留 LIRA 的暖色背景及圆角。上述体系并未规定所有滑块必须同色；普通参数统一颜色，是结合本项目提出的建议。

## 建议采用的统一规则

1. **普通参数共用一套外观。** 字号、间距、滚动速度、透明度使用一致的轨道、圆形滑块和交互色。优先接入已有的 `--color-control-accent`、`--color-control-focus`，并在实际背景上校验辨识度，避免继续增加硬编码配色。
2. **统一几何与状态。** 建议以 4px 轨道、18px 圆形滑块、28–32px 控件操作区高度作为桌面试样；这些是 LIRA 建议值。普通状态减弱渐变和光晕，悬浮、拖动、键盘聚焦时再加强反馈，禁用状态保持一致。视觉轨道粗细不等于可点击区域大小。
3. **保留精确输入，控制长度。** 保留数字框和现有同步逻辑；同一设置区统一数字框宽度与对齐。宽屏先试整组控件最大宽度 560–640px，窄区域随容器收缩。字号直接显示 `px`；速度用“慢／快”或“1–100”解释尺度，不把无单位数值写成百分比或物理速度。
4. **只为功能差异保留变体。** 正负偏移保留零点标记及从零向两侧填充，正负号也要可见；播放进度、紧凑音量控制可保留专用布局。仅因参数名称不同，不再切换轨道粗细或滑块形状。
5. **统一后检查基本操作。** 按[W3C Slider 模式](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)核对键盘步进、Home/End、可访问名称及数值含义；在 Electron 中确认数字同步、端点对齐和焦点可见。这里是后续验收建议，并非本次已完成的验证。

## 页面滚动条的判断

实际页面滚动条已有[桌面统一样式](../../public/css/overlays/desktop-scrollbars.css)：12px 槽位、静止可见部分 6px、交互时 8px，使用暖灰色和透明轨道，并有强制颜色模式回退。就现有样式方案而言可以保留；本次未逐页确认运行时覆盖情况。它与数值滑块承担不同任务，无需追求相同的颜色和尺寸。

实施优先级：先统一普通参数的颜色、几何和状态，再调整过长的控件布局及单位提示。预计改动主要位于共享滑块 CSS 和相关设置布局；继续使用原生 range 输入及现有数值同步，不需要重建组件。源码中已有部分固定变体外观的测试，实施时应按接受后的规则同步调整。
