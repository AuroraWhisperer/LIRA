# ADR-0015: 安装目录保存桌面数据

## 状态

已采纳（2026-09-13，替代 [ADR-0013](0013-persistent-desktop-user-data.md) 的 AppData 路径决策）

- 2026-09-13：内部浏览器与缓存子目录随后由 [ADR-0016](0016-separated-client-data-lifecycles.md) 细化。
- 2026-11-06：优化升级耗时——同目录安装且已验证旧卸载器能力时原地保留数据，其余场景继续走备份与恢复流程。
- 2026-11-13：取消管理员启动拦截，保留当前用户安装模式与目录可写检查。

## 背景

客户端数据需跟随用户实际选定的安装目录存放：首次安装检测到 D 盘时默认优先使用 D 盘，无 D 盘时沿用原默认安装位置。用户反馈的 Windows 10 诊断报告显示，由于 `customInit` 早于标准安装器的进程退出检查执行，安装器在旧版仍运行时复制 Chromium Cookies，触发文件共享冲突（错误码 32，robocopy 返回 9）。该问题已确认为文件占用导致的复制失败，并非安装包缺少 Electron 文件。

## 决策

- **程序与数据同目录**：首次安装检测到 D 盘时默认 `D:\LIRA`，未检测到则沿用打包工具（electron-builder）原默认目录。升级沿用本机已有路径，显式 `/D` 参数与目录选择页优先，不限制盘符。
- **当前用户安装与可写校验**：安装仅面向当前用户，允许普通或管理员权限启动但不主动请求提权；安装根目录与既有运行子目录必须对安装进程可写，检查在旧程序退出、备份与卸载之前完成。日常使用仍须选择运行账号可写的位置。拒绝全用户安装；旧版全用户安装须先保留数据并卸载，再选择当前用户可写路径重装，不自动迁移整份数据或改写权限。校验细节见 [NSIS 安装脚本参考](../../reference/engineering/build.md#6-nsis-安装脚本buildinstallernsh)。
- **安装目录运行布局**：数据库、配置、加密登录资料、机器授权资料、上传资源与 Chromium 分区存放在 `data/`；运行日志在 `logs/`；更新缓存与已下载安装包在 `updates/lira-updater/`；崩溃转储初设在 `data/Crashpad/`（随后由 [ADR-0016](0016-separated-client-data-lifecycles.md) 随浏览器目录细化迁入 `data/browser/Crashpad`）。开发模式继续使用仓库根目录 `data/`。
- **安全退出与原地保留优化**：安装器先确认旧 LIRA 及音频工作进程完全退出。普通同目录更新仅在实际旧卸载器与安装时记录的能力摘要一致，且无待恢复备份或遗留捆绑音频时原地保留数据；能力记录直接与旧卸载器文件摘要绑定，不靠版本号猜测，也不试跑未知卸载器。未知旧版、更换目录及历史迁移仍完整备份至新安装目录同级 `.lira-data-backup`，备份成功后再调用旧卸载器，恢复成功后再启动新版。升级调用卸载器时保留数据、日志与更新缓存。
- **卸载数据保护**：普通卸载删除程序、`logs/` 与 `updates/`，默认保留完整 `data/`。卸载页提供默认不勾选的“同时删除用户数据”选项；仅交互勾选并二次确认后，才删除当前安装数据及当前用户已知的旧版 AppData 数据，避免重装后重新导入。取消确认则继续卸载但保留数据；静默卸载一律保留数据，升级始终保留三个运行目录。手工备份、同级恢复备份与云端数据不在清理范围内。
- **防误恢复与冲突保护**：`.partial` 后缀仅表示尚未写入完成的临时副本，不能用于恢复；已发布备份不自动覆盖。遇到原数据与备份冲突、目标目录冲突或复制失败时中止操作并输出可诊断信息。
- **历史 AppData 兼容**：历史 AppData 目录仅在本地数据不存在时作为兼容来源，完整复制后启用本地目录并保留历史源；已有本地数据绝不被历史副本覆盖。
- **既有安全边界不变**：保留 `appId`、更新源、数据库表结构、会话分区与 `safeStorage` 加密；机器绑定不要求授权文件位于 C 盘。

## 影响

用户可在安装目录内统一备份与管理数据：常规升级保留数据，卸载默认保留数据并支持显式清除。已验证的同目录更新免去了整份数据复制开销，兼容升级备份仍需等量额外磁盘空间。原地保留不等于可回滚快照，数据库和目录迁移的容错恢复仍由各自负责模块保障，本优化不改变数据格式。未知旧版首次升级仍走备份路径，成功安装后后续更新方可启用能力记录。若升级中断导致恢复备份与活动数据同时存在，须依据报告人工确认，禁止猜测覆盖。

Windows 注册表、安装器解压与诊断临时文件仍由系统路径管理，本决策仅约束客户端持久化目录，不保证 Windows 自身完全不写入系统盘。卸载勾选删除数据时会清理 `%APPDATA%/com.aurorawhisperer.lira` 与 `%APPDATA%/lira` 两个已知兼容来源，不影响其他应用目录；删除过程不跟随目录链接，失败时报告未清理路径并保留卸载器以便重试。实机 Windows 10 环境的最终安装表现以实际用户验证为准。
