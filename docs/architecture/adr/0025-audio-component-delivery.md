# ADR-0025：音频组件独立 CDN 交付

## Status

Accepted。依据当前用户确认的安装包瘦身、6.0.0 复用和首次授权后后台补齐要求。实现验收记录见 [实施计划](../../../specs/plans/archive/2026-11-04-audio-component-cdn.md)。

## Context

原生音频组件及其私有 .NET 运行库约占安装后程序的三分之一。所有客户端更新都携带这些文件，而多数版本仅修改网页或业务逻辑；6.0.0 用户已拥有可复用组件。

## Decision

保持 Electron 和现有音频实现。音频组件按内容独立版本化，ZIP 单独分发，客户端内置固定描述与摘要；CDN 仅交付批准的字节，不决定可执行代码版本。一个桌面 owner 负责准备和路径，助手与播放输出共享文件并继续使用独立进程。

首次授权后后台准备，本地完整时零网络请求。旧版资源由安装器先纳入持久数据保护，再由主进程校验启用。运行库保留在组件内，终端用户不依赖系统 .NET；普通素材清单的文件类型和信任范围不扩大。

## Consequences

安装包及音频不变的后续更新明显变小；首次完整使用仍需下载音频包，安装后的总体文件占用基本不变。采用现有 Node ZIP 依赖与下载校验工具，无新增运行时依赖。需要维护旧版迁移、固定组件描述、准备状态和安装维护退出；缓存清理与业务云同步不管理可执行组件。

下载和上传合同由 [CDN 指南](../../guides/cdn-resources.md#音频组件独立交付)、[主进程](../../reference/desktop/main.md#电音助手生命周期)、[存储](../../reference/backend/storage.md#音频组件文件) 分别维护。
