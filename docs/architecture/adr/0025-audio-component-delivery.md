# ADR-0025: 音频组件独立 CDN 交付

## 状态

已采纳（依据安装包瘦身、6.0.0 本地复用与首次授权后后台补齐需求；验收记录见 [音频组件 CDN 交付计划](../../../specs/plans/archive/2026-11-04-audio-component-cdn.md)）

## 背景

原生音频组件及其私有 .NET 运行库约占安装后程序体积的三分之一。此前每次客户端更新都完整携带这些文件，而绝大多数版本仅改动前端页面或业务逻辑；同时 6.0.0 老用户本机已具备可复用的组件文件。

## 决策

保持 Electron 架构与现有音频实现不变。音频组件按内容独立编排版本并以 ZIP 单独分发，客户端内置固定的组件清单与校验摘要；CDN 只负责下发经审核的文件内容，不决定客户端加载的可执行代码版本。由桌面端单一模块统一负责组件准备与路径管理，电音助手与原生播放输出共用文件但继续分进程运行。

首次授权后在后台准备组件，本机校验完整时零网络请求；旧版资源由安装器先纳入持久数据保护，再由主进程校验启用。运行库保留在组件包内，终端用户无需预装系统 .NET；不扩大普通素材清单允许的文件类型与信任范围。

## 影响

安装包及音频未变更的后续更新体积显著减小；首次完整使用仍需下载音频包，安装后的总磁盘占用基本不变。实现复用既有 Node ZIP 与下载校验工具，不新增运行时依赖。需要维护旧版迁移、固定组件描述、准备状态以及安装或升级维护时的进程退出；普通缓存清理与业务云同步不管理可执行音频组件。

下载与上传规范分别由 [CDN 资源指南](../../guides/cdn-resources.md#音频组件独立交付)、[主进程参考](../../reference/desktop/main.md#电音助手生命周期) 与 [存储参考](../../reference/backend/storage.md#音频组件文件) 维护。
