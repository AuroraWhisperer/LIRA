# ADR-0009: 首次启动配置引导

## 状态

已替代（旧七步弹窗方案）

2026-09-22 已下线旧版七步弹窗和 `window.AdminApp.onboarding`。现行方案改为在真实控件上高亮引导，首次展示标记改存 `localStorage`（详见 [交互式引导说明](../../reference/frontend/interactive-tour.md)）；原方案中的三个设置键仅保留兼容，新界面不再写入。以下为当时的历史方案记录。

## 背景

LIRA 此前把 B 站登录、直播间号、歌单导入、音乐平台登录与 AI 配置分散在不同页面，新用户需要自行寻找入口，容易在未登录、未填写房间号或缺少歌库的情况下开始直播。

产品需要一个首次启动时出现的分步配置向导：当前步骤必须满足可验证条件后才能进入下一步；完成后不再自动弹出，但可从使用文档重新打开。LIRA 是本地模块化单体，已具备 Electron 登录窗口、加密 Cookie 快照、设置存储与 Admin 页面装配，引导流程不得复制或直接读取账号凭据。

## 决策

在现有 Admin 页面中增加首次启动引导控制器与遮罩层，不新增进程、HTTP 路由、IPC 通道或前端构建步骤。

引导流程复用现有接口与模块：

- B 站登录状态与扫码登录调用 `window.bilibiliAuth`。
- QQ 音乐与网易云音乐登录状态及登录调用 `window.musicAPI`。
- 直播间号与引导状态通过现有 `POST /api/settings` 提交；服务端继续使用设置白名单与 `normalizeRoomInput` 校验输入。
- DeepSeek 配置复用现有 `/api/ai/config` 与 `/api/ai/test/deepseek`，API Key 仅提交至既有密钥存储，不进入 WebSocket 全局状态或引导日志。
- 歌单导入复用点歌页已有的「导入导出」标签页及导入接口，引导仅说明入口与操作顺序，不复制文件解析逻辑。

引导步骤固定为：

1. 欢迎与运行模式说明。
2. B 站登录和直播间号（必做）：进入下一步要求处于桌面环境、B 站 `loggedIn === true`、房间号已通过现有接口保存且直播连接状态已刷新。
3. 导入歌单：指引进入「点歌 → 导入导出」，选择 XLSX/CSV/TSV 文件或粘贴表格后点击「导入歌库」。
4. 音乐平台登录位置：按需选择平台。QQ 音乐与网易云音乐在「播放」页顶部使用内置登录；全民 K 歌必须在全民 K 歌宿主客户端登录，LIRA 仅读取本机播放状态，不提供全民账号登录。此步骤仅作指引，不强制登录。
5. AI 弹幕姬（可选）：开启 AI 时须填写并测试 DeepSeek 配置；不启用时可跳过。
6. 说明文档位置：提示在「百宝箱 → 使用文档」查看完整功能说明、导入与登录细节及常见问题，并可在此重新打开首次启动引导。
7. 完成：列出仍未完成的可选项，并写入完成版本与时间。

步骤准入条件由纯函数计算，按钮状态由 DOM 控制：未满足条件时禁用“下一步”；异步保存与连接测试期间显示加载状态并防止重复提交；失败时停留在当前步骤并展示清晰错误提示。用户可点击“稍后设置”跳过 AI 步骤，但不可跳过 B 站基础配置、歌单导入说明、音乐平台登录说明及说明文档位置。已完成的引导不会因常规页面刷新再次弹出。

## 状态与持久化

在 `src/storage/settings-store.js` 新增以下普通设置键，沿用现有字符串存储格式：

- `onboardingVersion`：当前引导规范版本（如 `1`），空值表示从未完成。
- `onboardingCompletedAt`：ISO 时间字符串，仅在完成最后一步后写入。
- `onboardingSkippedOptional`：逗号分隔的可选步骤 ID（当前仅 `ai`），便于重新打开时提示未完成项。

引导当前所在步骤仅存于浏览器内存，不落库，避免异常退出留下错误的“已完成”状态。清空业务数据库时保留设置的既有行为不变；“重新开始引导”只清除上述三个键，不影响账号 Cookie、歌库、队列或 AI 密钥。

## 影响

### 正面影响

- 新用户按可验证步骤完成最小可用配置，减少“能打开但无法正常直播”的情况。
- 复用既有登录与密钥边界，凭据仍由 Electron 分区、`safeStorage` 与原有服务管理。
- 不改变现有公共 URL、API、IPC、WebSocket 或数据库表结构。
- 纯函数校验逻辑可在不依赖 Electron 的 Node 单元测试中稳定验证。

### 代价

- 首次启动增加一个遮罩层及若干状态轮询/刷新请求。
- Web 模式无法提供桌面扫码登录，须展示受限提示并允许用户进入后台处理，不能伪造登录成功。
- 歌单是否导入由用户自行确认，向导不复制导入解析逻辑，也不代为修改歌库。

## 备选方案

- **独立 Electron 设置窗口**：会重复实现 Admin 表单与状态逻辑，增加窗口生命周期与 IPC 接口范围，故否决。
- **纯静态产品导览**：无法校验登录、房间号与 AI 连通性，不能满足“完成当前操作才进入下一步”，故否决。
- **新增引导专用 HTTP API**：现有设置接口已具备白名单、鉴权与广播机制，新增端点无实际边界收益，故否决。
- **将完成状态存放在 `localStorage`**：服务端与多窗口间无法共享，且卸载或迁移行为不一致；仅适合暂存当前步骤，不用于记录完成状态。
