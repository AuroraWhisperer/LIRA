# 组件管理与直播软件导入

LIRA 的组件有两种用法：在直播场景中编排后导入一个地址，或直接导入某个组件的独立地址。两种方式都适用于 OBS 的「浏览器源」和哔哩哔哩直播姬的「浏览器 / 网页来源」。地址集中在客户端「点歌 → 浏览器源」。

“直播场景”指组件及其组合布局，“场景编辑器”指编辑页面，“画布”指编辑器内设置尺寸和摆放组件的区域。命名参考 [OBS 的场景概念](https://obsproject.com/kb/sources-guide)；组合组件并输出一个浏览器源的功能对应 [StreamElements 的 Overlay Editor](https://docs.streamelements.com/overlays)。

时钟与三类弹幕的参数按具体样式适配，设置方法、范围及导入兼容性见[逐样式外观效果](component-style-parameters.md)。

组件是弹幕、开播动画、全屏礼物感谢、时钟、背景等功能，样式是其中某个组件的外观。套装由多个组件类型的配套样式组成。这一定义适用于所有现有及以后新增的组件：多款弹幕外观仍是弹幕样式，静态与动态背景仍是背景样式，大航海感谢的多档动画仍是感谢样式。ZIP 只是交付格式，单组件样式也可以打成 ZIP 样式包；添加入口见[组件样式与套装](component-style-packages.md#主播怎么用)。

## 编辑直播场景

1. 在「点歌 → 浏览器源 → 直播场景」点击「编辑场景」。使用说明收在标题旁的问号中。
2. 首次打开是空画布；保存后再次进入会恢复已有组件、样式和位置。从单个组件的预览按钮进入，会添加或选中对应组件。
3. 顶部「添加组件」打开分类与样式小窗，包含背景、弹幕姬、萌时钟、点歌板、加班机、展示板、桌面歌词、直播小游戏、礼物滚动、盲盒盈亏榜、礼物许愿和文本框。同类组件可以添加多份并使用不同样式。
4. 新增组件以预定尺寸居中显示。拖动组件内部调整位置，选中后拖动边框或角点调整大小，也可在右侧精确输入位置和宽高、调整样式。拖拽中按 Esc 取消本次调整；锁定的组件不能拖拽。加班机的高度随倒计时和已启用的礼物规则自动调整，可拖动左右边框或输入宽度改变显示大小。公共画布分辨率由「画布设置」统一决定；添加组件或切换样式不会改变画布大小。
5. 点击右上角的「保存并应用」。它保存待提交参数、布局并更新直播输出；失败时保留上一版已应用布局，已经保存的共享参数仍会同步。
6. 回到客户端「浏览器源」，点击「直播场景 → 复制地址」，或在编辑网页右上角点击「复制直播源地址」。两处复制的是同一个场景的地址。
7. 在直播软件添加一个浏览器源，粘贴完整地址，宽高设为公共画布的分辨率，例如 1920 × 1080。之后修改场景再点「保存并应用」，原地址自动显示新版本。

底部组件栏同时表示图层顺序：越靠左越在上，越靠右越在下，新组件自动添加在最左、最上。
组件较多时，将鼠标停在组件栏上滚动滚轮即可左右浏览，栏内不显示滚动条。
按住组件名称拖动，词条会跟随鼠标，其他词条随落点让位；拖到边缘可自动滚动。栏内松手才改变画布层级；拖出栏外松手或按 Esc 则恢复原位。
成功排序可用 Ctrl+Z 撤销，正式直播仍由「保存并应用」更新。
点击组件旁的箭头，在更多菜单中选择「隐藏组件 / 显示组件」或「锁定组件 / 解锁组件」；锁定后不能移动和缩放，仍可切换可见性。这些操作也支持 Ctrl+Z 撤销，点击「保存并应用」后更新直播输出。草稿恢复与保存提示显示在上方保存操作区。

顶部「场景」可以保存多套布局，同一时间只输出一套。点击「新建」准备空场景，或
「复制」保留当前组件、位置和样式作为新场景；名称在「画布设置 → 场景名称」修改。
「保存场景」只保存布局，便于下次使用。选择其他场景会保留本次会话各自的未保存草稿，
点击「保存并应用」才替换当前直播画面；右上方显示当前直播使用的场景，直播源地址不变。

场景编辑器是 `/component-preview`，采用浅色工具栏、灰色工作区和下方横向组件列表；由客户端打开，链接随编辑会话失效。直接进入时参数面板收起，点击「画布设置」或下方图层可展开，顶部「收起参数」释放画布空间且保留选择与草稿。画布自动适配窗口，无需滚动页面；底色只影响预览。供直播软件导入的是 `/scene?id=…#token=…`，只显示直播内容，未放置组件的区域保持透明。请使用「复制地址」，不要复制浏览器地址栏中的编辑链接。关闭编辑网页不会停止已应用画面的输出，LIRA 客户端需要继续运行。

礼物姬的「全屏礼物感谢」和「大航海感谢」也可通过「在画布中预览」直接打开对应图层；首次进入会添加，之后打开会选中已有图层。画布循环展示示例，正式直播仅在触发时播放。保存并应用后，可复制组合直播源或选中图层复制单组件地址。

先从「浏览器源 → 样式与套装」导入月渡花汀 ZIP，再在「添加组件 → 套装」的月渡花汀分组选择「静态背景」或「动态背景」，也可从「添加组件 → 背景」选择。动态版保留浅淡配色，月亮反复出现与消失、柳枝分组随风摆动、灯笼摇曳，水面倒影与扩散波纹持续流动，云雾和花瓣各自循环；已有背景可在右侧「背景样式」中切换静态/动态。新增时自动铺满当前画布并放在最上层；需要作为底图时，将底部栏中的背景拖到最右侧；保存并应用后，壁纸会出现在直播输出中。原图为 16:9，其他画布比例会居中裁切；可继续调整背景的位置、大小、可见性与层级。系统启用减少动态效果时，动态版也显示静态原图。

### 添加组件样式与套装

选中背景后，右侧可调整不透明度、模糊和填充方式；「更多调整」中有亮度、饱和度、对比度及遮罩。降低不透明度会露出下层画面；要让背景颜色变浅，可加少量白色遮罩。视频另有播放速度与音量，默认循环、静音。调整立即在画布预览。套装资源背景按同一样式共享参数，保存后同步已有直播组件；普通图片/视频背景保留当前实例参数，「保存并应用」后更新直播。「恢复样式默认」恢复套装作者参数，没有作者参数时恢复客户端默认。普通图片、视频与月渡花汀均支持这些设置。

在对应组件页面点击「＋ 添加样式」，选择已解压的图片或视频。预览中拖动虚线框放置文字/弹幕/许愿内容，拖右下角调整区域大小，填名称后「添加样式」。样式会留在本机库，点击卡片可加入画布；已有图层则在右侧点「更换样式 / 添加素材」，位置、尺寸和层级会保留。背景素材从画布「添加组件 → 背景」添加。后续仍可在右侧修改内容区域、字号、颜色和播放设置。

作者提供的单组件 LIRA 样式包，从对应组件「＋ 添加样式 → 选择文件」添加。跨多个组件的 LIRA 套装，从「浏览器源 → 样式与套装 → 导入套装」导入；各成员加入对应组件分类，也可在画布「套装」分类中选择。同类多个样式仍归对应组件，不列为套装。第三方购买的普通 ZIP 请先自行解压，再选择对应素材文件。新增或更换样式要「保存并应用」后才更新直播布局；已有组件的共享参数保存后同步。导入不会覆盖现有场景。自定义样式使用本机场景来源，客户端须保持运行；在线弹幕姬地址不会因本机素材改变。

独立样式可点卡片右上角 × 从样式库移除；套装从「套装」分组标题旁的「删除套装」整体移除，更新则使用「更新套装」选择新版 ZIP。两种删除都保留已有场景及媒体文件，不立即回收磁盘空间。要移除画面中的组件，请在画布删除图层再保存应用。普通图片/视频样式的「改用内置样式」可让当前图层恢复内置外观；资源型样式通过「更换样式 / 添加素材」选择其他外观。套装版本替换与恢复见[套装指南](component-style-packages.md)。

支持 PNG、JPEG、GIF、WebP、MP4 和 WebM。视频是否含透明通道取决于文件本身；MP4 建议 H.264，透明素材可使用带 alpha 的 WebM，并在实际直播软件检查效果。感谢素材沿用现有触发条件，自动叠加当前观众/礼物文字；已带固定文字的成片可关闭「显示感谢文字」。网页链接沿用下方网页源入口。作者打包步骤与限制见[套装制作与导入](component-style-packages.md)。

### 导入第三方 HTML / CSS

所有组件分类的「＋ 添加样式」只需点击「选择文件」，程序自动识别 LIRA 样式包（ZIP）、HTML/CSS 或图片/视频；不支持图片/视频的组件会给出提示。收到网址或代码时，展开「粘贴网址或代码」直接粘贴，程序自动区分网页地址、HTML 和 CSS。名称和显示尺寸已有默认值，通常无需修改；需要时展开「更多设置」。普通购买包先解压到独立文件夹，保留原目录结构；无需编写 LIRA 清单。

- **HTML**：选择文件后，桌面选择器连同配套脚本、图片、字体等复制到本机样式库；也可在「更多设置」选择整套文件夹，程序优先选择首页或唯一网页，有多个无法判断的样式时才需手动选择。完整网页作为独立浏览器组件运行。
- **CSS**：选择文件自动带入资源；粘贴代码时可在「更多设置」补选配套资源文件夹。弹幕自动识别常见 blivechat/YouTube、BLC 结构，其他 CSS 套用当前原生组件。原工具专用 DOM、后端或 SDK 仍需作者配套网页/浏览器源，LAPLACE 样式会提示使用原工具。
- **浏览器源**：在同一个粘贴框填入作者提供的完整 HTTP(S) 展示地址，点击「添加样式」直接加入画布；名称默认使用网站域名，显示尺寸可在「更多设置」修改。

HTML/CSS 导入后点击样式卡片预览，再「保存并应用」。已有图层从「更换样式」替换，保留名称、位置和尺寸；HTML 图层也可继续选择其他本地网页。缺少静态资源时显示文件路径，失败不会安装半套素材。成功导入的文件保存在 LIRA 中，之后移动原始素材不影响已导入版本。导出场景模板不打包网页资源，迁移时仍需原素材重新导入。

### 添加文字、表情和礼物图片

在客户端「百宝箱 → 文本框」（位于「小游戏」上方）点击「新建文本框」。顶部横排切换不同文本框，下方编辑内容并查看预览；可复制、重命名和删除，每份独立保存。文本框没有固定数量上限，但整套场景仍受文档大小限制。

- 选中文字后，工具栏出现在选区上方，可设置加粗、斜体、下划线、字号和颜色；取消选择即收起，格式仅作用于选区。快捷键为 Ctrl+B / Ctrl+I / Ctrl+U，Ctrl+Z 撤销、Ctrl+Shift+Z 重做。粘贴只保留文字。
- 颜色按钮提供常用色、最近使用的 6 个颜色和自定义颜色。「更多文字格式」可开关文字描边、轻阴影，或「清除格式」恢复选中文字的默认字号、颜色及样式；礼物和图片保留，也可以撤销。
- 点击「礼物图片」，在「本房间礼物」或「全部礼物」中搜索并选择，再点「插入礼物图片」。编辑区显示不可拆分的「礼物图片·总督」等方块，直播画面只显示实际图片；选中方块可整块删除。
- 点击「上传图片」添加 PNG、JPEG、GIF 或 WebP，每张不超过 5 MB；GIF/WebP 动图保留动画。上传图默认约为两倍字号高度，礼物图约为 1.3 倍，保持原比例。
- 「颜文字 / 表情」提供开心、可爱、感谢、惊讶、委屈和表情六类选项，点击即可插入。

点击「在画布中调整」会选中当前这一个文本框；拖动边框改变整体大小与位置，文字和图片一起缩放。点击「保存并应用」更新直播输出，再用「复制直播地址」导入 OBS 或哔哩哔哩直播姬。也可以把多份文本框加入同一组合来源。删除等未保存操作可用「放弃修改」恢复。

画布「添加组件 → 文本框」也可以直接新建，或按预览选择当前场景里已配置的文本框并「添加副本」。副本保留内容、素材、样式和尺寸，添加后在右侧继续自定义，每份独立编辑。客户端和画布共用同一份场景，现有文本框无需重复添加就能在画布中选中调整。

### 导入其他浏览器源

在「添加组件」的分类列表底部点击短划线边框的「+ 更多」，填写组件名称、完整 HTTP / HTTPS 浏览器源地址和网页宽高，再点击「添加到画布」。添加窗口可用右上角关闭按钮或 Esc 退出。

网页分辨率默认 800 × 600，可设置每边 32–7680 像素，决定网页内部的内容布局。画布选框显示的是组件在场景里的尺寸；拖动边框、修改右侧的组件宽高会缩放显示，保留网页分辨率。名称、位置、网页地址与分辨率可以继续修改，也可使用现有的锁定、隐藏、删除和复制单组件地址功能。外部源的内部内容与样式仍在原工具设置；LIRA 提供整个网页的外投影、外发光、矩形边框及旋转/倾斜，兼容边界见[逐样式外观效果](component-style-parameters.md#导入-csshtml-和素材)。

点击「保存并应用」后，浏览器源随场景保存并加入直播输出。源地址可能包含访问令牌，因此保存时加密；导出模板会清空地址，导入时重新填写。浏览器的本地恢复草稿只保留布局和分辨率，已保存源沿用当前配置中的地址，新添加但未保存的地址需要重新输入。

请使用供应方允许嵌入的浏览器源链接。禁止 iframe 嵌入、依赖登录或同源存储的网页可能无法显示；这与 OBS 独立运行网页的方式存在区别。LIRA 保留网页的安全隔离，不绕过站点限制，也不强制改变外部网页背景。外部源显示的是其真实内容，网页加载完成不代表供应方业务连接已经就绪。

同一组可见组件保持原有内容配置与浏览器源地址时，保存位置、显示大小、层级或网页分辨率会保留已加载的网页，避免重新连接和动画重启。更换源地址、内置组件外观或增减可见组件时，仍会先准备完整新版，再切换输出。

### 浏览器源性能

组合来源直接在 OBS / 直播姬的浏览器中运行外部网页，LIRA 不会先录屏或编码再转发。外部网页的数据连接直接来自供应方，不经过 LIRA 的内置组件更新链路。

内置组件在数据变化后通过通知触发刷新，无需固定等待 750ms 轮询；短时间内的多次变化会合并读取。空闲时每五秒检查一次，减少重复读取。通知连接不可用时自动恢复 750ms 轮询，连接恢复后继续使用通知。实际显示延迟仍受消息到达、组件数据读取和直播软件渲染影响。

- 组合来源的宽高与画布保持一致。外部网页优先使用供应方建议的分辨率，确认内容布局正确后再减少空白区域；每个小组件都使用全屏分辨率会增加不必要的绘制开销。
- 在 OBS 中，滚动弹幕或连续动画可使用与直播输出一致的 60 FPS；简单静态信息可先用 30 FPS。提高帧率改善画面更新频率，但不会加快供应方的消息传输，也会增加渲染负担。
- 若优先保证切换场景时马上显示，在 OBS 中关闭「不可见时关闭源」和「场景变为活动状态时刷新浏览器」。代价是后台占用；低频使用的重型网页可按需卸载。设置含义见 [OBS 浏览器源说明](https://obsproject.com/kb/browser-source)。直播姬使用其当前版本提供的对应设置。
- 直播时关闭不需要的画布编辑预览和重复来源，保留 LIRA 客户端运行。组合成一个地址后，每个外部网页仍需独立运行；出现卡顿时先检查渲染负载，再降低网页尺寸或动画帧率，参见 [OBS 性能排查](https://obsproject.com/kb/encoding-performance-troubleshooting)。

| 礼物滚动 | 行数、滚动速率、最低金额和三档分界金额；金额输入使用元 |
| 全屏礼物感谢 | 林间花信动画，独立位置与尺寸；启用和触发金额在礼物姬设置 |
| 大航海感谢 | 独立位置与尺寸、动画文字；随收到的大航海等级播放对应效果 |
| 盲盒盈亏榜 | 标题、榜单人数、汇总/榜单布局、亏损过滤、翻页、字体和配色 |
| 礼物许愿 | 卡片、文字、圆环；周期、展示样式、完成项过滤、显示数量、间距和文字颜色 |
| 文本框 | 富文本、礼物图片、上传图片、颜文字与表情；局部字号配色、整体对齐和行高 |

这些组件通过“添加组件”创建独立图层，位置和宽高随场景保存。客户端已有的公共显示参数与画布双向同步，同样式共用；首次以客户端已保存参数为准。客户端没有对应项的实例配置仍随场景保存。游戏的开局、规则和转盘选项仍在客户端“直播小游戏”管理，礼物及许愿目标仍在礼物功能管理。画布仅显示所选游戏/互动类型的当前场次，不会同时启动多局游戏。编辑器使用明确标注的示例；正式来源读取真实数据，游戏类型不匹配或没有许愿时对应图层透明。

## 直接使用独立组件

不需要组合布局或额外调参时，直接到「点歌 → 浏览器源」复制对应地址即可。无需创建、编辑或发布场景。组件会读取已有的默认样式与实际数据。

下表中的 `<实际端口>` 由客户端当前运行端口决定，使用界面复制的完整地址，不要手工填写占位符。尺寸列说明尚未在画布保存宽高时的默认行为；保存后以保存的尺寸为准。

| 组件 | 浏览器源中的条目 | 本机独立地址 | 尺寸说明 |
| --- | --- | --- | --- |
| 弹幕姬 | 弹幕姬 · 本机组件 | `http://127.0.0.1:<实际端口>/danmaku?source=component` | 使用已保存的弹幕画布分辨率；未设置布局时按源窗口展示 |
| 萌时钟 | 萌时钟 | `http://127.0.0.1:<实际端口>/clock` | 通常为 580 × 210；竖向刻度为 240 × 400 |
| 点歌板 | 点歌板 | `http://127.0.0.1:<实际端口>/queue` | 按所选样式和队列显示范围设置 |
| 加班机 | 加班机 | `http://127.0.0.1:<实际端口>/overtime` | 按倒计时及背景的显示范围设置 |

需要更换默认样式时，在该组件的客户端面板选择样式并点击保存或应用按钮即可，不必编辑场景。从单组件预览按钮进入的图层与默认组件共用样式和尺寸：在画布里调整宽高并「保存并应用」后，上表中的原地址也会更新。通过「添加组件」新增的是独立组件，多份同类组件可以使用不同尺寸和样式；选中后点击顶部「复制单组件地址」，即可单独使用这一份已保存的组件。之后修改并应用，原地址继续有效。

例如保存为 **800 × 400**，单组件地址和组合场景内的该组件都使用 **800 × 400 像素**。浏览器源设成 2K 或 4K 会增加透明区域，组件不会跟着放大；视口小于组件时会裁切。画布中的自动适配只方便编辑。加班机保存的是所选宽度和自动测量的高度。此规则适用于本机组件及本机场景地址；直播软件中手动调整来源的变换比例仍会改变最终大小。

「弹幕姬 · 在线源」仍保留服务器返回的完整 HTTPS 地址，使用同一套已保存的弹幕样式。它可在关闭客户端后继续显示，但需要服务器与直播间连接正常。本机弹幕组件与直播场景复用客户端接收的服务器展示数据，不会再次执行业务动作或生成预览示例。

## 浏览器源设置与排查

- 本机 `127.0.0.1` 地址须在运行 LIRA 的同一台电脑上加载，并保持客户端运行和授权有效。
- OBS 选择「浏览器源」，取消「本地文件」，粘贴完整 URL。宽高是网页视口尺寸；整套场景可填写画布分辨率，单组件可填写它保存的宽高。填写更大的视口不会自动放大已保存的组件。OBS 官方说明见 [Browser Source](https://obsproject.com/kb/browser-source)。直播姬使用「浏览器 / 网页来源」填写同一地址及宽高。
- 检查底色、选框、编辑器按钮和示例消息不会进入统一直播源；空画布、未启用的组件或当前没有消息时，透明画面可能是正常状态。
- 统一源无内容时先检查是否添加了可见组件并成功「保存并应用」。独立弹幕源需要服务器处于已连接的开播状态；点歌板需要队列数据，加班机需要已启用。
- 重新加载浏览器源会读取已保存/已应用内容，不依赖编辑网页。常规保存、应用和同端口重启沿用原地址；若端口因冲突改变，或主动停用旧来源，需要重新复制。
- 将同一组件同时作为独立源和直播场景的一部分导入，会在直播软件中显示两份；按当前编排保留需要的来源。

实现契约见 [直播画面技术参考](../reference/frontend/overlays.md#64-组件系统的统一管理与独立导入) 与 [场景规格](../../specs/component-scenes.md)。
