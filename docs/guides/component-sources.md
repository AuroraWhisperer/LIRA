# 组件管理与直播软件导入

LIRA 的组件有两种用法：在统一画布中编排后导入一个地址，或直接导入某个组件的独立地址。两种方式都适用于 OBS 的「浏览器源」和哔哩哔哩直播姬的「浏览器 / 网页来源」。地址集中在客户端「点歌 → 浏览器源」。

## 统一管理一张直播画布

1. 在「点歌 → 浏览器源 → 组件统一管理」点击「打开统一预览」，或从「百宝箱 → 直播画布」进入。
2. 首次打开是空画布；保存后再次进入会恢复已有组件、样式和位置。从单个组件的预览按钮进入，会添加或选中对应组件。
3. 左侧「添加组件」打开分类与样式小窗，目前包含弹幕姬、萌时钟、点歌板、加班机。同类组件可以添加多份并使用不同样式。
4. 新增组件以预定尺寸居中显示。在中间拖动摆放，在右侧调整选中组件的样式、位置和宽高。公共画布分辨率由「画布设置」统一决定；添加组件或切换样式不会改变画布大小。
5. 点击「保存并应用」。它保存配置、布局并更新直播输出；失败时保留上一版已经应用的画面。
6. 回到客户端「浏览器源」，点击「统一直播画布 → 复制统一地址」，或在编辑网页点击「复制直播源地址」。两处复制的是同一张画布的地址。
7. 在直播软件添加一个浏览器源，粘贴完整地址，宽高设为公共画布的分辨率，例如 1920 × 1080。之后修改画布再点「保存并应用」，原地址自动显示新版本。

统一编辑网页是 `/component-preview`，含左侧组件列表、画布和右侧参数；由客户端打开，链接随编辑会话失效。供直播软件导入的是 `/scene?id=…#token=…`，只显示直播内容，背景透明。请使用「复制统一地址」，不要复制浏览器地址栏中的编辑链接。关闭编辑网页不会停止已应用画面的输出，LIRA 客户端需要继续运行。

## 直接使用独立组件

不需要组合布局或额外调参时，直接到「点歌 → 浏览器源」复制对应地址即可。无需打开统一预览，也无需创建或发布画布。组件会读取已有的默认样式与实际数据。

下表中的 `<实际端口>` 由客户端当前运行端口决定，使用界面复制的完整地址，不要手工填写占位符。

| 组件 | 浏览器源中的条目 | 本机独立地址 | 尺寸说明 |
| --- | --- | --- | --- |
| 弹幕姬 | 弹幕姬 · 本机组件 | `http://127.0.0.1:<实际端口>/danmaku?source=component` | 使用已保存的弹幕画布分辨率；未设置布局时按源窗口展示 |
| 萌时钟 | 萌时钟 | `http://127.0.0.1:<实际端口>/clock` | 通常为 580 × 210；竖向刻度为 240 × 400 |
| 点歌板 | 点歌板 | `http://127.0.0.1:<实际端口>/queue` | 按所选样式和队列显示范围设置 |
| 加班机 | 加班机 | `http://127.0.0.1:<实际端口>/overtime` | 按倒计时及背景的显示范围设置 |

需要更换默认样式时，在该组件的客户端面板选择样式并点击保存或应用按钮即可，不必打开统一预览。统一画布组件库新增的图层默认使用独立外观：调整这些图层只影响该画布。右侧明确选择「共享默认」的图层使用原组件的默认配置；默认样式保存后，统一画布仍需「保存并应用」才更新整套输出。

「弹幕姬 · 在线源」仍保留服务器返回的完整 HTTPS 地址，使用同一套已保存的弹幕样式。它可在关闭客户端后继续显示，但需要服务器与直播间连接正常。本机弹幕组件与统一画布复用客户端接收的服务器展示数据，不会再次执行业务动作或生成预览示例。

## 浏览器源设置与排查

- 本机 `127.0.0.1` 地址须在运行 LIRA 的同一台电脑上加载，并保持客户端运行和授权有效。
- OBS 选择「浏览器源」，取消「本地文件」，粘贴完整 URL。宽高是网页视口尺寸；统一画布应设置为相同分辨率。OBS 官方说明见 [Browser Source](https://obsproject.com/kb/browser-source)。直播姬使用「浏览器 / 网页来源」填写同一地址及宽高。
- 检查底色、选框、编辑器按钮和示例消息不会进入统一直播源；空画布、未启用的组件或当前没有消息时，透明画面可能是正常状态。
- 统一源无内容时先检查是否添加了可见组件并成功「保存并应用」。独立弹幕源需要服务器处于已连接的开播状态；点歌板需要队列数据，加班机需要已启用。
- 重新加载浏览器源会读取已保存/已应用内容，不依赖编辑网页。常规保存、应用和同端口重启沿用原地址；若端口因冲突改变，或主动停用旧来源，需要重新复制。
- 将同一组件同时作为独立源和统一画布的一部分导入，会在直播软件中显示两份；按当前编排保留需要的来源。
