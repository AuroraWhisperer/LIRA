# 制作和导入 LIRA 组件样式与套装

先分清三个概念：**组件**指弹幕、开播动画、全屏礼物感谢、时钟、背景等功能模块；**样式**是某个组件的外观（例如大航海感谢里的「航海旗帜」）；**套装**则是跨多个组件、风格配套的一组样式（例如同时包含背景、开播、时钟和弹幕）。同一组件里不管有多少配色、档位动效或变体，都归为该组件的样式，不算套装。ZIP 只是交付打包格式，单组件样式同样可以打成 ZIP 导入，只有跨多个组件的组合包才从「套装」入口导入。素材统一存在本机应用数据目录，更新样式无需重打安装包。

时钟与弹幕导入后可按各自样式调整效果；CSS、图片/视频与 HTML 的可用参数不同，见[逐样式外观效果](component-style-parameters.md)。

## 主播怎么用

单个组件样式（仅限提供新增入口的分类）：在画布「添加组件 → 对应组件分类 → ＋ 添加样式 → 选择文件」选择作者提供的标准样式包，核对后「添加样式」。提供样式列表的独立设置页也可从「＋ 添加样式」进入；直播歌词设置页直接调整歌词外观，额外样式从画布「添加组件 → 直播歌词」导入。它会出现在该组件的样式列表，不会出现在画布的「套装」分类。多个同类样式也使用此入口。滚动礼物、礼物许愿、心动盲盒、月底冲刺和盲盒盈亏榜不提供新增样式入口，已有导入样式仍可使用，入口范围见[组件指南](component-sources.md#添加组件样式与套装)。

样式包必须从对应入口导入：背景样式包只在背景分类添加，跨组件套装只在「套装 → 导入套装」导入。选错时会拒绝添加，并提示正确的分类路径；点击「前往…导入」会切换入口并继续检查刚选的 ZIP，原有样式不受影响。

跨组件套装：

1. 在客户端「点歌 → 浏览器源 → 直播场景」点击「编辑场景」，再到画布「添加组件 → 套装 → 导入套装」，直接选择作者提供的 LIRA 套装 ZIP，无需解压或手动放目录。
2. 核对名称、版本和组件清单，确认导入。
3. 在画布「添加组件 → 套装」按套装选成员，或在对应组件分类选择样式。每点一个卡片添加一个独立组件；也可直接从客户端的样式窗点击卡片进入画布。支持更换样式的已有组件可用「更换样式 / 添加素材」保留原位置和尺寸。
4. 调整布局后「保存并应用」。导入本身不会切换直播画面。

套装列表按整套分组，标题显示名称、版本和组件样式数量。点「更新套装」选择同一套装的新 ZIP，确认将替换的版本后安装；也可直接从「导入套装」选择新版。同一套装以清单 `id` 识别，安装成功后旧版从样式库撤下，失败则保留旧版。已有场景保留原效果；请在画布选用新版组件，再保存并应用。

点套装标题旁的「删除套装」并确认，即可整体移除可选样式；成员卡片只负责选用，不提供单独删除。已有场景及其素材继续保留，删除不会立即释放磁盘空间。误删后重新导入原 ZIP 可恢复整套，重复导入不产生副本。独立添加的样式仍可通过卡片右上角 × 删除。

从「组件」左侧导航底部或画布编辑器顶部打开「素材管理」，可以按包查看类型、名称、版本和成员数，更新或移除整包。单组件的多变体包也按整包更新，同一作者 ID 只显示此次导入的版本；旧场景继续使用旧资源。需要释放空间时，选择「清理未使用文件」并确认。系统会重新核对已保存和已发布场景、其他账号的场景及活动草稿；其他预设还有未保存修改时，先保存或放弃修改再清理。被场景使用的文件会保留，索引恢复情况及空间占用也在此显示。

换电脑时，先保存场景及样式参数，再从「素材管理」选择「导出素材与场景备份」。到新电脑登录后，选择「从备份恢复为副本」，核对素材包、布局数量及提示后确认。备份包含已导入素材、配套网页/字体、本地文本框图片、资源样式的已保存参数及当前账号的保存/发布布局。恢复为新的副本，不覆盖当前场景或自动切换直播；选中恢复的场景，检查后再「保存并应用」，重新复制直播源地址。重复恢复同一个备份不会重复创建副本，也不会覆盖副本上的后续修改。

未保存草稿、外部浏览器源地址、加班机电脑本地背景路径、账号凭据及业务数据不打包。外部来源及本地背景需重新添加，电脑字体需在新电脑安装；内置组件仍遵循客户端公共设置。备份 ZIP 与作者样式 ZIP 使用不同入口；恢复的样式标注「备份」，作者更新包请在正常分类入口另行导入。建议保留作者原版 ZIP，清理旧文件后如需重装可以直接使用；换电脑请使用上述专用备份，不要直接复制包含设备授权的整个应用数据目录。

第三方购买的普通 ZIP 先自行解压，保持配套文件的目录结构，再从对应组件「＋ 添加样式 → 选择文件」选择素材，程序自动识别格式；收到网址或代码时展开「粘贴网址或代码」，无需制作 LIRA 清单。画布会在当前浏览器直接打开文件选择框。客户端内选择 HTML/CSS 时会复制所在素材目录；引用超出该目录时，会再要求选择包含所选文件和全部资源的完整素材文件夹，确认范围后才读取。取消选择不会导入。请把每套素材放在独立文件夹内。在画布导入有配套资源的 HTML/CSS 时，从「更多设置 → 选择整个素材文件夹」导入；程序自动选择首页或唯一的样式，只有无法判断时才需手动选择。名称和显示尺寸通常不用改。

HTML 按完整网页运行，保留脚本、图片、字体和相对路径。CSS 的本地图片、字体一起导入；粘贴 CSS 时可选择配套资源文件夹。弹幕 CSS 会自动识别常见的 blivechat/YouTube 和 BLC 结构并灌入 LIRA 弹幕数据，其余 CSS 直接套在原生组件上。因为样式依赖原作者假定的网页结构，无法保证所有专用选择器完全兼容；LAPLACE 等依赖原工具的样式，请在原工具套用后再导入其展示地址或配套 HTML。需要原工具后端、登录或专用 SDK 的网页仍需运行作者要求的工具，不能仅靠导入样式替代它。

导入前检查静态资源引用；缺文件会显示具体路径并中止。动态拼接的路径、网络服务状态和专用脚本仍需在画布检查。选中样式卡片后预览，调整网页宽高，最后「保存并应用」；可直接用于 OBS 或哔哩哔哩直播姬的 LIRA 场景来源。

文本框上传图片和开播音乐、角色素材另有自动回收：上传或进入素材管理时，会检查超过 30 天且没有场景、当前预览或素材配置引用的旧文件；仍在使用或正在备份的文件保留。需要长期留存尚未使用的上传原件，请另存到自己的素材目录。导入素材包仍通过「素材管理 → 清理未使用文件」释放空间，详细规则见[文件回收](../reference/backend/storage.md#文件回收)。

### 以月渡花汀为例

选择月渡花汀套装 ZIP 后应看到 8 个样式：静态背景、动态背景、开播动画、时钟、弹幕姬、礼物许愿、点歌板、直播歌词；版本以导入清单为准。当前打包版本的点歌板使用暖色满月、群山与湖光倒影素材，旧套装继续使用已导入的边框。选中点歌板后，可改置顶公告及内容字号；也可关闭队列数字，或设为超过指定歌曲数量才显示。背景两款按需选用，其他成员也可以单独添加，不必整套一起用。本包没有全屏礼物感谢样式；其他套装的种类和数量以导入预览为准。

如果旧场景已经用了此前内置的月渡花汀，先导入 ZIP。弹幕姬从「添加组件」重新添加对应样式，核对位置和尺寸后移除要替换的旧图层；其他支持更换样式的组件，选中原图层，用「更换样式 / 添加素材」选择对应成员，最后「保存并应用」。锁定的图层需先解锁；更换样式会保留图层名称、位置、尺寸和层级。

这些样式用于本机场景，OBS 或哔哩哔哩直播姬须与 LIRA 在同一电脑上运行，直播时保持 LIRA 开启。弹幕也使用客户端提供的本机场景或组件地址。客户端内置教程位于「百宝箱 → 使用文档 → 直播姬 / OBS 与套装」，可搜索「套装」「ZIP」「月渡花汀」。

### 航海旗帜 · 上舰感谢

航海旗帜是大航海感谢的一款样式。进入「组件 → 礼物姬 → 大航海感谢 → ＋ 添加样式 → 选择文件」，选择 `航海旗帜-大航海感谢样式-1.0.1.zip`，无需解压。添加后与辉光、经典并列显示完整设置条目，可直接独立启用、模拟预览等级与观众；展开「外观设置」调整头像/昵称显示和昵称字号。「保存设置」同步该样式所有已有组件的公共参数，画布中也可调整；「在画布中预览」选中当前场景已有的同款图层，没有时添加，摆放后再「保存并应用」。每个图层的位置、尺寸和样式选择独立保存。

航海旗帜无需同时启用辉光/经典；同一笔购买只播放一次，三档等级动效属于同一款样式。旗帜中文固定在素材中，不提供无效的语言切换。老版本升级后会自动沿用原来的启用状态，首次手动调整后即独立生效；若旧版客户端提示需要升级，请先更新客户端。

### 林间花信 · 全屏礼物感谢

进入「组件 → 礼物姬 → 全屏礼物感谢」，点页面最下方「添加样式」中的「＋ 添加样式 → 选择文件」，选择 `林间花信-全屏礼物感谢样式-1.0.0.zip`，无需解压。它是一个全屏礼物感谢样式，不出现在「套装」分类。客户端需支持林间花信资源预设；旧版提示更新时先更新客户端。

未导入时页面不显示林间花信。导入后它作为一张独立卡片排在礼物掉落、礼物摇摇乐之后，卡片上有自己的启用开关、触发金额（默认 20 元）、观众/礼物/数量预览示例、「添加到画布」「在画布中预览」「移除」和「保存设置」；它的开关和金额只控制林间花信，不影响其他效果和导入的图片/视频。导入不会修改已保存的启用状态或金额。「添加到画布」默认 1920×1080；「在画布中预览」仍复用已有全屏礼物感谢图层。视频保持原始 2560×1440、30fps、8 秒透明效果，头像、感谢文字、数量与入退场位置保持原样，连续触发按原队列依次播放。

已有内置林间花信图层在本机导入 ZIP 后可继续播放；不用重建布局。已有图层更换样式时使用「更换样式 / 添加素材」，保留位置与尺寸，再「保存并应用」。重复导入同一 ZIP 不增加副本，从可选库移除卡片也不删除旧图层所需素材。直播时保持 LIRA 运行；换电脑需重新导入 ZIP 并核对画布布局。

### 遇到问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到套装导入入口，或提示需要更新客户端 | 先进入「直播场景 → 编辑场景 → 添加组件 → 套装」。若仍无入口，请升级到支持套装导入的正式客户端版本（月渡花汀等资源型套装还需客户端支持对应预设）。 |
| 普通购买包提示缺少清单 | 先解压，再从对应组件「＋ 添加样式」选择 HTML/CSS 或图片、视频；普通 ZIP 不需要改造成 LIRA 套装。 |
| 提示缺少配套资源 | 保留作者交付的目录结构并选择整套素材文件夹；粘贴 CSS 时同时选择资源文件夹。 |
| 导入成功，直播画面没变化 | 在画布选用样式，再点「保存并应用」；导入只增加可选样式。 |
| 误删样式卡片 | 重新导入原来的同一版本 ZIP，可恢复卡片；画布里删除的图层需重新添加。 |
| 同名同版本提示内容冲突 | 请作者提高包版本号后重新导出，不要覆盖旧包文件。同一套装 ID 的新版会替换库中旧版，已有图层保留原资源，需自行更换样式。 |
| 旧场景提示套装资源缺失 | 先重新导入对应 ZIP，在原图层重新选择样式并保存应用；新电脑没有原图层时，重新添加并核对布局。 |

## 作者目录与清单

单组件样式包和跨组件套装共用同一套 `lira-pack.json` 清单格式。客户端按 `styles` 里包含的组件类型自动归类：全部属于同一组件就是样式包，跨多个组件就是套装（旧版本导入的单组件包同样适用，无需重新导入）。

ZIP **根目录**必须有 UTF-8 的 `lira-pack.json`，不要把整个文件夹再套一层。最小示例：

```text
my-suite.zip
├── lira-pack.json
├── assets/
│   ├── background.mp4
│   ├── chat-frame.png
│   ├── clock.png
│   ├── wishes.png
│   ├── opening.webm
│   └── thanks.webm
└── 使用说明.txt
```

```json
{
  "schemaVersion": 1,
  "id": "my-studio.moon-suite",
  "name": "月色直播套装",
  "version": "1.0.0",
  "styles": [
    { "type": "background", "name": "月色背景", "file": "assets/background.mp4", "width": 1920, "height": 1080 },
    {
      "type": "danmaku", "name": "月色弹幕框", "file": "assets/chat-frame.png", "width": 480, "height": 720,
      "media": { "content": { "x": 10, "y": 12, "width": 80, "height": 76 }, "textColor": "#ffffff", "fontSize": 28 }
    },
    { "type": "clock", "name": "月色时钟", "file": "assets/clock.png", "width": 640, "height": 360 },
    { "type": "gift-wishes", "name": "月色许愿", "file": "assets/wishes.png", "width": 640, "height": 240 },
    { "type": "opening", "name": "月色开播", "file": "assets/opening.webm", "width": 1920, "height": 1080 },
    {
      "type": "gift-frame", "name": "月色礼物感谢", "file": "assets/thanks.webm", "width": 1280, "height": 720,
      "media": { "showText": true, "textTemplate": "感谢 {name} 的 {gift} ×{count}", "textDelayMs": 1000, "volume": 0 }
    },
    {
      "type": "guard-thanks", "name": "月色大航海感谢", "file": "assets/thanks.webm", "width": 1280, "height": 720,
      "media": { "showText": true, "textTemplate": "感谢 {name} 开通{tier} · {months}个月" }
    }
  ]
}
```

`id` 使用小写字母、数字、点或短横线，数字或字母开头，最长 80 字符；`version` 使用三段数字。包名、样式名不超过 80 字。`file` 大小写必须和 ZIP 内一致，使用 `/` 相对路径。宽高写素材或设计画布尺寸，不决定主播最后摆放位置。相同文件可以供多个组件使用。

`media` 控制装饰和文字，字段详情与默认值见[本地媒体样式规范](../reference/frontend/overlays.md#本地媒体样式)。`content` 是相对整张素材的百分比区域，弹幕内容、时钟和许愿进度在里面显示。组件配置 `config` 可省略；需要提供时必须符合对应组件已有规范，不能加入账号、网址凭据或直播业务数据。导入服务会自动生成素材 ID 和路径，清单无需填写这些值。

背景和装饰类视频默认循环播放；开播和感谢动画分别跟随客户端的开播开关与触发条件。事件图片默认显示 6 秒，事件视频播完为止（最长 120 秒，可用 `durationMs` 缩短）。导入感谢视频不会自动带入原卖家模板的触发规则，观众昵称、礼物名和数量由 LIRA 在预留区域叠加绘制；如果素材画面本身已经做好了固定文字，把 `showText` 设为 `false` 即可。

### 背景默认参数

静态与动态背景共用平铺在样式 `config` 内的外观参数（普通 `file/media` 与资源型 `preset/resources` 均支持，比例值 `1` 对应界面 100%，省略则保持原图效果）。导入后客户端会保留作者预设（点「恢复样式默认」可还原）；资源背景按样式 ID 共享当前参数，普通图片/视频背景按实例独立保存，作者无需填写客户端生成的 `backgroundDefaults`。完整滤镜字段（含白平衡、LGG、辉光、暗角、色阶等）、示例清单与制作方法见[带滤镜的背景样式包](background-style-packages.md)和[背景美术与滤镜来源](background-art-workflow.md)。

## 打 ZIP 与检查

在套装文件夹内打开 PowerShell，运行下面的命令，把 ZIP 放在文件夹外：

```powershell
Compress-Archive -Path .\lira-pack.json, .\assets, .\使用说明.txt -DestinationPath ..\moon-suite-1.0.0.zip
```

没有说明文件时，删除命令中的该项。先在 LIRA 导入自己的包，逐个检查文字区域和视频，最后在实际使用的 OBS 或哔哩哔哩直播姬预览透明边缘、音量和比例。改动内容后请保持清单 `id` 不变并提高 `version`（版本替换与恢复规则见上文[主播怎么用](#主播怎么用)）。

普通素材支持 PNG/JPEG/GIF/WebP/MP4/WebM。附件仅允许 TXT/MD 说明，保留在原 ZIP 中，不会安装成组件。不导入单独音频、脚本、自定义运行代码或整套场景布局。资源型样式还允许 SVG 与 WOFF2，见下节。文件大小按 Windows 的 1024 进位显示。单个媒体最多 512 MB，ZIP 最多 1 GB，解压后合计最多 2 GB。最多 256 个条目和 64 个样式，清单和单个说明最多 256 KB。不接受加密 ZIP、符号链接、重复路径或损坏内容。

已经压缩过的视频再放 ZIP 通常不会大幅变小。分离套装解决的是 EXE 不必携带所有大素材；实际减小素材仍需要控制分辨率、时长和编码码率。月渡花汀专用图片、视频和时钟裁剪字体已外置；共享字体库的完整文楷由 CDN 补齐并从本机缓存读取，交付规则见 [CDN 公共资源分发](cdn-resources.md)。套装 ZIP 自带的文楷分片仍随套装交付，两条资源路径分别维护。

## 月渡花汀与多素材样式

月渡花汀的时钟、弹幕、许愿和开播使用分层原画及客户端动画。用 `schemaVersion:2`、`preset` 和 `resources` 声明这种样式，客户端继续渲染真实时间、弹幕、礼物进度与程序动画。ZIP 不携带或执行 JS/CSS。根目录清单仍是可变长度的 `styles` 数组：可以缺少某类组件，也可以有多个同类样式；不要为不存在的内容建空文件夹。

运行 `node scripts/package-moonlit-suite.js`，生成 `tmp/output/月渡花汀-1.0.7.zip`。清单来自[套装导出脚本](../../scripts/package-moonlit-suite.js)，包含 8 个样式、去重的运行素材、预览图、字体许可证和使用说明。点歌板包含原生 1145×1374 的暖色满月、群山与湖光倒影无损材质，花仅作岸边点缀；旧套装继续使用已导入的边框。原始素材保留在仓库，`build.files` 排除安装包中的专用素材。

月渡花汀的直播歌词使用 `moonlit-lyrics` 资源预设：月白诗笺、银蓝花枝、雾蓝文楷与暖金逐字高亮，默认居中仅显示当前一句（主歌词 48px、诗笺默认高 108px，加大字号或出现多行翻译时自动增高避免裁字）。内置霞鹜文楷 Light（字体参数名为「月渡花汀文楷」，采用 SIL OFL 1.1 许可），随套装提供、离线可用。它复用现有直播歌词参数面板与同步逻辑，字体、字号、颜色、行高、翻译、描边、暂停隐藏与歌词偏移均可按样式共享调整；导入后可在「添加组件 → 套装 → 月渡花汀」选用，或在直播歌词组件中更换样式（需包含此预设的客户端版本）。

下面是一份全屏礼物感谢的单组件样式包清单，应从全屏礼物感谢的「＋ 添加样式」导入。它虽然包含预览图和视频两个文件，仍不是套装。将预览图和林间花信视频放到示例指定路径。`resources` 必须完整声明对应预设列出的资源，键是客户端逻辑路径，值是 ZIP 内的相对路径：

```json
{
  "schemaVersion": 2,
  "id": "my-studio.gift-frame-style",
  "name": "林间花信样式",
  "version": "1.0.0",
  "styles": [
    {
      "type": "gift-frame",
      "name": "林间花信",
      "preset": "woodland-gift-frame",
      "width": 1920,
      "height": 1080,
      "preview": "assets/preview.webp",
      "config": {},
      "resources": {
        "/img/overlays/gift-frame/woodland-bloom/woodland-bloom-v4.webm": "assets/woodland.webm"
      }
    }
  ]
}
```

已支持的预设由 [component-resource-style.js](../../public/js/shared/component-resource-style.js) 定义。`schemaVersion:2` 也支持前文的普通 `file/media` 样式，可以混装。例如下一包不含开播、多两款感谢视频，只需改变数组内容。AI 制作的全新程序动画需要先接入客户端渲染器，或作为兼容网页源使用；仅添加未知 `preset` 不会执行新程序。

### 交给 AI 制作下一套时

开播样式的默认参数放在每个成员的 `config` 中，随导入进入统一样式选择区。使用 `moonlit-opening` 时可提供 `title`、`subtitle`、`name`、`footer`、`quality`、`showNotes`、`showEq`；不提供则使用月渡花汀自己的默认值。客户端只显示该原生样式支持的控件，保存后的参数只属于此样式，并同步使用它的画布组件；各图层的位置、尺寸和样式选择独立保存。新设计沿用受支持的原生预设时复用其字段与布局；全新原生效果需要配套的客户端渲染器和参数定义。独立 HTML/CSS 仍按文件导入并保留自己的画面，不自动套用经典舞台参数。

先列出本次实际需要的成员，每个成员对应 `styles` 中一项；同类多款各写一项，没有的组件直接省略。普通图片或视频用 `file/media`，复用客户端已支持的分层动画用 `preset/resources`，同一个样式不要混用这两种声明。多个成员可以共用同一素材路径。

交付 ZIP 前检查：根目录清单可读取、每项素材路径存在、预览与实际内容一致、字体或素材许可随包附带；然后按前述步骤实际导入，选用所有成员并检查直播输出。作者应说明所需客户端能力；更新同一套装保持 `id` 不变并提高 `version`。需要新渲染器时，应先完成客户端适配再发素材包。

开发接入的接口、存储、渲染与打包边界见[技术参考入口](../reference/README.md#本机样式与外置套装)。
