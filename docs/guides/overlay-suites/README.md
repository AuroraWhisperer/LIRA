# 直播视觉套装制作指南 · 月渡花汀案例

整理日期：2026-10-06。根据本项目 11 个相关对话、原始提示词、参考截图、制作文件和当前源码整理。适合继续修改「月渡花汀」，也适合以同样的方法制作新主题套装。

这套作品是从参考视频、截图和开播样稿出发，逐项扩展配套，再通过多轮看图、看动画和反馈调出来的。构图、时长、运动方向、深浅配色与背景分辨率都在过程中改过。

本文档保留两种用途：[调试复盘](iteration-history.md) 记录当时遇到的问题、用户原话和修改结果；制作指南与提示词则把这些经验整理为下一次可用的方法。最终参数是复用时的参考，不应倒推成最初就写好的完整需求。

## 当前套装实际包含什么

“礼物”在制作时要分清三种用途：**累计目标进度**是礼物许愿；**消息流内的单次收礼**属于弹幕；**覆盖画面边缘的独立演出**是全屏感谢。它们的布局、头像规则、触发方式不同。

| 部件 | 当前版本与实现 | 状态 |
| --- | --- | --- |
| 静态背景 | 浅银蓝、低对比山水；1920×1080；`background / moonlit` | 已接入本地产品源码 |
| 动态背景 | 独立绘画部件合成；2560×1440、60fps、24 秒；`background / moonlit-animated` | 用户已确认画面，已接入本地产品源码 |
| 开播动画 | 22 片扇面共轴开合；约 15 秒完整往复；`opening / moonlit-fan` | 已接入本地产品源码 |
| 时钟 | 浅色 / 深色 / 定时交替，默认间隔 30 秒；`clock / moonlit-fan` | 已接入本地产品源码 |
| 弹幕、上任、礼物、SC | 深色小底框、笔墨染色、普通观众 + 三档大航海身份、顺序展开的卷轴；`danmaku / moonlit` | 已接入本地产品源码；对话记录有服务器源码同步，本次未核验部署 |
| 礼物许愿 | 贴圆白山茶与墨蓝枝叶、长水墨条、折扇起点、动态进度；`gift-wishes / moonlit` | 已接入本地产品源码 |
| 全屏上任 / 礼物感谢 | 最新为「月伞花汀」：两侧纸伞、底部连续花汀、单次 9.6 秒 | **独立视觉样片，尚未接入真实事件，也不在套装选择器中** |

导入月渡花汀 ZIP 后，套装选择器是 **6 个可添加条目**：静态背景、动态背景、开播、时钟、弹幕、礼物许愿。不能把“六类设计内容”误写成“全屏感谢也已经可以添加”。以 [套装注册表](../../../scripts/package-moonlit-suite.js) 为准。

本次是资料整理，没有重新制作动画、接入业务事件或部署服务。历史检查证明当时检查过的范围，不等同于今天完成了 Electron、OBS 或哔哩哔哩直播姬实播。

## 文件怎么放

```text
D:/Work/Live/
├─ docs/guides/overlay-suites/   ← 长期指南、可复用提示词、版本与路径索引
├─ archive/moonlit-suite/       ← 2026-10-06 制作档案
│  ├─ README.md                ← 打开方式、备份及恢复说明
│  ├─ manifest.json            ← 原路径 → 归档路径、文件大小、SHA-256
│  ├─ reference-index.md       ← 参考截图逐张索引
│  ├─ preview.html             ← 本地样片总入口
│  ├─ references/              ← 从聊天附件与临时目录复制的参考图
│  ├─ conversations/           ← 可见用户消息、最终回复、图像生成请求摘录
│  └─ files/                  ← 保留原目录结构的 tmp/ 与 public/ 精选快照
├─ tmp/                        ← 原过程目录仍保留；新一轮制作也在这里工作
└─ public/                     ← 应用真正加载的素材和前端模块
```

指南、归档说明、截图索引和清单可进入版本管理；原图、视频、对话和本地预览被归档目录自己的 `.gitignore` 排除。**Git 不会备份这些本地素材**，需要连同整个 `archive/moonlit-suite/` 另存到备份盘。现有安装包使用 `src/`、`public/` 等白名单，归档不属于运行资源。

归档是复制，不移动、不删除原文件，也不改变生产资源地址。旧脚本仍可能依赖原来的项目根目录和 `tmp/` 相邻目录，使用前按归档说明恢复到完整项目副本。
