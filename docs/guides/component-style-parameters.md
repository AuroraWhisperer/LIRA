# 时钟与弹幕的逐样式外观效果

在画布选中组件，打开右侧「外观效果」。时钟、固定弹幕、区域随机弹幕和飘窗弹幕共用参数范围，但按具体样式显示可用选项，并明确效果作用于文字、卡片底板还是整体图案。

## 样式参数的保存与恢复

- 从「添加组件」新增的每一份组件独立保存样式选择、位置和尺寸。内置组件的公共外观参数与资源型样式参数按同一样式共享，保存后同步其他同样式组件及已发布画面；导入的 CSS 和普通图片/视频样式仍按实例保存。不同样式的参数分别保留，导入样式按各自 ID 记忆。
- 从默认组件的预览按钮打开时，该图层与默认组件共用设置；右侧会标明这种关联。
- 展开某项后勾选「调整…」才覆盖原样式。取消勾选恢复作者的该项效果；不透明度或宽度设为 0 则关闭对应自定义光影或轮廓。未调整的效果保持原样。
- 弹幕参数和「外观效果」的滑块在拖动时只更新读数，松开后更新预览；数值框在确认或离开输入框后生效，颜色在完成一次选色操作后生效。字体、颜色、透明度和光影调整直接作用于当前弹幕，不清空重播；分布参数用于后续新弹幕，已显示弹幕保持原位置。
- 「恢复当前样式效果」仅清空当前款式的新增效果及进房开关，不清空其他款式，也不重置原有字体、字号和布局参数。
- 最后点击「保存并应用」。在线弹幕源需要服务器支持新参数；旧服务器未确认保存时会提示更新，不会当作成功。

## 花与信笺

在客户端「组件 → 弹幕姬 → 固定位置」或画布「添加组件 → 弹幕姬 → 固定弹幕」选择「花与信笺」。默认使用字体库中的悠哉字体，正文字号 24px，可调 18–40px；默认区域 640×850，边缘直接切断。可继续调整字体、正文色、纸面不透明度、滚动方向和边缘处理。

普通观众使用邮戳信笺，本房间粉丝为绿色花笺，舰长／提督／总督分别为蓝／紫／粉花笺。时间、昵称、灯牌等级和头像跟随真实消息；礼物、免费礼物、上舰和 SC 使用各自信封／短笺，金额取本次实际总额。长文只延展纸面，花叶保持比例。客户端画布「保存并应用」后通过场景浏览器源使用；在线独立弹幕源仍需服务器版本支持该样式。

## 手账风

在客户端「组件 → 弹幕姬 → 固定位置」或画布「添加组件 → 弹幕姬 → 固定弹幕」选择「手账风」。默认区域 640×720，正文字号默认 23px、范围 18–48px，可调整字体、正文颜色、滚动方向和边缘处理；边缘默认直接切断。普通、舰长、提督、总督使用对应身份色的便笺，头像、粉丝牌和 B 站表情跟随真实消息，表情不需要另行导入。

头像、纸张、昵称与正文分层出现，最新纸张轻浮动；新消息到达后，旧纸张停下，头像仍保留轻微动作。普通礼物、开通与 SC 显示各自实际字段。画布「保存并应用」后使用客户端场景浏览器源；在线独立弹幕源另需服务器支持该样式。

## 幽灵便笺（Spooky Notes）

在客户端「组件 → 弹幕姬 → 固定位置」选择「幽灵便笺」。默认区域 530×620，字号 16–36px、默认 20px；「便笺配色」提供紫色、秋日、灰紫、月光四款，「Chat Box 外框」可以显示或隐藏。外框随画布区域调整，隐藏后释放消息空间；配色和外框按当前样式保存，点击「应用到直播画面」或画布的「保存并应用」发布。

「正文配色」默认跟随主题，也可单独自定义。在「高级参数 → 背景与装饰配色」分别设置外框底色、普通消息底色、事件卡底色和装饰强调色；每项均可选择跟随主题或自定义。礼物、上舰与 SC 共用事件卡底色，强调色联动纸片、书签、蛛网和外框边线。外框、消息、事件卡各有 0–100% 不透明度，即使底色跟随主题也能调整；只影响主体底板及背衬纸片，文字、贴纸、头像和边线不会一起变淡。

切换四套主题时，跟随项使用新主题，自定义项继续保留。「恢复当前主题配色」清除五项颜色及三项背景不透明度的覆盖，保留主题、外框开关、字体、字号和布局；顶部「恢复默认」仍恢复整个当前样式的参数。同款样式的多份组件共享这些设置。

普通消息保留鬼魂/骷髅贴纸和纸片结构，只有本房间大航海身份显示副信息；礼物与上舰使用头像事件卡。SC 的头像、昵称和金额位于上方，完整正文在下方通栏显示；超长单条沿用公共 feed 的适配。进入消息仍由原有开关决定，使用简短提示。修改配色或外框不会重新播放已有消息。

## 哪些样式显示哪些参数

白平衡、亮部辉光、色阶、旋转与倾斜作用于内置组件整体；文字描边作用于文字节点。下面列出光影和轮廓的差别，括号内为样式标识，便于素材作者对应。

| 结构 | 样式 | 光影与轮廓的作用对象 | 内阴影 / 内发光 |
| --- | --- | --- | --- |
| 时钟卡片 | peach、starlight、soda、flip | 卡片；翻牌时钟作用于外框内容区，保留翻页动画 | 支持 |
| 时钟文字 | timeline-horizontal、timeline-vertical、digital、minimal | 文字投影、文字外发光和文字描边；隐藏底板轮廓 | 隐藏 |
| 时钟图案 | orbit | 整体图案的透明边缘 | 隐藏 |
| 月渡花汀时钟 | moonlit-fan | 月轮底板；保留扇子、花枝和流苏的原效果 | 支持 |
| 弹幕卡片 | bubble、signal、ranked、identity、sketch、harbor、mist、outline、cream、glow、starveil、floating、notebook | 该款的消息卡片底板，支持的 SC 使用自身卡片 | 支持 |
| 留白弹幕 | transparent | 文字；隐藏底板轮廓 | 隐藏 |
| 弹幕图案 | minimal、starlight、moonlit、comet、flower-letter | 卡片与装饰组成的整体透明边缘 | 隐藏 |
| 白描弹幕 | whiteframe | 原有线框及文字；保持透明底板 | 隐藏 |
| 幽灵便笺 | spooky | 消息卡片与纸片轮廓，文字效果覆盖昵称、事件和 SC 正文 | 隐藏 |

原有专属参数继续保留：固定弹幕的滚动方向与边缘处理、随机弹幕的停留时间与位置分布、飘窗速度，以及翻牌颜色、月轮明暗切换等。它们不能用一套通用光影参数替代。

固定弹幕在常规参数中选择“边缘处理”：两端渐隐让上下边缘逐渐透明；上边渐隐或下边渐隐只处理选定边缘，不随滚动方向改变；直接切断在边缘裁掉内容。流霞默认两端渐隐，仿推特 3.0、幽灵便笺、花与信笺和手账风默认直接切断，其他固定样式默认在移出端渐隐，并显示具体的上边或下边。选项按样式保存，“恢复默认参数”恢复该样式的默认值，最后点击“保存并应用”。

「琉璃」、「杏花白」、「灵动弹幕」、「留白」、「一纸素笺」和「仿推特 3.0」的礼物通知固定显示对应真实礼物图片，不提供插画切换；预览使用内置 WebP，正式直播使用该礼物随消息携带的原图。缺图或加载失败时图位留空，仍显示礼物名称与数量，不再回退为礼章或星星。「灵动弹幕」礼物右侧显示本次已结算总额，不重复乘数量；新建默认显示区域为 640×616，已保存的区域（包括原 640×560）保持不变。

「青雾」位于「区域随机」，默认铺满画布。普通弹幕为透明白框，本直播间大航海弹幕为浅青卡片；礼物、大航海感谢与 SC 也在区域内随机出现，均使用 2–30 秒停留时间，SC 可随 B 站下线通知撤下。背景透明度调整浅青底板，文字保持不透明；可继续设置字体、18–40 字号、正文色及位置分布。

「星语」可在「组件 → 弹幕姬」的样式参数、画布参数区或独立预览中选择「装饰图案」：四角星、爱心、圆角方块、五角星、小花、月牙、蝴蝶结。选择后自动播放该图案的轻动画：四角星闪烁、爱心轻跳、方块轻弹、五角星缓转、小花呼吸、月牙摇曳、蝴蝶结轻摆。普通弹幕、礼物和 SC 的装饰会一起切换，文字和排版保持原样；恢复默认回到四角星。系统开启减少动态效果时图案静止显示。点击「应用到直播画面」或画布的「保存并应用」后发布到直播画面，独立预览的修改仅在预览中生效。

「白描」、「流光溢彩」和「点点流萤」可在客户端「组件 → 弹幕姬」的样式参数或画布参数区选择「入场动画」。「动画 1 · 渐显」为默认效果；「动画 2 · 上浮弹入」让卡片和昵称上浮，整段正文从左侧滑入并轻微回弹，两部分同时在 0.5 秒内完成。选择按样式保存，恢复默认回到动画 1；修改只影响新消息，不重播已有消息，也不改变停留时间和随机位置。系统启用减少动态效果时直接显示完整消息。点击「应用到直播画面」或画布的「保存并应用」后，选择才会发布到直播画面。

固定位置的「仿推特 3.0」以白色社交面板展示普通聊天、礼物、大航海和 SC，默认区域为 530×850，正文字号为 18–40px、默认 22px，边缘默认直接切断。顶部显示当前配置直播间的房主头像、名称和 UID；评论、转发、爱心和分享为高清装饰图标，不代表真实互动数据。本房间舰长／提督／总督的对勾分别为蓝／紫／红，大航海购买等级与当前身份分别读取。预览使用合成房主和消息，正式直播资料来自当前房间；礼物固定使用原图，不提供插画切换。

固定位置的「RIPPLOID」为普通聊天、礼物票券、NEW MEMBER 上舰卡和 SC 提供统一的分层动效，默认区域为 520×640，正文字号为 18–48px、默认 24px。普通聊天最多显示当前房间粉丝牌名称／等级和当前房间大航海身份两枚徽标，不另显示用户等级。「聊天主色」选择默认时保留多色装饰，选择自定义时只统一普通聊天装饰，不改变事件卡颜色。

「高级参数 → RIPPLOID 事件配色」提供 15 个独立颜色：普通礼物按单条已结算人民币总额、SC 按实际金额分别使用 `<50`、`50～<100`、`100～<500`、`500～<1000`、`1000～<2000`、`≥2000` 元六档；上舰按购买的舰长、提督、总督分三档。所有事件档默认均为橙色 `#F39749`，可分别调整。参数按 RIPPLOID 样式保存，恢复默认只重置当前样式；点击「应用到直播画面」或画布的「保存并应用」后发布，独立预览的修改仅在预览中生效。

## 参数范围

「对白」在「高级参数 → 消息显示」提供“弹幕礼物卡片最低金额”，按每条礼物通知的人民币结算总额筛选（已含数量，包含上舰）。设为 0 显示全部；设为 10 时，低于 10 元的通知隐藏，恰好 10 元仍显示。可填 0–100000 元，最多两位小数；SC 不受此门槛影响。参数按该样式保存，需点击“应用到直播画面”或画布的“保存并应用”。

像素为组件的逻辑像素，随组件缩放。白平衡为相对冷暖和色偏调整，不是相机的开尔文色温。

| 参数 | 范围 |
| --- | --- |
| 外投影 | 颜色、不透明度 0–100%；X/Y 偏移 −100–100 px；模糊 0–80 px |
| 内阴影 | 颜色、不透明度 0–100%；X/Y 偏移 −30–30 px；模糊 0–40 px |
| 外发光 / 内发光 | 颜色、不透明度 0–100%；半径分别 0–80 / 0–40 px |
| 轮廓 / 文字描边 | 颜色、不透明度 0–100%；宽度分别 0–16 / 0–8 px |
| 白平衡 | 色温 −100–100；色调 −100–100 |
| 亮部辉光（Bloom） | 强度 0–100%；半径 0–80 px；亮度阈值 0–100% |
| 色阶 | 输入/输出黑场 0–254、白场 1–255，各自必须黑场小于白场；中间调 0.1–3 |
| 旋转 | X/Y −80°–80°；Z −180°–180° |
| 倾斜 | X/Y −45°–45° |
| 显示进房消息 | 仅弹幕，默认关闭，随当前样式参数保存；共享与实例范围同上 |

外发光沿形状边缘生成；亮部辉光按画面亮度阈值提取亮部后扩散。二者效果不同，可以单独调整。色阶与白平衡保持透明背景。较大的辉光、模糊和三维变换会增加绘制开销，实际流畅度取决于直播软件与显卡。

## 导入 CSS、HTML 和素材

已识别的 BLC、blivechat / YouTube CSS 使用对应的消息和文字节点；原生 CSS 沿用所选预设的结构。可以调整光影、文字描边、调色和变换。CSS 若隐藏或替换了目标节点、使用独立伪元素或强制覆盖属性，部分效果仍取决于作者结构，应在画布核对。导入图片/视频底图使用整体图案效果，文字描边只作用于 LIRA 渲染的文字，不能改变图片内已经画好的字。

完整 HTML 和外部网页继续在隔离框架内运行，只提供已验证可用的**整体外投影、外发光、矩形边框和旋转/倾斜**。不提供内部白平衡、Bloom、色阶、文字描边或内阴影：当前 Chromium 的 SVG 引用滤镜不能可靠作用于隔离网页内容，LIRA 也不访问它的内部结构。网页背景、内部样式和进房消息由原网页控制；若页面本身不透明，外发光会沿页面矩形而非内部文字产生。

## 进房消息

开启后，当前直播场次的新进房事件在弹幕中显示「进入了直播间」。服务器按同一观众 10 秒去重，并沿用用户屏蔽；只传昵称、舰队等级与展示所需的场次/时间，不公开 UID 或上游原包。不回放此前进房记录，也不向 B 站发送欢迎弹幕。自动欢迎发送仍由原有功能单独控制。

两种直播软件使用同一套浏览器源；自动化验证使用 Chromium 和隔离的 Electron 编辑流程，不能替代 OBS / 哔哩哔哩直播姬中的实际推流检查。
