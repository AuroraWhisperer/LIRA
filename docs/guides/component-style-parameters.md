# 时钟与弹幕的逐样式外观效果

在画布选中组件，打开右侧「外观效果」。时钟、固定弹幕、区域随机弹幕和飘窗弹幕共用参数范围，但按具体样式显示可用选项，并明确效果作用于文字、卡片底板还是整体图案。

客户端「组件 → 弹幕姬」可从「最近使用」快捷选择，或打开「全部样式」，按显示方式、样式动效、节日限定与视觉风格组合筛选内置样式。「样式动效」包含分层入场、图层变化和装饰动画，只有整卡淡入或移动的样式归为「无」。「清除筛选」跟随顶部筛选条件，样式数量与「添加样式」导入入口固定在样式库底部；选卡后回到原参数区，仍需点击「保存外观」。

## 样式参数的保存与恢复

- 从「添加组件」新增的每一份组件独立保存样式选择、位置和尺寸。内置组件的公共外观参数与资源型样式参数按同一样式共享，保存后同步其他同样式组件及已发布画面；导入的 CSS 和普通图片/视频样式仍按实例保存。不同样式的参数分别保留，导入样式按各自 ID 记忆。
- 从默认组件的预览按钮打开时，该图层与默认组件共用设置；右侧会标明这种关联。
- 展开某项后勾选「调整…」才覆盖原样式。取消勾选恢复作者的该项效果；不透明度或宽度设为 0 则关闭对应自定义光影或轮廓。未调整的效果保持原样。
- 弹幕参数和「外观效果」的滑块在拖动时只更新读数，松开后更新预览；数值框在确认或离开输入框后生效，颜色在完成一次选色操作后生效。字体、颜色、透明度和光影调整直接作用于当前弹幕，不清空重播；分布参数用于后续新弹幕，已显示弹幕保持原位置。
- 「恢复当前样式效果」仅清空当前款式的新增效果及机器人欢迎显示开关，不清空其他款式，也不重置原有字体、字号和布局参数。
- 最后点击画布的「保存并应用」，或客户端的「保存外观」。弹幕外观按 LIRA 账号保存在这台电脑，同款参数更新已发布的本地场景；位置、尺寸和样式选择由场景编辑器保存。

首次使用会读取已有服务器配置作为本机初始值，成功后只维护本地外观。保存失败时草稿保留，可重试；切换账号不会带入另一个账号的参数。直播软件请使用本地场景地址，并保持 LIRA 运行。旧服务器地址保留旧配置，不随这里的保存改变；换电脑也不会自动同步本机外观。

桌面设置、画布参数区和独立预览使用同一套参数控件；常用与高级均按当前样式记忆。区域随机的「停留（秒）」每款分别保存，可填 2–30 秒，恢复当前款默认回到 6 秒，不改变其他款。旧配置会先沿用原停留时间，再分别调整。独立预览会在当前页面保留基础参数与外观效果，刷新后继续使用；它不会自动保存外观。

## 随机与飘窗的动效

基础外观下面分别提供「随机弹幕通用参数」和「飘窗弹幕通用参数」。通用表示复用这些控制项，设置仍按小样式分别保存。

- 随机弹幕：设置停留、中心倾向和离散程度；退场可选渐隐或直接消失，渐隐时长 100–1000ms，默认 400ms。停留包含入场和退场，调整只影响后续消息。
- 一纸素笺、青雾、杏花白、白描、流光溢彩、点点流萤共用「样式渐显／上浮弹入／直接显示」及 100–1000ms 入场时长。漫画的入场在「高级参数 → 漫画造型与入场」单独调整。
- 飘窗弹幕：速度、分散与边缘显隐统一调整；可选两端、入场端、离场端渐隐或直接切断。柔化宽度 4–80px，每侧最多占区域宽度 4%；完整卡片与光尾移出后清理。极光和星轨默认双边柔化，另外两款默认直接切断。
- 极光、星轨的独立入场位于各自高级参数，均可选择直接显示。持续动画只控制吊饰、星芒、星尘等循环，与入场和移动独立。

关闭某项动效后，其时长或宽度控件停用，但已保存的数值保留。修改和保存动效参数不会清空、重播当前消息。

## 星轨飞语

在「组件 → 弹幕姬 → 全部样式 → 飘窗弹幕」选择「星轨飞语」，或在画布添加弹幕姬后选择本款。透明画面中，四角星、昵称和正文从右向左匀速移动，细光尾跟随；正文与表情保持稳定。默认正文 28px，可调 18–44px；字体、正文颜色、飘动速度和分散程度沿用常规参数。

展开「高级参数 → 星芒与光尾」：星芒颜色同时控制星芒、光尾和星尘的颜色与不透明度；星芒大小 12–40px（默认 24）、光尾长度 0–360px（默认 180，0 隐藏）、辉光强度 0–100%（默认 45%）、星尘开启／关闭（默认开启，光尾为 0 时一并隐藏）、入场方式（星芒点亮／直接显示）、入场时长 250–1200ms（默认 680，建议 450–800，调整后用于新消息）。辉光只作用于星芒和光尾；入场先在可视范围点亮星芒，再渐显昵称与正文，不改变移动速度。进入与离开画面边缘时自然柔化，完整光尾移出后清理，无需另设消失时长。「持续动画」关闭后停用星芒和星尘的呼吸动作，仍保留新消息入场与横向移动。

字体、正文字号／颜色、飘动速度、分散程度与持续动画是多款复用的公共控件，保存值仍按具体样式独立记忆。星芒颜色／大小、光尾长度、辉光、星尘与入场方式／时长是本款独立参数；边缘柔化在飘窗通用参数中调整。

普通弹幕与礼物共用轻量文字造型，礼物保留真实昵称、礼物名和数量；与其他飘窗一致，本款不显示 SC。点击「保存外观」或画布「保存并应用」后，同款参数更新本地场景；「恢复默认」只重置当前款。光尾完整离开画面后才移除消息。

## 花与信笺

在客户端「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布「添加组件 → 弹幕姬 → 固定弹幕」选择「花与信笺」。默认使用字体库中的悠哉字体，正文字号 24px，可调 18–40px；默认区域 640×850，边缘直接切断。可继续调整字体、正文色、纸面不透明度、滚动方向和边缘处理。

普通观众使用邮戳信笺，本房间粉丝为绿色花笺，舰长／提督／总督分别为蓝／紫／粉花笺。时间、昵称、灯牌等级和头像跟随真实消息；礼物、免费礼物、上舰和 SC 使用各自信封／短笺，金额取本次实际总额。长文只延展纸面，花叶保持比例。客户端画布「保存并应用」后通过场景浏览器源使用；新样式无需同步部署到服务器。

## 圣诞来信

在客户端「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布的固定弹幕样式中选择「圣诞来信」。这是奶油气泡与姜饼人、小鹿、雪人等角色组成的圣诞插画款。默认区域 560×720，正文 24px、可调 18–40px；支持字体、正文颜色、背景透明度、滚动方向与边缘处理，默认直接切断。

本房间的灯牌等级直接随身份显示，例如「粉丝团 12」「舰长 28」「提督 38」「总督 50」；没有等级数据时只显示已知身份。开通／续费卡使用对应角色与船只作右侧背景，左侧显示昵称、身份等级、动作和实际金额，省去泛称标题。普通礼物的昵称、动作、礼物名称、数量和合计统一跟随正文字号，上舰文案和金额也跟随；SC 保留独立的「SC · 醒目留言」标题与大号金额，按真实事件类型展示。

醒目留言有金色标题和大号金额，上舰按舰长／提督／总督使用浅蓝／淡紫／暖金卡面与对应角色背景，普通礼物使用紧凑通知。普通聊天约 720ms 完成入场；连续快速到达时自动减少扫光和星点，醒目留言与上舰保留完整动效。角色在入场后静止；系统的减少动态效果设置仍优先。点击「保存外观」或画布「保存并应用」后，由客户端本地场景浏览器源输出，直播时保持 LIRA 运行。

## 极光薄笺

在「组件 → 弹幕姬 → 全部样式 → 飘窗弹幕」或画布「添加组件 → 弹幕姬 → 飘窗弹幕」选择「极光薄笺」。珠光薄片、独立昵称签与轻摆吊饰从右向左飘过，普通文字、B 站表情、礼物与开通／续费使用真实消息，SC 沿用飘窗规则不显示。默认正文字号 26px，可调 18–40px；字体、文字颜色、背景不透明度、飘动速度和分散程度使用公共参数。

「高级参数 → 极光薄笺」可选择紫藤极光、冰川青蓝、玫瑰晨曦或香槟月白；珠光强度 0–100%、默认 55%；吊饰可选四角星、月牙或不显示；吊饰摆幅 0–12°、默认 5°，0° 静止。文字不会随吊饰摆动。关闭「持续动画」同时停止吊饰与流光，保留入场和横向移动；系统减少动态效果还会省略入场。背景不透明度只调整纸面及昵称签底板，正文保持清晰。

这些外观选项与新增的「入场方式／入场时长」都是本款独立参数。入场可选薄笺分层展开或直接显示，时长 180–1200ms、默认 520ms，按比例调整纸面、昵称和正文的出现节奏。字体、正文色、背景不透明度、速度、分散程度及持续动画使用公共控件，设置仍按款分别保存。左右边缘显隐在飘窗通用参数中调整，完全移出后清理，不另外设置停留时间。摆幅只在吊饰可见且持续动画开启时生效，隐藏吊饰或关闭循环后会保留原来的摆幅设置。

调参立即预览，已有消息不重播入场；「恢复默认」只重置当前款。点「保存外观」或画布「保存并应用」保存到当前账号本机，同款已发布场景同步更新。

## 手账风

在客户端「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布「添加组件 → 弹幕姬 → 固定弹幕」选择「手账风」。默认区域 640×720，正文字号默认 23px、范围 18–48px，可调整字体、正文颜色、滚动方向和边缘处理；边缘默认直接切断。普通、舰长、提督、总督使用对应身份色的便笺，头像、粉丝牌和 B 站表情跟随真实消息，表情不需要另行导入。

头像、纸张、昵称与正文分层出现，最新纸张轻浮动；新消息到达后，旧纸张停下，头像仍保留轻微动作。普通礼物、开通与 SC 显示各自实际字段。画布「保存并应用」后使用客户端场景浏览器源；直播软件使用本机场景地址，并保持 LIRA 运行。

「持续动画」默认开启；关闭后纸张与头像保持静止，新弹幕的入场和列表滚动仍按原节奏播放，适合背景本身已有较多动态的直播画面。

## 幽灵便笺（Spooky Notes）

在客户端「组件 → 弹幕姬 → 全部样式 → 固定位置」选择「幽灵便笺」。默认区域 530×620，字号 16–36px、默认 20px；「便笺配色」提供紫色、秋日、灰紫、月光四款，「Chat Box 外框」可以显示或隐藏。外框随画布区域调整，隐藏后释放消息空间；配色和外框按当前样式保存，点击「保存外观」或画布的「保存并应用」发布。

「正文配色」默认跟随主题，也可单独自定义。在「高级参数 → 背景与装饰配色」分别设置外框底色、普通消息底色、事件卡底色和装饰强调色；每项均可选择跟随主题或自定义。礼物、上舰与 SC 共用事件卡底色，强调色联动纸片、书签、蛛网和外框边线。外框、消息、事件卡各有 0–100% 不透明度，即使底色跟随主题也能调整；只影响主体底板及背衬纸片，文字、贴纸、头像和边线不会一起变淡。

切换四套主题时，跟随项使用新主题，自定义项继续保留。「恢复当前主题配色」清除五项颜色及三项背景不透明度的覆盖，保留主题、外框开关、字体、字号和布局；顶部「恢复默认」仍恢复整个当前样式的参数。同款样式的多份组件共享这些设置。

普通消息保留鬼魂/骷髅贴纸和纸片结构，只有本房间大航海身份显示副信息；礼物与上舰使用头像事件卡。SC 的头像、昵称和金额位于上方，完整正文在下方通栏显示；超长单条沿用公共 feed 的适配。进入消息仍由原有开关决定，使用简短提示。修改配色或外框不会重新播放已有消息。

## 哪些样式显示哪些参数

白平衡、亮部辉光、色阶、旋转与倾斜作用于内置组件整体；文字描边作用于文字节点。下面列出光影和轮廓的差别，括号内为样式标识，便于素材作者对应。

| 结构 | 样式 | 光影与轮廓的作用对象 | 内阴影 / 内发光 |
| --- | --- | --- | --- |
| 时钟卡片 | peach、starlight、soda、flip | 卡片；翻牌时钟作用于外框内容区，保留翻页动画 | 支持 |
| 时钟文字 | timeline-horizontal、timeline-vertical、digital、minimal | 文字投影、文字外发光和文字描边；隐藏底板轮廓 | 隐藏 |
| 时钟图案 | orbit | 整体图案的透明边缘 | 隐藏 |
| 月渡花汀时钟 | moonlit-fan | 月轮底板；保留扇子、花枝和流苏的原效果 | 支持 |
| 弹幕卡片 | bubble、signal、ranked、identity、sketch、harbor、mist、outline、cream、glow、starveil、floating、notebook | 该款的消息卡片底板，支持的 SC 使用自身卡片 | 支持 |
| 留白弹幕 | transparent | 文字；隐藏底板轮廓 | 隐藏 |
| 弹幕图案 | minimal、starlight、moonlit、comet、flower-letter、aurora | 卡片与装饰组成的整体透明边缘 | 隐藏 |
| 白描弹幕 | whiteframe | 原有线框及文字；保持透明底板 | 隐藏 |
| 幽灵便笺 | spooky | 消息卡片与纸片轮廓，文字效果覆盖昵称、事件和 SC 正文 | 隐藏 |
| 漫画对白 | comic | 纸面、墨线和网点组成的透明轮廓；正文保持独立 | 隐藏 |

原有专属参数继续保留：固定弹幕的滚动方向与边缘处理、随机弹幕的停留时间与位置分布、飘窗速度，以及翻牌颜色、月轮明暗切换等。它们不能用一套通用光影参数替代。

固定弹幕在常规参数中选择“边缘处理”：两端渐隐让上下边缘逐渐透明；上边渐隐或下边渐隐只处理选定边缘，不随滚动方向改变；直接切断在边缘裁掉内容。流霞默认两端渐隐，仿推特 3.0、幽灵便笺、花与信笺和手账风默认直接切断，其他固定样式默认在移出端渐隐，并显示具体的上边或下边。选项按样式保存，“恢复默认参数”恢复该样式的默认值，最后点击“保存并应用”。

「琉璃」、「杏花白」、「灵动弹幕」、「留白」、「一纸素笺」和「仿推特 3.0」的礼物通知固定显示对应真实礼物图片，不提供插画切换；预览使用内置 WebP，正式直播使用该礼物随消息携带的原图。缺图或加载失败时图位留空，仍显示礼物名称与数量，不再回退为礼章或星星。「灵动弹幕」礼物右侧显示本次已结算总额，不重复乘数量；新建默认显示区域为 640×616，已保存的区域（包括原 640×560）保持不变。

「青雾」位于「区域随机」，默认铺满画布。普通弹幕为透明白框，本直播间大航海弹幕为浅青卡片；礼物、大航海感谢与 SC 也在区域内随机出现，均使用 2–30 秒停留时间，SC 可随 B 站下线通知撤下。背景透明度调整浅青底板，文字保持不透明；可继续设置字体、18–40 字号、正文色及位置分布。

「漫画对白」也在「区域随机」中选择，以纸白、墨线和淡网点展示聊天、礼物、上舰与 SC，默认铺满画布，正文字号默认 26px、范围 18–42px。在「高级参数 → 漫画造型与入场」可调整以下六项；礼物与 SC 保留横排，分别使用旁白框和爆炸框。入场完成后文字保持稳定，系统减少动态效果时直接显示完整消息。

| 参数 | 可调范围 | 默认 |
| --- | --- | --- |
| 阅读方向 | 横排、竖排（从右向左） | 横排 |
| 气泡造型 | 混排、对白框、旁白框、爆炸框 | 混排 |
| 墨线粗细 | 1–4px | 2px |
| 网点浓度 | 0–30%，0 关闭 | 8% |
| 入场方式 | 漫画弹出、墨线勾勒、轻柔渐显 | 漫画弹出 |
| 入场时长 | 180–800ms | 420ms |

阅读方向、墨线和网点可直接更新当前预览；气泡造型与入场设置用于后续消息。同一条消息在混排下保持相同造型。勾线入场先显现纸面，再带出文字；正常消失沿用随机弹幕统一的约 400ms 原位渐隐，没有额外退场滑块。停留时间为 2–30 秒、默认 6 秒，包含入场和渐隐，按每款分别保存；默认组合可完整稳定显示约 5.3 秒。短句可以缩短停留，长留言建议 8–12 秒，尤其配合 600–800ms 的慢入场时。公共背景不透明度调整纸面和网点，不淡化文字。点击「保存外观」或画布的「保存并应用」后使用本机场景地址，保持 LIRA 运行；「恢复默认」只重置当前样式。

「星语」可在「组件 → 弹幕姬」的样式参数、画布参数区或独立预览中选择「装饰图案」：四角星、爱心、圆角方块、五角星、小花、月牙、蝴蝶结。选择后自动播放该图案的轻动画：四角星闪烁、爱心轻跳、方块轻弹、五角星缓转、小花呼吸、月牙摇曳、蝴蝶结轻摆。普通弹幕、礼物和 SC 的装饰会一起切换，文字和排版保持原样；恢复默认回到四角星。系统开启减少动态效果时图案静止显示。点击「保存外观」或画布的「保存并应用」后发布到直播画面，独立预览的修改仅在预览中生效。

「白描」、「流光溢彩」和「点点流萤」可在客户端「组件 → 弹幕姬」的样式参数或画布参数区选择「入场动画」。「动画 1 · 渐显」为默认效果；「动画 2 · 上浮弹入」让卡片和昵称上浮，整段正文从左侧滑入并轻微回弹，两部分同时在 0.5 秒内完成。选择按样式保存，恢复默认回到动画 1；修改只影响新消息，不重播已有消息，也不改变停留时间和随机位置。系统启用减少动态效果时直接显示完整消息。点击「保存外观」或画布的「保存并应用」后，选择才会发布到直播画面。

固定位置的「仿推特 3.0」以白色社交面板展示普通聊天、礼物、大航海和 SC，默认区域为 530×850，正文字号为 18–40px、默认 22px，边缘默认直接切断。顶部显示当前配置直播间的房主头像、名称和 UID；评论、转发、爱心和分享为高清装饰图标，不代表真实互动数据。本房间舰长／提督／总督的对勾分别为蓝／紫／红，大航海购买等级与当前身份分别读取。礼物与 SC 使用通栏色块，上舰使用阶梯箭头卡片。表情完整显示，宽图按比例适配，多张表情可换行，帖子随内容增长。预览使用合成房主和消息，正式直播资料来自当前房间；礼物固定使用原图，不提供插画切换。

顶部头像悬浮在白卡上沿，仍完整保留在组件范围内；名称下方以「@账号ID」显示当前房主的 B 站 UID。右侧「Followed」是参考样式的装饰，不读取或修改实际关注关系。

客户端和画布都可分别显示或隐藏「顶部资料区」「底部提示栏」「操作图标行」，隐藏后会把对应空间留给消息。隐藏底栏保留已有提示文字，再次显示时恢复。在「高级参数 → 礼物与 SC 配色」可调整低于 50 元、50～99.99 元、100～999.99 元、至少 1000 元四档底色及不透明度，礼物与 SC 共用，上舰保留身份配色。颜色会直接更新当前画面，不重播已有弹幕。默认全部显示并沿用视频配色；「恢复默认」只重置当前样式，修改后按原流程保存外观。

礼物原图缺失或加载失败时，空图位不占空间，赠送文字在色块内居中；有原图时，图片和文字整体居中。

「底部提示文字」默认为「欢迎来到直播间 ✨」，可在客户端参数、画布参数或独立预览中修改，最多 20 个可见字符，支持中文、英文、数字、符号和表情，组合表情也按一个字计数。过宽时自动换行，完整显示文案；留空或恢复默认参数可恢复默认文字。修改后按原流程「保存外观」，本机场景中的同款样式会更新，无需同步服务器样式。

预览的「适应窗口」会缩小整张画布，小字也会随之缩小。检查清晰度时按实际输出尺寸查看，并让 OBS 或哔哩哔哩直播姬网页源的宽高与 LIRA 画布一致。需要放大弹幕时，在 LIRA 内调整组件大小或字号，再保存外观，避免将较小的网页源直接拉大。

固定位置的「RIPPLOID」为普通聊天、礼物票券、NEW MEMBER 上舰卡和 SC 提供统一的分层动效，默认区域为 520×640，正文字号为 18–48px、默认 24px。普通聊天按「当前房间灯牌名称／等级 → UL 荣耀等级 → 当前房间大航海身份 → 昵称」排列，最多三枚徽标；大航海显示 CAPTAIN／ADMIRAL／GOVERNOR，分别对应舰长／提督／总督。三项均按真实数据独立显示，没有灯牌、荣耀等级或大航海身份时只隐藏对应徽标，全部缺失时只保留昵称；UL 使用荣耀等级，不借用其他用户等级。「聊天主色」选择默认时保留多色装饰，选择自定义时只统一普通聊天装饰，不改变事件卡颜色。

预览中的身份和等级为示例。正式直播画面的灯牌必须属于当前主播，大航海使用本房间身份；切换直播间后清空旧消息，新弹幕按新房间的数据展示。UL 是观众自身的荣耀等级，不随房间切换而换成其他等级。

「高级参数 → RIPPLOID 事件配色」提供 15 个独立颜色：普通礼物按单条已结算人民币总额、SC 按实际金额分别使用 `<50`、`50～<100`、`100～<500`、`500～<1000`、`1000～<2000`、`≥2000` 元六档；上舰按购买的舰长、提督、总督分三档。所有事件档默认均为橙色 `#F39749`，可分别调整。参数按 RIPPLOID 样式保存，恢复默认只重置当前样式；点击「保存外观」或画布的「保存并应用」后发布，独立预览的修改仅在预览中生效。

「白描」可在常规参数中单独设置「边框颜色」及其不透明度，用深色边框搭配浅色直播背景；正文色仍单独调整。「星语」也提供「持续动画」开关，关闭后保留所选图案，仅停止图案的循环动作。两项均按各自样式保存，恢复默认回到原白框或开启持续动画，修改后按原流程保存外观。

## 参数范围

「对白」在「高级参数 → 消息显示」提供“弹幕礼物卡片最低金额”，按每条礼物通知的人民币结算总额筛选（已含数量，包含上舰）。设为 0 显示全部；设为 10 时，低于 10 元的通知隐藏，恰好 10 元仍显示。可填 0–100000 元，最多两位小数；SC 不受此门槛影响。参数按该样式保存，需点击“保存外观”或画布的“保存并应用”。

像素为组件的逻辑像素，随组件缩放。白平衡为相对冷暖和色偏调整，不是相机的开尔文色温。

## 导入 CSS、HTML 和素材

已识别的 BLC、blivechat / YouTube CSS 使用对应的消息和文字节点；原生 CSS 沿用所选预设的结构。可以调整光影、文字描边、调色和变换。CSS 若隐藏或替换了目标节点、使用独立伪元素或强制覆盖属性，部分效果仍取决于作者结构，应在画布核对。导入图片/视频底图使用整体图案效果，文字描边只作用于 LIRA 渲染的文字，不能改变图片内已经画好的字。

完整 HTML 和外部网页继续在隔离框架内运行，只提供已验证可用的**整体外投影、外发光、矩形边框和旋转/倾斜**。不提供内部白平衡、Bloom、色阶、文字描边或内阴影：当前 Chromium 的 SVG 引用滤镜不能可靠作用于隔离网页内容，LIRA 也不访问它的内部结构。网页背景、内部样式和进房消息由原网页控制；若页面本身不透明，外发光会沿页面矩形而非内部文字产生。

## 机器人欢迎弹幕

「固定回复 → 进场欢迎」决定机器人是否向 B 站发送欢迎。「显示机器人欢迎弹幕」只决定这些消息是否同时出现在当前样式的弹幕姬画面中：欢迎已开启而显示关闭时，B 站聊天区仍有欢迎，弹幕姬隐藏；两者都开启时两处都显示；欢迎关闭时不会生成欢迎弹幕，显示开关没有额外作用。首次欢迎、用户定制、高荣耀欢迎、久别重逢和二次问候均遵守此规则。

显示开关默认开启，可手动关闭并保存；之前已保存为关闭的样式继续保持关闭。「恢复当前样式效果」会重新开启该样式的欢迎显示。

弹幕姬按服务器对实际欢迎回流的标记过滤，不按「欢迎」关键词或机器人昵称判断。观众手打的欢迎、其他机器人回复、礼物与 SC 沿用原规则；不再额外生成「某某进入了直播间」提示。配置仍沿用原来的逐样式显示开关值，切换后按原流程保存外观。需要配套服务器支持欢迎来源标记；旧服务器未标记的消息仍作为普通弹幕显示。预览中的欢迎只是模拟样例，不向 B 站发送。

两种直播软件使用同一套浏览器源；自动化验证使用 Chromium 和隔离的 Electron 编辑流程，不能替代 OBS / 哔哩哔哩直播姬中的实际推流检查。
