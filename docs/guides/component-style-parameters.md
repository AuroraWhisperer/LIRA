# 时钟与弹幕的逐样式外观效果

在画布选中组件，打开右侧「外观效果」。时钟、固定弹幕、区域随机弹幕、飘窗弹幕和横向滚动弹幕共用参数范围，但按具体样式显示可用选项，并明确效果作用于文字、卡片底板还是整体图案。

客户端「组件 → 弹幕姬」可从「最近使用」快捷选择，或打开「全部样式」，按显示方式、样式动效、节日限定与视觉风格组合筛选内置样式。「样式动效」包含分层入场、图层变化和装饰动画，只有整卡淡入或移动的样式归为「无」。「清除筛选」跟随顶部筛选条件，样式数量与「添加样式」导入入口固定在样式库底部；选卡后回到原参数区，仍需点击「保存外观」。

## 样式参数的保存与恢复

- 从「添加组件」新增的每一份组件独立保存样式选择、位置和尺寸。内置组件的公共外观参数与资源型样式参数按同一样式共享，保存后同步其他同样式组件及已发布画面；导入的 CSS 和普通图片/视频样式仍按实例保存。不同样式的参数分别保留，导入样式按各自 ID 记忆。
- 从默认组件的预览按钮打开时，该图层与默认组件共用设置；右侧会标明这种关联。
- 展开某项后勾选「调整…」才覆盖原样式。取消勾选恢复作者的该项效果；不透明度或宽度设为 0 则关闭对应自定义光影或轮廓。未调整的效果保持原样。
- 弹幕参数和「外观效果」的滑块在拖动时只更新读数，松开后更新预览；数值框在确认或离开输入框后生效，颜色在完成一次选色操作后生效。字体、颜色、透明度和光影调整直接作用于当前弹幕，不清空重播；分布参数用于后续新弹幕，已显示弹幕保持原位置。
- 「恢复当前样式效果」仅清空当前款式的新增效果及机器人欢迎显示开关，不清空其他款式，也不重置原有字体、字号和布局参数。固定弹幕的透视、旋转与倾斜位于独立的通用参数区，该按钮会保留它们；取消「调整旋转与倾斜」可还原这组设置。
- 最后点击画布的「保存并应用」，或客户端的「保存外观」。弹幕外观按 LIRA 账号保存在这台电脑，同款参数更新已发布的本地场景；位置、尺寸和样式选择由场景编辑器保存。

首次使用会读取已有服务器配置作为本机初始值，成功后只维护本地外观。保存失败时草稿保留，可重试；切换账号不会带入另一个账号的参数。直播软件请使用本地场景地址，并保持 LIRA 运行。旧服务器地址保留旧配置，不随这里的保存改变；换电脑也不会自动同步本机外观。

桌面设置、画布参数区和独立预览使用同一套参数控件；常用与高级均按当前样式记忆。客户端与已打开画布的同款参数共用草稿，任一处确认修改后，另一处的数值和画布预览同步更新；正在输入或拖动的未确认值会暂时保留。区域随机的「停留（秒）」每款分别保存，可填 2–30 秒；星尘 2.0 默认及恢复默认均为 12 秒，玻璃气泡为 5 秒，其余款为 6 秒，不改变其他款。其余款的旧配置会先沿用原停留时间，星尘 2.0 和玻璃气泡不承接旧共用时长。独立预览会在当前页面保留基础参数与外观效果，刷新后继续使用；它不会自动保存外观。

## 随机与飘窗的动效

「郁香海风」在「固定位置」，「郁香海风 · 随机」在「区域随机」。两版以宋体、彩色身份牌和文字倒影展示聊天、礼物、大航海与 SC，适合较深的直播背景。SC 的昵称、留言和金额按金额档位着色，倒影同步使用该颜色。默认正文 32px，可调 18–48px；昵称、身份牌和金额保持本款尺寸，整体大小在画布中缩放。固定款可选左／中／右对齐，默认居中；随机款默认覆盖全画布，也可在画布中缩小范围。若从已有固定组件切换为随机款，需要全屏散落时，在「位置与尺寸」中将 X/Y 设为 0，宽/高设为画布尺寸后保存。

随机款默认 800ms 分层渐显，身份牌、昵称与正文依次出现；可选通用入场和退场方式，停留默认 6 秒。两版参数分别记忆，点击「保存外观」或画布「保存并应用」后，通过本机场景地址输出。默认思源宋体由软件字体库首次联网补齐，之后复用本地缓存；SC 下线后只撤下对应留言。

两版在「高级参数 → 海风倒影」分别调整倒影强度、长度和距离；强度或长度设为 0 可关闭倒影。调整会更新当前消息，正文和身份牌不会一起变淡；固定款与随机款各自保留设置。

基础外观下面分别提供「随机弹幕通用参数」和「飘窗弹幕通用参数」。通用表示复用这些控制项，设置仍按小样式分别保存。

- 随机弹幕：设置停留、中心倾向和离散程度；退场可选渐隐或直接消失，渐隐时长 100–1000ms，星尘 2.0 默认 1000ms，其余款默认 400ms。停留包含入场和退场，调整只影响后续消息。
- 一纸素笺、青雾、杏花白、白描、流光溢彩、点点流萤、郁香海风随机共用「样式渐显／上浮弹入／直接显示」及 100–1000ms 入场时长。漫画的入场在「高级参数 → 漫画造型与入场」单独调整。
- 飘窗弹幕：速度、分散与边缘显隐统一调整；可选两端、入场端、离场端渐隐或直接切断。柔化宽度 4–80px，每侧最多占区域宽度 4%；完整卡片与光尾移出后清理。极光和星轨默认双边柔化，另外两款默认直接切断。
- 极光、星轨的独立入场位于各自高级参数，均可选择直接显示。持续动画只控制吊饰、星芒、星尘等循环，与入场和移动独立。

关闭某项动效后，其时长或宽度控件停用，但已保存的数值保留。修改和保存动效参数不会清空、重播当前消息。

## 玻璃气泡

在「组件 → 弹幕姬 → 全部样式 → 区域随机」选择「玻璃气泡」。默认铺满画布，以带银色高光的烟灰玻璃、深色昵称牌和柔化的居中尾尖展示消息；彩边与金额使用协调的柔和色系，在亮背景上也能辨认。气泡先横向展开，昵称与逐字显现自然衔接，普通长文会加快显示以赶在退场前呈现全文，SC 增加一次柔和扫光。正文默认 27px、可调 18–48px，昵称保持 21px；默认使用 M PLUS Rounded 1c，中文缺字回退到本机中文字体。

可调整字体、正文颜色、玻璃填色不透明度、位置分布和退场方式。普通消息默认停留 5 秒；礼物、上舰及 SC 比当前设置多 3 秒，默认 8 秒，均包含入场与退场。减少动态效果时直接完整显示。SC 保留实际金额与完整原文，按人民币数值使用蓝、青、绿、黄、橙、洋红、红七档，支持随 B 站下线撤下。点击「保存外观」或画布「保存并应用」，通过本机场景地址用于 OBS 或哔哩哔哩直播姬，保持 LIRA 运行。较旧浏览器内核可能显示圆角框而省略尾尖；玻璃不能模糊直播软件中的其他来源。

「高级参数 → 玻璃与显字」可选择逐字显现或整句显示，调整显字间隔、SC 扫光和玻璃高光。间隔越小显字越快，长文仍会自动加速以在退场前显示全文；整句显示保留气泡展开。显字方式和间隔只影响新消息，扫光与高光可更新当前消息。选择整句显示后，显字间隔控件停用并保留原值。

## 散落小窗

在常规参数区可直接显示或隐藏「大航海图标」和「粉丝牌」，两项默认开启。有本房间大航海身份时，昵称右侧显示对应的舰长／提督／总督图标；其右侧用圆角小牌显示本房间粉丝牌名称和等级，沿用粉丝牌颜色。没有对应身份时隐藏，不重复显示原有文字身份。

默认小窗宽度为 380px，昵称最多两行，图标和粉丝牌始终与昵称垂直居中；异常长名超出两行时省略，留言仍完整换行。两个开关可直接更新当前消息，点击「保存外观」或画布「保存并应用」后同步本机场景。

## 星尘 2.0

在「组件 → 弹幕姬 → 全部样式 → 区域随机」选择「星尘 2.0」。默认铺满 1920×1080 画布，以透明底、上方星芒、居中正文和下方昵称展示聊天、礼物、上舰与 SC。正文默认宋体 28px、可调 18–48px；礼物、上舰及 SC 正文大 2px，昵称保持 16px。SC 保留完整留言与实际金额，支持随 B 站下线通知撤下。

「外观效果」中的外投影、外发光和文字描边作用于正文、昵称及事件／金额标签；调色、旋转与倾斜复用公共参数。背景较亮时可按需添加深色文字描边，再保存外观；取消对应的「调整」或使用「恢复当前样式效果」可还原附加效果。

「高级参数 → 星尘 · 画面与互动」可关闭「汇聚与点亮」直接显示新消息，或关闭「为主播留白」让普通消息使用中央区域；区域过窄时按可用空间排布。「观众昵称」可显示或隐藏。「大额礼物门槛」为 0.01–1,000,000 元、默认 0.01 元，单条已结算总额达到门槛的礼物居顶，金额未知的礼物仍散落；上舰默认居底，可用「礼物与上舰上下对调」交换位置。

默认汇聚入场约 1.4 秒，停留 12 秒并包含最后 1000ms 渐隐。关闭「持续动画」只停止星芒与轨道循环；系统减少动态效果会省略入场并停止循环。位置、锚点和时长调整用于新消息，昵称显隐可更新当前消息；恢复默认只影响本款。按前述流程保存后使用本机场景，OBS 和哔哩哔哩直播姬共用该画面，直播时保持 LIRA 运行。

## 星轨飞语

在「组件 → 弹幕姬 → 全部样式 → 飘窗弹幕」选择「星轨飞语」，或在画布添加弹幕姬后选择本款。透明画面中，四角星、昵称和正文从右向左匀速移动，细光尾跟随；正文与表情保持稳定。默认正文 28px，可调 18–44px；字体、正文颜色、飘动速度和分散程度沿用常规参数。

展开「高级参数 → 星芒与光尾」：星芒颜色同时控制星芒、光尾和星尘的颜色与不透明度；星芒大小 12–40px（默认 24）、光尾长度 0–360px（默认 180，0 隐藏）、辉光强度 0–100%（默认 45%）、星尘开启／关闭（默认开启，光尾为 0 时一并隐藏）、入场方式（星芒点亮／直接显示）、入场时长 250–1200ms（默认 680，建议 450–800，调整后用于新消息）。辉光只作用于星芒和光尾；入场先在可视范围点亮星芒，再渐显昵称与正文，不改变移动速度。进入与离开画面边缘时自然柔化，完整光尾移出后清理，无需另设消失时长。「持续动画」关闭后停用星芒和星尘的呼吸动作，仍保留新消息入场与横向移动。

字体、正文字号／颜色、飘动速度、分散程度与持续动画是多款复用的公共控件，保存值仍按具体样式独立记忆。星芒颜色／大小、光尾长度、辉光、星尘与入场方式／时长是本款独立参数；边缘柔化在飘窗通用参数中调整。

普通弹幕与礼物共用轻量文字造型，礼物／大航海图片放在昵称前，与昵称文字同高，第二行保留动作、礼物名和数量；没有图片或图片加载失败时不显示图标。昵称按消息中的大航海身份分色：普通观众／粉丝牌为中性浅灰，舰长蓝、提督紫、总督红，沿用共享的 B 站大航海默认配色，不随星芒颜色改变。与其他飘窗一致，本款不显示 SC。点击「保存外观」或画布「保存并应用」后，同款参数更新本地场景；「恢复默认」只重置当前款。光尾完整离开画面后才移除消息。

## 暗月

在「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布「添加组件 → 弹幕姬」选择「暗月」。默认普通观众为紫灰细框，本房间的舰长、提督、总督使用金边与月环；其他房间的大航海身份不影响配色。礼物与上舰使用金色提醒条，SC 在提醒条下保留完整留言，数量和金额均来自实际事件。

默认区域 480×700、正文 24px，可调 18–40px；支持字体、正文色、背景不透明度、滚动方向和边缘处理。礼物和上舰文字按本款比例跟随字号，提醒昵称也使用所选字体。「高级参数」可为整组构图设置轮廓、投影、辉光和颜色效果，文字描边同时覆盖昵称、正文及金额。默认边缘直接切断，直播背景保持透明。关闭「持续动画」会停止星芒、星点及小轨道，保留新消息的分层入场；系统减少动态效果则直接显示完整卡片。点击「保存外观」或画布「保存并应用」，通过本机场景地址用于 OBS 或哔哩哔哩直播姬，直播时保持客户端运行。

「高级参数 → 月环与星芒」提供原作紫金、月白银紫、冰蓝星夜三套配色，可调月环大小并显示或隐藏边角星芒。配色和装饰直接更新当前消息，正文颜色继续单独设置；月环大小不会缩放文字，也不改变真实身份。

## Animated Gradient 渐变气泡

在「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布的固定弹幕中选择「渐变气泡」。渐变昵称牌错位叠在白色圆角气泡上，下方细线延后展开；礼物与上舰使用白色双框和从右侧显现的渐变标签，醒目留言保留实际金额和完整原文。

默认区域 480×700、正文 19px，可调 16–40px；支持字体、正文色、白底不透明度、滚动方向与边缘处理，默认直接切断。事件条的姓名、金额和标签按本款比例跟随字号；窄区域会把事件标签移到下一行，金额保持完整同一行。消息持续保留，直到被新消息推到区域外；关闭「持续动画」只停止颜色流转，系统减少动态效果时完整静态显示。点击「保存外观」或画布「保存并应用」，再使用本机场景浏览器源；OBS 和哔哩哔哩直播姬均需保持 LIRA 运行。

在「高级参数 → 渐变与昵称牌」切换原作流彩、落日暖霞、海盐青蓝或薰衣草紫，调整颜色流转周期，或隐藏下划线。周期越大流转越慢，不影响消息保留；关闭「持续动画」后周期控件停用并保留原值。配色和显隐直接更新当前消息，不重播入场。

## Glass 玻璃通知

在客户端「组件 → 弹幕姬 → 全部样式 → 固定位置」或画布的固定弹幕中选择「Glass 玻璃通知」。淡蓝玻璃卡片默认从顶部接收新消息，旧卡向下让位，新卡随后缓缓显现。普通弹幕使用上下两行，礼物左侧显示对应图片的静态首帧，大航海显示对应等级的 B 站 WebP 舰徽，均保留竖分隔线；SC 保留金额线条图标和完整留言。真实图片自动显示，无需切换参数；普通礼物图片缺失或加载失败时显示占位图，礼物名称、数量和金额仍保留。

默认区域 480×700、正文字号 22px（可调 16–40px），可调整字体、正文色、背景色、背景不透明度、滚动方向、边缘处理和持续动画。背景不透明度默认 20%，使用默认背景色时调到 100% 为实色；关闭持续动画会隐藏星点，仍保留新消息入场。昵称、时间和图标随组件整体缩放。点击「保存外观」或画布「保存并应用」后，本机场景使用相同设置；恢复默认只重置本款。

透明卡片适用于 OBS 与哔哩哔哩直播姬；玻璃效果保留底层画面颜色，网页无法模糊直播软件中的其他来源。

在「外观效果」中可调整卡片轮廓、投影、内阴影、内外发光，以及文字描边和调色；透视、旋转与倾斜在「高级参数 → 固定弹幕通用参数」中单独调整。卡片效果作用于玻璃底板，文字描边也覆盖时间与 SC 金额；旋转在新消息入场期间持续生效。背景较亮时可添加深色文字描边，再按正常流程保存；「恢复当前样式效果」可还原附加光影和调色，保留通用参数中的变换。

默认区域 640×720，基准字号 20px、可调 12–48px，聊天正文略大于基准；可以设置字体、正文色、底色透明度、滚动方向及边缘处理。「高级参数 → Astral · 星笺」可调整星芒颜色及透明度，或将「描框与星芒点亮」切换为「直接显示」。关闭「持续动画」只停止星芒闪烁，系统减少动态效果时直接完整显示。点击「保存外观」或画布「保存并应用」后，由本机组件／场景地址输出到 OBS 或哔哩哔哩直播姬，保持 LIRA 运行。

## 哪些样式显示哪些参数

白平衡、亮部辉光、色阶、旋转与倾斜作用于内置组件整体；文字描边作用于文字节点。下面列出光影和轮廓的差别，括号内为样式标识，便于素材作者对应。

固定弹幕在「高级参数 → 固定弹幕通用参数 → 旋转与倾斜」开启调整，Glowy 和 Stargazer 切成横排后仍使用此入口；其他弹幕、时钟及网页源沿用「外观效果 → 调色与变形 → 旋转与倾斜」。固定款的外观效果仅保留光影和调色，其中高级分组显示为「调色与辉光」，恢复效果会保留独立的变换设置。

「左右透视」默认 0，为正面；正数让左侧靠近、右侧远离，负数反过来。它产生近大远小的立体效果，不附加平面旋转。可用滑块或输入 −80°–80°。透视距离默认 1000px，可调 400–4000px；距离越小，近大远小越明显。原有平面旋转和其他角度仍可独立调整；若之前保存过旧侧倾预设，将「平面旋转」归零即可去掉原先附带的 2° 斜放。各款分别记忆参数，已有入场、飘动和翻页继续使用。

原有专属参数继续保留：固定弹幕的滚动方向与边缘处理、随机弹幕的停留时间与位置分布、飘窗速度，以及翻牌颜色、月轮明暗切换等。它们不能用一套通用光影参数替代。

固定弹幕在常规参数中选择“边缘处理”：两端渐隐让上下边缘逐渐透明；上边渐隐或下边渐隐只处理选定边缘，不随滚动方向改变；直接切断在边缘裁掉内容。流霞默认两端渐隐，仿推特 3.0、幽灵便笺、花与信笺和手账风默认直接切断，其他固定样式默认在移出端渐隐，并显示具体的上边或下边。选项按样式保存，“恢复默认参数”恢复该样式的默认值，最后点击“保存并应用”。

「琉璃」、「杏花白」、「灵动弹幕」、「留白」、「一纸素笺」和「仿推特 3.0」的礼物通知固定显示对应真实礼物图片，不提供插画切换；预览使用内置 WebP，正式直播使用该礼物随消息携带的原图。缺图或加载失败时图位留空，仍显示礼物名称与数量，不再回退为礼章或星星。「灵动弹幕」礼物右侧显示本次已结算总额，不重复乘数量；新建默认显示区域为 640×616，已保存的区域（包括原 640×560）保持不变。

「青雾」位于「区域随机」，默认铺满画布。普通弹幕为透明白框，本直播间大航海弹幕为浅青卡片；礼物、大航海感谢与 SC 也在区域内随机出现，均使用 2–30 秒停留时间，SC 可随 B 站下线通知撤下。背景透明度调整浅青底板，文字保持不透明；可继续设置字体、18–40 字号、正文色及位置分布。

「漫画对白」也在「区域随机」中选择，以纸白、墨线和淡网点展示聊天、礼物、上舰与 SC，默认铺满画布，正文字号默认 26px、范围 18–42px。在「高级参数 → 漫画造型与入场」可调整以下六项；礼物与 SC 保留横排，分别使用旁白框和爆炸框。入场完成后文字保持稳定，系统减少动态效果时直接显示完整消息。

阅读方向、墨线和网点可直接更新当前预览；气泡造型与入场设置用于后续消息。同一条消息在混排下保持相同造型。勾线入场先显现纸面，再带出文字；正常消失沿用随机弹幕统一的约 400ms 原位渐隐，没有额外退场滑块。停留时间为 2–30 秒、默认 6 秒，包含入场和渐隐，按每款分别保存；默认组合可完整稳定显示约 5.3 秒。短句可以缩短停留，长留言建议 8–12 秒，尤其配合 600–800ms 的慢入场时。公共背景不透明度调整纸面和网点，不淡化文字。点击「保存外观」或画布的「保存并应用」后使用本机场景地址，保持 LIRA 运行；「恢复默认」只重置当前样式。

「星语」可在「组件 → 弹幕姬」的样式参数、画布参数区或独立预览中选择「装饰图案」：四角星、爱心、圆角方块、五角星、小花、月牙、蝴蝶结。选择后自动播放该图案的轻动画：四角星闪烁、爱心轻跳、方块轻弹、五角星缓转、小花呼吸、月牙摇曳、蝴蝶结轻摆。普通弹幕、礼物和 SC 的装饰会一起切换，文字和排版保持原样；恢复默认回到四角星。系统开启减少动态效果时图案静止显示。点击「保存外观」或画布的「保存并应用」后发布到直播画面，独立预览的修改仅在预览中生效。

「白描」、「流光溢彩」和「点点流萤」可在客户端「组件 → 弹幕姬」的样式参数或画布参数区选择「入场动画」。「动画 1 · 渐显」为默认效果；「动画 2 · 上浮弹入」让卡片和昵称上浮，整段正文从左侧滑入并轻微回弹，两部分同时在 0.5 秒内完成。选择按样式保存，恢复默认回到动画 1；修改只影响新消息，不重播已有消息，也不改变停留时间和随机位置。系统启用减少动态效果时直接显示完整消息。点击「保存外观」或画布的「保存并应用」后，选择才会发布到直播画面。

固定位置的「仿推特 3.0」以白色社交面板展示普通聊天、礼物、大航海和 SC，默认区域为 480×700，正文字号为 18–40px、默认 22px，边缘默认直接切断。顶部显示当前配置直播间的房主头像、名称和 UID；评论、转发、爱心和分享为高清装饰图标，不代表真实互动数据。本房间舰长／提督／总督的对勾分别为蓝／紫／红，大航海购买等级与当前身份分别读取。礼物与 SC 使用通栏色块，上舰使用阶梯箭头卡片。表情完整显示，宽图按比例适配，多张表情可换行，帖子随内容增长。预览使用合成房主和消息，正式直播资料来自当前房间；礼物固定使用原图，不提供插画切换。

顶部头像悬浮在白卡上沿，仍完整保留在组件范围内；名称下方以「@账号ID」显示当前房主的 B 站 UID。右侧「Followed」是参考样式的装饰，不读取或修改实际关注关系。

客户端和画布都可分别显示或隐藏「顶部资料区」「底部提示栏」「操作图标行」，隐藏后会把对应空间留给消息。隐藏底栏保留已有提示文字，再次显示时恢复。在「高级参数 → 礼物与 SC 配色」可调整低于 50 元、50～99.99 元、100～999.99 元、至少 1000 元四档底色及不透明度，礼物与 SC 共用，上舰保留身份配色。颜色会直接更新当前画面，不重播已有弹幕。默认全部显示并沿用视频配色；「恢复默认」只重置当前样式，修改后按原流程保存外观。

礼物原图缺失或加载失败时，空图位不占空间，赠送文字在色块内居中；有原图时，图片和文字整体居中。

「底部提示文字」默认为「欢迎来到直播间 ✨」，可在客户端参数、画布参数或独立预览中修改，最多 20 个可见字符，支持中文、英文、数字、符号和表情，组合表情也按一个字计数。过宽时自动换行，完整显示文案；留空或恢复默认参数可恢复默认文字。修改后按原流程「保存外观」，本机场景中的同款样式会更新，无需同步服务器样式。

预览的「适应窗口」会缩小整张画布，小字也会随之缩小。检查清晰度时按实际输出尺寸查看，并让 OBS 或哔哩哔哩直播姬网页源的宽高与 LIRA 画布一致。需要放大弹幕时，在 LIRA 内调整组件大小或字号，再保存外观，避免将较小的网页源直接拉大。

固定位置的「RIPPLOID」为普通聊天、礼物票券、NEW MEMBER 上舰卡和 SC 提供统一的分层动效，默认区域为 480×700，正文字号为 18–48px、默认 24px。普通聊天按「当前房间灯牌名称／等级 → UL 荣耀等级 → 当前房间大航海身份 → 昵称」排列，最多三枚徽标；大航海显示 CAPTAIN／ADMIRAL／GOVERNOR，分别对应舰长／提督／总督。三项均按真实数据独立显示，没有灯牌、荣耀等级或大航海身份时只隐藏对应徽标，全部缺失时只保留昵称；UL 使用荣耀等级，不借用其他用户等级。「聊天主色」选择默认时保留多色装饰，选择自定义时只统一普通聊天装饰，不改变事件卡颜色。

预览中的身份和等级为示例。正式直播画面的灯牌必须属于当前主播，大航海使用本房间身份；切换直播间后清空旧消息，新弹幕按新房间的数据展示。UL 是观众自身的荣耀等级，不随房间切换而换成其他等级。

「参数调节 → RIPPLOID 事件配色」提供 15 个独立颜色，客户端和画布均直接展示，无需展开「高级参数」：普通礼物按单条已结算人民币总额、SC 按实际金额分别使用 `<50`、`50～<100`、`100～<500`、`500～<1000`、`1000～<2000`、`≥2000` 元六档；上舰按购买的舰长、提督、总督分三档。所有事件档默认均为橙色 `#F39749`，可分别调整。参数按 RIPPLOID 样式保存，恢复默认只重置当前样式；点击「保存外观」或画布的「保存并应用」后发布，独立预览的修改仅在预览中生效。

「白描」可在常规参数中单独设置「边框颜色」及其不透明度，用深色边框搭配浅色直播背景；正文色仍单独调整。「星语」也提供「持续动画」开关，关闭后保留所选图案，仅停止图案的循环动作。两项均按各自样式保存，恢复默认回到原白框或开启持续动画，修改后按原流程保存外观。

## 参数范围

「对白」在「高级参数 → 消息显示」提供“弹幕礼物卡片最低金额”，按每条礼物通知的人民币结算总额筛选（已含数量，包含上舰）。设为 0 显示全部；设为 10 时，低于 10 元的通知隐藏，恰好 10 元仍显示。可填 0–100000 元，最多两位小数；SC 不受此门槛影响。参数按该样式保存，需点击“保存外观”或画布的“保存并应用”。

像素为组件的逻辑像素，随组件缩放。白平衡为相对冷暖和色偏调整，不是相机的开尔文色温。

| 参数 | 范围 |
| --- | --- |
| 外投影 | 颜色、不透明度 0–100%；X/Y 偏移 −100–100 px；模糊 0–80 px |
| 内阴影 | 颜色、不透明度 0–100%；X/Y 偏移 −30–30 px；模糊 0–40 px |
| 外发光 / 内发光 | 颜色、不透明度 0–100%；半径分别 0–80 / 0–40 px |
| 轮廓 / 文字描边 | 颜色、不透明度 0–100%；宽度分别 0–16 / 0–8 px |
| 白平衡 | 色温 −100–100；色调 −100–100 |
| 亮部辉光（Bloom） | 强度 0–100%；半径 0–80 px；亮度阈值 0–100% |
| 色阶 | 输入/输出黑场 0–254、白场 1–255，各自必须黑场小于白场；中间调 0.1–3 |
| 左右透视 | −80°–80°，默认 0；正数左近右远，负数左远右近 |
| 旋转 | X −80°–80°；平面旋转（Z）−180°–180° |
| 倾斜 | X/Y −45°–45° |
| 透视距离 | 400–4000px，默认 1000px；与旋转一起使用 |
| 显示机器人欢迎弹幕 | 仅弹幕，默认开启，可手动关闭；控制机器人入场欢迎在弹幕姬中是否显示，随当前样式参数保存；共享与实例范围同上 |

外发光沿形状边缘生成；亮部辉光按画面亮度阈值提取亮部后扩散。二者效果不同，可以单独调整。色阶与白平衡保持透明背景。较大的辉光、模糊和三维变换会增加绘制开销，实际流畅度取决于直播软件与显卡。

## 导入 CSS、HTML 和素材

已识别的 BLC、blivechat / YouTube CSS 使用对应的消息和文字节点；原生 CSS 沿用所选预设的结构。可以调整光影、文字描边、调色和变换。CSS 若隐藏或替换了目标节点、使用独立伪元素或强制覆盖属性，部分效果仍取决于作者结构，应在画布核对。导入图片/视频底图使用整体图案效果，文字描边只作用于 LIRA 渲染的文字，不能改变图片内已经画好的字。

完整 HTML 和外部网页继续在隔离框架内运行，只提供已验证可用的**整体外投影、外发光、矩形边框和旋转/倾斜**。不提供内部白平衡、Bloom、色阶、文字描边或内阴影：当前 Chromium 的 SVG 引用滤镜不能可靠作用于隔离网页内容，LIRA 也不访问它的内部结构。网页背景、内部样式和进房消息由原网页控制；若页面本身不透明，外发光会沿页面矩形而非内部文字产生。

## 机器人欢迎弹幕

「固定回复 → 进场欢迎」决定机器人是否向 B 站发送欢迎。「显示机器人欢迎弹幕」只决定这些消息是否同时出现在当前样式的弹幕姬画面中：欢迎已开启而显示关闭时，B 站聊天区仍有欢迎，弹幕姬隐藏；两者都开启时两处都显示；欢迎关闭时不会生成欢迎弹幕，显示开关没有额外作用。首次欢迎、用户定制、高荣耀欢迎、久别重逢和二次问候均遵守此规则。

显示开关默认开启，可手动关闭并保存；之前已保存为关闭的样式继续保持关闭。「恢复当前样式效果」会重新开启该样式的欢迎显示。
