# 固定弹幕动效

本页维护客户端内置固定弹幕及共用有序 feed 的横向弹幕的动效职责、逐款设计与作者约束。适用于本地预览及使用同一 feed 的客户端组件；OBS 和哔哩哔哩直播姬均属于浏览器源消费场景。服务器有独立的 feed 与发布流程，本页不表示服务器实现已同步。消息结构和其他展示行为见 [overlays.md](overlays.md)。

## 设计目标

观众应先读懂弹幕，再感受到样式。新消息出现自然，已在阅读的消息平稳让位，动画结束后画面安静。动效表达样式的材质和节奏，不靠大幅跳动、文字缩放或每条消息的复杂表演制造区别。

「各样式独立」指各样式拥有自己的视觉决策：入场方式、时长、缓动及装饰编排。「公共」指位置计算和执行机制只有一份：排序、高度测量、目标位置、同批移动同步、打断续接、越界淘汰、减少动态效果和销毁。不能为了某款效果在公共 feed 内增加样式名称分支，也不能为每款复制列表控制器。

## 逐款设计

滑动时长为「基准 + 本次最大位移的 CSS 像素数」毫秒，不超过上限。同一批新旧消息共用本款时长和曲线；上下方向沿用用户设置。入场与列表移动同时开始，不排队等待。表内横移独立于纵向列表移动，不改变最终排版；入场时长记录各款默认值，已开放的独立参数见对应样式说明。

## Glowy 流光玻璃动效

参照 [Glowy 公开演示](https://www.etsy.com/listing/4391673194/glowy-chat-widget-horizontal-and) 的暗色玻璃、边光与层次节奏：材质层在 460ms 内揭开；头像延迟 90ms、昵称延迟 140ms、正文延迟 220ms、舰徽与事件图标延迟 370ms 分别淡入，最后一层在 670ms 完成，根入场标记于 760ms 清理。根节点只保留公共 `--component-transform`，材质裁切和子层透明度不覆盖用户透视，也不缩放或模糊文字。

横／竖排共用有序 feed 的同步让位、打断续接、边缘淘汰与销毁。上舰完成入场后仅舰徽以 5 秒周期轻微明暗变化；关闭「持续动画」停止该循环，保留新消息分层入场和正常移动。系统减少动态效果时直接显示完整内容。样式不增加独立计时器、订阅、消息队列或 JS 动画循环。

## Animated Gradient 渐变气泡动效

依据 [GhostTypeStudios 公开演示](https://www.etsy.com/listing/1365125747/animated-gradient-chat-widget)的 1280×1010、30fps、15 秒预览比对。聊天约 180ms 后开始显现，白底与错位昵称牌共同在 480ms 内由下方 8px 回到终态；底部细线自 330ms 起在 650ms 内由左向右展开。根入场标记 1100ms 完成。事件条先显现白色双框与姓名／金额，右侧渐变签在 1100ms 后从右方 25px 显现，500ms 完成；根标记 1650ms 结束。文字不缩放或模糊。

昵称牌与事件签默认以 10 秒往返流转青绿、蓝、紫、粉配色，每半程使用 `ease-in-out` 缓进缓出，折返时先减速再改变方向；按事件已过时间接续色相。「渐变与昵称牌」可改变配色和流转周期，也可隐藏细线；字段范围与默认值见[样式参数合同](overlays.md#animated-gradient-渐变气泡固定弹幕)。周期经 `--gradient-cycle` 调整，改变周期不重建节点、不重播入场。白色昵称与事件签文字带轻量紫灰阴影，帮助辨认浅色渐变上的字形；关闭持续动画后采用静态渐变，入场与列表仍正常。旧消息让位使用公共 feed，基准 280ms、上限 450ms，曲线 `cubic-bezier(.22,1,.36,1)`；控制点不超出进度上限，避免密集消息重测与中断时出现不同的续接速度。消息不定时淡出，历史快照与新消息均保留至滚出区域，由公共 feed 统一淘汰，样式不另建队列或计时器。

系统减少动态效果时各层直接完整显示，颜色停止流转。`gradient-body` 的内部入场不写根节点位置或用户旋转；事件条姓名／金额按正文的 17/19、事件签按 13/19 跟随字号，聊天昵称牌保持原尺寸。窄区域允许昵称折行，事件签空间不足时换到下一行，金额保持完整同一行，正文与表情保持用户所选尺寸。公开视频用于比对可见布局与时间，不能证明原字体文件或作者源代码。

## Neon Glass 霓光玻璃动效

玻璃胶囊与文字分层显现：空底板在 480ms 内从 0.94 倍横向宽度淡入，文字在前 20% 等待后从下方 3px 轻显，缓动均为 `cubic-bezier(.16,1,.3,1)`。只缩放空底板，文字不缩放或模糊；根节点的 `neonGlassEntry` 仅作为公共入场时钟，不覆盖用户旋转与透视。可选 200–1000ms 或直接显示，已有消息修改外观不重播。

横向 feed 的移动基准 360ms、上限 650ms，曲线 `cubic-bezier(.22,.61,.36,1)`；同批新旧消息续接同一偏移，超宽后两端柔和切入／移出，空闲时静止。卡片换行及超高适配沿公共测量，事件保留完整内容。系统减少动态效果直接显示完整文字和玻璃，停止列表动画；无持续装饰循环、新计时器或订阅。原作参考与字段见[Neon Glass](overlays.md#neon-glass-霓光玻璃横向弹幕)。

## 天穹横栏动效

参照 [Celestial Horizontal Chat](https://meldstudio.co/gallery/celestial-horizontal-chat/) 的实际公开组件：LIRA 默认 80px 横栏内，新消息由右侧 30px 在 500ms 内渐显，曲线 `cubic-bezier(.23,1,.32,1)`；超宽后将消息流平滑推向左侧，空闲时文字保持静止。LIRA 复用公共水平 feed，移动基准 300ms、上限 550ms、曲线 `cubic-bezier(.25,.1,.25,1)`；同批新旧消息和密集追加续接同一偏移，不把整条消息宽度叠加入场位移。原款浏览器原生 smooth scroll 的时长取决于运行环境，LIRA 的移动时长由公共 feed 明确定义。

本款 `--danmaku-enter-offset: 0` 使第一条消息只播放内层入场；超宽及打断续接时，新消息仍跟随前条的移动偏移。昵称、正文和星形不在入场时缩放。文字流左右两端各以最多 24px、且不超过区域宽度 4% 的遮罩柔和显隐，背景和金色边线保持完整。

星云保留 20 秒往返节奏和原渐变，用 200% 宽背景层的 `translateX(0 → -50% → 0)` 代替逐帧改变背景位置，避免空闲期间反复重绘。默认星点以 2–5 秒周期明暗呼吸，按序各错开 0.37 秒负延迟，进入画面即处于不同相位；「星云与星标」通过 CSS 调整浓度、可见星点、星标和分隔线，默认星点保留原来的位置，数量及字段合同见[天穹横栏](overlays.md#天穹横栏消息流)。调整不替换背景节点和消息。关闭持续动画保留新消息入场与横移，系统减少动态效果则直接显示完整消息并停止所有循环及列表动画。样式切换移除独立背景节点，公共 feed 销毁释放消息动画和监听。

## Charm 轻语横栏动效

依据 [Horizontal Charm 公开演示](https://www.etsy.com/listing/1656260287/horizontal-charm-chat-widget)的横向昵称签与气泡构图。小标在 480ms 内出现，昵称签在 550ms 内由右侧 12px 渐显，正文气泡在 650ms 内由右侧 24px 展开并显现，曲线为 `cubic-bezier(.16,1,.3,1)`。气泡使用裁切而非字形缩放，普通正文、事件文字与表情保持清晰；入场会组合公共旋转与透视。

公共水平 feed 的移动基准为 350ms、上限 650ms，曲线 `cubic-bezier(.23,1,.32,1)`；超宽后向左让位，空闲保持静止。根入场偏移为 0，不叠加整张卡片宽度。密集追加的中断位移按 feed 视口缩放与消息 zoom 换算，不使用取整后的卡片宽度比值，避免小数宽度或公共旋转累积跳位。两端各以最多 20px、且不超过横栏宽度 3% 的遮罩柔化。系统减少动态效果时直接显示内容；消息删除、清空与样式销毁均沿用公共 feed，不增加循环计时器。

## 线框星事参考与分层动效

参考为[线框星事公开视频](https://www.bilibili.com/video/BV1Uw8v6XENM/)（1920×1080、30fps）：18–24 秒展示三档上舰，25–29 秒展示礼物及 SC，29–37 秒展示各档聊天与长文，39–43 秒再次展示上舰。视频中的棋盘格和直播背景属于演示画面。清晰段以正文为 1em：聊天头像约 1.9em，昵称约 0.8em，头像与正文框间约 0.425em；上舰头像、横线与昵称各占独立层。

实现按实时 `data-live-entry` 编排，以下为默认时序：头像 0–360ms 淡入，圈线 0–600ms 收拢，边框和底色 100–580ms 揭开，昵称 180–480ms、正文 300–630ms 原位显现。上舰头像延长至 500ms，两侧线条 180–780ms 从中心伸出，昵称 400–700ms，舰徽和档位 500–850ms，欢迎语 650–980ms；根标记在 1100ms 完成。「圈线与描框」可选择直接显示或按所选时长等比调整各层，创建消息时锁定选择与比例，已有消息不因改参重播；完整字段见[线框星事](overlays.md#线框星事固定弹幕)。快照直接显示终态，无持续装饰循环；原头像、表情和文字不随圈线缩放或旋转。

位置测量、同批移动、打断续接及越界清理均沿用公共 feed，层动画不写根节点 `top`／`transform`。用户底色透明度写入背景颜色的 alpha，入场仅控制图层显隐，因此底色在动画过程中也遵守所选透明度。减少动态效果关闭全部层动画并直接显示完整内容。公开压缩视频可用于比较布局和编排，不能证明原作者字体文件、源代码或逐像素相等。

## Astral 星笺分层动效

[Astral 公开演示](https://www.etsy.com/listing/1692766782/astral-chat-widget-customizable-colors)中的细框、嵌边昵称、悬垂星芒和提醒框由本款 CSS 分层编排。边框 0–600ms 从左揭开；昵称 150–500ms、正文 300–700ms 原位显现；悬线 550–1000ms 落下，侧星、圆点及身份牌 650–1000ms 点亮，根标记在 1050ms 清理。列表同步让位 600ms，曲线 `[.22,1,.36,1]`；共享 feed 继续拥有密集到达时的打断、续接、排序及越界清理。上述数值是公开视频的本地拟合，不是原作者源码参数。

静态恢复直接显示终态。「直接显示」关闭本款层动画，仍保留正常移动；根节点通过 1ms 恒定显隐动画完成共享入场标记清理，重新开启分层时旧消息不会重播。关闭持续动画停止星芒 4.8 秒的明暗循环，保留入场。星芒循环作用于 SVG 路径，入场作用于外层，不互相覆盖。系统减少动态效果时关闭所有层动画和循环。公共三维变换与列表移动组合，正文不单独缩放或旋转；切换样式与销毁沿现有 feed 和效果控制器清理，不添加本款计时器。

## 暗月参考与分层动效

参考为作者的 [Dark Moon 2.0 演示](https://www.youtube.com/watch?v=p4WeWbdh9K0)及其 [Etsy 公开预览](https://www.etsy.com/listing/1309840773/dark-moon-chat-widget-minimal-starry)。后者为 1150×814、60fps、15 秒；普通消息约 0.25s 开始，0.40–0.50s 展开正文和底边星芒，0.70s 补齐细线；提醒卡约 3.82s 从中间展开，4.15s 图标出现，4.45s 标题显现。视频内的紫色背景属于宣传画面。

实现的普通消息依次为图标 0–420ms、昵称 50–270ms、底板 120–420ms、正文 170–410ms、底边 300–500ms、细线 420–660ms，根标记 800ms 完成；提醒底板和月相 0–500ms 从中间揭开，图标 300–720ms、书签 500–800ms、文字 600–830ms。SC 正文底板在 500–800ms 揭开，正文自 650ms 显现，底边星芒在 800–1000ms 补齐；该规则优先于共用提醒条的中心展开，根标记 1100ms 完成。原片的文字弹性改用固定字形的裁剪和透明度，以保持缩放画布中的文字稳定；不声明原字体或逐像素相等。

持续动画仅改变装饰：星芒 3.8s 闪烁、星点 4.6s 明暗、提醒卡轨道 5.2s 轻浮。`ambientMotion=off` 停止循环但不影响入场与列表；减少动态效果停止全部内部动画并呈现稳定终态。样式适配器不新增计时器或事件监听，feed 继续拥有打断、越界移除和销毁。

## RIPPLOID 分层动效

RIPPLOID 的普通聊天、普通礼物、购买大航海和 SC 共用细线、票券与可配置强调色，但分别拥有内部时间轴。聊天在 700ms 内擦除揭示正文，再让当前房间灯牌、UL 荣耀等级和大航海徽标依次显现，随后让昵称、细线和箭头分层落位；左侧竖线随正文实际高度延伸，箭头始终锚定灯牌所在行。系统与进房提示使用独立的紧凑横条，600ms 内先由强调色向昵称色展开，再淡出色层、显现原文，不重复显示聊天身份栏。礼物在 2000ms 内展开 GIFT 名称框、价格与签名票券，名称由强调色条带揭示，细框和框外双箭头短促闪烁，金额单位经过短暂字符切换后显示 RMB，橙色转场层自身持续 600ms；上舰在 1600ms 内依次显示 NEW／MEMBER、徽章、短促闪烁的发送者、上升头像与白色手写购买身份，橙色转场层自身持续 550ms。SC 的完整时间轴为 1900ms，大号空心标题与较小实心标题交替闪现后，由独立白边与强调色 SVG 路径组成撕裂层，自上而下露出稳定留言卡；开场剪影和撕裂轮廓来自[官方演示](https://www.bilibili.com/video/BV1UBpieAEhw/)的 30fps 帧采样，以对应的连续三次曲线插值，保留边缘的不规则起伏。

这些内部动画只作用于 `append()` 新增的 live entry。礼物、上舰和 SC 根节点分别重新声明完整的 `--danmaku-enter-animation`，让根标记持续到自身所有图层结束；公共 feed 仍在根动画结束时清除 `data-live-entry`，不增加样式分支。稳定内容是无动画的默认 CSS 状态，`render()` 快照和减少动态效果直接显示完整内容。图形与关键帧由 `danmaku-ripploid.js` 和 `danmaku/ripploid.css` 维护，消息字段与配色见 [overlays.md](overlays.md#ripploid-固定弹幕)。

四类卡片直接使用 feed 的可用宽度，SC 不再叠加旧式卡片的独立 zoom，聊天右侧细线与端点随边界适配。聊天与 SC 正文不叠深色文字描边，避免衬线字的细笔画被描边切断。礼物数量采用较大的衬线数字，RMB 与金额等大；右侧票券保留渐浅票面、窄体双行标题、签名框和带边框的疏密条码。入场透明度和装饰变换通过不继承的 CSS 注册属性插值，再应用到原节点，避免加速透明度／变换动画在开始与结束时切换文字和细线的栅格层。根动画只标记时间，不绘制整卡透明度；礼物票券的稳定裁切与入场末帧相同。列表继续使用公共 `top` 移动，不引入文字缩放、位图快照或常驻 `will-change`。回归在非整数画布缩放下比较四类卡片的入场末帧与稳定帧像素，检查清晰度交接。

## 幽灵便笺分层动效

幽灵便笺的根标记 `spookyEntry` 持续 1250ms。昵称、正文、衬纸、贴纸独立显现；礼物、上舰和 SC 的头像先出现，面板再向右展开，最后显现头部。正文不旋转或缩放，不占用公共列表的 `top`；SC 使用独立通栏正文，长内容通过公共适配保持头部可见。`render()` 快照直接显示稳定内容，`append()` 才播放入场，结束后不保留循环贴纸动画。系统减少动态效果时全部静止。框、主题切换和身份处理见 [overlays.md](overlays.md#幽灵便笺固定弹幕)。

入场透明度、衬纸横移与贴纸／头像旋转通过不继承的 CSS 注册属性插值，再应用到原节点，避免缩放画布中的 iframe 在动画期间使用低清晰度合成纹理、结束后才恢复清晰。原有透明度、延迟、时长、缓动、旋转角度、展开裁切和列表移动保持不变，不拆分面板或改变文字显现节奏。事件面板在稳定状态保留展开末帧的裁切范围，避免结束时切换绘制层。回归在非整数缩放的 iframe 中检查聊天、礼物、上舰和 SC 的入场末帧与稳定帧像素一致，并保留配色、减少动态效果及动画中追加的覆盖。

仅旋转衬纸使用 `will-change: transform` 保持绘制层，避免入场结束时细小边缘的栅格化跳变；该装饰层不包含正文。上述像素回归使用浏览器 CPU 降速，并在截图前等待动画暂停操作完成，覆盖渲染任务延迟下的动画交接。

## 手账风分层动效

手账风以原片的轻便纸张和各身份配色为依据，根标记 `notebookEntry` 持续 740ms。聊天头像透明度在约 500ms 完成，旋转约 420ms 回到持续摆动轨迹，竖直入场约 600ms；纸张延迟 150ms 后在 450ms 内从右侧 10px、3° 轻倾和 0.975 倍回正。昵称在 320ms 后用 300ms 显现，正文在 420ms 后用 320ms 显现。纸张自身的微小倾斜/缩放留在内部图层，不占用 feed 的位置或根 transform；可读文字出现时纸张已接近稳定。

最新聊天纸张约 2333ms 一轮、上下差约 4 个逻辑像素。旧消息通过样式层暂停纸张和对应基础浮动，保留暂停时的位置；头像内层的摆动约 4233ms 一轮，舰长／提督／总督的轻缩放分别约 4933／4100／3300ms，普通头像没有缩放循环。各数值是视频拟合而非原作者源码参数。静态表情只随内容图层进入，自身不加动画。

内部入场只在 `[data-live-entry]` 存在时播放；快照直接显示完整内容，根标记结束后不残留入场填充。礼物和 SC 使用 200ms 淡入，开通纸张延迟 120ms 后在 280ms 内淡入，继续保留分开的头像和文字层。`prefers-reduced-motion: reduce` 停止所有内部入场和循环，公共 feed 负责同步取消列表移动。样式不创建额外 JS 时间循环，也不修改共用消息控制器。

本机参数中关闭「持续动画」时，只停用纸张与头像浮动、头像摆动和身份缩放循环；内部入场与列表移动继续按原节奏播放。切换参数不重建消息，恢复默认重新开启循环。

## 仿推特 3.0 分层动效

仿推特 3.0 的时间轴按[参考视频](https://www.bilibili.com/video/BV1fr421c7t4/)的 30fps 帧采样校正。根标记 `twitterPostShell` 持续 1267ms，仅保持内部图层生命周期，不绘制整卡透明度；列表在 100ms 内完成让位，曲线拟合第 1/3、2/3 时间点约 38.75%、77.5% 的位移。灰色头像与昵称骨架先占位，约 400–633ms 交叉显现真实头像、正文与金额；礼物和 SC 同时使用带旋转加载标记的空白框过渡。四组操作从下方 34 个逻辑像素依次就位，起点分别为 333、400、467、533ms，单项持续 200ms。爱心约 833ms 开始圆形爆点，随后显示淡色圆环、实心红心与少量粒子；不生成点赞数或交互状态。

普通聊天、礼物、大航海和 SC 共用这一节奏，内部动画不占用列表 `top`，不改变正文尺寸。透明度与装饰变换使用不继承的 CSS 注册属性插值后应用到原节点，避免缩放或边缘遮罩下的动画图层交接改变文字栅格；稳定帧不残留动画。表情按比例预留尺寸、完整显示并可换行，帖子与操作行随实际内容增长，不复刻视频中对表情的裁切。

这些图层只作用于 `append()` 新增的 `[data-live-entry]`。共享 feed 继续测量不同高度的卡片、同步移动、处理动画中追加和淘汰；`render()` 快照直接呈现完整帖子。`prefers-reduced-motion: reduce` 时公共 feed 清除 live entry，样式同时停用内部动画并移除骨架、圆环和粒子。矢量结构及 SVG 操作图标由 `danmaku-twitter.js` 创建，样式与关键帧由 `danmaku/twitter.css` 维护；消息和房主资料边界见 [overlays.md](overlays.md#仿推特-30-固定弹幕)。

## 星语装饰动效

「装饰图案」在客户端弹幕姬、画布中选中星语后的参数区和独立预览共用，选定图案即使用对应轻动画。四角星保留缩放闪烁；爱心双拍轻跳；圆角方块轻弹、轻微挤压回正；五角星缓慢转动；小花轻旋呼吸；月牙轻浮摇曳；蝴蝶结左右轻摆。昵称两侧和金额旁的装饰按各自周期错开相位，动画只作用于装饰伪元素，不带动文字或列表排版；切换不清空或重播消息。系统减少动态效果时所有图案静止完整显示，关闭后恢复所选动画。客户端和服务端星语主题同步维护这一行为。

本机星语另可关闭「持续动画」，保留所选图案的静态造型，普通弹幕、礼物与 SC 同步生效；入场淡入与列表移动保持原样。重新开启时恢复所选图案动画，系统减少动态效果仍优先。

## 圣诞绮笺分层动效

圣诞绮笺以红金节日信笺为视觉参考，文字不旋转、不缩放。依据 [Cozy Christmas 公开预览](https://www.etsy.com/listing/1623353307/cozy-christmas-chat-widget-customizable)中卡片先显现、蝴蝶结随后展开的先后关系，采用独立图层进一步编排；以下时间为本款设计值，并非原作者源码参数。聊天根标记 `christmasEntry` 持续 1040ms：酒红底板在 0–320ms 展开，独立 SVG 圆角框在 60–580ms 沿轮廓描出；昵称在 90–270ms、正文在 150–350ms 原位渐显。右上金线在 260–660ms 揭示，侧边星饰在 380–820ms 自上而下出现并轻摆回正，蝴蝶结在 620–1040ms 由结心展开收尾。

礼物、大航海及 SC 的根标记持续 1180ms：底板在 360ms 内展开，金框在 60–660ms 描出，昵称在 100–280ms、正文在 180–400ms 显现。灯线在 300–740ms 铺开，花环在 420–900ms 显现回正，五颗彩灯从 620ms 起每隔 50ms 开始各自的 240ms 点亮，蝴蝶结在 760–1180ms 完成收尾。金额随所在的昵称栏或正文一起显现，不叠加第二层透明度动画。底板单独裁切，不裁切整个内容树；透明度、描边进度、裁切及装饰角度／比例使用不继承的 CSS 注册属性插值，文字沿用原栅格层，不在动画结束时切换合成纹理。

共享 feed 继续负责布局、测量、追加打断、越界移除和销毁。列表移动基准 300ms，上限 540ms，曲线 `.25,.1,.25,1`；不在公共层增加样式分支或计时器。旧消息不重播，`render()` 快照直接完整显示。只有最新一条消息的侧边星饰在入场完成后按 5.6 秒周期轻摆，事件彩灯按 4.8 秒错相呼吸（透明度 .72–1，静止时 .85）；彩灯的入场与呼吸使用两个独立属性，交接时不重启呼吸相位。到达下一条后前条循环停止；其尚未完成的有限入场继续收尾。「持续动画」关闭不重建消息，保留入场与列表移动；系统减少动态效果时入场、装饰与公共移动全部停止，完整显示边框和全部饰品。卡面底板透明度独立于文字与饰品。

## 圣诞来信分层动效

普通聊天的根入场生命周期为 720ms，金线与纸面约在 0–268ms 完成，昵称约 98–293ms、正文约 159–342ms 渐显，角色与星光在 707ms 前收束。正文和表情不缩放、不旋转、不模糊；纸面用独立裁切层展开，透明度使用不继承的注册属性。普通礼物、大航海与 SC 的根入场为 1460ms；SC 保留金色标题、大号金额与角色，开通／续费卡省去泛称标题和圣诞老人贴纸，改用对应舰长／提督／总督的静态角色船只背景，在 180–1000ms 淡入。上舰金额与动作正文并行渐显，背景不会改变文字栅格或卡片最终尺寸。

公共 feed 继续统一负责列表布局、连续打断、越界淘汰、撤回与销毁，不增加本款名称分支、定时器或消息队列。列表移动基准 290ms、上限 560ms、曲线 `.25,.12,.2,1`。根动画结束后清除实时标记，内部动效全部交还静态默认；减少动态效果直接显示完整内容并停止列表和装饰动画。

## Stargazer 星旅动效

[原作公开视频](https://bigbrauz.com/products/stargazer-stream-chat-widget) 展示平滑消息流、局部流星和提醒粒子，横排沿同一基线推进；透视作用于整列消息，文字不单独缩放。1440×1080／30fps 公开演示中，右列四次消息让位约 267–300ms，距离变化时仍接近 300ms。本地实现采用 300ms 同步移动，曲线 `[.22,.1,.25,1]`；新消息另外在 480ms 内渐显。卡面、昵称与正文保持同一图层，不加入额外摇摆或文字滤镜。时长与曲线是公开画面的拟合值，不是原作者源码参数。

流星每条 7 秒一轮，仅在其中约一秒可见；礼物／大航海／SC 的 8 个小粒子按不同相位在 4.4 秒内轻浮和闪烁。事件身份决定相位，重绘保持稳定。`ambientMotion: off` 停止流星和粒子，保留新消息入场及正常列表移动；系统减少动态效果同时省略入场和移动。循环全由节点 CSS 拥有，移除或销毁节点即释放，不新增计时器。

整卡淡入、流星和粒子的透明度／位移通过不继承的注册属性插值后绘制，避免动画把整卡及与装饰重叠的文字提升为独立合成纹理，在缩放 iframe 中先重采样、结束时再切换字形栅格。流星与粒子的轨迹、周期和相位保持不变，关闭持续动画后装饰仍回到透明终态。

横排复用公共 feed 的测量、同步移动、中断续接、越界淘汰与销毁，只将轴切换到 `left`；纵排继续使用 `top`，正文栅格不由 transform 驱动。保留秒数大于 0 时使用共享到期计时，最后最多 400ms 渐隐；新消息的移动不能取消该渐隐。快照直接显示完整卡片，SC 撤回及时移除。

## 实现契约

- 样式文件 `public/css/overlays/danmaku/<style>.css` 同时维护本款关键帧与 `--danmaku-enter-animation`、`--danmaku-move-base-ms`、`--danmaku-move-max-ms`、`--danmaku-move-curve`。雪狐保留已有内部装饰编排，只声明移动参数。这些是内部 CSS 接口，不是新用户设置或持久化字段。
- `danmaku-feed.js` 读取根节点继承的移动参数；未定义时使用原来的 420 / 760ms 和 `[0.3, 0.1, 0.2, 1]`。连续消息在当前位置和速度上续接，同批消息保持间距。
- 可选 `--danmaku-enter-offset` 以逻辑 CSS 像素指定首条入场偏移；后续入场仍续接前条的可见偏移。未设置时保留按消息尺寸计算的默认值，内部入场层自行拥有位移的样式可设为 0。
- 移动完成只用最近一次已测高度、间距和内边距淘汰完全越界的旧节点，不重新适配所有卡片。连续追加时，利用同一布局批次已读取的位置，清理当前与目标都越过退出边界的旧行，并预留效果外扩和行距；不等待反复被打断的移动结束，也不新增逐帧测量。仍在画面内或将进入画面的消息保留，部分可见行不中途消失。若已有内容或尺寸变化等待布局，先完成该次测量再清理；追加、区域/节点 resize 和效果更新仍走完整适配。
- 两个移动时长属性使用不带单位的毫秒数，曲线是四个逗号分隔的数值；入场属性使用完整 CSS animation 简写。样式只调本款声明，不能修改公共默认来间接调整其他样式。
- `motion.css` 负责公共接入与降级、边缘遮罩和仍被旧入口/随机样式消费的兼容动画。固定样式专属入场留在自己的文件。
- 新整条入场只用于 `append()`：节点标记 `data-live-entry`，结束时移除标记；`render()` 快照不播放这套新入场。节点重排、图片加载、区域缩放和后续消息到达不重播旧节点入场。雪狐、月渡花汀的既有内部装饰保持原规则。
- 列表沿用相对 `top` 移动，显式横排使用相对 `left`，以保持现有文字栅格效果。新增整条入场只使用透明度或横向独立 `translate`；不占用列表的 `top`，不修改纵向坐标、宽高、字体大小、字重和正文滤镜，也不覆盖组件的 `transform`。已有装饰动画不被公共层重新编排。
- 整卡及内部文字的透明度、位移使用不继承的 `--danmaku-enter-opacity`、`--danmaku-enter-x/y` 和 `--danmaku-enter-transform` 注册属性，由原节点在当前画布缩放下绘制，不直接对可读文字层加速 `opacity`／`transform`／`translate` 动画，也不添加 `will-change: transform`。样式继续拥有起止值、时长与缓动；特效边界的水平补偿与入场横移相加，用户旋转／倾斜仍由组件 transform 拥有。变换列表的终值使用对应的单位变换，避免自定义属性在变换列表与 `none` 之间离散切换。只标记内部入场生命周期的根动画使用无绘制作用的 `--danmaku-entry-clock`，不以恒定 `opacity: 1` 创建额外合成层。
- 装饰层与文字重叠时也可能促使文字提升为独立合成纹理。共用礼物扫光、渐变细线、星语饰品、月渡卷轴等使用绘制插值保留原轨迹与节奏；不能只检查动画目标是否直接含文字。纸笺的纸面轻浮与头像动作沿用原编排，注册属性互不继承，不把头像的旋转或缩放传给正文。
- 到期渐隐由 feed 插值 `--danmaku-exit-opacity` 并映射到根节点透明度；取消时恢复样式自身透明度。原到期点、减少动态效果、移动中继续淡出及销毁语义不变。
- 关键帧完成后交还普通 CSS 状态，不残留无期限的填充动画。`prefers-reduced-motion: reduce` 时直接显示完整内容，停止整条入场与列表移动，既有装饰遵循自身降级。

## 维护与体感验收

1. 先说明本款视觉气质、希望观众注意什么及动效的理由。默认动作已合适时可复用公共执行机制；仅参数不同时不要新建 JS 控制器。
2. 实际播放第一条、常速连续消息、动画未结束时追加、短时间多条、长正文、表情、礼物和 SC。查看入场中间帧与稳定帧；截图或代码检查不能单独证明顺滑。
3. 检查向上/向下、实际画布缩放及文字清晰度。旧消息不瞬移，不被新消息穿过，字形不忽胖忽瘦，顶部/底部边界不闪断；密集时不积压一长串表演。
4. 在浅色、深色背景检查半透明入场阶段，正文不能长时间不可读。保留既有造型、配色、层次和留白，不借动效任务重新设计外观。
5. 行为测试维护公共不变量，逐款真实播放负责审美；记录看到的效果、修正和环境限制。不能以「测试全绿」代替人眼验收，也不能把隔离浏览器结果写成真实直播验收。
6. 新样式将动效随自身 CSS 交付，扩展已有 `test/danmaku/danmaku-feed-motion.test.js` 行为覆盖；改公共机制时回归月渡花汀等既有消费者。

浅色背景检查用于发现动效是否加重原有对比问题，不意味着浅色线稿适用于所有背景。星语、绿萌等既有白色/浅色素材在浅底仍有对比限制，应结合实际直播底图与已有正文色设置选择；本轮不重做它们的配色与素材。

## 可直接复用的制作提示词

> 为 LIRA 的「样式名称」设计并实现固定弹幕动效。先阅读本页与该样式现有 CSS、素材和真实预览，保留它的配色、排版与视觉气质。用一句话说明入场想传递的感受，再确定入场方式、时长、列表移动节奏和边缘退出方式。样式文件拥有视觉参数和专属关键帧；排序、测量、动画打断续接、同批间距、淘汰与销毁继续复用公共 feed。普通消息以清晰易读为先，礼物和 SC 使用同一视觉语言；不让文字缩放、旋转、模糊，不给每条消息增加冗长表演，不在公共模块按样式名称堆分支。只有现有机制无法表达明确需求时才扩展公共接口，并说明边界。完成后实际播放常速和密集消息，检查短长文本、表情、礼物、SC、上下滚动、画布缩放和减少动态效果；保留中间帧及实时证据，依据看到的结果集中修正。报告具体改善、已执行验证与限制。月渡花汀已有动效保持原样。
