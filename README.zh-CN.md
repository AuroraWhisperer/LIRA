# LIRA

[English](README.md) | 简体中文

**LIRA**（**L**ive **I**nteractive **R**oom **A**ssistant，直播间互动助手）是一款轻量、本地优先的 Bilibili 直播伴侣，提供弹幕点歌、队列与歌库管理、直播画面等功能。直播互动、播放器、歌库和队列主要在主播电脑上运行；首次使用需连接 LIRA 授权服务器完成账号与设备授权。授权后还可按需将本地歌库同步为云端公开歌单，并自定义歌单页背景。观众发送弹幕点歌后，歌曲会自动进入队列，再通过 OBS 或哔哩哔哩直播姬（下文简称直播姬）的浏览器源 / 网页来源展示在直播画面中。B 站是直播平台，OBS 与直播姬均为受支持的直播软件。此外，LIRA 还集成了弹幕互动机器人、AI 弹幕姬、礼物驱动的加班机和全民 K 歌歌词捕捉等工具。

## 安装使用

从 [Releases](https://github.com/AuroraWhisperer/LIRA/releases) 下载最新安装包，双击安装即可。

### 首次使用与服务器协作

LIRA 仍以主播电脑上的本地运行时为核心，但桌面客户端需要在线完成授权。普通安装包会自动连接 LIRA 授权服务（发布版默认地址为 `https://api.lirahub.cn`），不需要手动填写服务器地址；定制部署以管理员提供的服务地址为准。

1. **首次使用先注册账号。** 在授权窗口选择「注册新账号」，输入用户名、密码和管理员提供的「注册激活码」，点击「注册并进入」。已有账号请选择「登录已有账号」。服务器会为这台电脑建立独立设备身份；密码和激活码不会保存到本机。
2. **以后启动自动检查。** 已绑定的电脑不需要再次输入用户名、密码或注册激活码，但每次启动仍会在线验证设备。授权服务暂时不可达时，在授权页点击「重试连接」；设备或授权被撤销、账号停用时，需要联系管理员重新授权。
3. **在其他电脑使用同一账号。** 请联系管理员获取一次性的「短效登录码」，在新电脑选择「登录已有账号」，输入原用户名、密码和短效登录码，点击「登录并进入」。授权后由云同步恢复受支持的共享歌库与设置；本地文件、设备身份和音乐平台登录状态不会自动迁移。不要复制旧电脑的 `data`、`userData`、设备私钥或登录令牌。
4. **云端歌单自动同步。** 授权后，本地歌库变更会标记待同步并自动上传完整快照；本地没有待上传变更时，会拉取云端较新的版本。仍可在「点歌 → 导入导出」手动同步当前歌单。当前服务最多接收 5000 首歌曲。同步采用完整快照，不会合并多台电脑的并发修改。该页面也管理 PNG/JPG/JPEG/WebP/GIF 背景（≤ 5 MB），上传替换原图，删除恢复默认背景。

当前客户端中，LIRA 服务器负责账号与设备授权、可选云端数据和权威 Bilibili 礼物检测。桌面端通过已认证的 HTTPS 设备通道接收规范化礼物事件，再供本地历史、统计、加班机和直播画面使用。Bilibili 登录、本地弹幕互动、歌曲队列、播放器及本地歌库仍由本机运行时负责；服务器弹幕姬则独立接收和展示 B 站弹幕。

以下三类地址用途不同，不要混用：

- **公开歌单：** 地址通常形如 `https://<账号>.lirahub.cn/`，以「查看网页歌单」提供的远程 HTTPS 链接为准。
- **本机直播画面：** 点歌队列、歌词、加班机等使用 `127.0.0.1` 地址，要求直播软件与 LIRA 在同一台电脑上运行。
- **服务器弹幕姬：** 使用从客户端或主播中心复制的完整 HTTPS `/overlay/<token>` 地址，依赖服务器的 B 站连接，关闭桌面客户端后仍可展示。

本机直播画面和服务器弹幕姬均可添加到 OBS 的浏览器源或直播姬的网页来源。

### 远程服务器地址

桌面客户端默认连接 `https://api.lirahub.cn`。维护者通过 `LIRA_LICENSE_API_BASE` 覆盖时，只能填写使用 DNS 主机名的 HTTPS 根地址（origin，例如 `https://api.example.com`），不得包含凭据、子路径、查询参数或片段；HTTP、`localhost` 和 IPv4/IPv6 字面地址都会被拒绝。设备 API 与加班机所用的服务器礼物目录都以此为入口。礼物目录缓存于本机 `data/cache/overtime-gift-catalog-v2.json`，短时断网时继续使用上次快照。

配置远程服务器地址不会改变本机画面的 `127.0.0.1` 地址；服务器弹幕姬则使用服务器返回的完整链接。添加浏览器源时，以对应功能的复制地址为准。

## 主要功能

**弹幕点歌**

- `点歌 晴天` — 观众发送弹幕点歌，支持模糊匹配歌库
- `随机点歌` — 从歌库随机一首，支持按歌手、分类、语言筛选
- `取消点歌` / `取消点歌 晴天` — 取消自己最近一条待处理点歌，或最近一条指定完整歌名的点歌；不影响其他观众的歌曲
- 手动入队、切歌、置顶、清空队列
- 点歌成功后显示悬浮通知

**弹幕监听**

- Bilibili 公开弹幕 WebSocket 实时监听，含历史补偿
- 醒目留言（SC）独立队列，按金额排序
- 礼物冲刺追踪：目标金额、已收统计、水晶球换算

**弹幕互动**

- 弹幕姬：用已登录账号向直播间发送弹幕，自动 @ 最近点歌人
- 签到 / 抽签机器人：`签到` 自动回复累计天数，`抽签` 每日一签
- 关键词回复：弹幕包含关键词时触发固定文案
- 完整匹配回复：整条弹幕与触发词一致时回复，内置 `菜单` 展示可用弹幕互动
- 定时／随机弹幕：直播中按固定或随机间隔，顺序或随机发送云端词库

**AI 弹幕姬**

- 观众弹幕包含已保存的自定义触发关键词时生成回复；关键词默认留空，不会自动触发
- 支持 DeepSeek、Kimi / Moonshot、OpenAI、Claude、Gemini、豆包账号登录（实验性）及自定义 OpenAI 兼容服务，可切换、保存和导入角色包
- 普通问答无需工具账号；联网、天气、地点和路线查询默认关闭，按模型能力和凭据配置启用。配置方法见 [AI 使用指南](docs/guides/third-party-api-support.md)

**点歌队列**

- 六种展示风格：经典队列、透明榜单、童话绘本、霓虹黑胶、樱花缎带、金色百合
- 循环或往返滚动，速率可调
- 11 套预设主题 + 颜色、透明度、字号、圆角、字体、字重自定义
- 毛玻璃效果、渐变背景、发光强度、低占用模式

**音乐播放器**

- 内置播放器，支持网易云音乐、QQ 音乐搜索播放
- 播放队列弹窗：当前播放高亮、已播灰显，可点击任意行跳转
- 播放历史记录，歌单循环播放
- 右侧抽屉面板：每日推荐、我喜欢、歌单浏览，支持播放全部 / 随机播放
- 直播歌词、音量控制、播放器停靠展开

**全民 K 歌歌词捕捉**

- 播放页的第三个播放来源：从本机全民 K 歌客户端读取当前歌曲、播放进度与逐字歌词，自动跟随播放并同步直播歌词
- 本地 QRC 缓存，缺失时自动回退到 QQ 音乐 / 网易云在线歌词
- 手动微调歌词时间偏移（±3000 ms）

**歌单展示板**

- 滚动展示全部可点歌曲，6 套独立预设主题
- 支持按首字母、分类、歌手、语言、歌名长度排序

**歌库管理**

- 歌曲新增、编辑、启用/停用、删除
- 搜索、分类筛选、语言筛选、歌手筛选

**设备授权与云端歌单**

- 首次启动的 LIRA 账号与设备授权，后续启动在线校验
- 由管理员为其他电脑签发一次性短效登录码，使用原账号登录
- 歌库变更自动同步到云端；本地无待上传变更时恢复云端新版本，也支持手动同步
- 自定义公开歌单页背景，支持 PNG/JPG/JPEG/WebP/GIF（≤ 5 MB）

**加班机**

- 礼物驱动的直播倒计时：观众送礼延长倒计时，直播画面实时展示（OBS / 直播姬通用）
- 礼物规则编辑器：直接改时间 / 随机抽结果 / 文字展板
- 礼物选择器优先读取服务器全局目录并在本机缓存；没有远程目录时保留原本地房间目录和本地礼物搜索

**主播计划**

- 本地主播工作台：按日期安排日历事件、开播前 / 直播中 / 下播后任务，并记录随手记、观众约定与复盘；使用 v3 工作台模型，兼容迁移旧计划数据

**桌面版特性**

- 无边框窗口，SVG 图标，最小化 / 最大化 / 关闭按钮自定义样式
- GitHub Releases 自动检查更新，一键重启升级
- 数据目录、日志目录一键打开
