# LIRA

[English](README.md) | 简体中文

**LIRA**（**L**ive **I**nteraction & **R**equest **A**ssistant，直播互动与点歌助手）是一款轻量、本地优先的 Bilibili 直播伴侣，主打弹幕点歌、队列与歌库管理、直播悬浮层等功能。直播互动、播放器、歌库和队列主要在主播电脑本地运行；首次使用需连接 LIRA 授权服务器完成账号与设备授权，授权后还可以按需把本地歌库同步为云端公开歌单并管理歌单页背景。观众弹幕点歌后自动进入队列，经 OBS / 直播姬网页源展示到直播画面。除点歌外，还集成弹幕互动机器人、AI 弹幕姬、礼物驱动的加班机与全民 K 歌歌词捕捉等工具。

## 安装使用

从 [Releases](https://github.com/AuroraWhisperer/LIRA/releases) 下载最新安装包，双击安装即可。

### 首次使用与服务器协作

LIRA 仍以主播电脑上的本地运行时为核心，但桌面客户端需要在线完成授权。普通安装包会自动连接生产授权服务（发布版默认地址为 `https://api.lirahub.cn`），不需要手动填写服务器地址；定制部署以管理员提供的服务地址为准。

1. **首次启动先激活设备。** 在「登录 LIRA」页面输入要绑定的用户名、密码和管理员提供的一次性激活密钥，点击「激活并进入 LIRA」。服务器会为这台电脑建立独立设备身份；密码和激活密钥不会保存到本机。
2. **以后启动自动检查。** 已绑定的电脑不需要再次输入用户名、密码或首次激活密钥，但每次启动仍会在线验证设备。授权服务暂时不可达时，在授权页点击「重试连接」；设备或授权被撤销、账号停用时，需要联系管理员重新授权。
3. **第二台电脑使用同一账号。** 请联系服务器管理员为新设备生成一次性授权码（配对码），在新电脑输入同一用户名、密码和授权码完成独立绑定。授权后由云同步恢复受支持的共享歌库与设置；本地文件、设备身份和音乐平台登录状态不随配对复制。不要复制旧电脑的 `data`、`userData`、设备私钥或登录令牌。
4. **云端歌单自动同步。** 授权后，本地歌库变更会标记待同步并自动上传完整快照；本地没有待上传变更时，会拉取云端较新的版本。仍可在「点歌 → 导入导出」手动同步当前歌单。当前服务最多接收 5000 首歌曲，完整快照不自动合并并发编辑。该页面也管理 PNG/JPG/JPEG/WebP/GIF 背景（≤ 5 MB），上传替换原图，删除恢复默认背景。

在当前客户端中，LIRA 服务器负责账号、设备授权、可选云端数据和权威 Bilibili 礼物检测；桌面端通过已认证的 HTTPS 设备通道接收规范化礼物事件，再投影到原有的本地历史、统计、加班姬和悬浮层链路。Bilibili 登录、弹幕、歌曲队列、播放器及本地歌库仍由本机运行时负责。公开歌单网页地址通常形如 `https://账号.lirahub.cn/`，以「打开网页歌单」提供的链接为准（远程 HTTPS），和 OBS / 直播姬使用的 `127.0.0.1` 本地浏览器源不是同一个地址；使用本地源时 OBS / 直播姬与 LIRA 必须在同一台电脑运行。

### 正式远程服务地址

桌面客户端默认连接 `https://api.lirahub.cn`。维护者通过 `LIRA_LICENSE_API_BASE` 覆盖时只能填写使用 DNS 主机名的 HTTPS 根域名（例如 `https://api.example.com`），不得包含账号密码、子路径、查询参数或片段；HTTP、`localhost` 和 IPv4/IPv6 地址都会被拒绝。该地址同时用于设备 API 和加班姬服务器礼物目录，目录会在本机 `data/overtime-gift-catalog-v2.json` 缓存，短时断网时继续使用上次快照。

OBS / 直播姬浏览器源仍使用 LIRA 本机运行时提供的 `127.0.0.1` 地址。这是同机访问的本地页面，与上述远程服务地址无关。

## 主要功能

**弹幕点歌**

- `点歌 晴天` — 观众发送弹幕点歌，支持模糊匹配歌库
- `随机点歌` — 从歌库随机一首，支持按歌手、分类、语言筛选
- 手动入队、切歌、置顶、清空队列
- 点歌成功时悬浮通知确认

**弹幕监听**

- Bilibili 公开弹幕 WebSocket 实时监听，含历史补偿
- 醒目留言（SC）独立队列，按金额排序
- 礼物冲刺追踪：目标金额、已收统计、水晶球换算

**弹幕互动**

- 弹幕姬：用已登录账号向直播间发送弹幕，自动 @ 最近点歌人
- 签到 / 抽签机器人：`签到` 自动回复累计天数，`抽签` 每日一签
- DIY 关键词回复：自定义关键词触发固定文案

**AI 弹幕姬**

- 弹幕提及「小米」时自动调用 DeepSeek 生成回复，人格与系统提示词可自定义
- 支持联网搜索、天气、路线查询，回复未送达自动重发

**点歌队列**

- 六种展示风格：经典队列、透明榜单、童话绘本、霓虹黑胶、樱花缎带、金色百合
- 循环或往返滚动，速率可调
- 11 套预设主题 + 颜色、透明度、字号、圆角、字体、字重自定义
- 毛玻璃效果、渐变背景、发光强度、低占用模式

**音乐播放器**

- 内置播放器，支持网易云音乐、QQ 音乐搜索播放
- 播放队列弹窗：当前播放高亮、已播灰显，可点击任意行跳转
- 播放历史记录，歌单循环播放
- 右侧抽屉面板：每日推荐、我喜欢、歌单浏览，支持播放全部 / 随机播放
- 桌面歌词、音量控制、播放器停靠展开

**全民 K 歌歌词捕捉**

- 播放页第三播放来源：从本机全民 K 歌客户端读取当前歌曲、进度与逐字歌词，自动跟随播放并同步桌面歌词
- 本地 QRC 缓存，缺失时自动回退 QQ 音乐 / 网易云在线歌词
- 歌词时间偏移手动微调（±3000ms）

**歌单展示板**

- 滚动展示全部可点歌曲，6 套独立预设主题
- 支持按首字母、分类、歌手、语言、歌名长度排序

**歌库管理**

- 歌曲新增、编辑、启用/停用、删除
- 搜索、分类筛选、语言筛选、歌手筛选

**设备授权与云端歌单**

- 首次启动的 LIRA 账号与设备授权，后续启动在线校验
- 由服务器管理员为其他电脑签发一次性新设备授权码（配对码）
- 歌库变更自动同步到云端；本地无待上传变更时恢复云端新版本，也支持手动同步
- 自定义公开歌单页背景，支持 PNG/JPG/JPEG/WebP/GIF（≤ 5 MB）

**加班机**

- 礼物驱动的直播倒计时：观众送礼延长倒计时，OBS 悬浮层实时展示
- 礼物规则编辑器：直接改时间 / 随机抽结果 / 时间盲盒
- 礼物选择器优先读取服务器全局目录并在本机缓存；没有远程目录时保留原本地房间目录和本地礼物搜索

**主播计划**

- 本地主播工作台：按日期安排日历事件、开播前 / 直播中 / 下播后任务，并记录随手记、观众约定与复盘；使用 v3 工作台模型，兼容迁移旧计划数据

**桌面版特性**

- 无边框窗口，SVG 图标，最小化 / 最大化 / 关闭按钮自定义样式
- GitHub Releases 自动检查更新，一键重启升级
- 数据目录、日志目录一键打开
